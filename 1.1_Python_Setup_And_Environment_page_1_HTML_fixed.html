Troubleshooting Tip
💡 If you see "Python is not recognized" on Windows, what's the most likely cause and solution?
PATH not configured
Python wasn't added to system PATH during installation.
Exactly right! Just reinstall Python and make sure to check that "Add Python to PATH" box. It's like making sure your lab equipment is plugged in properly - essential for operation!
Python is broken
The Python installation is corrupted.
Unlikely. Python installations rarely corrupt. The issue is almost always that Windows doesn't know where to find Python - that's what PATH configuration fixes!
Wrong terminal
You need to use a special Python terminal.
Not quite. Python should work in any command prompt or terminal once properly installed. The issue is system configuration, not the terminal choice.
