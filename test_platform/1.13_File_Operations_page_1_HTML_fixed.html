🔬 Chapter 2: Opening and Closing Files - Your Digital Lab Keys

Think of Files Like Hospital Doors - You Need to Open AND Close Them!

📚 Core Concept: The `open()` Function

The `open()` function is like a hospital keycard - it grants you access to important data:

# Opening files is like entering different hospital departments patient_file = open('patient_records.txt', 'r') # Viewing records (Read-only ward) report_file = open('medical_report.txt', 'w') # Creating reports (Write ward) history_file = open('patient_history.txt', 'a') # Adding to history (Append ward)
Copied!

🎮 File Mode Cheat Sheet:

  • 'r' (Read) = 👀 Look but don't touch (like viewing X-rays)
  • 'w' (Write) = ✍️ Create new (like writing prescriptions)
  • 'a' (Append) = ➕ Add to existing (like updating patient charts)

⚠️ Critical Rule: Always Close Your Files!

patient_file = open('records.txt', 'r') # Do important medical stuff... patient_file.close() # CRUCIAL! Like washing hands after patient contact
Copied!

🔬 Chapter 3: The Context Manager - Your Safety Protocol

Because "With Great Power Comes Great Responsibility" - Spider-Man (and HIPAA)

🛡️ Enter the Hero: The `with` Statement

Remember how we said to always close files? Well, Python has a superhero feature that does it automatically! Meet the `with` statement - it's like having a personal assistant who always cleans up after you.

# The OLD way (risky for patient data!) file = open('sensitive_data.txt', 'r') data = file.read() file.close() # Easy to forget! 😱 # The SUPERHERO way (with statement to the rescue!) with open('sensitive_data.txt', 'r') as file: data = file.read() # File automatically closed here! Magic! ✨
Copied!

🔬 Chapter 4: Reading Medical Data Files

Become a Data Detective - Uncover Health Insights!

Python offers three awesome ways to read files, each perfect for different medical scenarios:

📖 Method 1: Read Everything at Once

Perfect for small files like patient summaries:

# Reading a patient summary (small file) with open('patient_summary.txt', 'r') as file: content = file.read() print("📋 Patient Summary:") print(content)
Copied!

📜 Method 2: Read Line by Line

Ideal for huge files like genomic data:

# Processing genomic data without breaking your computer! with open('dna_sequence.txt', 'r') as file: for line_number, line in enumerate(file, 1): if 'MUTATION' in line: print(f"⚠️ Mutation found on line {line_number}!")
Copied!

📚 Method 3: Read All Lines into a List

Great for files with multiple entries:

# Analyzing multiple lab results with open('lab_results.txt', 'r') as file: all_results = file.readlines() abnormal_count = sum(1 for result in all_results if 'ABNORMAL' in result) print(f"🔬 Found {abnormal_count} abnormal results out of {len(all_results)} total")
Copied!

🧪 Lab Exercise 2: Build a Vital Signs Monitor

Mission: Create a system to read and display patient vital signs

Vital Signs Monitor Challenge
To read and display vital signs from a file, which combination would work best?
with open('vital_signs.txt', 'r') as file: vitals = file.read()
Use 'r' mode and read() method
Perfect! The 'r' mode opens the file for reading, and read() gets all the content at once - ideal for displaying vital signs.
with open('vital_signs.txt', 'w') as file: vitals = file.write()
Use 'w' mode and write() method
Not quite. The 'w' mode is for writing to files, not reading. Also, write() needs content to write, it doesn't return anything.
with open('vital_signs.txt', 'a') as file: vitals = file.append()
Use 'a' mode and append() method
Incorrect. The 'a' mode is for appending to files, and there's no append() method for file objects.
with open('vital_signs.txt') as file: vitals = file.get()
Use default mode and get() method
Close! The default mode is 'r' which is correct, but there's no get() method for file objects. Use read() instead.
