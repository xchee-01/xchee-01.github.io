🎯 Mission Briefing: F-Strings - Format Like a Pro!

F-strings are Python's way of making beautiful, formatted output. They're like having a professional medical report writer built into your code!

✨ The F-String Magic Formula

# Basic f-string - put an 'f' before the quotes! patient_id = "P2024-001" status = "Stable" print(f"Patient {patient_id} is {status}") # Output: Patient P2024-001 is Stable # Format numbers beautifully glucose = 95.7891234 print(f"Glucose: {glucose:.1f} mg/dL") # Just one decimal! # Output: Glucose: 95.8 mg/dL # Create professional reports medication = "Metformin" dosage = 500 schedule = "twice daily" print(f"📋 Rx: {medication} {dosage}mg - Take {schedule}")
Copied!

🏥 F-String Formatting Hospital

Learning Checkpoint: F-String Formatting
What does {test_name:.<20} do in an f-string?
Left-aligns and pads with dots to 20 characters
Creates output like: "Cholesterol........."
Correct! The :.<20 format specifier left-aligns the text and fills remaining space with dots up to 20 characters. Perfect for creating aligned medical reports!
Truncates to 20 characters
Cuts off text longer than 20 characters
Not quite. This format adds padding with dots, it doesn't truncate. It ensures the field is exactly 20 characters wide.
Repeats the text 20 times
Creates multiple copies of the text
That's not right. The format specifier controls alignment and padding, not repetition. Use * for repetition.
# Temperature with style temp = 98.6 print(f"Temperature: {temp}°F {'✅ Normal' if temp < 99 else '🔥 Fever!'}") # Padding for aligned reports test_name = "Cholesterol" value = 185 print(f"{test_name:.<20} {value:>6} mg/dL") # Output: Cholesterol.......... 185 mg/dL
Copied!

🎯 Ultimate Solution

ICU Vital Signs Monitoring System 2.0

# ICU Vital Signs Monitoring System 2.0 patient_name = "John Smith" patient_id = "ICU-2024-789" heart_rate = 88 blood_pressure_sys = 132 blood_pressure_dia = 84 oxygen_saturation = 96 temperature = 98.9 # Professional display with visual indicators print("╔═══════════════════════════════╗") print("║ ICU VITAL SIGNS MONITOR ║") print("╚═══════════════════════════════╝") print(f"Patient: {patient_name} ({patient_id})") print("─" * 33) # Heart rate with visual indicator hr_status = "✅" if 60 <= heart_rate <= 100 else "⚠️" print(f"❤️ Heart Rate: {heart_rate} bpm {hr_status}") # Blood pressure with interpretation bp_status = "✅" if blood_pressure_sys < 140 and blood_pressure_dia < 90 else "⚠️" print(f"🩺 Blood Pressure: {blood_pressure_sys}/{blood_pressure_dia} mmHg {bp_status}") # Oxygen saturation o2_status = "✅" if oxygen_saturation >= 95 else "⚠️ Low!" print(f"🫁 O2 Saturation: {oxygen_saturation}% {o2_status}") # Temperature temp_status = "✅" if temperature < 99.5 else "🔥 Fever!" print(f"🌡️ Temperature: {temperature}°F {temp_status}") print("─" * 33) print("Status: All vitals within normal range") print(f"Last updated: [timestamp]")
