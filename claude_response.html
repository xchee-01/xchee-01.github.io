🔬 Mission Briefing: Writing Your First Python Code

🧠 Why This Matters

Imagine being able to analyze thousands of patient records in seconds rather than weeks. That's the superpower Python gives you! Let's start with the basics.

Python statements are like medical orders – clear instructions that get things done. Just as you might write "Administer 500mg of medication" in a patient chart, in Python you write commands that the computer follows precisely.

# This is a comment - Python ignores this text # Comments are like your notes in a patient chart - they explain what's happening # A simple statement that displays text print("Welcome to Precision Health Programming!")

💡 Pro Tip: Comments (lines that start with #) help document your code. Good commenting is like good medical documentation – it helps others understand your thinking!

# Calculate Body Mass Index (BMI) weight_kg = 70 # Patient weight in kilograms height_m = 1.75 # Patient height in meters bmi = weight_kg / (height_m ** 2) # BMI formula: weight/(height²) print(bmi) # Displays 22.86

From Simple to Powerful

In real clinical situations, we often need to combine several steps of analysis. Python makes this easy:

# Analyze blood glucose levels fasting_glucose = 95 # mg/dL post_meal_glucose = 142 # mg/dL # First, we calculate the average average_glucose = (fasting_glucose + post_meal_glucose) / 2 print("Average glucose level:", average_glucose, "mg/dL") # Displays: Average glucose level: 118.5 mg/dL # Then, we make a clinical decision based on guidelines if average_glucose > 125: print("Schedule follow-up appointment") else: print("Glucose levels within normal range")
Copied!

This simple code demonstrates how Python can help evaluate patient metrics against clinical guidelines – something you'll do constantly in healthcare analytics.

💡 Fun Fact: Did you know that major hospitals use similar code (though much more complex) to automatically flag patients who might need immediate attention? Python helps identify at-risk patients before humans might notice the patterns!

🔬 Mission Briefing: Using Integers, Floats, and Strings

In healthcare, we work with three main types of data, which Python handles beautifully:

  1. Integers (int) - Whole numbers like patient counts or chromosome positions
  2. Floating-point numbers (float) - Precise measurements like lab values or drug dosages
  3. Strings (str) - Text data like patient names or DNA sequences

Think of these as the three vital signs of programming – they're fundamental to almost everything you'll do!

Integers: The Counters

# Integers in clinical context patient_id = 12945 # A patient identifier (like a medical record number) chromosome_position = 45329088 # Genomic position on chromosome mutation_count = 7 # Number of genetic mutations
Copied!

Integers are perfect for counting or identifying items. They're like your patient ID numbers – precise whole numbers.

💡 Pro Tip: Integers can be as large as you need in Python! This is perfect for genomics, where chromosome positions can be in the millions or billions.

Floats: The Measurements

# Floating-point numbers in laboratory context tumor_size_cm = 2.3 # Tumor size in centimeters p_value = 0.042 # Statistical significance value drug_concentration = 1.7e-6 # Drug concentration (scientific notation: 0.0000017 mol/L)
Copied!

Floats let us work with precise measurements – essential when a difference of 0.1 could mean life or death! The notation 1.7e-6 is scientific notation, which is perfect for the tiny concentrations we often use in medicine.

💡 Fun Analogy: If integers are like counting whole pills, floats are like measuring liquid medications where precision matters!

Strings: The Descriptors

# Strings in patient data context patient_name = "Jane Doe" diagnosis_code = "C50.911" # ICD-10 code for breast cancer dna_sequence = "ATCGTAGCTAGCTAGGGCTACT"
Copied!

Strings store text data, which is crucial for patient information and biological sequences. They're the medical charts of programming!

Identifying Types

You can always check what type of data you're working with:

# Identifying data types print(type(patient_id)) # print(type(tumor_size_cm)) # print(type(diagnosis_code)) #
Copied!
💡 Pro Tip: Always be aware of your data types. Using the wrong type can cause errors, just like administering the wrong medication!

Real-World Connection: At MD Anderson Cancer Center, bioinformaticians use these data types to build comprehensive patient profiles. Integers track genetic mutations, floats represent biomarker levels, and strings store genomic sequences. Together, they form the foundation of personalized cancer treatment plans.
