Chapter 3: Excel Files - The Clinical Research Favorite

Why Excel Rules the Clinical World 📊

Excel files are beloved in clinical research because they can organize complex studies across multiple sheets. Imagine a cancer study with separate tabs for patient demographics, treatment protocols, lab results, and outcomes - all in one file!

🎯 Single Sheet Import - Starting Simple

# Import specific sheet from multi-sheet workbook clinical_study = pd.read_excel('cancer_study.xlsx', sheet_name='patient_outcomes') # Memory saver: Import only the columns you need! biomarkers = pd.read_excel( 'tumor_markers.xlsx', usecols=['patient_id', 'CEA_level', 'CA125_level'] # Tumor marker levels )

💡 Did You Know?

CEA and CA125 are proteins that can indicate certain cancers. By tracking these biomarkers, doctors can monitor treatment effectiveness!

🎪 Multi-Sheet Magic - The Full Circus!

# Import ALL sheets at once - like opening all drawers in a filing cabinet! all_data = pd.read_excel('comprehensive_study.xlsx', sheet_name=None) # Now you have a dictionary of DataFrames! print(f"Available sheets: {list(all_data.keys())}") # Access individual sheets demographics = all_data['demographics'] lab_results = all_data['lab_results'] outcomes = all_data['clinical_outcomes']

Chapter 5: Text Files - When Doctors Write Notes

The Unstructured Data Challenge 📝

Clinical notes, discharge summaries, and radiology reports often come as plain text. These unstructured goldmines contain insights that structured data might miss!

📖 Reading Clinical Notes

# Read an entire clinical note with open('patient_notes.txt', 'r') as file: clinical_notes = file.read() # Count mentions of symptoms (simple text analysis) symptom_count = clinical_notes.lower().count('fever') print(f"Fever mentioned {symptom_count} times") # Pro tip: Real NLP (Natural Language Processing) can extract much more!

📋 Processing Medication Lists

# Read medications line by line with open('medication_list.txt', 'r') as file: medications = [line.strip() for line in file if line.strip()] # Remove duplicates and sort unique_meds = sorted(set(medications)) print(f"Patient is taking {len(unique_meds)} different medications") # Check for dangerous combinations (simplified example) if 'Warfarin' in unique_meds and 'Aspirin' in unique_meds: print("⚠️ WARNING: Potential interaction detected!")

✍️ Writing Medical Reports

# Generate a structured clinical summary def generate_patient_report(patient_id, diagnosis, lab_results): report = f""" PATIENT CLINICAL SUMMARY ======================== Generated: {pd.Timestamp.now().strftime('%Y-%m-%d %H:%M')} Report ID: RPT-{patient_id}-{pd.Timestamp.now().strftime('%Y%m%d')} Patient Information: ------------------- Patient ID: {patient_id} Primary Diagnosis: {diagnosis} Laboratory Results Summary: -------------------------- Hemoglobin: {lab_results.get('hemoglobin', 'Not tested')} g/dL White Blood Cell Count: {lab_results.get('wbc', 'Not tested')} K/μL Platelet Count: {lab_results.get('platelets', 'Not tested')} K/μL Clinical Recommendations: ------------------------ 1. Continue current treatment protocol 2. Repeat labs in 2 weeks 3. Monitor for signs of improvement This report is confidential and intended for medical professionals only. """ return report # Save the report report_content = generate_patient_report('P12345', 'Iron Deficiency Anemia', {'hemoglobin': 9.2, 'wbc': 5.8, 'platelets': 250}) with open('patient_P12345_summary.txt', 'w') as file: file.write(report_content) print("📄 Clinical summary generated successfully!")
