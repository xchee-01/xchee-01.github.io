🛡️ Safe Data Handling: Making Copies

In medical programming, data integrity is paramount. Always work with copies!

Clinical Trial Weights - DON'T modify the original! 
# Clinical trial weights - DON'T modify the original!
original_weights = [82.5, 81.8, 81.2, 80.5, 79.8, 79.1]

# Safe copy for analysis
analysis_weights = original_weights[:]  # The [:] creates a full copy

# Now we can modify without affecting the original
analysis_weights[0] = 83.0  # Oops, data entry error!
print(f"Original still intact: {original_weights[0]}")  # Still 82.5!

📊 Before/After Comparisons

A classic pattern in clinical research:

Weight Loss Program Analysis 
# Weight loss program - 12 week study
weights = [92.5, 91.8, 91.2, 90.5, 89.8, 89.1,  # First 6 weeks
          88.5, 87.9, 87.3, 86.8, 86.2, 85.7]   # Last 6 weeks

# Split at the midpoint
first_half = weights[:6]
second_half = weights[6:]

# Calculate progress
initial_avg = sum(first_half) / len(first_half)
final_avg = sum(second_half) / len(second_half)

print(f"First 6 weeks average: {initial_avg:.1f} kg")
print(f"Last 6 weeks average: {final_avg:.1f} kg")
print(f"That's {initial_avg - final_avg:.1f} kg of progress! 🎉")

🧬 Advanced Pattern: Genomic Reading Frames

mRNA Sequence Analysis 
# mRNA sequence - this codes for proteins!
mrna = ['A', 'U', 'G', 'C', 'A', 'A', 'U', 'C', 'C', 'G', 'A', 'U']

# Reading frame 1: Start from position 0
frame1 = [mrna[i:i+3] for i in range(0, len(mrna)-2, 3)]

# Reading frame 2: Start from position 1
frame2 = [mrna[i:i+3] for i in range(1, len(mrna)-2, 3)]

print("Frame 1 codons:", [''.join(codon) for codon in frame1])
print("Frame 2 codons:", [''.join(codon) for codon in frame2])

🏥 Scenario 1: ICU Vital Signs Monitoring

ICU Monitoring System 
# Vital signs collected every 15 minutes for 4 hours
# Format: [temp, heart_rate, blood_pressure_systolic, respiratory_rate]
vitals_4h = [
    [37.2, 78, 120, 16], [37.3, 82, 122, 18], [37.5, 85, 125, 20], [37.8, 88, 128, 22],
    [38.1, 92, 130, 24], [38.4, 95, 132, 26], [38.6, 98, 135, 28], [38.8, 102, 138, 30],
    [38.9, 105, 140, 32], [38.7, 103, 138, 30], [38.5, 100, 136, 28], [38.3, 97, 134, 26],
    [38.0, 94, 132, 24], [37.8, 91, 130, 22], [37.6, 88, 128, 20], [37.4, 85, 125, 18]
]

# Extract just temperatures for fever analysis
temperatures = [reading[0] for reading in vitals_4h]

# Find peak fever period (highest 4 consecutive readings)
max_sum = 0
peak_start = 0
for i in range(len(temperatures) - 3):
    current_sum = sum(temperatures[i:i+4])
    if current_sum > max_sum:
        max_sum = current_sum
        peak_start = i

peak_temps = temperatures[peak_start:peak_start+4]
print(f"Peak fever period: {peak_temps}")
print(f"Average during peak: {sum(peak_temps)/len(peak_temps):.1f}°C")

DNA Mutation Detection

patient =   ['A', 'T', 'G', 'C', 'A', 'G', 'T', 'C', 'G', 'G', 'A', 'T']
#                                   ^ mutation here!

# Find differences using slicing
for i in range(0, len(reference), 3):  # Check by codons
    ref_codon = reference[i:i+3]
    pat_codon = patient[i:i+3]
    if ref_codon != pat_codon:
        print(f"Mutation found at position {i}: {''.join(ref_codon)} → {''.join(pat_codon)}")

🏃‍♂️ Performance Tips

Optimization Strategies 
# When processing large datasets (like whole genome sequences)
large_data = list(range(1000000))  # 1 million data points

# ❌ Inefficient: Creating multiple intermediate lists
result = large_data[::10]  # Every 10th
result = result[:1000]     # First 1000 of those

# ✅ Efficient: Combine operations
result = large_data[::10][:1000]  # Same result, one operation

# ⚡ Most efficient for huge datasets: Use itertools
from itertools import islice
result = list(islice(large_data[::10], 1000))

🐛 Common Slicing Gotchas and How to Avoid Them

Common Pitfalls 
# Gotcha 1: Off-by-one errors
data = [1, 2, 3, 4, 5]
# Want elements 2 through 4?
wrong = data[2:4]   # Gets [3, 4] - oops!
right = data[1:4]   # Gets [2, 3, 4] - correct!

# Gotcha 2: Modifying while slicing
readings = [98.6, 99.1, 99.5, 100.2]
high_temps = readings[2:]  # This is a NEW list
high_temps[0] = 99.0      # Doesn't change original!

# Gotcha 3: Empty slices
empty = data[5:3]  # Start > Stop = empty list []
# Always validate your indices!

Build a system that analyzes patient vital signs for emergency detection:

# Patient monitoring data (heart rate every minute for 30 minutes)
heart_rate_log = [
    72, 73, 71, 74, 76, 78, 82, 88, 95, 103, 110, 118, 125,  # Escalating
    130, 135, 132, 128, 124, 119, 112, 105, 98, 91, 85,       # Recovering
    80, 77, 75, 73, 72, 71                                     # Stabilized
]

# Your mission: Implement these analyses
# 1. Find the 5-minute window with highest average HR
# 2. Detect rapid changes (>20 bpm increase in 3 minutes)
# 3. Identify recovery rate (time from peak to normal)

# TODO: Your code here!

# Hints:
# - Use sliding windows with slices
# - Compare slices at different positions
# - Use negative indices for recent readings
🚨 Emergency Solution Deployed! 
# 1. Find 5-minute window with highest average
max_avg = 0
max_window_start = 0
for i in range(len(heart_rate_log) - 4):
    window = heart_rate_log[i:i+5]
    avg = sum(window) / len(window)
    if avg > max_avg:
        max_avg = avg
        max_window_start = i

critical_window = heart_rate_log[max_window_start:max_window_start+5]
print(f"Critical period: minutes {max_window_start+1}-{max_window_start+5}")
print(f"Heart rates: {critical_window}, Average: {max_avg:.1f} bpm")

# 2. Detect rapid changes
alerts = []
for i in range(len(heart_rate_log) - 2):
    change = heart_rate_log[i+2] - heart_rate_log[i]
    if change > 20:
        alerts.append(f"ALERT at minute {i+1}: {change} bpm increase!")

for alert in alerts:
    print(alert)

# 3. Recovery analysis
peak_hr = max(heart_rate_log)
peak_index = heart_rate_log.index(peak_hr)
normal_hr = 75  # Define normal

# Find when HR returns to normal
for i in range(peak_index, len(heart_rate_log)):
    if heart_rate_log[i] <= normal_hr:
        recovery_time = i - peak_index
        print(f"Recovery time: {recovery_time} minutes from peak")
        break

🚀 Your Slicing Superpower Cheat Sheet

Essential Patterns to Remember 
data[:]          # Full copy
data[:n]         # First n elements
data[-n:]        # Last n elements
data[::n]        # Every nth element
data[::-1]       # Reverse the list
data[i:j]        # Elements from i to j-1
data[i:j:k]      # Elements from i to j-1, step k
