Strategic Missing Data Removal

The Surgical Approach to Data Cleaning

Instead of using a sledgehammer (removing all incomplete records), let's learn to use a scalpel. In clinical trials, we often care most about specific outcomes.

Creating a Complex Clinical Trial Dataset

# Create a more realistic clinical trial dataset clinical_trial_data = { 'patient_id': ['CT001', 'CT002', 'CT003', 'CT004', 'CT005', 'CT006'], 'age': [52, 48, None, 61, 45, 58], 'baseline_tumor_size': [2.3, 3.1, 2.8, None, 3.5, 2.9], 'treatment_response': ['Partial', 'Complete', 'Partial', None, 'Stable', 'Partial'], 'genetic_marker': ['BRCA1', None, 'BRCA2', 'BRCA1', None, 'Wild-type'], 'side_effects': ['Mild', 'None', None, 'Moderate', 'Mild', None] } # Create DataFrame df_trial = pd.DataFrame(clinical_trial_data) print("🏥 Clinical Trial Dataset:") print(df_trial) print("\n" + "="*60)

Smart Removal: Keeping What Matters

# Remove only rows missing the PRIMARY outcome df_with_outcomes = df_trial.dropna(subset=['treatment_response']) print(f"📊 Original patients: {len(df_trial)}") print(f"📈 Patients with treatment data: {len(df_with_outcomes)}") print(f"✅ Data retained: {(len(df_with_outcomes)/len(df_trial))*100:.0f}%") print("\n🎯 Filtered dataset:") print(df_with_outcomes)
Copied!

💡 Clinical Insight

Notice the difference? We kept 83% of our data by focusing on what matters most – the treatment response. Missing genetic markers? We can work with that. Missing side effects? Not ideal, but not a showstopper.

Threshold-Based Quality Control

🧪 Interactive Lab: Quality Control Checkpoint

Scenario: You're running a genomic study. The lab director says: "Keep only patients with at least 70% complete data."

Build Your Threshold Filter
def clean_by_completeness_threshold(dataframe, threshold_percent=70): """ Remove rows that have less than threshold_percent of complete data Think of this as a quality control checkpoint! """ # Step 1: How many columns do we have? n_columns = len(dataframe.columns) print(f"📊 Checking {n_columns} data points per patient...") # Step 2: What's our minimum bar? min_complete = n_columns * (threshold_percent / 100) print(f"🎯 Minimum required: {min_complete:.1f} complete fields") # Step 3: Count complete data per patient complete_per_row = dataframe.count(axis=1) # Count non-null values per row # Step 4: Who passes our quality check? quality_mask = complete_per_row >= min_complete # Create boolean mask # Step 5: Filter the dataframe df_quality = dataframe[quality_mask] # Apply the mask # Report results print(f"\n✅ Quality filter results:") print(f" Patients meeting {threshold_percent}% threshold: {len(df_quality)}") print(f" Patients excluded: {len(dataframe) - len(df_quality)}") print(f" Data retention rate: {(len(df_quality)/len(dataframe))*100:.1f}%") return df_quality # Test with our clinical trial data print("🧪 Testing threshold-based cleaning:") df_clean = clean_by_completeness_threshold(df_trial, threshold_percent=70) print("\n📋 Cleaned dataset:") print(df_clean)

Smart Data Imputation

Filling Gaps with Medical Intelligence

Sometimes, instead of removing data, we can intelligently fill in the gaps using medical knowledge and statistical methods.

# Create a dataset with missing age values patient_data_age = { 'patient_id': ['P001', 'P002', 'P003', 'P004', 'P005'], 'age': [45, None, 62, None, 58], 'disease_severity': ['Mild', 'Moderate', 'Severe', 'Mild', 'Moderate'], 'treatment_duration_days': [30, 45, 90, 25, 60] } df_patients_age = pd.DataFrame(patient_data_age) print("📊 Dataset with missing ages:") print(df_patients_age) # Method 1: Fill with median age (statistically sound) median_age = df_patients_age['age'].median() df_patients_age['age_median_filled'] = df_patients_age['age'].fillna(median_age) print(f"\n🧮 Median age: {median_age}") print("✅ After median imputation:") print(df_patients_age[['patient_id', 'age', 'age_median_filled']]) # Method 2: Forward fill (carry last observation forward) df_patients_age['age_ffill'] = df_patients_age['age'].fillna(method='ffill') print("\n📈 After forward fill:") print(df_patients_age[['patient_id', 'age', 'age_ffill']])
Copied!
Data Imputation Methods
Which imputation method is generally MOST appropriate for filling missing age values in a medical dataset?
A) Fill with zero
Zero age is not medically meaningful and would severely bias analysis.
B) Fill with median age
Correct! Median is robust to outliers and provides a statistically sound central tendency for age imputation.
C) Fill with maximum age
Using maximum age would bias the dataset toward older patients.
D) Forward fill (carry last observation)
Forward fill assumes temporal order, which isn't meaningful for age imputation across different patients.
