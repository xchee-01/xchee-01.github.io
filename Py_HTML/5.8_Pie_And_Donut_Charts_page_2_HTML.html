🔬 Donut Charts: Pie Charts with a Hole-some Twist! 🍩

Why Donuts Beat Pies (Sometimes)

Donut charts are like pie charts that went to medical school - they're smarter because they use their center space for additional information! Perfect for:

  • Summary statistics in the center
  • Key performance indicators
  • Total counts or averages
  • Modern dashboard aesthetics

🍩 Fun Fact: Studies show donut charts are easier to read than pie charts because comparing arc lengths is easier than comparing angles. Plus, they look cooler!

Patient Satisfaction Survey Example

# Patient satisfaction survey - the ultimate hospital report card!
satisfaction_levels = ['Very Satisfied', 'Satisfied', 'Neutral', 
                      'Dissatisfied', 'Very Dissatisfied']
patient_responses = [420, 310, 125, 95, 50]

plt.figure(figsize=(10, 8))

# Create the donut chart with a satisfaction color gradient
colors = ['#2ECC71', '#3498DB', '#F39C12', '#E67E22', '#E74C3C']
plt.pie(patient_responses, 
        labels=satisfaction_levels,
        colors=colors,
        autopct='%1.1f%%',
        startangle=90,
        pctdistance=0.85)  # Move percentage labels outward

# The magic: Create a white circle in the center!
centre_circle = plt.Circle((0,0), 0.70, fc='white')
fig = plt.gcf()
fig.gca().add_artist(centre_circle)

# Add informative center text
plt.text(0, 0, '1,000\nTotal\nResponses', 
         ha='center', va='center', fontsize=16, fontweight='bold')

plt.title('Patient Satisfaction Survey Results - Q4 2024', 
          fontsize=16, fontweight='bold')
plt.axis('equal')
plt.show()

✅ The Medicine-Taking Masterpiece Solution!

adherence_categories = ['Excellent (>90%)', 'Good (70-90%)', 
                       'Fair (50-70%)', 'Poor (<50%)']
patient_numbers = [180, 145, 95, 80]

plt.figure(figsize=(10, 8))

# Healthcare color gradient (green = taking meds, red = forgetting)
colors = ['#27AE60', '#F39C12', '#E67E22', '#E74C3C']

# Create the donut
plt.pie(patient_numbers, 
        labels=adherence_categories,
        colors=colors,
        autopct='%1.0f pts',  # Show patient counts
        startangle=90,
        pctdistance=0.85)

# Add the donut hole
centre_circle = plt.Circle((0,0), 0.70, fc='white')
fig = plt.gcf()
fig.gca().add_artist(centre_circle)

# Calculate weighted average (using range midpoints)
adherence_midpoints = [95, 80, 60, 25]  # Midpoints of each range
total_patients = sum(patient_numbers)
weighted_adherence = sum(p * a for p, a in zip(patient_numbers, adherence_midpoints)) / total_patients

# Display the "report card grade" in the center
plt.text(0, 0, f'{weighted_adherence:.1f}%\nOverall\nAdherence', 
         ha='center', va='center', fontsize=18, fontweight='bold', 
         color='#2C3E50')

plt.title('Diabetes Medication Adherence Program\n500 Patients Tracked', 
          fontsize=16, fontweight='bold')
plt.axis('equal')
plt.show()

🎯 Key Insight: That 71.5% overall adherence means nearly 30% of patients aren't taking medications properly - a huge opportunity for intervention!

Cancer Screening Participation by Age - A Tale of Three Generations

# Cancer screening participation by age - a tale of three generations
fig, (ax1, ax2, ax3) = plt.subplots(1, 3, figsize=(15, 5))

# Consistent colors for easy comparison
colors = ['#3498DB', '#E74C3C']  # Blue = participated, Red = declined

# The Millennials (18-39) - "I'm too young for cancer!"
data_18_39 = [125, 275]  # Only 31.3% participation - yikes!
ax1.pie(data_18_39, labels=['Participated', 'Declined'], 
        colors=colors, autopct='%1.1f%%', startangle=90)
ax1.set_title('Ages 18-39\n(n=400)', fontsize=12, fontweight='bold')

# Generation X (40-59) - "Okay, maybe I should check..."
data_40_59 = [380, 120]  # 76% participation - much better!
ax2.pie(data_40_59, labels=['Participated', 'Declined'], 
        colors=colors, autopct='%1.1f%%', startangle=90)
ax2.set_title('Ages 40-59\n(n=500)', fontsize=12, fontweight='bold')

# Baby Boomers (60+) - "I never miss a screening!"
data_60_plus = [295, 105]  # 73.8% participation - wisdom shows!
ax3.pie(data_60_plus, labels=['Participated', 'Declined'], 
        colors=colors, autopct='%1.1f%%', startangle=90)
ax3.set_title('Ages 60+\n(n=400)', fontsize=12, fontweight='bold')

plt.suptitle('Cancer Screening: The Generation Gap\n' +
             '"Why don\'t young people think they need screening?"', 
             fontsize=16, fontweight='bold')
plt.tight_layout()
plt.show()

✅ The FDA-Ready Clinical Trial Visualization!

sites = ['Site A - Urban', 'Site B - Suburban', 'Site C - Rural']
success_data = {
    'Site A': {'Success': 142, 'Partial': 48, 'No Response': 35},
    'Site B': {'Success': 168, 'Partial': 52, 'No Response': 30},
    'Site C': {'Success': 135, 'Partial': 45, 'No Response': 45}
}

fig, axes = plt.subplots(1, 3, figsize=(18, 6))

# Medical outcome colors (green=good, yellow=okay, red=concerning)
colors = ['#2ECC71', '#F39C12', '#E74C3C']
labels = ['Success', 'Partial', 'No Response']

for idx, (ax, site) in enumerate(zip(axes, sites)):
    # Extract data for this site
    data = success_data[site.split(' - ')[0]]
    values = [data['Success'], data['Partial'], data['No Response']]
    
    # Create donut chart
    ax.pie(values, labels=labels, colors=colors, 
           autopct='%1.0f', startangle=90, pctdistance=0.85)
    
    # Add donut hole
    centre_circle = plt.Circle((0,0), 0.70, fc='white')
    ax.add_artist(centre_circle)
    
    # Calculate success rate
    total = sum(values)
    success_rate = (data['Success'] / total) * 100
    
    # Add success rate to center - the number everyone cares about!
    ax.text(0, 0, f'{success_rate:.1f}%\nSuccess\nRate', 
            ha='center', va='center', fontsize=14, fontweight='bold',
            color='#2ECC71' if success_rate > 65 else '#E74C3C')
    
    # Add site info
    ax.set_title(f'{site}\n(n={total} patients)', fontsize=12, fontweight='bold')
    ax.axis('equal')

plt.suptitle('Cardiovascular Drug Trial: Success Rates by Location\n' +
             'Target: >65% Success Rate for FDA Approval', 
             fontsize=16, fontweight='bold')
plt.tight_layout()
plt.show()

💡 Golden Rules for Medical Pie Charts:

  1. Limit slices to 5-7 maximum (more = visual spaghetti)
  2. Order matters - largest to smallest, or by medical importance
  3. Colors should mean something - use medical conventions
  4. Always show totals - context prevents misinterpretation
  5. Explode sparingly - like medical emergencies, save it for real crises
