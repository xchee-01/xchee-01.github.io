🎯 Getting Started with Basic Setup

Let's start with something simple - tracking a diabetic patient's glucose levels. This is real-world stuff that could help millions manage their condition better!

# Import our visualization superhero library! 🦸‍♂️
import matplotlib.pyplot as plt

# Morning glucose readings - like checking blood sugar with your meter
time_hours = [0, 2, 4, 6, 8, 10, 12]  # Breakfast at 8!

# Glucose levels in mg/dL (milligrams per deciliter)
glucose_levels = [95, 110, 125, 140, 120, 105, 98]
💡 Tip Box: Notice how glucose spikes after meals? That 140 mg/dL at hour 6 is probably from breakfast! This is why doctors recommend checking blood sugar 2 hours after eating.
Glucose Pattern Interpretation

🎨 Creating Your First Medical Masterpiece

Now let's transform these numbers into a visual story:

# Create a canvas for our medical chart
plt.figure(figsize=(10, 6))  # Like choosing the right size clipboard!

# Draw the glucose journey
plt.plot(time_hours, glucose_levels, 'b-')  # 'b-' = blue line

# Add professional labels (doctors need clear charts!)
plt.title('Patient Glucose Monitoring - 12 Hour Profile', fontsize=14)
plt.xlabel('Time (hours)', fontsize=12)
plt.ylabel('Blood Glucose (mg/dL)', fontsize=12)

# Add gridlines - like graph paper for easier reading
plt.grid(True, alpha=0.3)  # alpha makes it subtle, not distracting

# Show our masterpiece!
plt.show()

🎉 Success! You've just created a chart that could appear in any medical record!

💊 Pharmacokinetics Visualization

Let's track how an antibiotic moves through a patient's bloodstream. This is crucial for ensuring the drug stays effective without becoming toxic!

# Antibiotic concentration over time
time_points = [0, 1, 2, 3, 4, 5, 6, 7, 8]
drug_concentration = [0, 2.5, 4.2, 5.8, 4.9, 3.7, 2.8, 2.1, 1.6]

# Create a figure with style!
plt.figure(figsize=(10, 6))

# Plot with markers - each point is a blood test!
plt.plot(time_points, drug_concentration, 'go-',  # green circles with line
         linewidth=2, markersize=8, label='Antibiotic Level')

# Add critical reference lines
plt.axhline(y=4, color='orange', linestyle='--', 
            label='Minimum Therapeutic Level')  # Below this = ineffective
plt.axhline(y=6, color='red', linestyle='--', 
            label='Toxic Threshold')  # Above this = dangerous!

# Professional labeling
plt.title('Antibiotic Pharmacokinetics - Patient ID: 12345', fontsize=14)
plt.xlabel('Time After Dose (hours)', fontsize=12)
plt.ylabel('Serum Concentration (mcg/mL)', fontsize=12)
plt.legend(loc='upper right')
plt.grid(True, alpha=0.3)
plt.show()
🔍 Clinical Insight: See how the drug peaks around hour 3? That's when it's most effective. By hour 8, we might need another dose to stay above the therapeutic threshold!

Element Purpose Example

🔬 Chapter 3: Multi-Line Plots - The Comparison Champions

🏥 Comparing Treatment Responses

In precision medicine, we often need to see how different patients respond to the same treatment. Let's visualize ovarian cancer patients' responses to chemotherapy:

# Tracking CA-125 tumor marker levels over 6 months
months = [0, 1, 2, 3, 4, 5, 6]

# Three different patient responses (U/mL = units per milliliter)
patient_A = [180, 165, 142, 120, 95, 78, 65]  # Great responder! 🌟
patient_B = [195, 188, 175, 168, 155, 148, 140]  # Poor response 😟
patient_C = [175, 155, 125, 95, 72, 58, 45]  # Good response! 👍

# Create comparison chart
plt.figure(figsize=(12, 7))

# Plot each patient with unique style
plt.plot(months, patient_A, 'b-o', linewidth=2, markersize=6, 
         label='Patient A - Responder')
plt.plot(months, patient_B, 'r-s', linewidth=2, markersize=6, 
         label='Patient B - Non-responder')
plt.plot(months, patient_C, 'g-^', linewidth=2, markersize=6, 
         label='Patient C - Partial Responder')

# Add normal level reference
plt.axhline(y=35, color='gray', linestyle=':', linewidth=2, 
            label='Normal CA-125 Level')

# Professional formatting
plt.title('Ovarian Cancer Treatment Response - CA-125 Monitoring', fontsize=16)
plt.xlabel('Months Since Treatment Start', fontsize=12)
plt.ylabel('CA-125 Level (U/mL)', fontsize=12)
plt.legend(loc='upper right')
plt.grid(True, alpha=0.3)
plt.ylim(0, 210)  # Set y-axis range for clarity
plt.show()
🎯 What This Tells Us:
  • Patient A: Excellent response! CA-125 dropping below normal ✅
  • Patient B: Treatment not working - time to try something else ❌
  • Patient C: Good response, almost at target level 📊
