🤔 Self-Explanation Moment

Learning Checkpoint
Why do we add a space after the colon in input("Name: ")?
For better readability
The space makes the input look cleaner when the user types.
Correct! The space makes the input look cleaner when the user types. Without it, their text would appear immediately after the colon, making it harder to read!
It's required syntax
Python requires a space after colons in input prompts.
Not quite. The space is not required by Python syntax - it's purely for visual formatting to make the user experience better.
To prevent errors
Without the space, Python will throw an error.
That's not correct. Python won't throw an error without the space. It's purely for aesthetics and user experience.

Approach B:

symptoms = input("List your symptoms (separate with commas): ")

Learning Checkpoint
When would you use each approach?
Use A for fixed number, B for variable
Approach A when you need exactly 3 symptoms, B when the number varies.
Correct! Approach A: When you need exactly 3 symptoms or want to guide the patient. Approach B: When the number of symptoms varies or you want faster input.
Always use Approach A
Approach A is always better because it's more structured.
Not quite. While Approach A provides structure, it's not flexible when patients have varying numbers of symptoms to report.
Always use Approach B
Approach B is always better because it's faster.
Not always. Sometimes you need the structure of Approach A to ensure you collect specific information in a guided manner.

") pain_level = input("Rate your discomfort (0-10): ") allergies = input("List any allergies: ") medications = input("Current medications: ") # Generate summary print("\n" + "="*40) print("📄 PATIENT INTAKE SUMMARY") print("="*40) print(f"Name: {name} (Age: {age})") print(f"Emergency Contact: {emergency_contact}") print(f"\nChief Complaint: {main_symptom}") print(f"Duration: {symptom_duration}") print(f"Pain Level: {pain_level}/10") print(f"\nAllergies: {allergies if allergies else 'None reported'}") print(f"Medications: {medications if medications else 'None'}") # Priority assignment pain_score = int(pain_level) if pain_score >= 8 or "chest pain" in main_symptom.lower(): print("\n🔴 PRIORITY: URGENT - See doctor immediately") elif pain_score >= 5: print("\n🟡 PRIORITY: MODERATE - See doctor within 1 hour") else: print("\n🟢 PRIORITY: ROUTINE - See doctor within 2-3 hours") print("\nThank you!
