🧬 Dictionaries in Precision Health Programming 🧬

Welcome to one of Python's most powerful data structures for medical informatics! 🏥 Did you know that a single electronic health record can contain over 50,000 data points? That's where dictionaries come to the rescue! Think of dictionaries as the Swiss Army knife of healthcare data - they're like having a perfectly organized medical chart where every piece of information has its own labeled drawer. No more hunting through endless files!

In precision health, dictionaries are the unsung heroes managing everything from your genomic profile (with its 3 billion base pairs!) to your medication history. They're the digital equivalent of those color-coded patient charts nurses use, but infinitely more powerful. Ready to unlock the secrets of medical data management? Let's dive in! 🚀

💡 Fun Fact

The world's largest medical dictionary, Epic's Chronicles database, stores over 300,000 different types of medical data points per patient - all organized using dictionary-like structures!

Dictionary Methods: Your Medical Data Swiss Army Knife

The Safe Access Pattern - Never Crash on Missing Data!

In healthcare, missing data is common. Maybe a test wasn't ordered, or results aren't back yet. Crashing your program over missing data could be dangerous!

The risky way (DON'T do this in production!) 
medications = {
    "metformin": "500mg twice daily",
    "lisinopril": "10mg once daily",
    "atorvastatin": "20mg at bedtime"
}

# This would crash if aspirin isn't in the dictionary:
dose = medications["aspirin"]  # KeyError! 💥
Question: Safe Dictionary Access

What happens when you try to access a key that doesn't exist in a dictionary?

A Returns None

Enter the get() Method - Your Safety Net

The safe way - using get() with a default 
# The safe way - using get() with a default
aspirin_dose = medications.get("aspirin", "Not prescribed")
insulin_dose = medications.get("insulin", "Not prescribed")

print(f"Aspirin: {aspirin_dose}")
print(f"Insulin: {insulin_dose}")

# Even better - check before prescribing interactions
if medications.get("warfarin"):
    print("⚠️ WARNING: Patient on blood thinner!")

Exploring Your Medical Database

Dictionary Methods in Action 
# See all medications at a glance
print("\n📋 Current Medications:")
for drug in medications.keys():
    print(f"  • {drug}")

# Get all dosages
print("\n💊 Dosing Schedule:")
for dose in medications.values():
    print(f"  • {dose}")

# Or get both together!
print("\n💉 Complete Medication List:")
for drug, dose in medications.items():
    print(f"  • {drug.capitalize()}: {dose}")

Question: Medication Safety

💡 Hint: Amoxicillin is a penicillin-type antibiotic! What should the safety checker report?

A Safe - amoxicillin is not in the allergy list
B Unsafe - cross-allergy with penicillin
C Unknown - need more information
D Safe - they are different medications
Complete solution with safety checking 
allergy_profile = {
    "penicillin": "severe",
    "sulfa": "moderate",
    "latex": "mild"
}

# Task 1: Safe aspirin check
aspirin_status = allergy_profile.get("aspirin", "No known allergy")
print(f"Aspirin allergy status: {aspirin_status}")

# Task 2: List all allergens
print("\n🚨 Known Allergens:")
for allergen in allergy_profile.keys():
    severity = allergy_profile[allergen]
    emoji = "🔴" if severity == "severe" else "🟡" if severity == "moderate" else "🟢"
    print(f"  {emoji} {allergen} ({severity})")

# Task 3: Medication safety checker
def check_medication_safety(med_name, allergies):
    # Check for direct allergies
    if med_name in allergies:
        return f"❌ ALLERGIC to {med_name}!"
    
    # Check for cross-allergies
    if med_name == "amoxicillin" and "penicillin" in allergies:
        return f"❌ CROSS-ALLERGY: {med_name} is a penicillin!"
    
    if med_name == "bactrim" and "sulfa" in allergies:
        return f"❌ CROSS-ALLERGY: {med_name} contains sulfa!"
    
    return f"✅ {med_name} appears safe"

# Test the checker
print("\n💊 Medication Safety Check:")
for med in ["amoxicillin", "aspirin", "bactrim", "tylenol"]:
    print(f"  {check_medication_safety(med, allergy_profile)}")
