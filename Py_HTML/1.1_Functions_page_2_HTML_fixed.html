Mission Briefing: Functions Without Return Values

🎭 The Silent Workers

Not all functions need to return a value. Some functions perform actions like displaying information or saving data to a file. These are like medical procedures that have an immediate effect but don't produce a test result - such as:

  • 💉 Administering a vaccine (action performed, no result needed)
  • 📝 Updating a patient's chart (information recorded)
  • 🔔 Setting a medication reminder (task scheduled)

In Python, these functions technically return None, but we don't use that value.

Mission Briefing: Function Scope and Variables

🏠 Variable Privacy: What Happens in Functions, Stays in Functions!

Variables created inside a function exist only within that function - this is called "scope". Think of it like patient confidentiality:

  • 🏥 Information discussed in Room 101 stays in Room 101
  • 🏥 Information discussed in Room 102 stays in Room 102
  • 📋 Unless explicitly shared via the patient's chart (return values)!

This concept protects your data and prevents functions from accidentally interfering with each other - imagine if calculating one patient's dosage accidentally changed another patient's prescription! 😱

🔒 Understanding Scope with Medical Examples

Understanding scope is crucial in medical programming where patient privacy and data integrity are paramount. Let's explore with a pediatric dosing example:

# Demonstrating function scope - Pediatric Dosing Calculator def calculate_pediatric_dose(adult_dose, child_age): """ Calculate child's dose based on age Local variables = Private patient room """ # This age_factor variable only exists inside this function # It's like a calculation done on a private notepad age_factor = child_age / 18 # Rough approximation safety_margin = 0.9 # Extra safety for children pediatric_dose = adult_dose * age_factor * safety_margin # These variables disappear when function ends! return pediatric_dose # Global scope - The main hospital floor standard_adult_dose = 500 # This exists outside any function # The age_factor variable doesn't exist here - it's private to the function
# Each function call creates its own "room" with private variables child_dose = calculate_pediatric_dose(standard_adult_dose, 6) print(f"6-year-old dose: {child_dose:.0f}mg") # Different call, different "room", different local variables teen_dose = calculate_pediatric_dose(standard_adult_dose, 15) print(f"15-year-old dose: {teen_dose:.0f}mg") # This would cause an error - age_factor doesn't exist here! # print(age_factor) # NameError: name 'age_factor' is not defined

""" # Check from most severe to least severe if systolic > 180 or diastolic > 120: return "⚠️🚨 HYPERTENSIVE CRISIS - Seek emergency care immediately!" elif systolic >= 140 or diastolic >= 90: return "🔴 Stage 2 Hypertension - Medication likely needed" elif systolic >= 130 or diastolic >= 80: return "🟡 Stage 1 Hypertension - Lifestyle changes + possible medication" elif systolic >= 120 and diastolic < 80: return "🟠 Elevated blood pressure - Lifestyle changes recommended" else: return "🟢 Normal blood pressure - Keep it up!" # Test the function with various readings print("BP Classification System") print("-" * 40) # Test cases test_cases = [ (118, 75, "Normal adult"), (125, 78, "Slightly elevated"), (135, 85, "Stage 1 HTN"), (145, 92, "Stage 2 HTN"), (185, 115, "Crisis - Emergency!") ] for sys, dia, description in test_cases: result = classify_blood_pressure(sys, dia) print(f"{sys}/{dia} ({description}): {result}")
