Finding Commonalities (Intersection)

Real scenario: Identifying patients with comorbidities 
diabetes_patients = {"P001", "P002", "P003", "P004", "P005"}
hypertension_patients = {"P003", "P004", "P006", "P007"}

# Who has BOTH conditions? (Critical for treatment planning!)
comorbid = diabetes_patients & hypertension_patients
print(f"🚨 High-risk patients (both conditions): {comorbid}")

# Output: High-risk patients (both conditions): {'P003', 'P004'}

Level Up: Professional-Grade Set Operations

Now let's explore the methods that power enterprise healthcare systems:

Method-Based Operations (More Readable!)

Hospital department patient tracking 
emergency_patients = {"E001", "E002", "E003", "E004"}
cardiology_patients = {"C001", "C002", "E002", "E003"}

# Using methods instead of operators - clearer intent!
shared = emergency_patients.intersection(cardiology_patients)
print(f"🏥 Patients seen in both departments: {shared}")

total = emergency_patients.union(cardiology_patients)
print(f"📊 Total unique patients: {total}")

Set Comprehensions for Genomic Data Processing

🧬 Power Tool: Set Comprehensions

Set comprehensions are like list comprehensions but automatically handle uniqueness. Perfect for filtering large datasets!

Filtering by Criteria

Gene expression analysis (real bioinformatics task!) 
gene_expression = {"BRCA1": 2.5, "TP53": 0.8, "EGFR": 3.2, "KRAS": 1.5}

# Find highly expressed genes (threshold > 2.0)
highly_expressed = {gene for gene, value in gene_expression.items() if value > 2.0}
print(f"🔥 Highly expressed genes: {highly_expressed}")

# Output: Highly expressed genes: {'BRCA1', 'EGFR'}

Conditional Filtering

Database constraint: medication names must be ≤8 characters 
medications = {"Aspirin", "Acetaminophen", "Ibuprofen", "Metformin"}
short_names = {drug for drug in medications if len(drug) <= 8}
print(f"💊 Database-compliant names: {short_names}")

# Drug interaction safety system solution
interactions = {
    "Warfarin": {"Aspirin", "Ibuprofen", "Vitamin K"},
    "Metformin": {"Alcohol", "Contrast Dye"},
    "Lisinopril": {"Potassium", "NSAIDs"}
}

patient_meds = {"Warfarin", "Metformin", "Lisinopril"}
new_substances = {"Aspirin", "Alcohol", "Potassium", "Vitamin D"}

# Find all possible interactions using set comprehension
all_interactions = {item for med in patient_meds if med in interactions 
                   for item in interactions[med]}

# Identify dangerous combinations
dangerous_combinations = new_substances & all_interactions

# Find safe substances
safe_substances = new_substances - dangerous_combinations

print(f"⚠️  All possible interactions: {all_interactions}")
print(f"🚫 Dangerous combinations: {dangerous_combinations}")
print(f"✅ Safe to add: {safe_substances}")
