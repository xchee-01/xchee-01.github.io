🧬 Part 2: Naming Your Variables Like a Pro

Python's Simple Rules

Think of variable names like patient ID bands – they need to be clear and follow certain rules:

  1. Start with a letter or underscore (not a number)
  2. Use only letters, numbers, and underscores
  3. Case matters (Patient ≠ patient)
✅ Good variable names ===================== patient_age = 45 blood_type = "O+" is_allergic_to_penicillin = True ❌ Won't work - starts with number ================================= 2nd_dose = 500 # Error! ❌ Won't work - has spaces ========================= patient name = "John" # Error!
Copied!

💡 Pro Tip: In healthcare, clarity saves lives! Always choose descriptive names:

  • temp ❌ (Temperature? Temporary?)
  • body_temperature_celsius ✅ (Crystal clear!)

🔬 Part 3: Data Types in Clinical Context

The Fantastic Four of Medical Data

Python automatically figures out what type of data you're storing (smart, right?). Here are the four types you'll use constantly:

1. Strings (text) - For names, IDs, and descriptions

patient_mrn = "MRN2024-001" diagnosis = "Type 2 Diabetes" medication_name = "Metformin"
Copied!

2. Integers (whole numbers) - For counts and discrete values

patient_age = 67 pills_per_day = 3 hospital_room = 204
Copied!

3. Floats (decimals) - For precise measurements

weight_kg = 72.5 hemoglobin_a1c = 6.8 drug_dose_mg = 12.5
Copied!

4. Booleans (True/False) - For yes/no conditions

is_pregnant = False has_insurance = True needs_interpreter = False
Copied!
🤔 Think About It
Why might storing weight as an integer (72 instead of 72.5) be dangerous in pediatric medicine?
It saves memory
Integers use less computer memory than floats
While true about memory, this doesn't address the medical danger. Think about precision in pediatric dosing.
Dosing calculations require precision
Small differences in weight can significantly affect medication dosing for children
Exactly right! In pediatrics, medication doses are often calculated per kilogram. A 0.5kg difference could mean a 10% change in dosage for a small child!
It's easier to type
Whole numbers are simpler to enter
Convenience should never compromise medical accuracy. Patient safety always comes first!
It doesn't matter
The difference is negligible
In medicine, precision matters! Even small differences can impact patient care, especially for vulnerable populations.

🚀 Part 4: Variable Reassignment – Tracking Patient Changes

The Power of Updates

In healthcare, nothing stays constant. Variables can be updated to reflect changes:

Morning vital signs

oxygen_saturation = 95 print(f"Morning O2: {oxygen_saturation}%")
Copied!

After oxygen therapy

oxygen_saturation = 98 print(f"After treatment: {oxygen_saturation}%")
Copied!

💭 Medical Metaphor: Think of reassignment like updating a patient's chart. The chart (variable name) stays the same, but the information (value) gets updated.

Progressive Monitoring Example

ICU patient monitoring over time

patient_status = "critical" print(f"Admission: {patient_status}") # After 2 hours of treatment patient_status = "serious" print(f"2 hours later: {patient_status}") # After successful intervention patient_status = "stable" print(f"Current status: {patient_status}")
Copied!
🎯 Self-Check
What will this code output?
pain_level = 8 pain_level = pain_level - 3 print(pain_level) # What number appears?
8
The original value remains unchanged
Not quite! The second line updates the variable. pain_level = pain_level - 3 means "take the current value (8), subtract 3, and store the result back in pain_level".
5
8 minus 3 equals 5
Correct! The variable is reassigned: pain_level starts at 8, then we subtract 3 (8 - 3 = 5), and store 5 back in pain_level.
3
The amount subtracted
That's not right. We're subtracting 3 from 8, not displaying the amount subtracted. The result is 8 - 3 = 5.
Error
You can't use a variable in its own reassignment
Actually, you can! Python evaluates the right side first (pain_level - 3 = 8 - 3 = 5), then assigns that result to the left side.

Summary: Variables and Assignment in Precision Health

Congratulations! You've mastered the fundamental concepts of variables and assignment in the context of precision health. Let's recap what you've learned:

  1. Variables are containers: They store medical data like patient names, vital signs, and test results – just like labeled specimen tubes in a lab.
  2. Clear naming saves lives: Using descriptive variable names like patient_glucose_level instead of pgl makes your code safer and more maintainable.
  3. Data types matter in medicine:
    • Strings for patient identifiers and text
    • Integers for counts and discrete values
    • Floats for precise measurements (crucial for dosing!)
    • Booleans for binary medical states
  4. Variables can be updated: Just like patient conditions change, variables can be reassigned to reflect new values – essential for tracking treatment progress.

What's Next? In the next module, you'll learn about arithmetic operators and how to perform calculations with your medical data – from BMI calculations to drug dosing formulas. Keep up the excellent work!
