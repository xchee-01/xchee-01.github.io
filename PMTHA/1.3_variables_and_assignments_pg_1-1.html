Introduction to Variables

Let's start simple. A variable in Python is like a labeled specimen jar in your lab - it stores something important that you'll need to reference later. Before we dive into medical applications, let's understand the basics:

# Your first Python variable - simple and straightforward message = "Hello, Python!" print(message)
Copied!

Now that wasn't so scary, was it? You've just created your first variable! 🎉

You could also create a variable to store your name:

# Create a variable to store your name your_name = "Jane Doe" print("Hello,", your_name)
Copied!

As we progress, you'll learn how variables can store everything from patient IDs to blood glucose levels to gene sequences. Just as a good medical professional keeps track of changing patient metrics, you'll use variables to monitor and analyze biomedical data in your Python programs.

Mission Briefing: Creating and Assigning Values to Variables

Think of variables as the lab equipment of programming - essential tools that make your work possible! Before we start processing medical data, let's learn the fundamentals:

# Creating a simple variable lab_name = "Bioinformatics Lab" print(lab_name)
Copied!
Learning Checkpoint
What will the code above output?
lab_name
Not quite right. When you use a variable in a print statement, Python outputs the value stored in the variable, not the variable name itself.
Bioinformatics Lab
Correct! When you print a variable, Python displays the value that is stored in that variable. In this case, the variable lab_name stores the string "Bioinformatics Lab".
Error message
That's not correct. Python can print variables without any issues. The print() function can display the values stored in variables.
"lab_name" = "Bioinformatics Lab"
That's not right. The print() function only outputs the value of what you put inside the parentheses, not the assignment statement.

Creating variables in Python is simple - choose a name, use the equals sign (the assignment operator), and specify a value. The computer will reserve a spot in memory for your data and slap a convenient label on it.

Let's try with different types of data:

# Creating variables with different types of data lab_number = 42 # A number (integer) temperature = 37.5 # A decimal number (float) is_refrigerated = True # A yes/no value (boolean)

Quick Check
What would happen if we tried to add 5 to patient_age?
We would get 39
Correct! Since patient_age is an integer with value 34, adding 5 would result in 39. Numeric variables can be used in mathematical operations.
We would get "345"
That's not correct. String concatenation happens with strings, but patient_age is an integer. Adding another integer to it will perform arithmetic addition, not concatenation.
We would get an error
That's not right. In Python, you can perform operations on variables, and integers can be used in mathematical operations like addition.
Quick Check
What would happen if we tried to add 5 to patient_name?
We would get "Alex Smith5"
Not quite. While string concatenation is possible, you can't directly add a number to a string. You would need to convert the number to a string first.
We would get an error
Correct! Python doesn't allow adding integers directly to strings. You would get a TypeError: "can only concatenate str (not 'int') to str". To combine them, you would need to convert the integer to a string first using str(5).
We would get 5 copies of "Alex Smith"
That's not right. Multiplication of a string by an integer does repeat the string, but we're talking about addition here, not multiplication. The + operator with a string and an integer produces an error.

When you create these variables, Python allocates memory space to store the values. This is much easier than having to remember the actual values - imagine remembering hundreds of patient temperatures without labels!

Self-Check Question
Why might we want to use a float for temperature but an integer for heart rate?
Precision requirements
Body temperature often requires decimal precision (like 37.2°C), while heart rate is typically measured in whole beats per minute.
Correct! Medical measurements have different precision requirements. Body temperature is clinically significant down to the decimal point (the difference between 37.0°C and 37.5°C can be important), while heart rate is almost always expressed as a whole number of beats per minute.
Memory optimization
Integers use less memory than floats, so we only use floats when absolutely necessary.
While integers do use slightly less memory than floats, the difference is negligible for most applications. The main reason for choosing data types in medical data is accuracy and precision, not memory optimization.
Calculation requirements
We need to perform more complex math on temperature values than on heart rate values.
The choice between float and integer isn't primarily about the complexity of calculations. Both can be used in complex calculations. The choice is about representing the inherent precision of the data being stored.
Display requirements
We need to display temperature with a decimal point but heart rate as a whole number.
While it's true that these values are typically displayed differently, we choose data types based on the nature of the data itself, not just how it will be displayed. The display format can be adjusted regardless of the underlying data type.

Summary: Creating and Assigning Variables

Congratulations on completing the first part of your variables journey! Let's review what you've learned:

  1. Variables are labeled containers for data - they store values that your program can reference and use
  2. Creating a variable uses the assignment operator (=) - the variable name goes on the left, the value on the right
  3. Variables can store different types of data - strings (text), integers (whole numbers), floats (decimal numbers), and booleans (true/false)
  4. Variables make your code more readable and usable - they create meaningful names for your data

In a healthcare context, these skills allow you to create organized, labeled storage for all types of medical data - from patient information to vital signs to test results.

In Part 2, we'll explore how to properly name your variables and how to update them as values change - essential skills for tracking patient metrics over time!
