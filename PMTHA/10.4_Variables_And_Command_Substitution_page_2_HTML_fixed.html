10.4.5. Command Substitution Fundamentals

Command substitution is a powerful shell feature that allows you to capture the output of a command and use it as part of another command or assign it to a variable. This is fundamental for creating dynamic scripts that adapt to system conditions and automate complex workflows.

Basic Syntax

There are two ways to perform command substitution in bash:

# Modern way (preferred) - using $() current_date=$(date) file_count=$(ls | wc -l) # Classic way (avoid) - using backticks current_date=`date` # Why prefer $()? It handles nesting better: backup="backup_$(date +%Y%m%d)_$(hostname).tar"
Copied!

Best Practice: Always use the modern $() syntax instead of backticks. It's easier to read, handles nesting properly, and is less prone to errors with special characters.

Real-World Applications

Command substitution is extensively used in system administration and bioinformatics pipelines. Here are practical examples you'll encounter:

1. Dynamic Filenames

# Create timestamped log files LOG="/var/log/app_$(date +%Y%m%d_%H%M%S).log" # Backup with hostname and date BACKUP="/backup/$(hostname)_$(date +%Y-%m-%d).tar" # Research data with experiment ID DATA_FILE="experiment_$(cat /tmp/exp_id)_results.csv"

2. System Information Gathering

# Capture system metrics MEM_USED=$(free -m | grep Mem | awk '{print $3}') CPU_LOAD=$(uptime | awk -F'average:' '{print $2}') MY_IP=$(hostname -I | awk '{print $1}') # Check available disk space ROOT_SPACE=$(df -h / | tail -1 | awk '{print $4}')

3. Process Management

# Find the user with most processes BUSY_USER=$(ps aux | awk '{print $1}' | sort | uniq -c | sort -nr | head -1) # Count Java processes JAVA_COUNT=$(ps aux | grep -c '[j]ava') # Get PID of a specific service NGINX_PID=$(pgrep nginx)

#!/bin/bash # System Information Reporter Script - Complete Solution # Basic system information HOSTNAME=$(hostname) # Get the system hostname KERNEL=$(uname -r) # Get kernel release version UPTIME=$(uptime | awk '{print $3}' | tr -d ',') # Resource usage metrics MEM_TOTAL=$(free -m | grep Mem | awk '{print $2}') MEM_USED=$(free -m | grep Mem | awk '{print $3}') MEM_PCT=$(free | grep Mem | awk '{printf "%d", $3/$2*100}') # Calculate memory percentage DISK_USAGE=$(df -h / | tail -1 | awk '{print $5}') CPU_COUNT=$(nproc) # Get number of CPU cores # Network information IP_ADDRESS=$(hostname -I | awk '{print $1}') # Get primary IP address # Generate the report REPORT_DATE=$(date '+%Y-%m-%d %H:%M:%S') cat > system_report.txt << EOF === SYSTEM REPORT === Generated: $REPORT_DATE Hostname: $HOSTNAME Kernel: $KERNEL Uptime: $UPTIME days === RESOURCES === Memory: ${MEM_USED}MB / ${MEM_TOTAL}MB (${MEM_PCT}%) Disk Usage: $DISK_USAGE CPU Cores: $CPU_COUNT === NETWORK === IP Address: $IP_ADDRESS EOF echo "Report generated: system_report.txt"
Copied!

Explanation of solutions:

  • hostname - Returns the system's hostname
  • uname -r - The -r flag shows the kernel release version
  • free | grep Mem | awk '{printf "%d", $3/$2*100}' - Calculates memory usage percentage by dividing used by total
  • nproc - Returns the number of processing units (CPU cores)
  • hostname -I | awk '{print $1}' - Gets all IP addresses and selects the first one

10.4.6. Advanced Techniques and System Monitoring

Now that you understand the basics, let's explore advanced command substitution techniques that enable sophisticated system monitoring and automation. These patterns are essential for managing complex computational environments used in bioinformatics and precision medicine research.

Nested Command Substitution

Complex operations often require multiple levels of command substitution:

# Find and backup recently modified config files RECENT_CONFIGS=$(find /etc -name "*.conf" -mtime -1) for config in $RECENT_CONFIGS; do BACKUP_NAME="/backup/$(basename "$config")_$(date +%Y%m%d).bak" cp "$config" "$BACKUP_NAME" done # Process files based on their content for file in $(grep -l "ERROR" $(find /var/log -name "*.log")); do echo "Processing error log: $file" ERROR_COUNT=$(grep -c "ERROR" "$file") echo " Found $ERROR_COUNT errors" done
Copied!

Error Handling with Command Substitution

Robust scripts must handle cases where commands might fail:

# Safe command substitution with fallback IP=$(hostname -I 2>/dev/null) if [ -z "$IP" ]; then # Fallback method if hostname -I fails IP=$(ip addr show | grep "inet " | grep -v "127.0.0.1" | head -1 | awk '{print $2}' | cut -d/ -f1) fi # Check if command succeeded before using result if DOCKER_VERSION=$(docker --version 2>/dev/null); then echo "Docker installed: $DOCKER_VERSION" else echo "Docker not found - installing..." fi
Copied!

Performance Monitoring Patterns

Advanced system monitoring requires combining multiple commands:

# Find resource-intensive processes CPU_HOG=$(ps aux | sort -k3 -nr | head -1 | awk '{print $11}') MEM_HOG=$(ps aux | sort -k4 -nr | head -1 | awk '{print $11}') echo "Top CPU consumer: $CPU_HOG" echo "Top memory consumer: $MEM_HOG" # Monitor disk I/O by process IO_STATS=$(iotop -b -n 1 2>/dev/null | grep -A 5 "Total DISK") # Track network connections CONNECTIONS=$(ss -tan | grep ESTABLISHED | wc -l) echo "Active connections: $CONNECTIONS"
Copied!

Quick Reference: Special Variables

When working with command substitution, these special variables are invaluable:

# Exit status of last command result=$(some_command) if [ $? -eq 0 ]; then echo "Command succeeded" fi # Process ID of current shell echo "Script PID: $$" # Number of arguments echo "Arguments passed: $#" # All arguments as separate words echo "All args: $@" # Last argument of previous command echo "Last arg: $_"
Copied!

Pro Tip: When debugging command substitution, use set -x at the beginning of your script to see each command as it's executed. This shows you exactly what's being substituted.

Answer:

#!/bin/bash # Advanced System Monitor for Research Cluster - Complete Solution # Configuration ALERT_THRESHOLD_CPU=80 ALERT_THRESHOLD_MEM=90 ALERT_THRESHOLD_DISK=85 LOG_DIR="/var/log/monitor" # Ensure log directory exists mkdir -p "$LOG_DIR" # Function to check CPU usage check_cpu() { # Get average CPU usage over last minute CPU_USAGE=$(top -bn1 | grep "Cpu(s)" | awk '{print int($2)}') if [ "$CPU_USAGE" -gt "$ALERT_THRESHOLD_CPU" ]; then echo "ALERT: High CPU usage: ${CPU_USAGE}%" # Find top 3 CPU-consuming processes TOP_PROCS=$(ps aux | sort -k3 -nr | head -3 | awk '{printf "%s %s (%.1f%%), ", $11, $2, $3}') echo "Top CPU processes: $TOP_PROCS" fi } # Function to check memory check_memory() { # Calculate memory usage percentage MEM_USAGE=$(free | grep Mem | awk '{printf "%d", $3/$2*100}') if [ "$MEM_USAGE" -gt "$ALERT_THRESHOLD_MEM" ]; then echo "ALERT: High memory usage: ${MEM_USAGE}%" # Show memory by process MEM_HOGS=$(ps aux | sort -k4 -nr | head -3 | awk '{printf "%s %s (%.1fGB), ", $11, $2, $6/1024/1024}') echo "Memory intensive processes: $MEM_HOGS" fi } # Function to check disk space check_disk() { # Check all mounted filesystems while read -r filesystem; do USAGE=$(df -h "$filesystem" | tail -1 | awk '{print int($5)}') MOUNT=$(df -h "$filesystem" | tail -1 | awk '{print $6}') if [ "$USAGE" -gt "$ALERT_THRESHOLD_DISK" ]; then echo "ALERT: Disk space critical on $MOUNT: ${USAGE}%" # Find large files LARGE_FILES=$(find "$MOUNT" -type f -size +1G 2>/dev/null | head -3 | xargs -I {} du -h {} | sort -hr) echo "Large files: $LARGE_FILES" fi done < <(df -h | grep -v Filesystem | awk '{print $1}') } # Function to check running jobs check_jobs() { # Count running analysis jobs (assuming they contain 'analysis' in name) RUNNING_JOBS=$(ps aux | grep -c '[a]nalysis') echo "Running analysis jobs: $RUNNING_JOBS" # Check for stuck jobs (running > 24 hours) STUCK_JOBS=$(ps aux | awk '$10 ~ /[0-9]+-[0-9]+:[0-9]+:[0-9]+/ || $10 ~ /[0-9]+:[0-9]+:[0-9]+/ && $10 !~ /^0:/ {print $1, $2, $3, $4, $10, $11}') if [ -n "$STUCK_JOBS" ]; then echo "WARNING: Possible stuck jobs detected" echo "$STUCK_JOBS" fi } # Main monitoring loop echo "=== System Monitor Report - $(date) ===" check_cpu check_memory check_disk check_jobs # Log results TIMESTAMP=$(date '+%Y%m%d_%H%M%S') { echo "Monitor run at: $(date)" check_cpu check_memory check_disk check_jobs } > "$LOG_DIR/monitor_${TIMESTAMP}.log" echo "=== End of Report ==="
Copied!

Key solutions explained:

  • top -bn1 | grep "Cpu(s)" | awk '{print int($2)}' - Extracts CPU usage percentage from top command
  • ps aux | sort -k3 -nr - Sorts processes by CPU usage (column 3) in reverse numeric order
  • free | grep Mem | awk '{printf "%d", $3/$2*100}' - Calculates memory usage as percentage
  • find "$MOUNT" -type f -size +1G - Finds files larger than 1GB in the filesystem
  • ps aux | grep -c '[a]nalysis' - Counts processes with 'analysis' in name (bracket trick prevents grep from matching itself)
