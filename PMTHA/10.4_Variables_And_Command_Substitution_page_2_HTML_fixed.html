10.4.5. Getting Started with Command Substitution

Command substitution in R enables you to construct and execute code dynamically, a crucial skill when dealing with varied clinical datasets or when building automated analysis workflows.

Basic Syntax

The fundamental tools for command substitution in R are:

  • substitute() - Creates an unevaluated expression
  • bquote() - Similar to substitute but more flexible
  • quote() - Creates an unevaluated expression without substitution
  • expression() - Creates a vector of unevaluated expressions
# Basic substitution example patient_var <- "systolic_bp" threshold <- 140 # Using substitute to create dynamic expression expr <- substitute(data[data$var > value, ], list(var = as.name(patient_var), value = threshold)) print(expr) # Shows: data[data$systolic_bp > 140, ] # Using bquote for cleaner syntax expr2 <- bquote(data[data$.(as.name(patient_var)) > .(threshold), ]) print(expr2) # Same result

# Dynamic formula construction for clinical models create_clinical_model <- function(outcome, predictors, interactions = NULL) { # Base formula formula_parts <- c(outcome, "~", paste(predictors, collapse = " + ")) # Add interactions if specified if (!is.null(interactions)) { interaction_terms <- apply(interactions, 1, function(x) paste(x, collapse = ":")) formula_parts <- c(formula_parts, "+", paste(interaction_terms, collapse = " + ")) } # Create formula object formula_str <- paste(formula_parts, collapse = " ") as.formula(formula_str) } # Example: Building models for diabetes risk # Simple model model1 <- create_clinical_model("diabetes_risk", c("bmi", "age", "glucose")) print(model1) # diabetes_risk ~ bmi + age + glucose # Model with interactions interactions <- matrix(c("bmi", "age", "glucose", "family_history"), ncol = 2, byrow = TRUE) model2 <- create_clinical_model("diabetes_risk", c("bmi", "age", "glucose", "family_history"), interactions) print(model2) # diabetes_risk ~ bmi + age + glucose + family_history + bmi:age + glucose:family_history

Error Handling and Validation

In medical applications, robust error handling is crucial to prevent misinterpretation of results:

# Safe command substitution with validation safe_biomarker_analysis <- function(data, biomarker, operation = "mean") { # Validate inputs if (!biomarker %in% names(data)) { stop(paste("Biomarker", biomarker, "not found in dataset")) } # Create safe expression with error handling safe_expr <- bquote({ tryCatch({ values <- data[[.(biomarker)]] # Check for valid numeric data if (!is.numeric(values)) { stop(paste("Biomarker", .(biomarker), "contains non-numeric data")) } # Check for sufficient data valid_values <- values[!is.na(values)] if (length(valid_values) < 3) { warning("Less than 3 valid measurements available") } # Perform operation result <- switch(.(operation), "mean" = mean(valid_values), "median" = median(valid_values), "sd" = sd(valid_values), stop("Unknown operation: ", .(operation))) list( biomarker = .(biomarker), operation = .(operation), result = result, n_valid = length(valid_values), n_missing = sum(is.na(values)), status = "success" ) }, error = function(e) { list( biomarker = .(biomarker), operation = .(operation), error = e$message, status = "error" ) }) }) eval(safe_expr) }
