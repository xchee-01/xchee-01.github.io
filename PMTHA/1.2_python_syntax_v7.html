Mission Briefing: Data Types - The Building Blocks of Health Information

Let's build on our foundation by learning about data types. Before we jump straight into medical applications, let's understand the basics:

What Are Data Types?

Think of data types like different kinds of hospital equipment - each designed for a specific purpose:

# Just showing different types of data print(42) # A number without a decimal point print(98.6) # A number with a decimal point print("Patient") # Text data in quotes
Copied!

Python recognizes different kinds of data and treats them differently, just like you'd use different tools for taking temperature versus measuring blood pressure.

Integers (int) - Whole Numbers

Integers are whole numbers without decimal points:

# Examples of integers print(5) print(0) print(-10)
Copied!

Let's see how we might use integers in healthcare:

Mission Briefing: Boolean Values - The True/False of Medical Decisions

In medicine, you often deal with yes/no questions: Is the test positive? Is the treatment working? Does the patient have a fever? Python uses Boolean values to represent these true/false situations.

What Are Boolean Values?

Boolean values are simple - they can only be True or False (notice the capital letters!):

# The two Boolean values print(True) print(False)
Copied!

That's it! Just two possible values. But their simplicity makes them powerful for decision-making.

Using Boolean Values in Healthcare

Let's see how Boolean values apply to medical scenarios:

# Boolean values in a patient record has_diabetes = True is_allergic_to_penicillin = False fasting_completed = True print("Diabetes diagnosis:", has_diabetes) print("Penicillin allergy:", is_allergic_to_penicillin) print("Fasting before test:", fasting_completed)
Copied!

Think of Boolean values as those checkboxes on medical forms - they're either checked (True) or unchecked (False).

Creating Boolean Values with Comparisons

One of the most common ways to create Boolean values is through comparisons. These comparison operators evaluate a condition and return either True or False:

# Simple comparisons print(5 > 3) # Is 5 greater than 3? print(10 < 7) # Is 10 less than 7? print(4 == 4) # Is 4 equal to 4? print(5 != 5) # Is 5 not equal to 5?
Copied!

Output:

True False True False

Let's see how comparisons help in medical contexts:

# Medical comparisons temperature = 38.5 heart_rate = 72 blood_glucose = 5.4 has_fever = temperature > 37.5 tachycardia = heart_rate > 100 normal_glucose = 4.0 <= blood_glucose <= 7.0 print("Fever present:", has_fever) print("Tachycardia present:", tachycardia) print("Glucose in normal range:", normal_glucose)
Copied!

Combining Boolean Values with Logical Operators

In medicine, you often need to consider multiple factors together. Python provides logical operators to combine Boolean values:

# The three logical operators a = True b = False print("a AND b:", a and b) # True only if both are True print("a OR b:", a or b) # True if at least one is True print("NOT a:", not a) # Inverts the value
Copied!

Output:

a AND b: False a OR b: True NOT a: False

Let's apply these to a clinical scenario:

# Clinical decision support example fever = True cough = True shortness_of_breath = False contact_with_covid = True # Clinical criteria covid_suspected = fever and (cough or shortness_of_breath) needs_testing = covid_suspected or contact_with_covid needs_immediate_care = fever and shortness_of_breath print("COVID suspected:", covid_suspected) print("Testing recommended:", needs_testing) print("Immediate care needed:", needs_immediate_care)
Copied!

Mission Briefing: Type Conversion for Medical Data Processing

In healthcare informatics, you'll often need to convert between different data types to properly process patient information. For example, patient data entered into forms often comes in as strings, but you might need to convert to numbers for calculations or analysis.

Python provides built-in functions to convert between data types:

  • int(): Converts to integer
  • float(): Converts to floating-point number
  • str(): Converts to string
  • bool(): Converts to Boolean

Let's see how these functions are used in medical contexts:

# Converting string inputs to numeric values patient_age_input = "65" # Age from a form (string) height_cm_input = "172.5" # Height from a form (string) # Convert to appropriate numeric types patient_age = int(patient_age_input) height_cm = float(height_cm_input) # Now we can perform calculations height_m = height_cm / 100 # Convert to meters years_until_screening = 75 - patient_age # Calculate years until next screening print("Patient age:", patient_age, "years") print("Height:", height_m, "meters") print("Years until geriatric assessment:", years_until_screening)
Copied!

Converting from numbers to strings is useful when creating reports or composing messages:

# Convert numbers to strings for reporting systolic_bp = 128 diastolic_bp = 82 bmi = 24.7 # Create a formatted medical report report = "Blood Pressure: " + str(systolic_bp) + "/" + str(diastolic_bp) + " mmHg" print(report) status_message = "Your BMI of " + str(bmi) + " is within normal range." print(status_message)
Copied!

Converting to Boolean can help with interpretation of medical values:

# Converting values to Boolean white_blood_cells = 12000 # Elevated WBC count # 0 converts to False, non-zero values convert to True abnormal_wbc = bool(white_blood_cells - 10000) # True if WBC > 10000 print("WBC elevation detected:", abnormal_wbc) diagnostic_finding = "" # Empty string # Empty strings convert to False finding_present = bool(diagnostic_finding) print("Diagnostic finding recorded:", finding_present)
Copied!

One common use case in medical applications is parsing clinical data from different sources:

# Process lab values from different systems glucose_result = "126" # From one system (string) cholesterol_result = 210 # From another system (integer) bmi_value = 27.4 # From a calculator (float) # Standardize values for diabetes risk assessment glucose = float(glucose_result) # Convert to float cholesterol = float(cholesterol_result) # Convert to float # Calculate diabetes risk score diabetes_risk = (glucose / 100) + (cholesterol / 200) + (bmi_value / 25) print("Diabetes risk score:", diabetes_risk) print("Elevated risk:", diabetes_risk > 3)
Copied!

Health Tech Tip: Always validate data after type conversion. For example, check that a converted age is positive and within a reasonable range. Invalid data in clinical algorithms can lead to erroneous recommendations!

Real-World Connection: In genomic data processing pipelines, type conversion is critical. DNA sequences might come in as strings but need conversion to numeric representations for machine learning algorithms that predict disease risk or treatment response.

What is Lou-Greig's Disease?

Click to learn about this rare genetic disorder relevant to precision medicine...

Lou-Greig's Disease is a rare genetic disorder characterized by progressive neurological deterioration and distinctive skin manifestations. First described in 2018, it affects approximately 1 in 250,000 individuals worldwide.

Key clinical features include:

  • Early-onset cognitive decline (typically beginning in adolescence)
  • Characteristic salmon-colored rash on extremities
  • Gradually increasing muscle weakness
  • Distinctive biomarker profile with elevated CSF protein levels

Recent precision medicine approaches have identified specific genetic variants in the LGD1 and LGD2 genes associated with this condition. Targeted therapies are currently in Phase II clinical trials, demonstrating the potential of genomic medicine to address previously untreatable disorders.
