🔬 Chapter 1: What is Plotly and Why Should You Care?

Breaking it Down - The Basics 🧩

Plotly is like having a conversation with your data instead of just staring at it from across the room. While matplotlib gives you a photograph of your data, Plotly gives you a living, breathing, interactive experience. Imagine showing a patient their glucose levels where they can zoom into specific days, hover over exact readings, and actually explore their own health journey - that's the Plotly difference!

# Let's start simple - importing our visualization superpowers! # ================================================== import plotly.graph_objects as go # Your main toolkit for custom visualizations import plotly.express as px # The express lane for quick plots import pandas as pd # Because medical data loves DataFrames

📊 Chapter 2: Your First Medical Visualization - Let's Track Some Glucose!

Starting Simple: A Day in the Life of a Diabetic Patient

Let's create our first visualization by tracking blood glucose throughout the day. This isn't just an exercise - it's exactly what endocrinologists use to adjust insulin regimens!

# Step 1: Create realistic patient data # ===================================== # Fun fact: These patterns mirror actual post-meal glucose spikes! # ================================================== glucose_times = ['6:00', '8:00', '10:00', '12:00', '14:00', '16:00', '18:00', '20:00', '22:00'] glucose_levels = [95, 140, 125, 180, 165, 130, 170, 145, 110] # mg/dL # Notice the spikes? That's breakfast (140), lunch (180), and dinner (170)! # ==================================================
Copied!
🤔 Pause and Predict
Before we plot this, looking at the glucose values, when would you expect to see the highest glucose levels?

Fasting glucose is typically lowest. Look for the post-meal spikes in the data!
After meals (12:00, 18:00)
Post-prandial peaks
Exactly! Glucose spikes after meals. Notice 180 mg/dL at noon (after lunch) and 170 mg/dL at 6 PM (after dinner). This is classic diabetic pattern!
Late night (22:00)

By bedtime, glucose typically stabilizes. The peaks occur 1-2 hours after eating.
Constant throughout the day
Stable levels
In diabetes, glucose fluctuates significantly with meals. Look at the values - they range from 95 to 180!
# Step 2: Create your figure canvas # ================================= fig = go.Figure() # Think of this as your blank medical chart # Step 3: Add the glucose data as a line trace # ============================================ fig.add_trace(go.Scatter( x=glucose_times, y=glucose_levels, mode='lines+markers', # Both lines AND points - best of both worlds! name='Blood Glucose', line=dict(color='blue', width=3), # Nice thick line for clarity marker=dict(size=8) # Big enough dots to hover over easily ))
Copied!

Correct! Normal post-meal glucose should stay under 140 mg/dL. Our patient shows spikes up to 180 mg/dL - concerning for diabetes!

That's dangerously low! This range indicates hypoglycemia.
# Step 4: Make it medical-grade with proper labels # ================================================ fig.update_layout( title='Patient PMH-2024-001: Daily Glucose Monitoring', xaxis_title='Time of Day', yaxis_title='Blood Glucose (mg/dL)', hovermode='x unified' # Shows all values at each time point! ) # Step 5: The magic moment - show your interactive masterpiece! # ================================================== fig.show()

🚀 Chapter 3: Plotly Express - Your Medical Visualization Fast Track

From Zero to Clinical Trial Results in 5 Lines!

Remember how we said Plotly Express is the microwave? Let's prove it by analyzing a clinical trial in record time:

# Create a realistic clinical trial dataset # ========================================= data = { 'Treatment': ['Drug A', 'Drug A', 'Drug A', 'Drug B', 'Drug B', 'Drug B', 'Placebo', 'Placebo', 'Placebo'], 'Patient_ID': ['P001', 'P002', 'P003', 'P004', 'P005', 'P006', 'P007', 'P008', 'P009'], 'Tumor_Reduction': [45, 52, 38, 25, 30, 28, 10, 12, 8], # Percentage reduction 'Side_Effects': [2, 3, 1, 4, 5, 4, 1, 0, 1] # Severity score } # Convert to DataFrame - the preferred format for medical data # ================================================== clinical_trial_df = pd.DataFrame(data)

# One line of code for a complete statistical visualization! # ================================================== fig = px.box(clinical_trial_df, x='Treatment', y='Tumor_Reduction', title='Clinical Trial: Tumor Reduction by Treatment Group', labels={'Tumor_Reduction': 'Tumor Size Reduction (%)'}, color='Treatment', points="all") # Show individual patient data too! fig.show()

🎨 Chapter 4: Making Your Visualizations Publication-Ready

The Difference Between "It Works" and "It's Professional"

Let's elevate our visualizations to medical journal standards. We'll track kidney function using creatinine levels:

# Generate a month of kidney function data # ======================================== import numpy as np dates = pd.date_range('2024-01-01', periods=30, freq='D') # Normal creatinine: 0.7-1.3 mg/dL. Our patient hovers around 1.2 # ================================================== creatinine_levels = np.random.normal(1.2, 0.15, 30) # Create a medical-grade DataFrame # ================================ lab_results = pd.DataFrame({ 'Date': dates, 'Creatinine': creatinine_levels }) # Start with a basic line plot # ============================ fig = px.line(lab_results, x='Date', y='Creatinine')
Copied!

Now let's add the professional touches:

# Add clinical reference range (the green zone of safety!) # ================================================== fig.add_hrect(y0=0.7, y1=1.3, fillcolor="lightgreen", opacity=0.3, annotation_text="Normal Range", annotation_position="top left") # Add a danger zone above normal # ============================== fig.add_hrect(y0=1.3, y1=2.0, fillcolor="lightcoral", opacity=0.2, annotation_text="Elevated - Monitor Closely") # Professional formatting that journals love # ========================================== fig.update_layout( title=dict( text='30-Day Kidney Function Monitoring: Serum Creatinine Trends', font=dict(size=16, family='Arial, sans-serif') ), xaxis_title='Date', yaxis_title='Creatinine (mg/dL)', template='plotly_white', # Clean, professional look showlegend=True ) # Add precise hover information # ============================= fig.update_traces( hovertemplate='Date: %{x|%Y-%m-%d}
Creatinine: %{y:.2f} mg/dL
Status: %{customdata}' ) fig.show()
Copied!
🏆 Publishing Pro-Tip
Why do medical journals require specific formatting for visualizations?
To make authors' lives difficult
Arbitrary rules
There are important scientific reasons for standardization in medical publishing!
For consistency and clarity across studies
Scientific standardization
Exactly! Standardized formatting ensures readers can quickly understand and compare results across different studies. Consistent fonts, sizes, and color schemes reduce cognitive load and prevent misinterpretation - crucial when medical decisions depend on the data!
To save printing costs
Economic reasons
While cost matters, the primary reason is scientific clarity and reproducibility.
Copyright protection
Legal requirements
Formatting standards are about scientific communication, not copyright. Plotly lets you control every pixel!

# Professional oncology dashboard # =============================== import plotly.graph_objects as go from plotly.subplots import make_subplots weeks = list(range(1, 13)) cea_levels = [15.2, 14.8, 13.5, 11.2, 9.8, 8.5, 7.2, 6.8, 6.2, 5.8, 5.5, 5.2] ca19_9_levels = [85, 82, 78, 72, 65, 58, 52, 48, 45, 42, 40, 38] # Create subplot structure # ======================== fig = make_subplots( rows=2, cols=1, subplot_titles=('CEA Levels (Carcinoembryonic Antigen)', 'CA 19-9 Levels'), vertical_spacing=0.15, row_heights=[0.5, 0.5] ) # Add CEA tracking # ================ fig.add_trace( go.Scatter(x=weeks, y=cea_levels, mode='lines+markers', name='CEA', line=dict(color='darkblue', width=3), marker=dict(size=8)), row=1, col=1 ) # Add CA 19-9 tracking # ==================== fig.add_trace( go.Scatter(x=weeks, y=ca19_9_levels, mode='lines+markers', name='CA 19-9', line=dict(color='darkgreen', width=3), marker=dict(size=8)), row=2, col=1 ) # Add normal ranges # ================= fig.add_hline(y=5.0, line_dash="dash", line_color="red", annotation_text="Normal CEA < 5.0 ng/mL", row=1, col=1) fig.add_hline(y=37, line_dash="dash", line_color="red", annotation_text="Normal CA 19-9 < 37 U/mL", row=2, col=1) # Professional formatting # ======================= fig.update_xaxes(title_text="Weeks of Treatment", row=2, col=1) fig.update_yaxes(title_text="CEA (ng/mL)", row=1, col=1) fig.update_yaxes(title_text="CA 19-9 (U/mL)", row=2, col=1) fig.update_layout( title='Chemotherapy Response: Tumor Marker Monitoring', height=600, showlegend=False, template='plotly_white' ) # Add success annotation # ====================== fig.add_annotation( text="Treatment Success: Both markers approaching normal!", xref="paper", yref="paper", x=0.5, y=1.05, showarrow=False, font=dict(size=14, color="green") ) fig.show()
