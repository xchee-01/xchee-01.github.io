4.3.4. Exporting Your Discoveries - Sharing is Caring!

The Art of Data Export 🎨

After analyzing medical data, sharing your findings effectively can literally save lives. Let's master the art of creating exports that healthcare professionals will love!

📤 CSV Export - Quick and Universal

# Create a risk assessment report risk_assessment = pd.DataFrame({ 'patient_id': ['P001', 'P002', 'P003'], 'risk_score': [0.75, 0.32, 0.91], 'priority': ['High', 'Low', 'Critical'], 'recommended_action': ['Immediate consultation', 'Routine follow-up', 'Emergency alert'] }) # Export without the index (those pesky row numbers) risk_assessment.to_csv('urgent_patient_alerts.csv', index=False) print("✅ Alert file created! Medical team notified.")
Copied!

📊 Excel Export - Professional Reports

# Create a comprehensive clinical report with multiple sheets with pd.ExcelWriter('weekly_clinical_report.xlsx', engine='openpyxl') as writer: # Summary statistics on first sheet summary_stats.to_excel(writer, sheet_name='Executive_Summary', index=False) # Detailed patient data on second sheet patient_details.to_excel(writer, sheet_name='Patient_Details', index=False) # High-risk patients on third sheet (with formatting!) high_risk.to_excel(writer, sheet_name='Urgent_Cases', index=False) # Pro tip: Add a timestamp sheet timestamp_df = pd.DataFrame({ 'Report Generated': [pd.Timestamp.now()], 'Data Period': ['Last 7 days'], 'Analyst': ['Your Name'] }) timestamp_df.to_excel(writer, sheet_name='Metadata', index=False) print("📊 Professional report ready for the medical board!")
Copied!

Scenario: You're working at a genetic counseling center. Parents need clear, actionable reports about carrier screening results. Complete the code to export genetic screening results.

# Genetic screening results are in! genetic_results = pd.DataFrame({ 'family_id': ['FAM001', 'FAM002', 'FAM003'], 'cystic_fibrosis': ['Not a carrier', 'Carrier', 'Not a carrier'], 'sickle_cell': ['Not a carrier', 'Not a carrier', 'Carrier'], 'tay_sachs': ['Not a carrier', 'Carrier', 'Not a carrier'], 'risk_level': ['Low', 'Moderate', 'Moderate'] }) # TODO: Export full results to CSV genetic_results.___('genetic_screening_full_report.csv', ___) # TODO: Create filtered report for genetic counselors (only moderate/high risk) counselor_alerts = genetic_results[genetic_results['risk_level'] != '___'] # TODO: Export counselor alerts counselor_alerts.___('genetic_counselor_priority.csv', index=False) # Bonus: Add a consultation notes column before exporting genetic_results['consultation_notes'] = '' genetic_results.loc[genetic_results['risk_level'] != 'Low', 'consultation_notes'] = 'Schedule genetic counseling session'
Copied!

Expected output:

Two CSV files created: 1. genetic_screening_full_report.csv - Contains all family screening results 2. genetic_counselor_priority.csv - Contains only families with moderate/high risk levels

Answer:

# Complete solution genetic_results.to_csv('genetic_screening_full_report.csv', index=False) counselor_alerts = genetic_results[genetic_results['risk_level'] != 'Low'] counselor_alerts.to_csv('genetic_counselor_priority.csv', index=False) # The bonus solution shows how to add helpful notes for the medical team!
