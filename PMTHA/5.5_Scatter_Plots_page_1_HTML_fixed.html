5.5.1. Fundamentals of Medical Scatter Plots

🧬 Scatter Plots for Precision Health Analytics 🧬

Welcome to the fascinating world of scatter plots in medical data visualization! 🎯 As a future precision health programmer, you're about to discover how these powerful visualization tools help uncover hidden relationships between medical variables – from drug dosage vs. treatment response to genetic markers vs. disease risk. Get ready to become a medical data detective! 🔍

Ever wondered how researchers discovered that certain genetic variants increase cancer risk? Or how doctors determine the optimal drug dosage for individual patients? The answer often lies in scatter plots – the Swiss Army knife of medical data exploration!

🔬 Mission Briefing: Understanding Scatter Plots in Healthcare

Scatter plots are like medical X-rays for data relationships! They display individual data points as dots on a two-dimensional plane, revealing patterns, correlations, and outliers that might save lives. In precision health, scatter plots help us:

  • Identify Biomarker Relationships: Discover how different blood markers correlate with disease states
  • Optimize Drug Dosing: Visualize the relationship between drug concentration and therapeutic effect
  • Detect Patient Subgroups: Spot clusters of patients with similar genetic or clinical profiles
  • Quality Control: Identify measurement errors or unusual patient responses
Learning Checkpoint
Think of each dot as a patient's story – their unique combination of medical measurements frozen in time. When we plot hundreds or thousands of these stories together, patterns emerge that guide personalized treatment decisions.

Lab Exercise 1: Drug Response Analysis

Scenario: You're analyzing a new diabetes medication. Create a scatter plot showing the relationship between drug dose and glucose reduction.

# Your task: Visualize drug dose-response relationship import matplotlib.pyplot as plt import numpy as np # Generate clinical trial data np.random.seed(123) patient_count = 80 # Drug doses in mg drug_doses = np.random.uniform(5, 50, patient_count) # Glucose reduction follows logarithmic dose-response curve # (Common in pharmacology!) glucose_reduction = 20 * np.log(drug_doses) + np.random.normal(0, 5, patient_count) glucose_reduction = np.clip(glucose_reduction, 0, 100) # TODO: Create scatter plot showing dose vs glucose reduction # Include proper labels, title, and grid # Bonus: Color-code points by response level (low/medium/high)
Copied!

Answer:

# Solution: Drug dose-response visualization plt.figure(figsize=(10, 8)) # Create color categories based on response level colors = ['red' if x < 30 else 'yellow' if x < 60 else 'green' for x in glucose_reduction] # Create scatter plot plt.scatter(drug_doses, glucose_reduction, c=colors, alpha=0.6, s=60, edgecolor='black', linewidth=0.5) # Add labels and title plt.title('Diabetes Medication Dose-Response Curve (n=80)', fontsize=16, pad=20) plt.xlabel('Drug Dose (mg)', fontsize=14) plt.ylabel('Glucose Reduction (%)', fontsize=14) # Add grid plt.grid(True, alpha=0.3, linestyle='--') # Add legend for color coding from matplotlib.patches import Patch legend_elements = [Patch(facecolor='red', label='Low Response (<30%)'), Patch(facecolor='yellow', label='Medium Response (30-60%)'), Patch(facecolor='green', label='High Response (>60%)')] plt.legend(handles=legend_elements, loc='lower right') # Show plot plt.show()
Copied!

Tip: In pharmacology, dose-response curves often follow logarithmic patterns because drug receptors can become saturated! 💊

Learning Checkpoint
Why is a logarithmic relationship (using np.log) appropriate for modeling drug dose-response?
It makes the math easier
Mathematical convenience isn't the primary reason.
Not quite. While logarithms can simplify some calculations, the choice is based on biological reality, not mathematical convenience.
Drug receptors can become saturated, leading to diminishing returns at higher doses
This reflects the biological reality of receptor binding.
Correct! Drug receptors have limited binding sites. As dose increases, more receptors become occupied until saturation occurs, creating a logarithmic relationship between dose and response.
It creates more colorful plots
Visual appearance isn't the reason for model choice.
That's not right. The choice of mathematical model is based on biological mechanisms, not aesthetic considerations.
Logarithms are always used in medical data
Many medical relationships are linear or follow other patterns.
Incorrect. Different biological processes follow different mathematical relationships. Logarithmic models are specifically appropriate for saturable processes like receptor binding.

🎨 Using Color to Encode Patient Categories

In medical research, we often need to visualize multiple patient groups simultaneously. Color-coding helps identify patterns within subpopulations!

# Generate multi-group patient data for cardiovascular study np.random.seed(100) # Three patient groups with different risk profiles n_per_group = 50 # Low risk group (healthy lifestyle) ldl_low_risk = np.random.normal(100, 15, n_per_group) hdl_low_risk = np.random.normal(60, 8, n_per_group) # Medium risk group (some risk factors) ldl_med_risk = np.random.normal(130, 20, n_per_group) hdl_med_risk = np.random.normal(45, 7, n_per_group) # High risk group (multiple risk factors) ldl_high_risk = np.random.normal(160, 25, n_per_group) hdl_high_risk = np.random.normal(35, 6, n_per_group)

📏 Bubble Plots: Adding a Third Dimension with Size

Sometimes we need to visualize three variables simultaneously. Enter the bubble plot – where dot size represents a third variable!

# Generate cancer research data with three variables np.random.seed(77) n_patients = 100 # Tumor size in mm tumor_size = np.random.exponential(20, n_patients) tumor_size = np.clip(tumor_size, 5, 80) # Biomarker level (correlates with tumor size) biomarker_level = 10 + 2 * tumor_size + np.random.normal(0, 15, n_patients) biomarker_level = np.clip(biomarker_level, 0, 200) # Treatment duration in weeks (larger tumors need longer treatment) treatment_weeks = 4 + 0.3 * tumor_size + np.random.normal(0, 2, n_patients) treatment_weeks = np.clip(treatment_weeks, 2, 30)
Copied!
# Create bubble plot figure plt.figure(figsize=(12, 8))
Copied!
# Create scatter plot with variable sizes # Size represents treatment duration bubble_sizes = treatment_weeks * 20 # Scale for visibility scatter = plt.scatter(tumor_size, biomarker_level, s=bubble_sizes, c=treatment_weeks, cmap='viridis', alpha=0.6, edgecolor='black', linewidth=0.5)
Copied!
