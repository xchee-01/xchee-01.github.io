6.7.1. Understanding Summary Statistics in Healthcare

Summary statistics are the foundation of medical data analysis. They transform complex patient datasets into meaningful insights that guide clinical decisions. Think of them as your diagnostic tools for data!

The summary() Function: Your Statistical Swiss Army Knife

# Patient cholesterol levels (mg/dL) cholesterol <- c(180, 195, 220, 185, 240, 210, 198, 175, 230, 205) # Get comprehensive summary summary(cholesterol) # Output: # Min. 1st Qu. Median Mean 3rd Qu. Max. # 175.0 186.2 202.5 203.8 218.8 240.0
Copied!

The summary() function provides six key statistics:

  • Min (Minimum): Lowest value in the dataset
  • 1st Qu (First Quartile): 25% of values fall below this
  • Median: Middle value when data is ordered
  • Mean: Average of all values
  • 3rd Qu (Third Quartile): 75% of values fall below this
  • Max (Maximum): Highest value in the dataset

Real-World Clinical Application

# Blood pressure readings from hypertension study systolic_bp <- c(118, 125, 132, 140, 145, 138, 156, 162, 148, 135) # Analyze the distribution bp_summary <- summary(systolic_bp) print(bp_summary) # Clinical interpretation normal_range <- sum(systolic_bp < 120) elevated <- sum(systolic_bp >= 120 & systolic_bp < 130) stage1 <- sum(systolic_bp >= 130 & systolic_bp < 140) stage2 <- sum(systolic_bp >= 140) cat("Blood Pressure Classification:\n") cat("Normal (<120):", normal_range, "patients\n") cat("Elevated (120-129):", elevated, "patients\n") cat("Stage 1 HTN (130-139):", stage1, "patients\n") cat("Stage 2 HTN (≥140):", stage2, "patients\n")

6.7.2. Mean and Median: Your First Tools

The mean and median are fundamental measures of central tendency in medical statistics. Understanding when to use each is crucial for accurate data interpretation.

Mean: The Arithmetic Average

# Heart rates of cardiac patients (bpm) heart_rates <- c(65, 72, 68, 75, 82, 70, 78, 69, 73, 71) # Calculate mean mean_hr <- mean(heart_rates) cat("Mean heart rate:", round(mean_hr, 1), "bpm\n") # Manual calculation to understand sum_hr <- sum(heart_rates) n_patients <- length(heart_rates) manual_mean <- sum_hr / n_patients cat("Manual calculation:", sum_hr, "/", n_patients, "=", manual_mean, "bpm\n")
Copied!

Median: The Middle Value

# Same heart rate data median_hr <- median(heart_rates) cat("Median heart rate:", median_hr, "bpm\n") # Understanding median with sorted data sorted_hr <- sort(heart_rates) cat("Sorted values:", sorted_hr, "\n") cat("Middle position(s):", (n_patients + 1) / 2, "\n")
Copied!

When Outliers Matter: Mean vs Median

# Emergency room wait times (minutes) # Note: One patient waited unusually long due to non-urgent condition wait_times <- c(15, 20, 18, 25, 22, 19, 180, 21, 23, 17) mean_wait <- mean(wait_times) median_wait <- median(wait_times) cat("Mean wait time:", round(mean_wait, 1), "minutes\n") cat("Median wait time:", median_wait, "minutes\n") cat("Difference:", round(mean_wait - median_wait, 1), "minutes\n") # Visual comparison cat("\nWhich better represents typical wait time?\n") cat("- Mean suggests typical wait is", round(mean_wait, 0), "minutes\n") cat("- Median suggests typical wait is", median_wait, "minutes\n")
Copied!
Learning Checkpoint

Correct! The median (20.5 minutes) better represents the typical patient experience because it's not skewed by the single 180-minute outlier.

Incorrect. The median isn't always better - it depends on the data distribution and presence of outliers.

Not correct. The choice isn't about ease of calculation but about which measure best represents the data.

🏥 Clinical Insight: In medical research, the median is often preferred for reporting patient outcomes like survival times or hospital stays because these distributions typically have outliers (e.g., patients with complications staying much longer).

6.7.3. Measuring Variability: Consistency Matters!

In healthcare, knowing the average isn't enough. We need to understand how much values vary. High variability might indicate unstable conditions or inconsistent treatment responses.

Range: The Simplest Measure

# Blood glucose readings throughout the day (mg/dL) glucose_readings <- c(95, 145, 110, 180, 120, 98, 165, 105) # Calculate range glucose_range <- range(glucose_readings) cat("Glucose range:", glucose_range[1], "to", glucose_range[2], "mg/dL\n") cat("Total variation:", glucose_range[2] - glucose_range[1], "mg/dL\n") # Clinical interpretation if(glucose_range[2] - glucose_range[1] > 50) { cat("⚠️ High variability detected - consider continuous monitoring\n") }
Copied!

Standard Deviation: The Gold Standard

# Calculate standard deviation glucose_sd <- sd(glucose_readings) glucose_mean <- mean(glucose_readings) cat("Mean glucose:", round(glucose_mean, 1), "mg/dL\n") cat("Standard deviation:", round(glucose_sd, 1), "mg/dL\n") # Coefficient of variation (CV) - relative variability cv <- (glucose_sd / glucose_mean) * 100 cat("Coefficient of variation:", round(cv, 1), "%\n") # Interpretation if(cv < 36) { cat("✓ Glucose control: STABLE\n") } else { cat("⚠️ Glucose control: UNSTABLE\n") }
Copied!
Learning Checkpoint

The first patient (SD = 45)

Incorrect. Higher SD means more variability, indicating poorer glucose control.
The second patient (SD = 15)

Correct! Lower SD indicates more consistent glucose levels, which is a sign of better diabetes control.

Incorrect. Glucose control isn't just about average levels but also consistency (variability).

Incorrect. SD directly measures variability, which is a key indicator of glucose control.

Variance: SD Squared

# Variance calculation glucose_var <- var(glucose_readings) cat("Variance:", round(glucose_var, 1), "(mg/dL)²\n") cat("Standard deviation:", round(sqrt(glucose_var), 1), "mg/dL\n") # Relationship between variance and SD cat("\nVerification: SD² =", round(glucose_sd^2, 1), "= Variance\n")
Copied!

💊 Clinical Application: In pharmacology, low variability in drug blood levels is crucial. High variability might indicate poor absorption, drug interactions, or non-compliance with medication schedules.

6.7.4. Percentiles in Clinical Assessment

Percentiles help us understand where a patient's values fall within a population. They're essential for growth charts, diagnostic thresholds, and risk stratification.

Understanding Percentiles

# Pediatric weight data (kg) for 5-year-olds weights <- c(14.5, 16.2, 17.8, 18.5, 19.2, 19.8, 20.5, 21.0, 21.8, 22.5, 23.2, 24.0, 25.5, 27.0, 29.5) # Calculate key percentiles percentiles <- quantile(weights, probs = c(0.05, 0.25, 0.50, 0.75, 0.95)) print(percentiles) # Interpret a specific child's weight child_weight <- 16.0 percentile_rank <- ecdf(weights)(child_weight) * 100 cat("\nA child weighing", child_weight, "kg is at the", round(percentile_rank, 0), "th percentile\n") if(percentile_rank < 5) { cat("⚠️ Below 5th percentile - evaluate for undernutrition\n") } else if(percentile_rank > 95) { cat("⚠️ Above 95th percentile - evaluate for obesity\n") } else { cat("✓ Within normal range\n") }
Copied!
Learning Checkpoint
If a patient's cholesterol level is at the 80th percentile, what does this mean?
Their cholesterol is 80% of normal
Percentage of normal value
Incorrect. Percentiles don't represent percentage of normal but position in the distribution.
80% of people have lower cholesterol than this patient
Position in population
Correct! The 80th percentile means this patient's cholesterol is higher than 80% of the reference population.
They have 80 mg/dL cholesterol
Absolute measurement
Incorrect. Percentiles indicate relative position, not absolute values.
Their risk is 80% higher than average
Risk assessment
Incorrect. Percentiles show position in distribution, not risk percentages.

Clinical Applications of Percentiles

# Blood lead levels in children (μg/dL) lead_levels <- c(0.5, 0.8, 1.2, 1.5, 1.8, 2.1, 2.5, 2.8, 3.2, 3.5, 3.8, 4.2, 4.5, 5.0, 5.5) # CDC reference level is 3.5 μg/dL (97.5th percentile) reference_percentile <- ecdf(lead_levels)(3.5) * 100 cat("3.5 μg/dL represents the", round(reference_percentile, 0), "th percentile in this sample\n") # Check how many children exceed reference exceed_reference <- sum(lead_levels >= 3.5) cat(exceed_reference, "children exceed CDC reference level\n") # Create risk categories for(i in 1:length(lead_levels)) { level <- lead_levels[i] ptile <- ecdf(lead_levels)(level) * 100 if(level < 3.5) { risk <- "Low" } else if(level < 5.0) { risk <- "Elevated" } else { risk <- "High" } cat("Child", i, ": ", level, "μg/dL (", round(ptile, 0), "th percentile) - Risk:", risk, "\n") }
Copied!

📊 Real-World Use: Percentiles are the foundation of pediatric growth charts. A child consistently below the 5th percentile for weight might need nutritional intervention, while one above the 95th percentile might need obesity prevention counseling.

Key Takeaways

Congratulations on mastering basic statistical functions in R! You've learned essential tools for medical data analysis:

  1. summary() Function: Your one-stop tool for comprehensive data overview, providing six key statistics at once.
  2. Mean vs Median:
    • Use mean for normally distributed data without outliers
    • Use median when outliers are present or data is skewed
    • In clinical practice, median often better represents typical patient experience
  3. Measures of Variability:
    • Range: Quick assessment of data spread
    • Standard Deviation: Gold standard for measuring consistency
    • Lower variability often indicates better clinical control
  4. Percentiles:
    • Essential for comparing patients to reference populations
    • Critical for pediatric growth assessment
    • Help identify patients needing intervention

🎯 Pro Tip: Always calculate multiple summary statistics. A complete picture requires understanding both central tendency (mean/median) and spread (SD/range). In precision medicine, this comprehensive approach helps identify subtle patterns that might indicate treatment response or disease progression.
