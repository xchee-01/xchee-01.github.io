4.2.1. Mission Briefing: Understanding DataFrames in Healthcare

What Are DataFrames? Your New Best Friend! 🤝

DataFrames are two-dimensional, labeled data structures that can hold different types of data in columns. Picture them as:

  • Smart spreadsheets that understand medical data
  • Digital patient charts that can perform calculations
  • Programmable databases that speak Python fluently

💡 Fun Fact: The name "DataFrame" comes from the statistical programming language R, but pandas made them famous in Python. It's like how kleenex became synonymous with tissues!

Not correct. While DataFrames can work with databases, they are in-memory data structures in Python, not database management systems themselves.

Why DataFrames Matter in Precision Medicine

In healthcare, data comes in all shapes and sizes:

  • Patient IDs (strings): "PT-2024-001"
  • Age (integers): 45 years
  • Blood pressure (floats): 120.5 mmHg
  • Test results (booleans): True/False for positive/negative

DataFrames handle this diversity like a pro! They're the backbone of:

  • Electronic Health Records (EHR) analysis
  • Clinical trial management
  • Genomic data processing
  • Population health studies

Your First DataFrame: Patient Vital Signs

Let's create our first DataFrame - think of it as building a mini hospital database:

# Create a simple DataFrame for patient vital signs patient_data = pd.DataFrame({ 'patient_id': ['P001', 'P002', 'P003'], 'age': [45, 32, 67], 'systolic_bp': [120, 135, 142], 'diastolic_bp': [80, 85, 90] }) print("Patient Vital Signs Dashboard:") print(patient_data)
Copied!

What's happening here? 🤔

  • Each key becomes a column name
  • Each list contains the values for that column
  • pandas automatically assigns row numbers (0, 1, 2)

💡 Tip Box: Always use descriptive column names! Future you (and your colleagues) will thank you when reviewing code six months later.

4.2.2. Mission Briefing: Creating DataFrames from Dictionaries

The Dictionary Method: Your Clinical Data's Best Friend 📚

Dictionaries are perfect for medical data because they mirror how we think about patient information:

  • Key = Medical measurement type
  • Value = List of measurements across patients

Think of it like a filing system where each drawer (key) contains files (values) for all patients!

Building a Clinical Trial DataFrame

Let's create a more complex DataFrame for a diabetes drug trial:

# Clinical trial data structure clinical_trial_data = { 'patient_id': ['PT101', 'PT102', 'PT103', 'PT104', 'PT105'], 'treatment_group': ['placebo', 'drug_A', 'placebo', 'drug_A', 'drug_A'], 'baseline_glucose_mg_dl': [95, 110, 88, 125, 105], 'week_4_glucose_mg_dl': [92, 98, 90, 102, 95], 'adverse_events': [False, False, False, True, False] } # Convert to DataFrame - like magic! ✨ trial_df = pd.DataFrame(clinical_trial_data) print("Clinical Trial Results:") print(trial_df)

4.2.3. Mission Briefing: Creating DataFrames from Lists

When Lists Make Life Easier 📝

Sometimes your data arrives as separate lists from different sources:

  • Lab instrument outputs
  • Database query results
  • API responses

Let's see how to combine them into a unified DataFrame!

Genomic Variant Analysis: Precision Medicine in Action

Imagine you're working at a cancer genomics lab. Different instruments give you separate data files:

# Data from different sequencing instruments sample_ids = ['GS001', 'GS002', 'GS003', 'GS004'] gene_names = ['BRCA1', 'BRCA2', 'TP53', 'EGFR'] variant_types = ['missense', 'frameshift', 'nonsense', 'missense'] pathogenicity_scores = [0.95, 0.99, 0.87, 0.76] # Method 1: Using zip() - like a zipper joining lists! genetic_variants_df = pd.DataFrame( list(zip(sample_ids, gene_names, variant_types, pathogenicity_scores)), columns=['sample_id', 'gene', 'variant_type', 'pathogenicity'] ) print("Genetic Variants Report:") print(genetic_variants_df)
Copied!
Code Analysis
When creating genetic_variants_df using zip(), what does list(zip(...)) produce before it's passed to pd.DataFrame()?
A single list with all values concatenated
['GS001', 'BRCA1', 'missense', 0.95, 'GS002', ...]
No, zip() doesn't concatenate. It creates tuples by pairing elements from each list at the same position.
A list of tuples, each containing one element from each list
[('GS001', 'BRCA1', 'missense', 0.95), ('GS002', 'BRCA2', 'frameshift', 0.99), ...]
Correct! zip() creates tuples by taking the first element from each list, then the second element from each list, and so on. Each tuple becomes a row in the DataFrame.
A dictionary with lists as values
{'sample_id': ['GS001', ...], 'gene': ['BRCA1', ...]}
That would be the dictionary method, not the zip() method. zip() creates tuples, not dictionaries.
Four separate lists unchanged
The original lists remain separate.
zip() combines the lists into tuples. It doesn't leave them separate.

Method 2: Direct List Assignment

Sometimes you need more control over your DataFrame creation:

# Method 2: Create empty DataFrame first, then add columns lab_results_df = pd.DataFrame() # Add columns one by one (useful when data arrives sequentially) lab_results_df['test_id'] = ['LAB001', 'LAB002', 'LAB003', 'LAB004'] lab_results_df['creatinine_mg_dl'] = [0.9, 1.2, 1.5, 0.8] lab_results_df['egfr_ml_min'] = [95, 68, 52, 102] lab_results_df['kidney_stage'] = ['normal', 'mild', 'moderate', 'normal'] print("Kidney Function Test Results:") print(lab_results_df)
Copied!

💡 Clinical Note: eGFR (estimated Glomerular Filtration Rate) is the gold standard for assessing kidney function. Values above 90 are normal, 60-89 indicate mild decrease, and below 60 suggests kidney disease.

Method 3: From a List of Lists

When your data comes as rows (common from database exports):

# Data as rows (each inner list is a patient record) patient_records = [ ['P101', 'Female', 45, 165, 68], ['P102', 'Male', 52, 178, 82], ['P103', 'Female', 38, 160, 55], ['P104', 'Male', 61, 175, 90] ] # Create DataFrame with explicit column names demographics_df = pd.DataFrame( patient_records, columns=['patient_id', 'gender', 'age', 'height_cm', 'weight_kg'] ) # Calculate BMI for each patient demographics_df['bmi'] = demographics_df['weight_kg'] / (demographics_df['height_cm'] / 100) ** 2 print("Patient Demographics with BMI:") print(demographics_df)
Copied!

# Complete solution for COVID-19 vaccine trial analysis participant_ids = ['VAC001', 'VAC002', 'VAC003', 'VAC004', 'VAC005'] age_groups = ['18-30', '31-50', '51-70', '18-30', '31-50'] dose_numbers = [2, 2, 3, 2, 3] antibody_levels = [980, 1250, 1890, 1100, 1650] side_effects = ['mild', 'none', 'mild', 'moderate', 'none'] # Create DataFrame using zip() method vaccine_trial_df = pd.DataFrame( list(zip(participant_ids, age_groups, dose_numbers, antibody_levels, side_effects)), columns=['participant_id', 'age_group', 'dose_numbers', 'antibody_levels', 'side_effects'] ) # Add high_response column vaccine_trial_df['high_response'] = vaccine_trial_df['antibody_levels'] > 1200 # Display results print("COVID-19 Vaccine Trial Results:") print(vaccine_trial_df) # Count participants with high antibody response high_responders = vaccine_trial_df['high_response'].sum() print(f"\nParticipants with high antibody response: {high_responders}") # Extra analysis: Response rate by dose number dose_analysis = vaccine_trial_df.groupby('dose_numbers')['high_response'].mean() print(f"\nResponse rate by dose number:") print(dose_analysis)
