Understanding Functions: Your Digital Medical Assistants

Learning Objective: Master R functions as essential tools for medical data analysis

In medical practice, we have specialized instruments for specific tasks - a stethoscope for heart sounds, a glucometer for blood sugar. Similarly, R functions are specialized tools that perform specific operations on your data.

Learning Checkpoint
# Convert fever reading from Celsius to Fahrenheit patient_temp_celsius <- 38.5 # Mild fever patient_temp_fahrenheit <- (patient_temp_celsius * 9/5) + 32 print(paste("Temperature:", patient_temp_fahrenheit, "°F")) # Output: Temperature: 101.3 °F # Analyze glucose readings glucose_readings <- c(95, 110, 125, 98, 105) # mg/dL mean_glucose <- mean(glucose_readings) print(paste("Average glucose:", mean_glucose, "mg/dL")) # Output: Average glucose: 106.6 mg/dL
Copied!
What function would you use to find the highest glucose reading from the glucose_readings vector?
mean(glucose_readings)
This calculates the average of all readings.
Not quite. The mean() function calculates the average, not the maximum value. For the highest reading, you need a different function.
max(glucose_readings)
This finds the highest value in the vector.
Correct! The max() function returns the highest value in a vector, which would be 125 mg/dL in this case.
sum(glucose_readings)
This adds all readings together.
That's not right. The sum() function adds all values together, which doesn't help identify the highest individual reading.
length(glucose_readings)
This counts how many readings there are.
Not correct. The length() function counts the number of elements, not their values. You need max() to find the highest value.

Mathematical Functions for Clinical Calculations

Pediatric Dosage Calculation
# Calculate pediatric drug dosage patient_weight_kg <- 25 # 7-year-old child drug_dose_per_kg <- 45 daily_dose <- patient_weight_kg * drug_dose_per_kg dose_per_administration <- daily_dose / 3 print(paste("Give:", round(dose_per_administration), "mg every 8 hours")) # Output: Give: 375 mg every 8 hours # Round to nearest pill strength calculated_dose <- 187.6 rounded_dose <- round(calculated_dose / 25) * 25 print(paste("Dispense:", rounded_dose, "mg tablets")) # Output: Dispense: 200 mg tablets
Copied!
What does the round() function do in the pediatric dosage calculation?
Increases the dose for safety
Always rounds up to ensure adequate dosing.
Incorrect. The round() function doesn't always round up - it rounds to the nearest integer based on standard rounding rules.
Rounds to the nearest whole number
Converts 375.0 to 375 for practical dosing.
Correct! The round() function rounds to the nearest integer, making the dose practical for real-world administration.
Reduces the dose for children
Automatically adjusts doses for pediatric patients.
Not right. The round() function only rounds numbers - it doesn't make clinical adjustments.
Converts mg to mL
Changes units for liquid medications.
Incorrect. The round() function doesn't convert units - it only rounds numerical values.

Statistical Functions for Lab Analysis

Statistical Analysis
# Analyze cholesterol levels cholesterol_levels <- c(180, 195, 210, 175, 220, 190, 205, 188) avg_cholesterol <- mean(cholesterol_levels) median_cholesterol <- median(cholesterol_levels) cholesterol_sd <- sd(cholesterol_levels) if(avg_cholesterol > 200) { print("⚠️ Elevated cholesterol - consider statin therapy") } else { print("✅ Cholesterol within acceptable range") }
Copied!
Why might median be preferred over mean for cholesterol analysis?
Less affected by outliers
One extremely high reading won't skew the median as much.
Excellent! The median is robust to outliers, making it ideal when a patient might have one unusually high or low reading.
Easier to calculate
The median requires less computation than mean.
Not correct. Both are easy to calculate in R, but median is preferred for its statistical properties, not computational simplicity.
Always lower than mean
Median gives more optimistic results for patients.
Incorrect. The median isn't always lower than the mean - it depends on the data distribution.
Required by medical guidelines
Clinical protocols mandate median over mean.
Not true. The choice between median and mean depends on the specific analysis needs, not mandated guidelines.

💊 Did You Know? The median is often more useful than the mean in medicine because it's not affected by extreme outliers!

Copied!
What does the tolower() function accomplish in the drug standardization example?
Prevents medication errors
Ensures all drug names match regardless of capitalization.
Excellent! By converting all variations to lowercase, tolower() prevents dangerous medication errors that could occur from case-sensitive mismatches.
Removes spaces from names
Cleans up drug names by removing whitespace.
Incorrect. The tolower() function only changes case, it doesn't remove spaces. Use trimws() for whitespace removal.
Abbreviates drug names
Shortens long medication names for convenience.
Not right. The tolower() function only converts to lowercase - it doesn't abbreviate or shorten text.
Validates drug names
Checks if drug names are in the formulary.
Incorrect. The tolower() function only changes text case - it doesn't validate against any database or list.
