Learning Checkpoint
What does the header = TRUE parameter do in read.csv()?
It creates a header row in the output
This would add a new header to the data.
Not quite. The parameter doesn't create new headers but tells R how to interpret the existing file structure.
It treats the first row as column names
R will use the first row for column naming.
Correct! The header = TRUE parameter tells R to use the first row of the CSV file as column names for the data frame.
It removes the header from the file
This would strip header information.
Incorrect. The parameter doesn't remove anything; it tells R how to interpret the first row.
It adds line numbers to the data
This would number each row.
That's not right. Row numbers are controlled by other parameters, not the header parameter.

Learning Checkpoint
Why do we use row.names = FALSE when writing CSV files for medical data?
To make the file smaller
This reduces file size by removing row names.
While it might save a tiny bit of space, this isn't the main reason for using this parameter with medical data.
To prevent R from adding row numbers as the first column
This stops automatic row numbering.
Correct! Setting row.names = FALSE prevents R from adding automatic row numbers (1, 2, 3...) as the first column, which could be confused with patient IDs.
To remove patient names for privacy
This protects patient information.
Not quite. Row names are different from patient data columns. This parameter only affects automatic row numbering.
To speed up the writing process
This makes file writing faster.
Incorrect. The performance difference is negligible. The main reason is to avoid confusion with data columns.

What does the na.strings parameter do in the clinical data reading example?
It removes all NA values from the dataset
This eliminates missing data entirely.
Incorrect. The parameter doesn't remove values, it just tells R how to recognize them as missing.
It converts specified strings to NA values in R
This identifies which text represents missing data.
Correct! The na.strings parameter tells R which text values in the file should be interpreted as NA (missing data), such as "Not tested" or empty strings.
It replaces NA values with empty strings
This converts missing data to blanks.
Not right. It works in the opposite direction - converting strings to NA, not NA to strings.
It counts the number of missing values
This provides a missing data summary.
Incorrect. This parameter only identifies what should be considered missing, not count them.

Learning Checkpoint
To calculate the average blood pressure reduction, which values should fill the blanks in avg_reduction <- _____ - _____?
final_avg - baseline_avg
Subtract baseline from final averages.
This would give a negative number since final BP is lower. We want a positive reduction value.
baseline_avg - final_avg
Subtract final from baseline averages.
Correct! The reduction is calculated as baseline_avg - final_avg to get a positive number representing how much the blood pressure decreased.
mean(baseline_bp) - mean(final_bp)
Calculate means of the columns directly.
These variables don't exist in the scope. We need to use the already calculated baseline_avg and final_avg.
trial_data$baseline_bp - trial_data$final_bp
Subtract entire columns element-wise.
This would give individual reductions for each patient, not the average reduction we need.
Learning Checkpoint
What should fill the blank in write.csv(_____, "trial_summary.csv", ...)?
trial_data
Export the raw trial data.
This would export all patient data, not the summary statistics we created.
summary_report
Export the summary statistics.
Correct! The summary_report data frame contains the summarized metrics that should be exported to the trial_summary.csv file.
responders
Export high responders data.
The responders data is exported separately to "high_responders.csv", not the summary file.
avg_reduction
Export just the reduction value.
This is just a single number, not the complete summary data frame we need to export.

Answer:

# Create sample data set.seed(42) trial_data <- data.frame( patient_id = paste0("PT", 1001:1050), baseline_bp = round(rnorm(50, mean = 152, sd = 10)), final_bp = round(rnorm(50, mean = 135, sd = 8)) ) # Calculate effectiveness baseline_avg <- mean(trial_data$baseline_bp) final_avg <- mean(trial_data$final_bp) avg_reduction <- baseline_avg - final_avg # Create summary summary_report <- data.frame( metric = c("Number of Patients", "Average Reduction"), value = c(nrow(trial_data), round(avg_reduction, 1)) ) # Export results write.csv(summary_report, "trial_summary.csv", row.names = FALSE) # Find high responders (>20 mmHg reduction) responders <- trial_data[trial_data$baseline_bp - trial_data$final_bp > 20, ] write.csv(responders, "high_responders.csv", row.names = FALSE)
