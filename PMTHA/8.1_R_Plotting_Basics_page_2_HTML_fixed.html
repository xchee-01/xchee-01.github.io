Mission Briefing: Visualizing Distributions with hist()

Histograms are like taking a "population snapshot" - they show how measurements distribute across many patients. Essential for spotting outliers and understanding "normal"!

Cholesterol Check-Up Day

Let's examine cholesterol levels from a company health screening:

# Generate realistic cholesterol data (mg/dL) set.seed(123) # For reproducibility cholesterol <- c(rnorm(200, mean = 200, sd = 30)) # Create histogram with meaningful breaks hist(cholesterol, main = "Distribution of Total Cholesterol in Patient Cohort", xlab = "Total Cholesterol (mg/dL)", col = "lightgreen", breaks = 15) # Add reference line for high cholesterol threshold abline(v = 240, col = "red", lwd = 2, lty = 2)

Reading the Health Story
Looking at the cholesterol histogram above, what does the red dashed line at 240 mg/dL represent?
The mean cholesterol level
The average cholesterol value across all patients.
Not quite right. The mean would be around 200 mg/dL based on our data generation. The red line is at 240 mg/dL, which represents something else.
The median cholesterol level
The middle value when all cholesterol levels are sorted.
That's not correct. The median would also be close to 200 mg/dL. The red line at 240 mg/dL has clinical significance.
The high cholesterol threshold
The clinical cutoff point above which cholesterol is considered high.
Correct! The red dashed line at 240 mg/dL represents the clinical threshold for high cholesterol, above which patients need intervention.
The standard deviation
A measure of spread in the cholesterol data.
Not correct. Standard deviation is a measure of spread (30 in our data), not a specific value like 240 mg/dL.
  • Most employees cluster around 200 (healthy!)
  • But look at that tail extending past 240...
  • Those folks need immediate intervention!
Lab Exercise 3: Analyzing Emergency Department Wait Times
In the histogram code, what does the breaks = 15 parameter control?
The width of the histogram bars
How wide each individual bar appears in the plot.
Not quite. The width is determined by the range of data divided by the number of breaks, not directly set by this parameter.
The number of bins in the histogram
How many bars the histogram will have to group the data.
Correct! The breaks parameter determines how many bins (bars) the histogram will have, affecting how the data is grouped and displayed.
The maximum value displayed
The highest value shown on the x-axis.
That's incorrect. The maximum value is determined by your data, not the breaks parameter.
The color intensity of the bars
How dark or light the histogram bars appear.
Not correct. Color is controlled by the col parameter, not breaks.

Your Mission: You're the new hospital administrator. The Board wants to know: "How long are patients waiting in our ER?" Time to investigate!

# Lab scenario: ED wait time analysis set.seed(456) # TODO: Create wait_times variable using rnorm() # Mean should be 45 minutes, standard deviation 15 # TODO: Create histogram with appropriate labels # TODO: Identify what percentage appear to wait over 60 minutes
Copied!

Solution:

set.seed(456) wait_times <- rnorm(100, mean = 45, sd = 15) wait_times[wait_times < 0] <- 5 # No negative wait times! hist(wait_times, main = "Emergency Department Wait Time Distribution", xlab = "Wait Time (minutes)", ylab = "Number of Patients", col = "coral", breaks = 10) # Add 60-minute threshold line abline(v = 60, col = "darkred", lwd = 2, lty = 2) # Calculate percentage over 60 minutes percent_over_60 <- sum(wait_times > 60) / length(wait_times) * 100 print(paste("Patients waiting over 60 minutes:", round(percent_over_60, 1), "%"))

Mission Briefing: Creating Box Plots for Group Comparisons

Box plots are like getting a "stat sheet" for each group - showing the median, spread, and outliers all at once. Perfect for comparing surgical techniques!

# Simulated recovery time data (days) for three surgical methods set.seed(789) method_a <- rnorm(30, mean = 5, sd = 1.5) # Traditional method_b <- rnorm(30, mean = 7, sd = 2) # Laparoscopic method_c <- rnorm(30, mean = 4, sd = 1) # Robotic # Combine into a list for boxplot recovery_data <- list( "Traditional" = method_a, "Laparoscopic" = method_b, "Robotic" = method_c ) # Create comparative boxplot boxplot(recovery_data, main = "Post-Surgical Recovery Time by Method", ylab = "Recovery Time (days)", col = c("lightcoral", "lightblue", "lightgreen"))
Copied!
Box Plot Decoder Ring
In a boxplot, what does the thick line inside each box represent?
The mean value
The average of all values in that group.
Not quite. While means are important, boxplots show a different measure of central tendency.
The median value
The 50th percentile or middle value of the data.
Correct! The thick line inside each box represents the median (50th percentile) of the data, showing the central tendency for each group.
The mode value
The most frequently occurring value.
That's incorrect. Boxplots don't show the mode (most frequent value).
The standard deviation
A measure of data spread or variability.
Not correct. Standard deviation isn't directly shown by the line, though the box size relates to spread.
  • Box center line: Median recovery time
  • Box edges: 25th and 75th percentiles
  • Whiskers: Range of typical values
  • Dots: Outlier patients
Surgical Method Comparison
Based on the surgical recovery boxplot code, which method would likely have the most consistent recovery times?
Traditional (method_a) with sd = 1.5
Traditional surgery approach with moderate variability.
Not quite. While sd = 1.5 is moderate, there's a method with even less variability.
Laparoscopic (method_b) with sd = 2
Minimally invasive approach with higher variability.
That's incorrect. This method has the highest standard deviation (sd = 2), meaning the most variability.
Robotic (method_c) with sd = 1
Advanced robotic-assisted surgery with low variability.
Correct! The Robotic method (method_c) has the smallest standard deviation (sd = 1), indicating the most consistent recovery times with less variability between patients.
All methods have equal consistency
The standard deviations don't affect consistency.
Not correct. The different standard deviations (1, 1.5, and 2) clearly show different levels of consistency.

Mission Briefing: The Power of Multiple Plots with par()

Time to create a "Patient Dashboard" - like mission control for someone's health! The par() function lets you display multiple vital signs at once.

Understanding par()
What does par(mfrow = c(2, 2)) accomplish in R?
Creates a 2x2 grid for multiple plots
Sets up a layout with 2 rows and 2 columns for displaying 4 plots.
Correct! The par(mfrow = c(2, 2)) command creates a 2x2 grid layout, allowing you to display 4 plots in one figure window.
Sets the plot size to 2 inches by 2 inches
Controls the physical dimensions of the plot area.
That's not correct. The numbers refer to rows and columns, not inches.
Displays only 2 data points
Limits the number of data points shown in the plot.
Not correct. This controls plot layout, not data points.
Repeats the same plot 4 times
Creates 4 identical copies of a single plot.
Incorrect. It creates space for 4 different plots, not copies of the same plot.
# Set up 2x2 plot layout par(mfrow = c(2, 2)) # Plot 1: Heart rate over time time <- 1:10 heart_rate <- c(78, 82, 79, 85, 88, 84, 80, 77, 75, 73) plot(time, heart_rate, type = "l", main = "Heart Rate Trend", ylab = "BPM", xlab = "Days") # Plot 2: Blood pressure systolic <- c(130, 128, 125, 122, 120, 118, 117, 115, 114, 112) plot(time, systolic, type = "b", main = "Systolic BP Trend", ylab = "mmHg", xlab = "Days") # Plot 3: Weight changes weight <- c(85, 84.5, 84.2, 83.8, 83.5, 83.2, 82.9, 82.7, 82.5, 82.3) plot(time, weight, type = "b", main = "Weight Loss Progress", ylab = "Weight (kg)", xlab = "Days") # Plot 4: Medication doses doses <- c(20, 20, 15, 15, 10, 10, 10, 5, 5, 5) barplot(doses, main = "Daily Medication Dose", ylab = "Dose (mg)", xlab = "Days") # Reset to single plot par(mfrow = c(1, 1))

Plot Type Parameters
In the patient dashboard code, what's the difference between type = "l" and type = "b"?
"l" creates lines only, "b" creates both points and lines
Different visualization styles for different data types.
Correct! In R plots, type = "l" creates lines only connecting the data points, while type = "b" creates both points and lines (both).
"l" means logarithmic, "b" means binary
Different mathematical transformations of the data.
Not correct. These letters refer to plot appearance, not mathematical transformations.
"l" is for left alignment, "b" is for bottom alignment
Controls where the plot elements are positioned.
That's incorrect. These control how data points are displayed, not alignment.
There is no difference
Both parameters produce identical plots.
Not correct. There's a clear visual difference between lines only and both points and lines.

Essential R Functions in Your Medical Toolkit
Which R function would you use to compare recovery times across different surgical methods?
hist()
Shows the distribution of a single variable.
Not quite. hist() is great for showing distributions of one variable, but not for comparing multiple groups side by side.
boxplot()
Compares distributions across multiple groups.
Correct! Boxplot() is ideal for comparing distributions across multiple groups, showing medians, quartiles, and outliers for each surgical method.
plot()
General purpose plotting function.
While plot() is versatile, it's not specifically designed for group comparisons like boxplot() is.
barplot()
Shows counts or frequencies as bars.
barplot() is better for categorical counts, not for showing the distribution of continuous recovery times.
  • plot() - Your go-to for tracking anything over time
  • barplot() - Perfect for comparing treatments or patient groups
  • hist() - Reveals population patterns and helps define "normal"
  • boxplot() - The ultimate comparison tool for clinical trials
  • par() - Creates professional dashboards
