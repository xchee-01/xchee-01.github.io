Mission Briefing: Boolean Values - The True/False of Medical Decisions

In medicine, you often deal with yes/no questions: Is the test positive? Is the treatment working? Does the patient have a fever? Python uses Boolean values to represent these true/false situations.

What Are Boolean Values?

Boolean values are simple - they can only be True or False (notice the capital letters!):

# The two Boolean values print(True) print(False)
Copied!

That's it! Just two possible values. But their simplicity makes them powerful for decision-making.

Using Boolean Values in Healthcare

Let's see how Boolean values apply to medical scenarios:

# Boolean values in a patient record has_diabetes = True is_allergic_to_penicillin = False fasting_completed = True print("Diabetes diagnosis:", has_diabetes) print("Penicillin allergy:", is_allergic_to_penicillin) print("Fasting before test:", fasting_completed)
Copied!

Think of Boolean values as those checkboxes on medical forms - they're either checked (True) or unchecked (False).

Creating Boolean Values with Comparisons

One of the most common ways to create Boolean values is through comparisons. These comparison operators evaluate a condition and return either True or False:

# Simple comparisons print(5 > 3) # Is 5 greater than 3? print(10 < 7) # Is 10 less than 7? print(4 == 4) # Is 4 equal to 4? print(5 != 5) # Is 5 not equal to 5?
Copied!

Let's see how comparisons help in medical contexts:

# Medical comparisons temperature = 38.5 heart_rate = 72 blood_glucose = 5.4 has_fever = temperature > 37.5 tachycardia = heart_rate > 100 normal_glucose = 4.0 <= blood_glucose <= 7.0 print("Fever present:", has_fever) print("Tachycardia present:", tachycardia) print("Glucose in normal range:", normal_glucose)
Copied!

Combining Boolean Values with Logical Operators

In medicine, you often need to consider multiple factors together. Python provides logical operators to combine Boolean values:

# The three logical operators a = True b = False print("a AND b:", a and b) # True only if both are True print("a OR b:", a or b) # True if at least one is True print("NOT a:", not a) # Inverts the value
Copied!

Let's apply these to a clinical scenario:

# Clinical decision support example fever = True cough = True shortness_of_breath = False contact_with_covid = True # Clinical criteria covid_suspected = fever and (cough or shortness_of_breath) needs_testing = covid_suspected or contact_with_covid needs_immediate_care = fever and shortness_of_breath print("COVID suspected:", covid_suspected) print("Testing recommended:", needs_testing) print("Immediate care needed:", needs_immediate_care)
Copied!

Clinical Insight: Electronic health records use Boolean logic to trigger alerts when certain combinations of symptoms, lab values, or medications indicate potential issues.

Mission Briefing: Type Conversion - Transforming Your Medical Data

In healthcare, information comes from many different sources: electronic forms, lab systems, medical devices, and more. Often, you'll need to convert data from one type to another to work with it effectively.

Why Do We Need Type Conversion?

Imagine you have a patient's age entered as "42" (a string) but need to calculate dosage based on age. You can't do math with text! This is where type conversion comes in.

Let's start with the basic conversion functions:

# Basic type conversion functions print(int(5.7)) # Convert float to integer (removes decimal) print(float(5)) # Convert integer to float (adds decimal) print(str(5)) # Convert number to string (adds quotes)
Copied!

Converting to Integers with int()

The int() function converts values to integers:

# Converting to integers print(int(10.7)) # Float to integer (truncates, doesn't round) print(int("25")) # String to integer print(int(True)) # Boolean to integer (True becomes 1) print(int(False)) # Boolean to integer (False becomes 0)
Copied!

Caution: int() doesn't round - it truncates. So int(10.7) becomes 10, not 11.

Converting to Floats with float()

The float() function converts values to floating-point numbers:

# Converting to floats print(float(10)) # Integer to float print(float("25.5")) # String to float print(float("25")) # String to float print(float(True)) # Boolean to float (True becomes 1.0)
Copied!

Converting to Strings with str()

The str() function converts values to strings:

# Converting to strings print(str(10)) # Integer to string print(str(25.5)) # Float to string print(str(True)) # Boolean to string
Copied!

Type Conversion in Healthcare Applications

Let's see how type conversion helps in medical applications:

# Patient data from a form (strings) patient_id = "P12345" age_input = "45" temperature_input = "98.6" diabetic_input = "1" # 1 for Yes, 0 for No # Convert to appropriate types for processing age = int(age_input) temperature = float(temperature_input) is_diabetic = bool(int(diabetic_input)) # Convert to int first, then bool # Now we can use the data for calculations age_in_months = age * 12 temperature_celsius = (temperature - 32) * 5/9 # Display processed patient information print("Patient:", patient_id) print("Age:", age, "years (", age_in_months, "months )") print("Temperature:", temperature, "°F (", round(temperature_celsius, 1), "°C )") print("Diabetic:", is_diabetic)
Copied!
Learning Checkpoint
Why did we use bool(int(diabetic_input)) instead of just bool(diabetic_input) in the healthcare example above?
Because any non-empty string (including "0") would become True
We need to convert the string to an integer first, so that "0" becomes the integer 0, which then becomes False when converted to a boolean.
Correct! In Python, any non-empty string, including "0", will convert to True when passed directly to bool(). By converting to an integer first, we ensure that the string "0" becomes the integer 0, which then correctly converts to False.
It's just a coding preference
Either approach would work the same way, but this is more explicit.
Not correct. The two approaches actually produce different results. If diabetic_input is "0", then bool("0") would be True (since it's a non-empty string), but bool(int("0")) would be False.
To handle errors
Using int() first prevents errors when converting strings to booleans.
Not correct. Python doesn't generate errors when converting strings to booleans using bool(). The issue is that all non-empty strings convert to True, including "0", which is not what we want in this context.

Key points to remember:
  • int() truncates floats (doesn't round) and can convert numeric strings, but not non-numeric text.
  • float() can convert integers and numeric strings (with or without decimals).
  • str() can convert virtually any value to a string representation.
  • Type conversion errors occur when the conversion doesn't make logical sense (like trying to convert "abc" to an integer).
