Variables and Basic Concepts

Variables and command substitution are fundamental Linux skills. This module covers variable basics, naming rules, and types.

10.4.1. Shell Variables: Your Digital Sticky Notes 📝

Variables store information for later use:

# Creating variables (NO spaces around =) MY_NAME="Linux Learner" FAVORITE_DIR="/home/projects" COUNT=5 # Accessing with $ echo $MY_NAME # Output: Linux Learner echo "Count: $COUNT"
Copied!

Try This:

FAV_CMD="ls -la" echo "My favorite: $FAV_CMD"
Copied!

10.4.2. Variable Naming Rules

✅ Good Names:

user_count=42 # Snake case userName="Alice" # Camel case LOG_LEVEL="DEBUG" # Uppercase constants _temp=100 # Underscore start
Copied!

❌ Bad Names:

user-count=42 # No hyphens 2fast="movie" # No number start my var=42 # No spaces my$var="oops" # No special chars
Copied!

10.4.3. Environment vs Shell Variables

Shell Variables (local):

my_var="local" bash # New shell echo $my_var # Empty!
Copied!

Environment Variables (global):

export APP_NAME="MyApp" export DB_PORT="5432" bash -c 'echo $APP_NAME' # Works!
Copied!

System Variables:

echo $HOME # Home directory echo $USER # Username echo $PATH # Command locations echo $PWD # Current directory
Copied!

10.4.4. Special Variables

Variable Purpose
$? Last command exit status (0=success)
$$ Current process ID
$0 Script/shell name
$# Argument count
$USER Current username
$RANDOM Random number (0-32767)

Exit Status Example:

ls /etc/passwd echo $? # 0 (success) ls /not/exist 2>/dev/null echo $? # Non-zero (failure)
Copied!

Lab Exercise 3: Process Monitoring Script

Create a system monitoring script for the medical research facility that uses special variables to track processes and check command success.

# Lab scenario: Build a process monitoring script using special variables # Replace the ... with appropriate special variables echo "=== System Monitor Starting ===" echo "Monitor PID: ..." # Show this script's process ID echo "Running as user: ..." # Show current username echo "Script name: ..." # Show the script/shell name # Check if a critical service is running ps aux | grep mysql > /dev/null SERVICE_STATUS=... # Capture the exit status if [ $SERVICE_STATUS -eq 0 ]; then echo "MySQL service: RUNNING" else echo "MySQL service: NOT RUNNING" fi # Generate a log file with random ID LOG_ID=... # Use random number variable echo "Log file: /tmp/monitor_${LOG_ID}.log"
Copied!

Expected output (example):

=== System Monitor Starting === Monitor PID: 12345 Running as user: medtech_admin Script name: bash MySQL service: RUNNING Log file: /tmp/monitor_8472.log

Answer:

# Complete solution echo "=== System Monitor Starting ===" echo "Monitor PID: $$" # Show this script's process ID echo "Running as user: $USER" # Show current username echo "Script name: $0" # Show the script/shell name # Check if a critical service is running ps aux | grep mysql > /dev/null SERVICE_STATUS=$? # Capture the exit status if [ $SERVICE_STATUS -eq 0 ]; then echo "MySQL service: RUNNING" else echo "MySQL service: NOT RUNNING" fi # Generate a log file with random ID LOG_ID=$RANDOM # Use random number variable echo "Log file: /tmp/monitor_${LOG_ID}.log"
Copied!
