9.1.1. Introduction to Linux and the Terminal Shell

What is Linux?

Linux is an open-source operating system that forms the backbone of modern scientific computing. In precision medicine, Linux systems power:

  • 96.3% of top web servers hosting biomedical databases
  • All major genomic sequencing and analysis platforms
  • High-performance computing clusters for drug discovery
  • Cloud infrastructure for healthcare data processing

Key Concept: Linux is the operating system kernel. Distributions like Ubuntu, CentOS, and Fedora build complete systems around this kernel, each optimized for different use cases in scientific computing.

The Terminal Shell - Your Command Interface

The terminal (also called command line or shell) is your direct interface to Linux. In bioinformatics workflows, the terminal allows you to:

  • Process thousands of genomic files with a single command
  • Automate repetitive analysis tasks
  • Access remote high-performance computing clusters
  • Chain multiple tools into analysis pipelines

GUI vs Terminal for Scientific Computing:

  • GUI: Like using pre-configured analysis templates - limited options
  • Terminal: Like writing custom analysis protocols - complete flexibility

The shell translates your commands into system actions. Most Linux distributions use Bash (Bourne Again Shell) as the default shell.

Your First Commands

Let's start with essential commands that you'll use daily in bioinformatics work:

# Check current date and time (important for logging analyses) date # Display your username (crucial for file permissions) whoami # Show system hostname (useful for cluster computing) hostname # Display Linux distribution information cat /etc/os-release # Check your current shell echo $SHELL # Display Bash version bash --version

Real-World Connection: Major genomics centers like the Broad Institute and Sanger Institute run their entire sequencing pipelines on Linux clusters, processing petabytes of genetic data daily.

9.1.2. Command Structure and Documentation

Understanding Command Structure

Linux commands follow a consistent pattern, similar to how scientific protocols have standard formats:

command [options] [arguments] # Real bioinformatics examples: samtools view -b -S input.sam > output.bam blastn -query sequence.fasta -db nr -outfmt 6
Copied!

Components explained:

  • Command: The program you want to run (e.g., `ls`, `samtools`, `blastn`)
  • Options: Modify command behavior, start with `-` (short) or `--` (long)
  • Arguments: The targets or inputs for the command (files, directories, etc.)

Common option patterns in bioinformatics tools:

# Short vs long options (they do the same thing) ls -a # Short form ls --all # Long form # Common bioinformatics tool options bwa mem -t 8 # Use 8 threads fastqc --quiet # Suppress progress messages gatk --java-options "-Xmx4g" # Allocate 4GB memory
Copied!
Learning Checkpoint
In the command samtools sort -@ 4 -o sorted.bam unsorted.bam, what is unsorted.bam?
The command
The main program being executed.
Not correct. The command is `samtools`, not the BAM file.
An option
A modifier that changes command behavior.
Incorrect. Options start with `-` or `--`. This is a filename.
An argument
The input file for the sorting operation.
Correct! `unsorted.bam` is the argument specifying which alignment file samtools should sort.
The output file
Where the sorted data will be saved.
Not right. The output file is specified with `-o sorted.bam`.

Getting Help and Documentation

In bioinformatics, understanding tool documentation is crucial. Linux provides multiple ways to access help:

# Comprehensive manual pages man ls # Full documentation man samtools # Bioinformatics tool manual # Quick help (most bioinformatics tools support this) bwa --help # BWA aligner help fastqc --help # FastQC help ls --help # Quick command reference # Brief description of a command whatis pwd # One-line description whatis blastn # BLAST tool description # Search for commands by keyword apropos "sequence" # Find sequence-related tools apropos "align" # Find alignment tools
Copied!

Navigating Manual Pages:

  • ↑/↓ arrows = scroll line by line
  • Space = next page
  • b = previous page
  • /searchterm = search forward
  • ?searchterm = search backward
  • q = quit manual
Learning Checkpoint
You need to find all installed tools related to "genome" analysis. Which command would help?
man genome
Show the manual for the genome command.
This would only work if there's a command called "genome", not for finding related tools.
apropos "genome"
Search for all commands with "genome" in their description.
Correct! The `apropos` command searches through all command descriptions to find tools related to your keyword.
whatis genome
Show a brief description of the genome command.
`whatis` shows descriptions of specific commands, not searches for related tools.
genome --help
Show help for the genome command.
This assumes "genome" is a command, but we want to search for genome-related tools.

9.1.3. Command History and Workflow Efficiency

Leveraging Command History

In bioinformatics, you often need to repeat or modify complex commands. Linux provides powerful history features to boost your productivity:

# View your complete command history history # Show last 10 commands (useful for reviewing recent work) history 10 # Execute the last command again !! # Execute command number 42 from history !42 # Execute the last command starting with "samtools" !samtools # Search command history interactively # Press Ctrl+R, then type to search Ctrl+R # Clear history (use cautiously!) history -c
Copied!

Productivity Tips for Bioinformatics:

  • Use ↑ and ↓ arrows to navigate through recent commands
  • Ctrl+R is invaluable for finding that complex pipeline command you ran last week
  • Save frequently used commands in a text file for reference
  • Use `history | grep samtools` to find all your samtools commands
Learning Checkpoint
You just ran a complex BLAST command with many parameters. What's the quickest way to run it again?
Retype the entire command
Manually enter all parameters again.
This works but is inefficient and error-prone. Linux offers faster methods.
Type !!
Execute the immediately previous command.
Correct! The `!!` shortcut immediately re-executes the last command, perfect for rerunning analyses with the same parameters.
Type history
View the history list.
This shows history but doesn't execute anything. You'd still need to copy or retype.
Restart the terminal
Close and reopen to refresh.
This would actually lose your immediate history. Not helpful!

Pro Tip: Many bioinformaticians create aliases for frequently used long commands. For example: `alias blastx='blastx -db nr -num_threads 8 -outfmt 6'` makes running BLASTX searches much faster!
