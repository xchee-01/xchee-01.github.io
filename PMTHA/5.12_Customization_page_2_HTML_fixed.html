🔬 Mission Briefing: Advanced Styling with Matplotlib Styles and RC Parameters

The Secret to Consistency: Style Sheets and RC Parameters 🎨

Imagine you're writing a paper with 15 figures. Figure 1 has Arial font, Figure 2 uses Times New Roman, Figure 3 has a gray background, Figure 4 is on white... Reviewers would think you have multiple personality disorder! 😅

This is where matplotlib's style sheets and RC (Runtime Configuration) parameters save the day. Think of them as "visual protocols" for your lab—ensuring every plot follows the same standards, just like how every Western blot in your lab uses the same antibody dilutions.

Correct! The syntax gs[0, :2] creates a subplot that spans the first row (index 0) and the first two columns (from index 0 to 1, as :2 means up to but not including 2). This creates a wider subplot that takes up two column spaces.

Incorrect. This syntax creates a single subplot that spans multiple grid positions, not multiple separate subplots.

That's not right. The colon notation :2 indicates a range (from start to 2), not a specific position. To place at position (0, 2), you would use gs[0, 2].

Clinical trial data weeks = np.array([0, 2, 4, 6, 8, 10, 12]) biomarker_placebo = np.array([100, 98, 102, 99, 101, 103, 100]) biomarker_treatment = np.array([100, 85, 72, 58, 45, 38, 32]) side_effects_placebo = np.array([2, 3, 2, 4, 3, 3, 2]) side_effects_treatment = np.array([2, 5, 8, 7, 6, 5, 4]) # Calculate error bars (SEM) biomarker_placebo_sem = biomarker_placebo * 0.05 biomarker_treatment_sem = biomarker_treatment * 0.05 side_effects_placebo_sem = side_effects_placebo * 0.3 side_effects_treatment_sem = side_effects_treatment * 0.3 # Patient numbers (simulating dropout) n_placebo = [150, 148, 145, 142, 140, 138, 135] n_treatment = [150, 147, 143, 139, 136, 133, 130] # Create multi-panel figure fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(8, 10), sharex=True, gridspec_kw={'height_ratios': [1.2, 1]}) # Add sample sizes above data points for i, week in enumerate(weeks): ax1.text(week, 108, f'{n_placebo[i]}', ha='center', va='bottom', fontsize=8, color='#7F8C8D') ax1.text(week, biomarker_treatment[i] + biomarker_treatment_sem[i] + 3, f'{n_treatment[i]}', ha='center', va='bottom', fontsize=8, color='#E74C3C') # Primary Endpoint: Serum Biomarker Response', fontsize=12, loc='left', pad=10) ax1.grid(True, alpha=0.3, linestyle='--') ax1.legend(loc='upper right', frameon=True, shadow=True, fontsize=10) ax1.set_ylim(20, 115) # Add clinical significance threshold ax1.axhline(y=50, color='green', linestyle=':', linewidth=2, alpha=0.5) ax1.text(0.5, 52, 'Clinical response threshold', fontsize=9, color='green', style='italic') # Panel B: Safety profile (Secondary Endpoint) width = 0.35 x = np.arange(len(weeks)) # Create bars with error bars bars1 = ax2.bar(x - width/2, side_effects_placebo, width, yerr=side_effects_placebo_sem, capsize=4, label='Placebo', color='#7F8C8D', alpha=0.8, edgecolor='black', linewidth=1.5, error_kw={'linewidth': 1.5, 'capthick': 1.5}) bars2 = ax2.bar(x + width/2, side_effects_treatment, width, yerr=side_effects_treatment_sem, capsize=4, label='Treatment', color='#E74C3C', alpha=0.8, edgecolor='black', linewidth=1.5, error_kw={'linewidth': 1.5, 'capthick': 1.5}) # Highlight weeks with concerning side effects for i, (se_placebo, se_treatment) in enumerate(zip(side_effects_placebo, side_effects_treatment)): if se_treatment > 6: # Threshold for concern ax2.add_patch(plt.Rectangle((i-0.5, 0), 1, 12, facecolor='red', alpha=0.1)) # Add safety threshold ax2.axhline(y=10, color='red', linestyle=':', linewidth=2, label='Safety threshold', alpha=0.7) # Annotations and styling ax2.set_ylabel('Adverse Events\n(count per 100 patients)', fontsize=12) ax2.set_xlabel('Study Week', fontsize=12) ax2.set_title('B.
