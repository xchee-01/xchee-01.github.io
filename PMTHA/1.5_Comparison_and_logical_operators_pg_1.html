🔬 Mission Briefing: The Art of Exact Comparison

Before we dive into medical mysteries, let's master the most basic detective tools: equality operators. Think of these as your magnifying glass for examining whether two pieces of data are exactly the same or different.

Your First Detective Tools:

  • == (equals): "Are these exactly the same?"
  • != (not equals): "Are these different?"

These might look simple, but they're the backbone of medical safety systems worldwide!

Let's start with something simple before we get to the medical stuff:

# Basic comparison - like checking if two puzzle pieces match piece_a = 5 piece_b = 5 pieces_match = piece_a == piece_b print("Do the pieces match?", pieces_match)

Complete Solution:

# Complete solution - Hospital Identity Verification System # Patient registration information patient_first_name = "Maria" patient_last_name = "Rodriguez" patient_dob = "1985-07-22" patient_mrn = "MRN-789456" # Information from hospital database stored_first_name = "Maria" stored_last_name = "Rodriguez" stored_dob = "1985-07-22" stored_mrn = "MRN-789456" # Individual verification checks using == for exact matches first_name_matches = patient_first_name == stored_first_name # True last_name_matches = patient_last_name == stored_last_name # True dob_matches = patient_dob == stored_dob # True mrn_matches = patient_mrn == stored_mrn # True # Error detection using != to identify discrepancies name_error = first_name_matches != last_name_matches # False (both are True) date_error = patient_dob != stored_dob # False (they match) critical_error = patient_mrn != stored_mrn # False (they match) print("🏥 PATIENT IDENTITY VERIFICATION REPORT") print("=" * 45) print(f"First name verification: {first_name_matches}") # True print(f"Last name verification: {last_name_matches}") # True print(f"Date of birth verification: {dob_matches}") # True print(f"Medical record number verification: {mrn_matches}") # True print() print("ERROR DETECTION:") print(f"Name discrepancy detected: {name_error}") # False print(f"Date discrepancy detected: {date_error}") # False print(f"Critical MRN mismatch: {critical_error}") # False
Copied!

Key Learning Points:

  • Use == to verify exact matches (positive verification)
  • Use != to detect discrepancies (error detection)
  • All verifications are True = patient identity confirmed
  • All errors are False = no discrepancies detected
  • This patient can safely proceed with treatment!

🧪 Lab Exercise 2: Laboratory Result Verification

🔬 Scenario

You're working in a clinical laboratory where accuracy is paramount. Create a system to verify that lab results are correctly transcribed and processed.

The Challenge:

Sometimes lab results get transcribed incorrectly or processed through different systems. Your job is to catch these errors before they reach physicians.

# Lab result from testing machine machine_patient_id = "LAB-2024-5501" machine_test_name = "Complete Blood Count" machine_result_value = "12.5" machine_units = "g/dL" machine_reference_range = "12.0-15.5" # Lab result from manual transcription manual_patient_id = "LAB-2024-5501" manual_test_name = "Complete Blood Count" manual_result_value = "12.8" # Transcription error! manual_units = "g/dL" manual_reference_range = "12.0-15.5" # Exercise: Complete the verification system # Fill in the appropriate operators patient_id_correct = machine_patient_id ___ manual_patient_id test_name_correct = machine_test_name ___ manual_test_name result_value_error = machine_result_value ___ manual_result_value units_correct = machine_units ___ manual_units reference_correct = machine_reference_range ___ manual_reference_range print("🔬 LABORATORY RESULT VERIFICATION") print("=" * 40) print(f"Patient ID matches: {patient_id_correct}") print(f"Test name matches: {test_name_correct}") print(f"Result value discrepancy: {result_value_error}") print(f"Units match: {units_correct}") print(f"Reference range matches: {reference_correct}") print() # Overall quality check transcription_error_detected = result_value_error # Any discrepancy is concerning print(f"🚨 Transcription error detected: {transcription_error_detected}") if transcription_error_detected: print("⚠️ ACTION REQUIRED: Verify original lab result before reporting!") else: print("✅ All verifications passed - result approved for reporting")
