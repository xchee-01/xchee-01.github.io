Strategic Missing Data Removal

The Surgical Approach to Data Cleaning

Instead of using a sledgehammer (removing all incomplete records), let's learn to use a scalpel. In clinical trials, we often care most about specific outcomes.

Threshold-Based Quality Control

🧪 Interactive Lab: Quality Control Checkpoint

Scenario: You're running a genomic study. The lab director says: "Keep only patients with at least 70% complete data."

def clean_by_completeness_threshold(dataframe, threshold_percent=70): """ Remove rows that have less than threshold_percent of complete data Think of this as a quality control checkpoint! """ # Step 1: How many columns do we have? n_columns = len(dataframe.columns) print(f"📊 Checking {n_columns} data points per patient...") # Step 2: What's our minimum bar? min_complete = n_columns * (threshold_percent / 100) print(f"🎯 Minimum required: {min_complete:.1f} complete fields") # Step 3: Count complete data per patient complete_per_row = dataframe.count(axis=1) # Count non-null values per row # Step 4: Who passes our quality check? quality_mask = complete_per_row >= min_complete # Create boolean mask # Step 5: Filter the dataframe df_quality = dataframe[quality_mask] # Apply the mask # Report results print(f"\n✅ Quality filter results:") print(f" Patients meeting {threshold_percent}% threshold: {len(df_quality)}") print(f" Patients excluded: {len(dataframe) - len(df_quality)}") print(f" Data retention rate: {(len(df_quality)/len(dataframe))*100:.1f}%") return df_quality # Test with our clinical trial data print("🧪 Testing threshold-based cleaning:") df_clean = clean_by_completeness_threshold(df_trial, threshold_percent=70) print("\n📋 Cleaned dataset:") print(df_clean)
Copied!

🔬 Research Tip: In real clinical studies, the completeness threshold often depends on regulatory requirements. FDA submissions typically require very high data completeness (>90%), while exploratory research might accept lower thresholds.

Smart Data Imputation

Filling Gaps with Medical Intelligence

Sometimes, instead of removing data, we can intelligently fill in the gaps using medical knowledge and statistical methods.

# Create a dataset with missing age values patient_data_age = { 'patient_id': ['P001', 'P002', 'P003', 'P004', 'P005'], 'age': [45, None, 62, None, 58], 'disease_severity': ['Mild', 'Moderate', 'Severe', 'Mild', 'Moderate'], 'treatment_duration_days': [30, 45, 90, 25, 60] } df_patients_age = pd.DataFrame(patient_data_age) print("📊 Dataset with missing ages:") print(df_patients_age) # Method 1: Fill with median age (statistically sound) median_age = df_patients_age['age'].median() df_patients_age['age_median_filled'] = df_patients_age['age'].fillna(median_age) print(f"\n🧮 Median age: {median_age}") print("✅ After median imputation:") print(df_patients_age[['patient_id', 'age', 'age_median_filled']]) # Method 2: Forward fill (carry last observation forward) # Using modern pandas syntax (ffill() instead of fillna(method='ffill')) df_patients_age['age_ffill'] = df_patients_age['age'].ffill() print("\n📈 After forward fill:") print(df_patients_age[['patient_id', 'age', 'age_ffill']])
Copied!

Advanced Imputation: Group-Based Strategies

# Create a more complex dataset complex_data = { 'patient_id': ['P001', 'P002', 'P003', 'P004', 'P005', 'P006'], 'age': [45, None, 62, None, 58, 71], 'disease_severity': ['Mild', 'Mild', 'Severe', 'Mild', 'Severe', 'Severe'], 'bmi': [24.5, 23.8, None, 25.1, None, 28.9] } df_complex = pd.DataFrame(complex_data) # Group-based median imputation # Fill missing ages based on disease severity group df_complex['age_group_filled'] = df_complex.groupby('disease_severity')['age'].transform( lambda x: x.fillna(x.median()) ) print("🧬 Smart imputation by disease severity:") print(df_complex[['patient_id', 'disease_severity', 'age', 'age_group_filled']]) # The mild group median: (45 + 58) / 2 = 51.5 → fills P002 and P004 # The severe group median: (62 + 71) / 2 = 66.5
Copied!
Learning Checkpoint
Which imputation method is generally MOST appropriate for filling missing age values in a medical dataset?
Fill with zero
A simple approach that sets all missing ages to 0.
Zero age is not medically meaningful and would severely bias any analysis.
Fill with median age
Use the middle value of all known ages.
Correct! Median is robust to outliers and provides a statistically sound central tendency for age imputation.
Fill with maximum age
Use the highest age value in the dataset.
Using maximum age would bias the dataset toward older patients and distort age-related analyses.
Forward fill
Carry the last known observation forward.
Forward fill assumes temporal order, which isn't meaningful for age imputation across different patients.
