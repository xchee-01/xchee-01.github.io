8.2.3. Legends and Annotations in Clinical Context

Think of legends and annotations as the narrator in a medical drama. Without them, your audience is left guessing. Good annotations transform data into insights!

Learning Checkpoint
Why are legends and annotations critical in medical visualizations?
To make plots colorful
They add visual appeal to otherwise boring charts.
Not quite. While aesthetics matter, the primary purpose of legends and annotations goes beyond visual appeal. They provide essential context for interpreting clinical data accurately.
To provide clinical context
They enable accurate interpretation of medical data and clinical significance.
Excellent! Legends and annotations provide crucial context like sample sizes, drug doses, clinical thresholds, and statistical significance - all essential for making informed medical decisions.
To fill empty space
They help balance the plot layout when there's too much white space.
That's not correct. Legends and annotations serve a critical functional purpose in medical visualizations, not aesthetic filler. They communicate vital information about treatments, outcomes, and statistical significance.
To impress colleagues
They demonstrate advanced R programming skills.
While well-crafted visualizations do reflect skill, the primary purpose is functional. In medical contexts, clear annotations can be the difference between correct and incorrect clinical interpretations.

Creating a Multi-Arm Clinical Trial Masterpiece

Let's visualize a cholesterol-lowering drug trial:

# The Great Cholesterol Showdown! months <- c(0, 1, 3, 6) placebo <- c(220, 218, 215, 212) statin_low <- c(220, 195, 175, 165) statin_high <- c(220, 185, 160, 145) new_drug <- c(220, 180, 150, 130) # Create base plot plot(months, placebo, type = "n", xlim = c(0, 6), ylim = c(120, 230), xlab = "Months of Treatment", ylab = "LDL Cholesterol (mg/dL)", main = "Comparative Efficacy: Cholesterol-Lowering Therapies") # Plot all treatment groups lines(months, placebo, col = "gray40", lwd = 3, lty = 1) points(months, placebo, col = "gray40", pch = 15, cex = 1.5) lines(months, statin_low, col = "blue", lwd = 3, lty = 2) points(months, statin_low, col = "blue", pch = 16, cex = 1.5) lines(months, statin_high, col = "darkblue", lwd = 3, lty = 2) points(months, statin_high, col = "darkblue", pch = 17, cex = 1.5) lines(months, new_drug, col = "darkgreen", lwd = 3, lty = 1) points(months, new_drug, col = "darkgreen", pch = 18, cex = 1.5) # Add clinical thresholds abline(h = 190, col = "orange", lty = 3, lwd = 2) text(0.5, 195, "High Risk Threshold", col = "orange", cex = 0.8, font = 2) abline(h = 160, col = "red", lty = 3, lwd = 2) text(0.5, 165, "Very High Risk", col = "red", cex = 0.8, font = 2) abline(h = 130, col = "darkgreen", lty = 3, lwd = 2) text(0.5, 135, "Target LDL", col = "darkgreen", cex = 0.8, font = 2)
Copied!

This level indicates very high cardiovascular risk requiring aggressive treatment.
Correct! LDL cholesterol above 160 mg/dL is considered very high risk, requiring immediate intervention with lifestyle changes and medication to prevent cardiovascular events.

This is the high risk threshold requiring medical attention.
That's the high risk threshold (orange line), not the very high risk level. The very high risk threshold is lower at 160 mg/dL (red line).

That's the starting cholesterol level for all patients, not a risk threshold. The very high risk threshold is marked at 160 mg/dL.

Learning Checkpoint
In the legend() function, what does the parameter 'lty' control?
Line thickness
It sets how thick the lines appear in the plot.
Not quite. Line thickness is controlled by 'lwd' (line width). The 'lty' parameter controls something else about the line appearance.
Line type
It determines whether lines are solid, dashed, dotted, etc.
Excellent! 'lty' stands for line type. In our example, lty=1 creates solid lines (placebo and novel drug) while lty=2 creates dashed lines (both statin doses).
Line color
It specifies the color of each line in the legend.
That's not right. Line color is controlled by the 'col' parameter. The 'lty' parameter affects the line style pattern.
Legend title
It sets the title text that appears above the legend.
Incorrect. The legend title is set using the 'title' parameter. 'lty' is related to line appearance, not text.
# Add statistical significance text(6, placebo[4] + 5, "ns", cex = 0.8, font = 2) text(6, statin_low[4] + 5, "*", cex = 1.5, font = 2) text(6, statin_high[4] + 5, "**", cex = 1.5, font = 2) text(6, new_drug[4] + 5, "***", cex = 1.5, font = 2) mtext("*p<0.05, **p<0.01, ***p<0.001 vs placebo", side = 1, line = 4, cex = 0.7, adj = 1)

Learning Checkpoint
What does "***" above the novel PCSK9i treatment indicate?
Three doses tested
The drug was tested at three different dose levels.
Not correct. The asterisks represent statistical significance levels, not dose counts. Look at the legend at the bottom of the plot for clarification.
Third best treatment
It ranks third in effectiveness among all treatments.
That's not right. The asterisks indicate statistical significance, not ranking. In fact, more asterisks mean stronger evidence of difference from placebo.
p < 0.001 vs placebo
Extremely strong statistical evidence of difference from placebo.
Correct! Three asterisks (***) indicate p < 0.001, meaning there's less than 0.1% chance the observed difference from placebo occurred randomly. This is very strong evidence of treatment efficacy.
Triple the effect size
The drug is three times more effective than placebo.
Incorrect. The asterisks indicate statistical significance (p-values), not effect size magnitude. The actual effect size can be seen from the cholesterol reduction in the plot.

Clinical Pearl: PCSK9 inhibitors can lower LDL by 50-60%! They prevent degradation of LDL receptors, literally vacuuming cholesterol from blood.

Learning Checkpoint
How do PCSK9 inhibitors lower cholesterol differently from statins?
Block cholesterol production
They inhibit HMG-CoA reductase to reduce cholesterol synthesis.
That's actually how statins work, not PCSK9 inhibitors. PCSK9 inhibitors use a different mechanism focused on cholesterol removal rather than production.
Preserve LDL receptors
They prevent degradation of LDL receptors, increasing cholesterol removal from blood.
Excellent! PCSK9 inhibitors block the PCSK9 protein, which normally breaks down LDL receptors. More receptors mean more LDL cholesterol is removed from the bloodstream - like having more vacuum cleaners!
Bind cholesterol directly
They attach to cholesterol molecules and remove them from circulation.
Not correct. PCSK9 inhibitors don't interact with cholesterol directly. They work by preserving the receptors that naturally remove LDL cholesterol from blood.
Increase bile production
They enhance bile acid synthesis to excrete more cholesterol.
That's the mechanism of bile acid sequestrants, not PCSK9 inhibitors. PCSK9 inhibitors work by maintaining more LDL receptors on liver cells.

Expected output:

A heatmap showing: - Blue-to-red gradient representing negative to positive fold changes - Patient IDs (PT001-PT008) on x-axis - Biomarker names (CA-125, CEA, AFP, CA19-9) on y-axis - Grid lines separating cells - Gold stars marking super responders - Overall response rate displayed at bottom

# Complete solution # Precision Oncology Data patients <- paste0("PT", sprintf("%03d", 1:8)) biomarkers <- c("CA-125", "CEA", "AFP", "CA19-9") fold_changes <- matrix( c(-2.5, -1.8, -0.5, 0.2, -3.1, -2.2, -1.5, -0.8, -1.2, -0.8, 0.3, 0.5, -1.5, -0.9, -0.3, 0.1, -0.5, -0.2, 1.2, 1.5, -0.8, -0.3, 0.8, 1.1, -3.0, -2.5, -1.8, -1.2, -3.5, -2.8, -2.0, -1.5), nrow = 4, byrow = TRUE ) # Create clinical color palette n_colors <- 100 color_palette <- colorRampPalette( c("darkblue", "blue", "white", "red", "darkred") )(n_colors) # Build heatmap image(1:ncol(fold_changes), 1:nrow(fold_changes), t(fold_changes), col = color_palette, xlab = "", ylab = "", axes = FALSE, main = "Tumor Biomarker Response: 12-Week Post-Treatment Assessment") # Add axes axis(1, at = 1:length(patients), labels = patients, las = 2, cex.axis = 0.9) mtext("Patient ID", side = 1, line = 3.5, cex = 1.1) axis(2, at = 1:length(biomarkers), labels = biomarkers, las = 1, cex.axis = 1) mtext("Serum Biomarkers", side = 2, line = 3, cex = 1.1) # Add grid abline(h = seq(0.5, 4.5, by = 1), col = "gray80", lwd = 0.5) abline(v = seq(0.5, 8.5, by = 1), col = "gray80", lwd = 0.5) # Identify super responders mean_response <- colMeans(fold_changes) responders <- which(mean_response < -1.5) for(i in responders) { text(i, 4.7, "★", col = "gold", cex = 1.5) text(i, 5.0, "R", col = "darkgreen", cex = 0.8, font = 2) } # Add response rate response_rate <- round(length(responders)/length(patients) * 100, 1) text(5, 0.3, paste0("Overall Response Rate: ", response_rate, "%"), cex = 0.9, font = 3)

Learning Checkpoint
In the heatmap color scheme, what does dark blue represent?
Large negative fold change
Strong decrease in biomarker levels, indicating good treatment response.
Excellent! Dark blue represents large negative fold changes, meaning biomarker levels decreased significantly - a positive sign in cancer treatment as tumor markers drop.
Large positive fold change
Strong increase in biomarker levels, indicating disease progression.
Not correct. Positive fold changes (increases) are shown in red colors. Blue represents negative changes (decreases) in biomarker levels.
No change
Biomarker levels remained stable during treatment.
Incorrect. No change (fold change near 0) is represented by white in the color palette. Dark blue indicates strong negative changes.
Missing data
Biomarker measurements were not available for these patients.
That's not right. The color represents actual fold change values. Missing data would typically be shown as gray or excluded from the heatmap.
Learning Checkpoint
How is the overall response rate calculated in this analysis?
Patients with any decrease
Count all patients showing any biomarker reduction.
Not quite. The code defines responders more stringently - only those with mean fold change < -1.5 across all biomarkers are counted as responders.
Mean fold change < -1.5
Patients whose average biomarker decrease exceeds 1.5-fold.
Correct! The code calculates the mean fold change across all biomarkers for each patient, then counts those with mean < -1.5 as responders. This ensures only patients with substantial overall biomarker reduction are classified as responders.
CA-125 reduction only
Based solely on the primary biomarker CA-125 levels.
Incorrect. The response calculation uses the mean across ALL four biomarkers, not just CA-125. This provides a more comprehensive assessment of treatment response.
Clinical symptoms
Based on patient-reported improvement in symptoms.
Not correct. This analysis uses objective biomarker measurements (fold changes) to determine response, not subjective clinical symptoms.

8.2.4. Advanced Visualization Techniques

Building on your foundation in legends and annotations, let's explore advanced techniques for creating publication-ready medical visualizations.

Color Palettes for Medical Data

Choosing appropriate colors is crucial in medical visualization. Colors should be:

  • Colorblind-friendly
  • Intuitive (red for warnings, green for normal)
  • Consistent across related plots
  • Print-friendly
# Colorblind-friendly palette for categorical data cb_palette <- c("#999999", "#E69F00", "#56B4E9", "#009E73", "#F0E442", "#0072B2", "#D55E00", "#CC79A7") # Sequential palette for continuous data seq_palette <- colorRampPalette(c("#FFF5F0", "#FEE0D2", "#FCBBA1", "#FC9272", "#FB6A4A", "#EF3B2C", "#CB181D", "#A50F15", "#67000D")) # Diverging palette for fold changes div_palette <- colorRampPalette(c("#053061", "#2166AC", "#4393C3", "#92C5DE", "#D1E5F0", "#F7F7F7", "#FDDBC7", "#F4A582", "#D6604D", "#B2182B", "#67001F"))

Learning Checkpoint
Which type of color palette is most appropriate for visualizing gene expression fold changes?
Sequential palette
A gradient from light to dark of a single color.
Not ideal. Sequential palettes work well for data that goes from low to high, but fold changes have both positive and negative values that need distinct representation.
Diverging palette
Two colors diverging from a neutral center point.
Correct! Diverging palettes are perfect for fold changes because they clearly show upregulation (positive) and downregulation (negative) with a neutral color at zero, making it easy to identify genes that increase or decrease.
Categorical palette
Distinct colors for different categories.
Not appropriate. Categorical palettes are for discrete groups, not continuous numerical data like fold changes. They wouldn't show the magnitude of changes.
Rainbow palette
Full spectrum from red through violet.
Poor choice. Rainbow palettes are problematic for scientific data - they're not colorblind-friendly, create false perceptual boundaries, and don't have an intuitive ordering.

Multi-Panel Figures

Complex medical data often requires multiple related plots. The par(mfrow) function creates multi-panel layouts:

# Create a 2x2 panel layout par(mfrow = c(2, 2), mar = c(4, 4, 3, 2)) # Panel 1: Baseline biomarkers boxplot(baseline_data, main = "A) Baseline Biomarkers", ylab = "Concentration (ng/mL)", col = cb_palette[1:4]) # Panel 2: Post-treatment boxplot(post_data, main = "B) Post-Treatment", ylab = "Concentration (ng/mL)", col = cb_palette[1:4]) # Panel 3: Individual responses plot(patient_responses, main = "C) Individual Responses", xlab = "Patient ID", ylab = "% Change") # Panel 4: Correlation plot(biomarker1, biomarker2, main = "D) Biomarker Correlation", xlab = "CA-125", ylab = "CEA") # Add overall figure title mtext("Figure 1: Comprehensive Biomarker Analysis", outer = TRUE, cex = 1.5, line = -2)
