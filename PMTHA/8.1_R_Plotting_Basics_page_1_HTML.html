🧬 R Plotting Basics for Precision Health 🧬

Welcome to the exciting world of data visualization in medical research! As a precision health programmer, you'll discover how R's powerful plotting capabilities transform raw medical data into meaningful visual insights. Think of it like this: just as a doctor uses X-rays to see what's hidden inside the body, you'll use R plots to reveal hidden patterns in clinical data that can save lives! 🩺

💡 Fun Fact Box: Did you know? The first medical data visualization was created by Florence Nightingale in 1858! She used a "coxcomb chart" to show that more soldiers were dying from preventable diseases than from battle wounds. Her visualization convinced the British government to improve hospital sanitation, saving countless lives. Today, you're continuing her legacy!

Mission Briefing: Understanding the Power of Medical Data Visualization

Picture this: You're a detective solving medical mysteries! 🕵️‍♀️ Your magnifying glass? R's plotting functions. Your clues? Patient data points scattered across your screen.

In precision medicine, visual representation of data is crucial for:

  • Pattern Detection: Spotting that one patient whose recovery doesn't follow the expected trajectory
  • Treatment Monitoring: Watching tumor sizes shrink in real-time
  • Biomarker Discovery: Finding the needle in the haystack of genomic data

🎯 Why This Matters

Every plot you create could reveal:

  • Why some patients respond better to treatment than others
  • Hidden side effects of a new medication
  • The early warning signs of disease progression

Mission Briefing: The plot() Function - Your Medical Visualization Swiss Army Knife

The plot() function is like the stethoscope of R - simple, versatile, and absolutely essential! Just as a stethoscope can detect heart murmurs, arrhythmias, or lung sounds, plot() can reveal relationships between any two variables in your medical data.

🏥 Let's Start with Patient Recovery

Imagine you're monitoring patients recovering from knee surgery:

# Create patient recovery data days_post_surgery <- c(1, 3, 5, 7, 10, 14) pain_scores <- c(8, 7, 5, 4, 3, 2) # 0-10 scale # Create a basic scatter plot plot(days_post_surgery, pain_scores)

🧪 Lab Exercise 1: Visualizing Blood Glucose Patterns

Your Mission: You're a clinical researcher at a diabetes center. Your patient, Sarah, needs help managing her blood glucose throughout the day. Let's visualize her readings to find patterns! 🩸

Lab Challenge
Sarah's glucose readings were taken at 6 AM, 8 AM, 12 PM, 3 PM, 6 PM, and 9 PM. Which code correctly creates vectors for time and realistic glucose levels?
Option A
time_points <- c(6, 8, 12, 15, 18, 21) glucose_levels <- c(300, 350, 400, 450, 500, 550)
These glucose values (300-550 mg/dL) are dangerously high and unrealistic for a managed diabetes patient. Normal values range from 80-180 mg/dL.
Option B
time_points <- c(6, 8, 12, 15, 18, 21) glucose_levels <- c(95, 140, 110, 125, 160, 105)
Excellent! Option B shows realistic glucose values (80-180 mg/dL range) with appropriate time points in 24-hour format. Morning fasting is lower (95), post-meal readings are higher (140, 160).
Option C
time_points <- c(1, 2, 3, 4, 5, 6) glucose_levels <- c(95, 140, 110, 125, 160, 105)
The glucose values are realistic, but the time points (1-6) don't represent the actual hours of the day when readings were taken.
Option D
time_points <- c(6, 8, 12, 15, 18, 21) glucose_levels <- c(50, 40, 30, 20, 10, 5)
These glucose values are dangerously low and would indicate severe hypoglycemia. Values below 70 mg/dL are considered low blood sugar.

Exercise Solution

time_points <- c(6, 8, 12, 15, 18, 21) glucose_levels <- c(95, 140, 110, 125, 160, 105) plot(time_points, glucose_levels)
Copied!

Mission Briefing: Understanding Plot Types with type Parameter

Different medical scenarios call for different visualization styles. The type parameter lets you control this:

# Patient temperature monitoring data hours <- seq(0, 24, by = 4) temperature <- c(38.5, 38.2, 37.9, 37.6, 37.4, 37.2, 37.0) # Points only (type = "p") - like taking spot checks plot(hours, temperature, type = "p", main = "Fever Resolution Pattern") # Lines only (type = "l") - shows the continuous trend plot(hours, temperature, type = "l", main = "Fever Resolution Pattern") # Both points and lines (type = "b") - best of both worlds! plot(hours, temperature, type = "b", main = "Fever Resolution Pattern")
Copied!
Knowledge Check
Which plot type would be MOST appropriate for showing a patient's hourly heart rate measurements where you want to see both individual readings and the overall trend?
type = "p" (points only)
Shows individual readings but not the trend.
Points only show individual measurements but make it harder to see the overall trend between readings.
type = "l" (lines only)
Shows trend but not individual measurements.
Lines show the trend but you lose the ability to see exact measurement points, which are important for heart rate monitoring.
type = "b" (both points and lines)
Shows both individual readings and trend.
Correct! type = "b" shows both individual measurements (points) and the connecting trend (lines), providing the most complete picture of heart rate changes over time.
type = "h" (histogram-like vertical lines)
Not ideal for time-series data.
Histogram-like lines are not appropriate for showing heart rate trends over time. They're better for bar-like representations.

🧪 Lab Exercise 2: Tracking Tumor Marker Levels

Your Mission: You're an oncologist monitoring John's response to chemotherapy. CA-125 is a protein that indicates tumor activity - we want to see it drop! 🎗️

Lab Challenge
John's CA-125 levels need to drop from an initial high value to below 35 U/mL (normal range) over 6 months. Which vector best represents a successful treatment response?
ca125_levels <- c(35, 35, 35, 35, 35, 35, 35)
All values already normal - no treatment needed.
These levels are all normal from the start, indicating no tumor was present initially. We need to see a decrease from high to normal levels.
ca125_levels <- c(250, 280, 310, 340, 370, 400, 430)
Levels are increasing - treatment failing.
This shows increasing CA-125 levels, indicating tumor growth and treatment failure. We want to see decreasing values.
ca125_levels <- c(250, 180, 120, 85, 60, 45, 35)
Progressive decrease to normal range.
Excellent! Option C shows decreasing CA-125 levels from 250 to 35 U/mL, indicating successful tumor response to chemotherapy. The values progressively decrease and reach the normal range (below 35) by month 6.
ca125_levels <- c(35, 45, 60, 85, 120, 180, 250)
Levels increasing from normal - tumor growing.
This shows CA-125 levels increasing from normal to high, indicating tumor growth rather than treatment response.

Exercise Solution

months <- c(0, 1, 2, 3, 4, 5, 6) ca125_levels <- c(250, 180, 120, 85, 60, 45, 35) plot(months, ca125_levels, type = "b", main = "CA-125 Tumor Marker Response to Chemotherapy", xlab = "Months Since Treatment Start", ylab = "CA-125 Level (U/mL)")
Copied!

Mission Briefing: Creating Bar Plots with barplot()

Bar plots are perfect for comparing categories - like comparing the effectiveness of different medications. Think of them as a visual "medication showdown"! 💊

# Medication adherence rates (percentage) adherence_rates <- c(85, 72, 90, 68, 78) drug_names <- c("DrugA", "DrugB", "DrugC", "DrugD", "DrugE") # Create named vector for better labeling names(adherence_rates) <- drug_names # Create bar plot barplot(adherence_rates, main = "Patient Medication Adherence by Drug Type", ylab = "Adherence Rate (%)", col = "lightblue")
Copied!

💡 Fun Fact: Pharmacists use plots like this to identify which medications need better patient education or reformulation!

Knowledge Check
When would a barplot() be MORE appropriate than a plot() function in medical data visualization?
Showing patient temperature changes over 24 hours
This is continuous time-series data.
Temperature over time is continuous data best shown with a line or scatter plot. Bar plots are for categorical comparisons.
Comparing success rates of different surgical procedures
This compares distinct categories.
Correct! Bar plots are ideal for comparing discrete categories (like different surgical procedures). Time-series data and continuous relationships are better shown with plot() functions.
Tracking blood pressure readings over time
This is time-series data.
Blood pressure over time is continuous data that shows trends, better suited for line or scatter plots rather than bar plots.
Displaying the relationship between age and cholesterol levels
This shows correlation between two continuous variables.
Relationships between continuous variables like age and cholesterol are best shown with scatter plots, not bar plots.
