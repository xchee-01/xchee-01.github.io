Mission Briefing: Introduction to Subplots

Think of subplots as organizing your medical office desk - instead of papers scattered everywhere, you have neat sections for different patient information. In the digital world, matplotlib's subplot functionality is your organizational superpower! 🦸‍♀️

Let me share a secret: The day I discovered subplots was like finding out I could clone myself to analyze multiple patient datasets at once. No more switching between windows or losing track of which graph belonged to which patient!

🎯 Quick Exercise
What do you think will happen when we create a 2x2 grid of plots?
Creates 2 plots side by side
A) Creates 2 plots side by side
Not quite right. A 2x2 grid means 2 rows and 2 columns, which creates 4 plots total, not just 2 side by side.
Creates 4 plots in a 2x2 grid layout
B) Creates 4 plots in a 2x2 grid layout
Correct! A 2x2 grid creates 4 subplot areas (2 rows × 2 columns = 4 plots). This is perfect for creating comprehensive patient dashboards!
Creates 2 plots stacked vertically
C) Creates 2 plots stacked vertically
That's not correct. To create 2 plots stacked vertically, you would use a 2x1 grid, not 2x2.
Creates a single plot with 2 data series
D) Creates a single plot with 2 data series
That's not right. Subplots create multiple separate plotting areas, not multiple data series on one plot.
# Create a figure with 2 rows and 2 columns for patient vital signs # ================================================== # This is like setting up four monitors in an ICU room # ================================================== fig, axes = plt.subplots(2, 2, figsize=(10, 8)) # The 'fig' represents the entire figure (your complete monitoring station) # ================================================== # 'axes' is a 2D array containing individual plot areas (each monitor screen) # ================================================== print(f"Figure object type: {type(fig)}") print(f"Axes array shape: {axes.shape}") print(f"First subplot: {axes[0, 0]}") # Top-left plot

📊 Basic Subplot Access Patterns

Here's where it gets interesting! Accessing subplots is like navigating a hospital floor plan:

# Method 1: Using array indexing (like room numbers) # ================================================== top_left = axes[0, 0] # ICU Room 1 top_right = axes[0, 1] # ICU Room 2 bottom_left = axes[1, 0] # ICU Room 3 bottom_right = axes[1, 1] # ICU Room 4 # Method 2: Flattening for sequential access (like walking down a hallway) # ================================================== all_plots = axes.flatten() for i, ax in enumerate(all_plots): ax.text(0.5, 0.5, f'Monitor {i+1}', ha='center', va='center', fontsize=20) ax.set_xlim(0, 1) ax.set_ylim(0, 1)
Copied!
Real-World Connection
In telemedicine platforms, doctors often view multiple patient streams simultaneously. If you have a 3x3 grid of subplots created with `fig, axes = plt.subplots(3, 3)`, how would you access the center plot?
axes[1, 1]
A) axes[1, 1]
Correct! In a 3x3 grid, the center plot is at row index 1, column index 1 (remembering that indexing starts at 0).
axes[2, 2]
B) axes[2, 2]
Not quite. axes[2, 2] would access the bottom-right plot, not the center. Remember that indexing starts at 0!
axes[4]
C) axes[4]
That's not right. This would only work if you flattened the array first, and it would give you the 5th plot (index 4), not necessarily the center.
axes.center()
D) axes.center()
There's no .center() method for accessing subplot arrays. You need to use array indexing with [row, column].

Mission Briefing: Creating Basic Multiple Plots

Now for the exciting part - let's create a realistic diabetes management dashboard! This is exactly what endocrinologists use to track patient progress over time.

🏥 Building a Diabetes Patient Dashboard

# Generate sample data for a diabetes patient over 12 months # ================================================== # Note: In real applications, this would come from EMR systems # ================================================== months = np.arange(1, 13) np.random.seed(42) # For reproducibility in clinical research # Simulate realistic patient data with treatment effects # ================================================== # Blood glucose showing gradual improvement (starting high, trending down) # ================================================== glucose = 180 - 5 * months + np.random.normal(0, 10, 12) glucose = np.clip(glucose, 70, 250) # Keep within physiological range # Systolic blood pressure with medication effect # ============================================== blood_pressure = 140 - 2 * months + np.random.normal(0, 5, 12) blood_pressure = np.clip(blood_pressure, 100, 180) # Weight loss from lifestyle changes (kg) # ======================================= weight = 95 - 0.8 * months + np.random.normal(0, 1, 12) # HbA1c percentage - quarterly measurements (more realistic) # ================================================== hba1c_months = [3, 6, 9, 12] hba1c_values = [8.5, 7.8, 7.2, 6.8] # Showing improvement

📈 Creating the Clinical Dashboard

# Create a 2x2 subplot layout for comprehensive patient monitoring # ================================================== fig, axes = plt.subplots(2, 2, figsize=(14, 10)) fig.patch.set_facecolor('white') # Professional white background # Plot 1: Blood Glucose Trend (top-left) - The star of diabetes management! # ================================================== ax1 = axes[0, 0] ax1.plot(months, glucose, 'b-o', linewidth=2, markersize=6, label='Measured') ax1.fill_between(months, glucose-10, glucose+10, alpha=0.2, color='blue', label='Variability') ax1.axhline(y=126, color='red', linestyle='--', linewidth=2, label='Diabetic threshold') ax1.axhline(y=100, color='green', linestyle='--', linewidth=2, label='Target') ax1.set_title('Blood Glucose Levels', fontsize=14, fontweight='bold', pad=10) ax1.set_xlabel('Month') ax1.set_ylabel('Glucose (mg/dL)') ax1.grid(True, alpha=0.3) ax1.legend(loc='upper right', fontsize=8) ax1.set_ylim(60, 200) # Add trend annotation # ==================== if glucose[-1] < glucose[0]: ax1.annotate('Improving! ✓', xy=(11, glucose[-1]), xytext=(9, glucose[-1]+20), arrowprops=dict(arrowstyle='->', color='green', lw=2), fontsize=10, color='green', fontweight='bold')
Copied!
💡 Clinical Insight
The blue shaded area represents glucose variability. Why is high variability concerning even if average glucose is good?
It makes the graph look messy
A) It makes the graph look messy
That's not a medical concern. The appearance of the graph is less important than what the data tells us about patient health.
High variability increases complication risk
B) High variability increases complication risk
Correct! Glucose variability (glycemic variability) is an independent risk factor for diabetic complications. Even with good average control, large swings between high and low glucose can damage blood vessels and nerves.
It's harder to calculate the average
C) It's harder to calculate the average
Not correct. Calculating the average is straightforward regardless of variability. The concern is about patient health outcomes.
Patients prefer stable numbers
D) Patients prefer stable numbers
While patient preference matters, the medical concern is that glucose variability increases the risk of complications.
# Plot 2: Blood Pressure Trend (top-right) - Cardiovascular health indicator # ================================================== ax2 = axes[0, 1] ax2.plot(months, blood_pressure, 'r-s', linewidth=2, markersize=6) ax2.axhline(y=130, color='orange', linestyle='--', label='Stage 1 HTN') ax2.axhline(y=120, color='green', linestyle='--', label='Target') ax2.axhspan(120, 130, alpha=0.1, color='yellow', label='Pre-hypertension') ax2.set_title('Systolic Blood Pressure', fontsize=14, fontweight='bold', pad=10) ax2.set_xlabel('Month') ax2.set_ylabel('BP (mmHg)') ax2.grid(True, alpha=0.3) ax2.legend(loc='upper right', fontsize=8) ax2.set_ylim(100, 160) # Plot 3: Weight Loss Progress (bottom-left) - Lifestyle modification tracker # ================================================== ax3 = axes[1, 0] # Calculate BMI for additional context # ==================================== height = 1.75 # meters (assumption) bmi = weight / (height ** 2) ax3.plot(months, weight, 'g-^', linewidth=2, markersize=8, label='Weight') # Add BMI on secondary y-axis # =========================== ax3_bmi = ax3.twinx() ax3_bmi.plot(months, bmi, 'm--', linewidth=1, alpha=0.7, label='BMI') ax3_bmi.set_ylabel('BMI', color='m') ax3_bmi.tick_params(axis='y', labelcolor='m') ax3.set_title('Weight Loss Progress', fontsize=14, fontweight='bold', pad=10) ax3.set_xlabel('Month') ax3.set_ylabel('Weight (kg)', color='g') ax3.tick_params(axis='y', labelcolor='g') ax3.grid(True, alpha=0.3) # Add target zones # ================ ax3.axhline(y=85, color='green', linestyle=':', alpha=0.5) ax3.text(1, 86, 'Target Weight', fontsize=8, color='green')
Copied!
# Plot 4: HbA1c Levels (bottom-right) - Long-term glucose control # ================================================== ax4 = axes[1, 1] bars = ax4.bar(hba1c_months, hba1c_values, width=0.8, edgecolor='black', linewidth=2) # Color-code bars based on control level # ====================================== colors = ['red', 'orange', 'yellow', 'lightgreen'] for bar, color in zip(bars, colors): bar.set_facecolor(color) ax4.axhline(y=7.0, color='blue', linestyle='--', linewidth=2, label='ADA Target') ax4.axhline(y=6.5, color='green', linestyle='--', linewidth=2, label='Optimal') ax4.set_title('HbA1c Levels (Quarterly)', fontsize=14, fontweight='bold', pad=10) ax4.set_xlabel('Month') ax4.set_ylabel('HbA1c (%)') ax4.set_xticks(hba1c_months) ax4.set_ylim(6, 9) ax4.legend(loc='upper right', fontsize=8) ax4.grid(True, alpha=0.3, axis='y') # Add value labels on bars # ======================== for i, (month, value) in enumerate(zip(hba1c_months, hba1c_values)): ax4.text(month, value + 0.1, f'{value}%', ha='center', fontweight='bold') # Add an overall title with patient ID # ==================================== fig.suptitle('Diabetes Management Dashboard - Patient ID: DM2024-156\n12-Month Treatment Progress', fontsize=16, fontweight='bold') # Add timestamp # ============= fig.text(0.99, 0.01, f'Generated: {pd.Timestamp.now().strftime("%Y-%m-%d %H:%M")}', ha='right', fontsize=8, alpha=0.5) # Optimize layout to prevent overlap # ================================== plt.tight_layout(rect=[0, 0.02, 1, 0.96]) plt.show()
