2.5. Mission Briefing: Essential List Methods for Medical Data

💡 Quick Concept: Built-in Methods = Your Data Analysis Toolkit

Python gives you powerful tools to analyze lists without writing complex code. Think of these methods as specialized medical instruments - each designed for a specific diagnostic purpose!

📊 Statistical Methods

# Patient cholesterol levels (mg/dL) cholesterol = [195, 210, 188, 225, 205] # How many tests did we run? num_readings = len(cholesterol) print(f"Total tests: {num_readings}") # Find the range (important for variability) highest = max(cholesterol) lowest = min(cholesterol) print(f"Range: {lowest} - {highest} mg/dL") print(f"Variation: {highest - lowest} mg/dL") # Calculate average (mean) total = sum(cholesterol) average = total / len(cholesterol) print(f"Average cholesterol: {average:.1f} mg/dL") # Quick health check if average > 200: print("⚠️ Borderline high cholesterol detected!")
Copied!
💡 Method Quick Reference
Which list method would you use to find the highest blood pressure reading from a list of measurements?
len(list)
Count items (How many tests?)
Not quite. len() counts the number of items in a list, but doesn't find the highest value.
max(list)
Highest value (Worst reading?)
Correct! max() returns the highest value in a list - perfect for finding the most critical blood pressure reading.
min(list)
Lowest value (Best reading?)
Not the right choice. min() finds the lowest value, not the highest.
sum(list)
Add all values (For averaging)
Not correct. sum() adds all values together, but doesn't identify the highest individual reading.

🔍 Finding and Counting

# Emergency room blood type inventory blood_types = ["A+", "O-", "B+", "A+", "AB+", "O-", "A+", "B-"] # Do we have universal donor blood? if "O-" in blood_types: o_neg_count = blood_types.count("O-") print(f"✓ Universal donor available: {o_neg_count} units") # Most common type? a_pos_count = blood_types.count("A+") print(f"A+ units: {a_pos_count} (most common)") # Find position of first O- unit first_o_neg = blood_types.index("O-") print(f"First O- unit in position: {first_o_neg}")

🔄 Sorting and Organizing

# Patient wait times (minutes) wait_times = [45, 12, 67, 23, 89, 34] # Sort for analysis wait_times.sort() # Modifies the original list print(f"Sorted times: {wait_times}") print(f"Median wait: {wait_times[len(wait_times)//2]} minutes") # Reverse for worst-first review wait_times.reverse() print(f"Longest waits first: {wait_times}") # Creating a sorted copy (preserves original) original = [45, 12, 67, 23, 89, 34] sorted_copy = sorted(original) # Returns new list print(f"Original unchanged: {original}") print(f"Sorted copy: {sorted_copy}")
Copied!
🤔 Think About It
When would you want to modify the original list vs. create a sorted copy?
Always modify the original
It's more efficient to sort in place.
Not always. Sometimes you need to preserve the original order, like maintaining chronological patient arrival times.
Create a copy when you need both versions
Use sorted() to keep original order and get sorted data.
Correct! In medical records, you might need both chronological order (for patient history) and sorted order (for analysis).
Never modify the original
Always create copies to be safe.
Too restrictive. Sometimes modifying in-place is perfectly fine and more memory efficient.

🏥 Real-World Application: Lab Result Processing

# Glucose readings with one error glucose_readings = [95, 102, 98, 999, 106, 101] # 999 is clearly wrong! # Remove the error if 999 in glucose_readings: glucose_readings.remove(999) print("Error removed, clean data:", glucose_readings) # Now safe to analyze avg_glucose = sum(glucose_readings) / len(glucose_readings) print(f"True average: {avg_glucose:.1f} mg/dL")

2.6. Mission Briefing: Working with Lists of Medical Records

💡 Quick Concept: Complex Operations for Real-World Scenarios

In actual healthcare settings, you'll work with lists containing hundreds or thousands of records. Let's explore advanced techniques for managing complex medical data!

🏥 Emergency Room Triage System

# ER patient data: [name, age, severity_score] er_patients = [ ["John", 45, 3], ["Sarah", 72, 8], ["Mike", 28, 2], ["Emma", 89, 9], ["Lisa", 34, 5] ] # Extract severity scores for quick analysis severity_scores = [patient[2] for patient in er_patients] print(f"Severity scores: {severity_scores}") # Find most critical patient critical_score = max(severity_scores) critical_index = severity_scores.index(critical_score) critical_patient = er_patients[critical_index] print(f"Most critical: {critical_patient[0]}, Age {critical_patient[1]}, Severity {critical_patient[2]}")

🧬 Genetic Testing Results

# Patient genetic markers genetic_markers = ["BRCA1", "APOE4", "MTHFR", "BRCA1", "HLA-B27", "APOE4", "CFH"] # Create unique marker list unique_markers = list(set(genetic_markers)) unique_markers.sort() print(f"Unique markers found: {unique_markers}") # Risk assessment high_risk_markers = ["BRCA1", "APOE4"] risk_count = 0 for marker in high_risk_markers: risk_count += genetic_markers.count(marker) print(f"High-risk marker occurrences: {risk_count}") # Detailed risk report print("\nRisk Analysis:") for marker in high_risk_markers: count = genetic_markers.count(marker) if count > 0: print(f"- {marker}: {count} copies", end="") if marker == "BRCA1": print(" (breast/ovarian cancer risk)") elif marker == "APOE4": print(" (Alzheimer's risk)")
Copied!
💡 Advanced Tip Box
Which conversion would you use to remove duplicate genetic markers from a list?
set(list)
Remove duplicates by converting to set
Correct! Converting to a set automatically removes duplicates, then you can convert back to list.
sorted(list)
Get sorted copy
sorted() only sorts the list, it doesn't remove duplicates.
list.copy()
Make a safe copy for analysis
copy() creates a duplicate of the list, including all duplicate values.

📊 Population Health Analysis

# BMI values for clinic patients bmi_values = [22.5, 28.3, 31.2, 19.8, 26.7, 35.4, 24.1, 29.9] # Categorize patients normal = [bmi for bmi in bmi_values if 18.5 <= bmi < 25] overweight = [bmi for bmi in bmi_values if 25 <= bmi < 30] obese = [bmi for bmi in bmi_values if bmi >= 30] print(f"Normal weight: {len(normal)} patients") print(f"Overweight: {len(overweight)} patients") print(f"Obese: {len(obese)} patients") # Calculate health metrics avg_bmi = sum(bmi_values) / len(bmi_values) print(f"\nClinic average BMI: {avg_bmi:.1f}") print(f"Percentage overweight/obese: {(len(overweight) + len(obese)) / len(bmi_values) * 100:.0f}%")
Copied!
🤔 Challenge
How would you find all patients with BMI between 25-30 without using list comprehension?
Use a for loop with if statement
overweight = []
for bmi in bmi_values:
  if 25 <= bmi < 30:
    overweight.append(bmi)
Correct! This traditional loop approach achieves the same result as list comprehension but with more explicit steps.
Use filter() function
overweight = filter(bmi_values, 25, 30)
Not quite. The filter() syntax is incorrect - it needs a function as the first argument.
Use index slicing
overweight = bmi_values[25:30]
Incorrect. Slicing uses positions, not values. This would try to get elements at positions 25-30.
