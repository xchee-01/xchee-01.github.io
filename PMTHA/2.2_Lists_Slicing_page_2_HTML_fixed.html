🛡️ Safe Data Handling: Making Copies

In medical programming, data integrity is paramount. Always work with copies!

# Clinical trial weights - DON'T modify the original! original_weights = [82.5, 81.8, 81.2, 80.5, 79.8, 79.1] # Safe copy for analysis analysis_weights = original_weights[:] # The [:] creates a full copy # Now we can modify without affecting the original analysis_weights[0] = 83.0 # Oops, data entry error! print(f"Original still intact: {original_weights[0]}") # Still 82.5!

📊 Before/After Comparisons

A classic pattern in clinical research:

# Weight loss program - 12 week study weights = [92.5, 91.8, 91.2, 90.5, 89.8, 89.1, # First 6 weeks 88.5, 87.9, 87.3, 86.8, 86.2, 85.7] # Last 6 weeks # Split at the midpoint first_half = weights[:6] second_half = weights[6:] # Calculate progress initial_avg = sum(first_half) / len(first_half) final_avg = sum(second_half) / len(second_half) print(f"First 6 weeks average: {initial_avg:.1f} kg") print(f"Last 6 weeks average: {final_avg:.1f} kg") print(f"That's {initial_avg - final_avg:.1f} kg of progress! 🎉")

🧬 Advanced Pattern: Genomic Reading Frames

# mRNA sequence - this codes for proteins! mrna = ['A', 'U', 'G', 'C', 'A', 'A', 'U', 'C', 'C', 'G', 'A', 'U'] # Reading frame 1: Start from position 0 frame1 = [mrna[i:i+3] for i in range(0, len(mrna)-2, 3)] # Reading frame 2: Start from position 1 frame2 = [mrna[i:i+3] for i in range(1, len(mrna)-2, 3)] print("Frame 1 codons:", [''.join(codon) for codon in frame1]) print("Frame 2 codons:", [''.join(codon) for codon in frame2])
Copied!

🤔 Self-Explanation Prompt

Why might different reading frames matter?

Answer:

Mutations that insert or delete nucleotides can shift the reading frame, potentially creating completely different proteins - this is how some genetic diseases occur!

🏃‍♂️ Performance Tips

# When processing large datasets (like whole genome sequences) large_data = list(range(1000000)) # 1 million data points # ❌ Inefficient: Creating multiple intermediate lists result = large_data[::10] # Every 10th result = result[:1000] # First 1000 of those # ✅ Efficient: Combine operations result = large_data[::10][:1000] # Same result, one operation # ⚡ Most efficient for huge datasets: Use itertools from itertools import islice result = list(islice(large_data[::10], 1000))

data[:] # Full copy data[:n] # First n elements data[-n:] # Last n elements data[::n] # Every nth element data[::-1] # Reverse the list data[i:j] # Elements from i to j-1 data[i:j:k] # Elements from i to j-1, step k
