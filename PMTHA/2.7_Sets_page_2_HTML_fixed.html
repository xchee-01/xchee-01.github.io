Python Sets: Advanced Operations for Medical Data

Mission Briefing: Set Comparisons in Genetic Research

🧬 The Power of Set Mathematics in Medicine

This is where sets truly shine! Set operations help us answer critical questions like:

  • Which patients have multiple conditions?
  • What genes are common across cancer types?
  • Which medications interact with each other?

Finding Commonalities (Intersection)

diabetes_patients = {"P001", "P002", "P003", "P004", "P005"} hypertension_patients = {"P003", "P004", "P006", "P007"} # Who has BOTH conditions? (Critical for treatment planning!) comorbid = diabetes_patients & hypertension_patients print(f"🚨 High-risk patients (both conditions): {comorbid}") # Output: High-risk patients (both conditions): {'P003', 'P004'}
Copied!

Not quite. The | operator performs union, not intersection.

B
The ampersand operator for intersection
Correct! The & operator performs set intersection, returning elements present in both sets.
- (minus)
C
The minus operator for difference
The - operator is for set difference, not intersection.

D
The caret operator for symmetric difference
The ^ operator finds elements in either set but not both.

Combining Groups (Union)

all_chronic = diabetes_patients | hypertension_patients print(f"📋 Total chronic care patients: {all_chronic}") # Output: Total chronic care patients: {'P001', 'P002', 'P003', 'P004', 'P005', 'P006', 'P007'}
Copied!

Finding Exclusives (Difference)

diabetes_only = diabetes_patients - hypertension_patients print(f"💊 Diabetes-only treatment group: {diabetes_only}") # Output: Diabetes-only treatment group: {'P001', 'P002', 'P005'}
Copied!

Level Up: Professional-Grade Set Operations

Now let's explore the methods that power enterprise healthcare systems:

Method-Based Operations (More Readable!)

emergency_patients = {"E001", "E002", "E003", "E004"} cardiology_patients = {"C001", "C002", "E002", "E003"} # Using methods instead of operators - clearer intent! shared = emergency_patients.intersection(cardiology_patients) print(f"🏥 Patients seen in both departments: {shared}") total = emergency_patients.union(cardiology_patients) print(f"📊 Total unique patients: {total}")
Copied!
Learning Checkpoint
What is the method equivalent of the | operator for sets?
intersection()
Method for finding common elements
intersection() is equivalent to &, not |.
difference()
Method for finding elements in one set but not another
difference() is equivalent to -, not |.
union()
Method for combining all unique elements
Correct! The union() method is equivalent to the | operator, combining all unique elements from both sets.
symmetric_difference()
Method for finding elements in either set but not both
symmetric_difference() is equivalent to ^, not |.

Subset and Superset Checking

cardiac_emergencies = {"E002", "E003"} properly_referred = cardiac_emergencies.issubset(cardiology_patients) print(f"✅ Referral compliance: {properly_referred}") # Output: Referral compliance: True
Copied!

Set Comprehensions for Genomic Data Processing

🧬 Power Tool: Set Comprehensions

Set comprehensions are like list comprehensions but automatically handle uniqueness. Perfect for filtering large datasets!

Filtering by Criteria

gene_expression = {"BRCA1": 2.5, "TP53": 0.8, "EGFR": 3.2, "KRAS": 1.5} # Find highly expressed genes (threshold > 2.0) highly_expressed = {gene for gene, value in gene_expression.items() if value > 2.0} print(f"🔥 Highly expressed genes: {highly_expressed}") # Output: Highly expressed genes: {'BRCA1', 'EGFR'}
Copied!
Learning Checkpoint
Which set comprehension correctly creates a set of patient IDs where age > 65?
Given: patients = {"P001": 45, "P002": 70, "P003": 68, "P004": 55}
{id for id in patients if patients[id] > 65}
Using dictionary key access
This works but is less Pythonic than using .items().
{id for id, age in patients.items() if age > 65}
Using .items() to unpack key-value pairs
Correct! This comprehension correctly iterates over dictionary items and filters by age > 65, returning patient IDs.
{patients[id] for id in patients if id > 65}
Comparing ID string with number
This compares the ID string with 65, not the age value.
{age for id, age in patients if age > 65}
Missing .items() method
This is missing .items() and would return ages, not IDs.

Data Transformation

patient_ids = {101, 102, 103, 104, 105} research_codes = {f"RES{id:04d}" for id in patient_ids} print(f"🔒 Anonymized codes: {research_codes}") # Output: Anonymized codes: {'RES0101', 'RES0102', 'RES0103', 'RES0104', 'RES0105'}
Copied!

Conditional Filtering

medications = {"Aspirin", "Acetaminophen", "Ibuprofen", "Metformin"} short_names = {drug for drug in medications if len(drug) <= 8} print(f"💊 Database-compliant names: {short_names}")
Copied!

Performance Note: Set comprehensions are not just elegant - they're also faster than building sets with loops!

Answer:

# Drug interaction safety system solution interactions = { "Warfarin": {"Aspirin", "Ibuprofen", "Vitamin K"}, "Metformin": {"Alcohol", "Contrast Dye"}, "Lisinopril": {"Potassium", "NSAIDs"} } patient_meds = {"Warfarin", "Metformin", "Lisinopril"} new_substances = {"Aspirin", "Alcohol", "Potassium", "Vitamin D"} # Find all possible interactions using set comprehension all_interactions = {item for med in patient_meds if med in interactions for item in interactions[med]} # Identify dangerous combinations dangerous_combinations = new_substances & all_interactions # Find safe substances safe_substances = new_substances - dangerous_combinations print(f"⚠️ All possible interactions: {all_interactions}") print(f"🚫 Dangerous combinations: {dangerous_combinations}") print(f"✅ Safe to add: {safe_substances}")
