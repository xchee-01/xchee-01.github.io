Colors and Themes in Medical Visualization

Quick Check
Before diving in, predict what makes medical visualizations different from regular plots:
They use more colors
Medical plots should be colorful to catch attention.
Not quite! Medical visualizations actually prioritize clarity over colorfulness. Too many colors can confuse critical information.
They must consider color blindness and clinical conventions
Medical visualizations need to be accessible and follow established clinical color meanings.
Correct! Medical visualizations must be accessible to all healthcare providers (including colorblind ones) and follow universal clinical conventions like red for danger.
They don't need labels
Medical professionals understand data without labels.
Incorrect! Clear labeling is crucial in medical contexts where misinterpretation could have serious consequences.
Wrong colors could lead to misdiagnosis
Color choices can affect clinical decision making.
Absolutely right! Using non-standard colors (like green for danger) could lead to dangerous misinterpretations in time-critical situations.

The Life-or-Death Importance of Color Choice

Picture this: You're presenting glucose data to doctors at 3 AM during an emergency case review. One glance at your plot needs to instantly communicate which patients are in danger.

In the medical world, colors speak a universal language:

  • Red = Danger, elevated risk, "pay attention NOW!"
  • Yellow/Gold = Caution, borderline, "keep an eye on this"
  • Green = Normal, safe, "all systems go"
  • Blue = Control groups, baseline, "reference point"
Fun Fact
Approximately 1 in 12 men and 1 in 200 women have color blindness. Why is this important for medical visualizations?
Always test with colorblind-friendly palettes
Ensure all healthcare providers can interpret your visualizations.
Exactly! Using colorblind-friendly palettes ensures that all medical professionals can accurately interpret critical patient data.
Only use black and white
Avoid colors entirely to be safe.
Not quite! Colors can still be very useful - we just need to choose palettes that work for everyone, like using both color and shape to distinguish categories.
It's not that important
Most medical professionals aren't colorblind.
Incorrect! Even if most aren't colorblind, ensuring accessibility for all healthcare providers is crucial for patient safety.

Your First Medical Color Masterpiece

# Creating patient glucose data glucose_levels <- c(95, 110, 125, 140, 165, 180, 195) patient_ids <- c("P001", "P002", "P003", "P004", "P005", "P006", "P007") # The boring default plot plot(glucose_levels, main = "Patient Glucose Levels", xlab = "Patient Index", ylab = "Glucose (mg/dL)") # Now let's add clinical intelligence with colors! # Medical thresholds: # Normal: < 100 mg/dL # Pre-diabetic: 100-125 mg/dL # Diabetic: > 125 mg/dL point_colors <- ifelse(glucose_levels < 100, "darkgreen", ifelse(glucose_levels <= 125, "gold", "darkred")) # Create the life-saving visualization! plot(glucose_levels, col = point_colors, pch = 19, cex = 2, main = "Patient Glucose Levels by Clinical Category", xlab = "Patient Index", ylab = "Glucose (mg/dL)") # Add critical threshold line abline(h = 125, col = "red", lty = 2, lwd = 2) text(1, 130, "Diabetic Threshold", col = "red", pos = 4)
Copied!

Lab Exercise 1: Blood Pressure Visualization

You're the lead data scientist for a hypertension study. The cardiologist needs a visualization STAT showing which patients need immediate intervention!

# Emergency Department Data systolic <- c(118, 125, 132, 145, 158, 162, 170, 135, 128, 155) diastolic <- c(75, 82, 85, 92, 95, 98, 102, 88, 80, 94) # TODO: Create visualization with: # - Green: normal BP (sys < 120 AND dia < 80) # - Yellow: elevated BP # - Red: hypertensive crisis (sys ≥ 140 OR dia ≥ 90)

Exercise Solution

# Define risk categories risk_colors <- ifelse(systolic < 120 & diastolic < 80, "darkgreen", ifelse(systolic >= 140 | diastolic >= 90, "darkred", "gold")) # Create the plot plot(systolic, diastolic, col = risk_colors, pch = 19, cex = 1.5, main = "Blood Pressure Risk Categories - Immediate Action Required for Red!", xlab = "Systolic Pressure (mmHg)", ylab = "Diastolic Pressure (mmHg)", xlim = c(110, 180), ylim = c(70, 110)) # Add clinical thresholds abline(v = 120, col = "gray", lty = 3) abline(v = 140, col = "red", lty = 2) abline(h = 80, col = "gray", lty = 3) abline(h = 90, col = "red", lty = 2) # Add legend legend("bottomright", legend = c("Normal BP", "Elevated BP", "Hypertensive Crisis!"), col = c("darkgreen", "gold", "darkred"), pch = 19, bty = "n")

Axes and Labels for Clinical Clarity

The $300 Million Mistake

True Story
In 2015, a biotech company's stock crashed 65% because analysts misread a clinical trial plot. The y-axis showed drug concentration in μg/mL, but everyone assumed mg/mL—a 1000x difference! What lesson does this teach us?
Always include units clearly on axes
Clear unit labeling prevents costly misinterpretations.
Exactly! This $300 million mistake could have been prevented with clearer axis labeling. Always make units impossible to miss!
Don't use metric units
Avoid μg/mL to prevent confusion.
Not the right lesson. Metric units are standard in science. The issue was unclear labeling, not the units themselves.
Analysts should be more careful
This was the readers' fault, not the plot's.
While readers should be careful, it's our responsibility as data scientists to make visualizations clear and unambiguous.

Crafting Axes Like a Pro Pharmacologist

Let's track a cancer drug in a patient's bloodstream:

# Simulating pharmacokinetic data time_hours <- seq(0, 24, by = 2) drug_concentration <- c(0, 2.8, 4.2, 5.1, 4.8, 4.2, 3.5, 2.8, 2.1, 1.5, 1.0, 0.6, 0.3) # Set up the canvas plot(time_hours, drug_concentration, type = "n", xlab = "", ylab = "", xlim = c(0, 24), ylim = c(0, 6), axes = FALSE) # Craft the x-axis axis(1, at = seq(0, 24, by = 4), labels = paste0(seq(0, 24, by = 4), "h"), cex.axis = 0.9) mtext("Time Post-Administration", side = 1, line = 2.5, cex = 1.1) # Create the y-axis axis(2, at = seq(0, 6, by = 1), las = 1, cex.axis = 0.9) mtext("Plasma Concentration (μg/mL)", side = 2, line = 3, cex = 1.1) # Add therapeutic window rect(0, 2, 24, 4, col = rgb(0, 1, 0, 0.1), border = NA) text(12, 3, "Therapeutic Range", col = "darkgreen", cex = 0.9) # Plot the data lines(time_hours, drug_concentration, col = "darkblue", lwd = 2) points(time_hours, drug_concentration, col = "darkblue", pch = 19) # Add danger zones text(1, 4.5, "TOXIC", col = "red", font = 2, cex = 0.8) text(1, 1.5, "INEFFECTIVE", col = "orange", font = 2, cex = 0.8) # Final touches title(main = "Pharmacokinetic Profile: Novel Anticancer Agent XR-2847", sub = "Phase I Clinical Trial - Patient Cohort A") grid(col = "lightgray", lty = "dotted") box()
Copied!

Lab Exercise 2: Tumor Growth Curves

You're testing a new MEK inhibitor. Create a publication-quality figure showing tumor growth over 21 days.

# Preclinical tumor study data days <- seq(0, 21, by = 3) control_tumor <- c(100, 145, 210, 305, 445, 650, 945, 1380) treatment_tumor <- c(100, 120, 135, 142, 138, 125, 108, 95) # TODO: Create plot with: # - Y-axis on LOG SCALE # - Both tumor curves # - Proper labels and legend
Copied!

Complete Solution

# Set up with log scale plot(days, control_tumor, type = "n", log = "y", xlim = c(0, 21), ylim = c(50, 2000), xlab = "", ylab = "", axes = FALSE) # Custom axes axis(1, at = seq(0, 21, by = 7), cex.axis = 0.9) mtext("Days Post-Treatment Initiation", side = 1, line = 2.5, cex = 1.1) y_ticks <- c(50, 100, 200, 500, 1000, 2000) axis(2, at = y_ticks, labels = y_ticks, las = 1, cex.axis = 0.9) mtext("Tumor Volume (mm³)", side = 2, line = 3.5, cex = 1.1) # Plot data lines(days, control_tumor, col = "red", lwd = 2.5, lty = 1) points(days, control_tumor, col = "red", pch = 16, cex = 1.2) lines(days, treatment_tumor, col = "blue", lwd = 2.5, lty = 2) points(days, treatment_tumor, col = "blue", pch = 17, cex = 1.2) # Title and legend title(main = "Tumor Growth Inhibition: Novel MEK Inhibitor Study", sub = "C57BL/6 Mice, B16 Melanoma Model") legend("topleft", legend = c("Vehicle Control", "MEK Inhibitor (50mg/kg)"), col = c("red", "blue"), lty = c(1, 2), lwd = 2.5, pch = c(16, 17), bty = "n") # Add statistics text(15, 100, "p < 0.001", font = 2, cex = 0.9) text(15, 85, "n = 8/group", font = 3, cex = 0.8)
