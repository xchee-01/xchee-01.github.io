🔬 Statistical Enhancement: Adding Trend Lines and Correlations

Medical researchers don't just want to see data points – they need to understand relationships! Let's add statistical insights to our scatter plots.

📈 Linear Regression and Correlation Coefficients

# Generate data for hypertension study np.random.seed(200) n_patients = 120 # Age of patients age = np.random.uniform(30, 80, n_patients) # Blood pressure increases with age (with variation) systolic_bp = 100 + 0.8 * age + np.random.normal(0, 12, n_patients)
Copied!
# Calculate correlation coefficient from scipy import stats correlation, p_value = stats.pearsonr(age, systolic_bp)
Copied!
# Perform linear regression slope, intercept = np.polyfit(age, systolic_bp, 1) regression_line = slope * age + intercept
Copied!
Linear Regression Basics
What does the slope value in a linear regression equation represent in the context of age vs blood pressure?
Average blood pressure across all ages
The average blood pressure value
Not quite. The average blood pressure would be calculated differently. The slope represents the rate of change.
Change in blood pressure per year of age
The increase in BP for each year increase in age
Correct! The slope tells us how much blood pressure changes for each unit increase in age.
Blood pressure when age is zero
The y-intercept value
That's the intercept, not the slope. The intercept is the theoretical BP at age 0.
Correlation coefficient
The strength of the relationship
The correlation coefficient (r) is a separate measure of relationship strength, not the slope.
# Create enhanced statistical plot plt.figure(figsize=(12, 8))
Copied!
# Plot scatter points plt.scatter(age, systolic_bp, alpha=0.6, s=60, c='navy', edgecolor='black', linewidth=0.5)
Copied!
# Add regression line plt.plot(age, regression_line, 'r-', linewidth=2, label=f'Linear fit: BP = {slope:.1f} × Age + {intercept:.1f}')
Copied!
# Add confidence interval (95%) from scipy import stats predict_error = systolic_bp - regression_line ci = 1.96 * np.std(predict_error) # 95% confidence interval plt.fill_between(age, regression_line - ci, regression_line + ci, alpha=0.2, color='red', label='95% Confidence Interval')
Copied!
Confidence Intervals
What does a 95% confidence interval around a regression line indicate?
95% of data points fall within
Most data points are in this range
That's a common misconception. The CI is about the regression line, not individual data points.
95% confidence the true line is within
We're 95% confident the true regression line is in this band
Correct! The CI represents our uncertainty about where the true population regression line lies.
Correlation is 0.95
The correlation coefficient value
The 95% refers to confidence level, not the correlation coefficient value.
P-value is less than 0.05
Statistical significance level
While related to significance, the CI shows uncertainty about the regression line position.
# Add correlation info to plot textstr = f'Pearson r = {correlation:.3f}\np-value = {p_value:.4f}' plt.text(0.05, 0.95, textstr, transform=plt.gca().transAxes, fontsize=12, verticalalignment='top', bbox=dict(boxstyle='round', facecolor='wheat', alpha=0.8))
Copied!
# Finalize plot with labels plt.title('Age-Related Blood Pressure Changes in Hypertension Study', fontsize=16, pad=20) plt.xlabel('Patient Age (years)', fontsize=14) plt.ylabel('Systolic Blood Pressure (mmHg)', fontsize=14) plt.legend(loc='lower right') plt.grid(True, alpha=0.3) plt.show()
Copied!

Statistical Insight: A p-value < 0.05 indicates a statistically significant relationship. In medical research, we also consider clinical significance – even small correlations can be meaningful for patient care! 📊

🎯 Identifying and Highlighting Outliers

In medical data, outliers might represent:

  • Patients with rare genetic variants
  • Measurement errors needing investigation
  • Candidates for personalized treatment protocols
# Generate clinical trial data with outliers np.random.seed(300) n_patients = 150 # Most patients respond normally to treatment dose = np.random.uniform(10, 100, n_patients) response = 20 + 0.5 * dose + np.random.normal(0, 8, n_patients) # Add some outliers (unusual responders) outlier_indices = [10, 25, 67, 89, 134] for idx in outlier_indices: if idx < len(response): # Some are hyper-responders, some are non-responders if idx % 2 == 0: response[idx] = response[idx] + 40 # Hyper-responder else: response[idx] = 10 # Non-responder
Copied!
# Identify outliers using z-score method z_scores = np.abs(stats.zscore(response)) outlier_mask = z_scores > 2.5 # Points beyond 2.5 standard deviations
Copied!
Outlier Detection
What does a z-score of 2.5 indicate about a data point?
2.5 times larger than mean
The value is 2.5× the average
Z-score measures standard deviations, not multiples of the mean.
2.5 standard deviations from mean
It's 2.5 SDs away from the average
Correct! Z-score measures how many standard deviations a point is from the mean.
25th percentile
In the bottom quarter of data
Z-score doesn't directly indicate percentile. A z-score of 2.5 is actually very extreme.
Correlation of 0.25
Weak correlation with other variables
Z-score is about distance from mean, not correlation with other variables.
# Create plot with highlighted outliers plt.figure(figsize=(12, 8))
Copied!
# Plot normal responders plt.scatter(dose[~outlier_mask], response[~outlier_mask], alpha=0.6, s=60, c='blue', label='Normal Responders')
Copied!
# Highlight outliers with different color and size plt.scatter(dose[outlier_mask], response[outlier_mask], alpha=0.8, s=200, c='red', marker='*', edgecolor='darkred', linewidth=2, label='Unusual Responders')
Copied!
# Add annotations for outliers for i, (d, r) in enumerate(zip(dose[outlier_mask], response[outlier_mask])): plt.annotate(f'Patient {np.where(outlier_mask)[0][i]}', xy=(d, r), xytext=(d+5, r+5), arrowprops=dict(arrowstyle='->', color='red', alpha=0.7), fontsize=10, color='darkred')
Copied!
# Complete the clinical plot plt.title('Drug Response Variability: Identifying Unusual Responders', fontsize=16, pad=20) plt.xlabel('Drug Dose (mg)', fontsize=14) plt.ylabel('Clinical Response Score', fontsize=14) plt.legend() plt.grid(True, alpha=0.3) plt.show()
Copied!

Precision Medicine Note: These "outliers" might have genetic variants affecting drug metabolism. In precision health, today's outlier could be tomorrow's personalized treatment group! 🧬

💊 Personalized Medicine: Pharmacogenomics

Scatter plots help identify how genetic variations affect drug response:

# Simulate pharmacogenomics study np.random.seed(600) # Three genetic variants with different drug clearance rates n_per_variant = 60 # Wild type (normal) drug_dose_wt = np.random.uniform(50, 200, n_per_variant) blood_level_wt = drug_dose_wt * np.random.normal(1.0, 0.15, n_per_variant) # Heterozygous (reduced clearance) drug_dose_het = np.random.uniform(50, 200, n_per_variant) blood_level_het = drug_dose_het * np.random.normal(1.5, 0.2, n_per_variant) # Homozygous (poor clearance) drug_dose_hom = np.random.uniform(50, 200, n_per_variant) blood_level_hom = drug_dose_hom * np.random.normal(2.2, 0.25, n_per_variant)
Copied!

Decrease dose by ~55%

# Create personalized medicine visualization fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 6)) # Left panel: Raw data ax1.scatter(drug_dose_wt, blood_level_wt, c='green', alpha=0.6, s=50, label='Wild Type') ax1.scatter(drug_dose_het, blood_level_het, c='orange', alpha=0.6, s=50, label='Heterozygous') ax1.scatter(drug_dose_hom, blood_level_hom, c='red', alpha=0.6, s=50, label='Homozygous Variant') # Add therapeutic window ax1.axhspan(100, 200, alpha=0.2, color='lightblue', label='Therapeutic Range') ax1.axhspan(200, 400, alpha=0.2, color='salmon', label='Toxic Range') ax1.set_xlabel('Drug Dose (mg)', fontsize=12) ax1.set_ylabel('Blood Level (ng/mL)', fontsize=12) ax1.set_title('Pharmacogenomic Drug Response by Genotype', fontsize=14) ax1.legend() ax1.grid(True, alpha=0.3) # Right panel: Dosing recommendations genotypes = ['Wild Type', 'Heterozygous', 'Homozygous'] recommended_doses = [150, 100, 68] dose_ranges = [25, 20, 15] x_pos = np.arange(len(genotypes)) ax2.bar(x_pos, recommended_doses, yerr=dose_ranges, color=['green', 'orange', 'red'], alpha=0.7, error_kw={'linewidth': 2, 'capsize': 5}) ax2.set_ylabel('Recommended Dose (mg)', fontsize=12) ax2.set_title('Personalized Dosing Guidelines', fontsize=14) ax2.set_xticks(x_pos) ax2.set_xticklabels(genotypes) ax2.grid(True, axis='y', alpha=0.3) plt.tight_layout() plt.show()
