Mission Briefing: Variable Naming Conventions

Imagine walking into a lab where all the test tubes are labeled with random symbols like "X1", "Z42", and "???" - chaos would ensue! Similarly, in Python, how we name our variables matters immensely.

Let's start with basic naming before adding medical context:

# Simple variable names name = "Claude" age = 25 height_in_cm = 175.5
Copied!

In medical programming, clear labeling is even more critical - the difference between hba1c and hgba1c could lead to serious misinterpretations!

Python has specific rules for creating variable names:

# RULE 1: Variable names can contain letters, numbers, and underscores sample_1 = "Blood sample" patient_name = "John Smith" test_result_2023 = "Negative" # Let's try to break rule 1 - uncomment to see the error # patient-name = "Jane Smith" # Hyphens aren't allowed!
Copied!

Which of these variable names would cause an error in Python?
patient_name
Incorrect. This variable name is valid in Python. It uses only letters and underscores, which are allowed.
patient-name
Correct! Variable names in Python cannot contain hyphens. Python would interpret the hyphen as the subtraction operator, leading to a syntax error.

Incorrect. While snake_case is more common in Python, camelCase is perfectly valid and won't cause an error.

Incorrect. Numbers are allowed in variable names, as long as the name doesn't start with a number. This is a valid variable name.
# RULE 2: Variable names cannot start with a number # 1st_patient = "Jane Smith" # This would cause an error first_patient = "Jane Smith" # This is correct

Beyond these basic rules, following conventions makes your medical code more readable:

# Use descriptive names that explain purpose # Not so good: x = 37.5 # Much better: body_temperature_celsius = 37.5 # Use lowercase letters and underscores (snake_case) blood_glucose_level = 105.5 dna_methylation_status = "hypermethylated"

Mission Briefing: Variable Reassignment

Much like how a patient's vital signs change over time, variables in Python can be updated through a process called "reassignment." This allows us to track changing values throughout our program.

Let's start with a simple, non-medical example:

# Simple variable assignment and reassignment score = 10 print("Initial score:", score) # Now let's change the value score = 15 print("Updated score:", score)
Copied!
Prediction Challenge
What will the code above output?
Initial score: 10
Updated score: 15
Correct! The variable 'score' is first assigned the value 10, which is printed. Then it's reassigned the value 15, which is printed next. Reassignment replaces the old value with the new one.
Initial score: 10
Updated score: 10
Incorrect. The second assignment (score = 15) changes the value stored in the variable, so the second print statement will show the updated value, not the original.
Initial score: 10
Updated score: 25
Incorrect. The assignment operator (=) completely replaces the old value with the new one; it doesn't add them together. To add the values, you would need code like: score = score + 15 or score += 15.
Error: Cannot reassign a variable
Incorrect. Python allows variables to be reassigned with new values at any time. This is different from some languages that have "constants" that can't be changed after initial assignment.

When you reassign a variable, Python replaces the old value with the new one. This is like updating a patient's chart with new information.

Now let's explore this in a healthcare context:

# Initial diagnosis information diagnosis = "Suspected Type 2 Diabetes" fasting_glucose = 126 # mg/dL hba1c = 6.8 # % treatment_plan = "Pending confirmation" print("Initial assessment:") print("Diagnosis:", diagnosis) print("Fasting Glucose:", fasting_glucose, "mg/dL") print("HbA1c:", hba1c, "%") print("Treatment Plan:", treatment_plan) # After additional testing, we can reassign these variables diagnosis = "Confirmed Type 2 Diabetes" fasting_glucose = 131 # Repeat test showed higher value hba1c = 7.1 # Repeat test showed higher value treatment_plan = "Metformin 500mg daily + Lifestyle modification" print("\nUpdated assessment after comprehensive testing:") print("Diagnosis:", diagnosis) print("Fasting Glucose:", fasting_glucose, "mg/dL") print("HbA1c:", hba1c, "%") print("Treatment Plan:", treatment_plan)
Copied!

You can also reassign variables based on their current values, which is incredibly useful for tracking changes:

# Tracking tumor size during treatment tumor_diameter_mm = 24.5 # Initial measurement print("Initial tumor diameter:", tumor_diameter_mm, "mm") # After first treatment cycle - let's reduce it by 3.2mm tumor_diameter_mm = tumor_diameter_mm - 3.2 print("After first treatment cycle:", tumor_diameter_mm, "mm") # After second treatment cycle - another reduction of 5.7mm tumor_diameter_mm = tumor_diameter_mm - 5.7 print("After second treatment cycle:", tumor_diameter_mm, "mm")
Copied!

Key point to remember:
When tracking changes with variable reassignment, each operation builds upon the current value, not the original value. This is why we get 15.6mm rather than 24.5 - (3.2 + 5.7) = 15.6mm.

Variables can even be reassigned to different data types, though in medical applications, we need to be careful:

# Changing a variable's type through reassignment patient_status = "Stable" # Initially a string print("Status:", patient_status) patient_status = 2 # Reassigned to an integer code (e.g., 2 = Stable) print("Status code:", patient_status) # In medical applications, be careful with type changes to avoid confusion!

Clinical Insight: When writing code for clinical decision support systems, variables that represent a patient's status often need to be reassigned as new information becomes available. For example, a stroke risk assessment might begin with a preliminary score but be reassigned when imaging results arrive.

Real-World Connection: In pharmacokinetic modeling, researchers use variable reassignment to simulate how drug concentrations change in different body compartments over time. The PKPD (Pharmacokinetics/Pharmacodynamics) models that determine personalized dosing regimens depend on continuously updating variables to track concentrations in blood, tissue, and elimination pathways.

Summary: Part 2 - Variable Naming and Reassignment

Excellent work! In Part 2, you've learned essential skills for creating maintainable, clear code that can track changing medical data:

  1. Variable Naming Rules and Conventions:
    • Names can contain letters, numbers, and underscores
    • Names cannot start with a number
    • Names cannot contain spaces or special characters
    • Names are case-sensitive
    • Use descriptive, lowercase_with_underscores names
  2. Variable Reassignment:
    • Variables can be updated with new values using the assignment operator
    • You can reassign based on current values (like tracking changes)

These skills are fundamental for developing precision health applications that process patient data over time, track disease progression, or simulate biological processes.
