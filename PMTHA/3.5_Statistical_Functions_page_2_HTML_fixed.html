Mission Briefing: Statistical Functions on Multi-dimensional Data

🎯 Quick Context: Real medical data is rarely one-dimensional. Think of it as a spreadsheet where rows are patients and columns are different measurements!

🏥 The Clinical Trial Spreadsheet

Imagine a spreadsheet:

  • Rows = Different patients
  • Columns = Measurements over time
  • We need statistics both ways!

📚 Understanding Axes: The Direction Matters!

# Simple visualization of axes # Think of a patient data table: # Day1 Day2 Day3 # Patient1 10 8 6 # Patient2 12 9 7 # Patient3 11 10 8 # # axis=0 : ↓ (down columns) - across patients # axis=1 : → (across rows) - across time
Copied!

Let's see this in action:

# Biomarker levels: rows=patients, columns=time points (days) # Measuring inflammatory marker CRP (C-Reactive Protein) in mg/L # Normal CRP: <3 mg/L, Inflammation: >3 mg/L import numpy as np crp_levels = np.array([ [8.5, 7.2, 5.8, 4.1, 3.2], # Patient 1: Improving! [12.3, 10.5, 8.7, 6.9, 5.5], # Patient 2: Slower improvement [6.7, 6.1, 5.2, 4.5, 3.8], # Patient 3: Steady progress [15.2, 13.8, 11.2, 8.5, 6.7] # Patient 4: High start, improving ]) # Question 1: What's the average CRP across all patients each day? daily_means = np.mean(crp_levels, axis=0) print("Average CRP by day:", daily_means) # Shows treatment is working - CRP drops each day! # Question 2: What's each patient's average CRP over the study? patient_means = np.mean(crp_levels, axis=1) print("Average CRP by patient:", patient_means) # Shows which patients had more severe inflammation
Copied!
🤔 Self-Check: Which axis would you use to find the sickest patient on day 1?
You have patient CRP data where rows are patients and columns are days. To find which patient had the highest CRP on day 1, which operation would you use?
np.max(crp_levels, axis=0)
Find the maximum value for each day across all patients.
Not quite. This would give you the maximum CRP for each day, but not which patient had it. You need the patient index, not just the maximum value.
np.argmax(crp_levels[:, 0])
Find the index of the patient with highest CRP on day 1 (column 0).
Correct! crp_levels[:, 0] selects all patients' data for day 1, and argmax returns the index of the patient with the highest value. This helps identify which patient needs immediate attention!
np.max(crp_levels, axis=1)
Find the maximum value for each patient across all days.
This would find each patient's highest CRP across all days, not specifically on day 1. We need to focus on just the first column of data.
np.mean(crp_levels[0, :])
Calculate the average CRP for the first patient.
This calculates the average CRP for patient 1 across all days, not finding which patient had the highest CRP on day 1.
# Tracking improvement variability daily_std = np.std(crp_levels, axis=0) print("Daily variation (std):", daily_std) # High variation = patients responding differently to treatment
Copied!

💡 Tip Box: Remember the axis trick:

  • axis=0: Collapse rows (analyze each column)
  • axis=1: Collapse columns (analyze each row)
  • No axis: Analyze everything as one big group

In the glucose data array where rows are patients and columns are meal times, which axis operations would you use?
axis=0 for meals, axis=1 for patients
Use axis=0 to analyze each meal across patients, axis=1 to analyze each patient across meals.
Correct! axis=0 collapses the patient rows, giving you statistics for each meal column. axis=1 collapses the meal columns, giving you statistics for each patient row.
axis=1 for meals, axis=0 for patients
Use axis=1 to analyze each meal across patients, axis=0 to analyze each patient across meals.
That's backwards! Remember: axis=0 operates down columns (across rows), while axis=1 operates across columns (along rows).
No axis parameter needed
Just use np.mean(glucose_data) for both calculations.
Without specifying an axis, you'd get the overall average of all values, not separate averages for each meal or patient.
Use axis=2 for advanced analysis
axis=2 provides more detailed statistical analysis.
Our glucose_data is a 2D array, so it only has axis=0 and axis=1. axis=2 would only exist in 3D arrays or higher.

Expected output:

💊 Excellent clinical analysis! Lunch shows the highest glucose spikes (173 mg/dL average). This suggests:

  • Lunch portions might be too large
  • Morning medication might be wearing off by noon

📊 Section Summary

  • Multi-dimensional data: Like spreadsheets with patients and measurements
  • axis=0: Analyze across rows (patient comparisons)
  • axis=1: Analyze across columns (time/measurement comparisons)

Mission Briefing: Correlation Analysis

🎯 Quick Context: Correlation finds relationships - like discovering that taller people tend to weigh more, or that exercise tends to lower blood pressure!

🔗 The Dance Partner Analogy

Correlation measures how two variables "dance together":

  • Positive correlation (+): They move in the same direction (height & weight)
  • Negative correlation (-): They move opposite ways (exercise & blood pressure)
  • No correlation (0): They ignore each other (shoe size & IQ)

📚 Understanding Correlation Values

# Simple example: Study hours vs test scores study_hours = np.array([1, 2, 3, 4, 5, 6, 7, 8]) test_scores = np.array([60, 65, 70, 75, 80, 82, 85, 88]) # Calculate correlation correlation = np.corrcoef(study_hours, test_scores)[0, 1] print(f"Study-Score correlation: {correlation:.3f}") # ~0.99: Nearly perfect positive correlation!
Copied!

Now for medical relationships:

# Patient data: age and systolic blood pressure ages = np.array([25, 35, 45, 55, 65, 30, 40, 50, 60, 70]) systolic_bp = np.array([118, 125, 132, 145, 158, 122, 130, 140, 152, 165]) # Calculate correlation coefficient correlation = np.corrcoef(ages, systolic_bp)[0, 1] print(f"Age-BP correlation: {correlation:.3f}") # ~0.99: Strong positive - BP tends to increase with age
Copied!

🔍 The Correlation Matrix: Relationship Map

# Add BMI data for the same patients bmi = np.array([22.5, 25.8, 28.2, 30.1, 29.5, 24.3, 27.6, 31.2, 29.8, 28.9]) # Create correlation matrix (shows all relationships) health_data = np.vstack([ages, systolic_bp, bmi]) corr_matrix = np.corrcoef(health_data) # Pretty print the correlation matrix variables = ['Age', 'Systolic BP', 'BMI'] print("\nCorrelation Matrix:") print(" ", " ".join(f"{var:>10}" for var in variables)) for i, var in enumerate(variables): print(f"{var:>8}", " ".join(f"{corr_matrix[i,j]:>10.3f}" for j in range(3)))
Copied!

💡 Tip Box: Correlation strength guide:

  • 0.9 to 1.0: Very strong
  • 0.7 to 0.9: Strong
  • 0.5 to 0.7: Moderate
  • 0.3 to 0.5: Weak
  • 0.0 to 0.3: Very weak

Fun Fact 🌟: Correlation ≠ Causation! Ice cream sales correlate with drowning deaths (both increase in summer), but ice cream doesn't cause drowning!

🤔 Think About It: If exercise and heart disease have correlation = -0.8, what does this mean for patients?
A study finds that exercise frequency and heart disease risk have a correlation of -0.8. What does this tell us?
Strong negative relationship
As exercise increases, heart disease risk tends to decrease significantly.
Correct! A correlation of -0.8 indicates a strong negative relationship. People who exercise more tend to have lower heart disease risk. However, remember this doesn't prove exercise directly prevents heart disease - other factors might be involved!
Exercise causes heart disease
The negative sign means exercise is harmful to the heart.
Not correct. The negative sign means an inverse relationship - as one goes up, the other goes down. So more exercise correlates with LESS heart disease, not more!
Weak relationship
The relationship is barely noticeable in real patients.
Actually, -0.8 indicates a STRONG relationship. Values close to -1 or +1 are strong, while values close to 0 are weak.
80% of exercisers avoid heart disease
The -0.8 means 80% effectiveness in prevention.
That's a common misconception. Correlation coefficients don't translate directly to percentages. -0.8 describes the strength and direction of the relationship, not a success rate.

Mission Briefing: Statistical Aggregation Functions

🎯 Quick Context: Aggregation functions are like having a team of data analysts who can instantly answer questions about your entire patient database!

🏥 The Hospital Database Scenario

Imagine you're managing a hospital lab with thousands of test results daily. You need to quickly find:

  • Which patient has critically low platelets?
  • What's the range of white blood cell counts today?
  • Are there any outliers suggesting lab errors?

📚 Finding Extremes and Ranges

# Patient lab results: rows=patients, columns=[WBC, RBC, Platelets] # Normal ranges: # WBC: 4-11 ×10^9/L # RBC: 4.5-5.5 ×10^12/L (men), 4.0-5.0 (women) # Platelets: 150-400 ×10^9/L lab_results = np.array([ [7.2, 4.8, 250], # Normal patient [15.8, 4.2, 180], # High WBC (infection?) [4.1, 3.2, 320], # Low RBC (anemia?) [8.5, 5.1, 150], # Borderline low platelets [6.9, 4.6, 280] # Normal patient ]) # Find min/max for each test type min_values = np.min(lab_results, axis=0) max_values = np.max(lab_results, axis=0) test_names = ['WBC', 'RBC', 'Platelets'] print("Test ranges in today's patients:") for i, test in enumerate(test_names): print(f"{test}: {min_values[i]:.1f} - {max_values[i]:.1f}")
Copied!

🔍 Smart Outlier Detection

# Identify outliers using the IQR method q1 = np.percentile(lab_results, 25, axis=0) q3 = np.percentile(lab_results, 75, axis=0) iqr = q3 - q1 # Outlier boundaries (1.5 × IQR rule) lower_bound = q1 - 1.5 * iqr upper_bound = q3 + 1.5 * iqr print("\n🚨 Outlier Alert System:") for i, test in enumerate(test_names): # Check each patient's value for this test outliers = np.logical_or( lab_results[:, i] < lower_bound[i], lab_results[:, i] > upper_bound[i] ) if np.any(outliers): patient_ids = np.where(outliers)[0] + 1 print(f"{test}: Patient(s) {patient_ids} flagged for review!")
Copied!

💡 Tip Box: The 1.5 × IQR rule catches values that are unusually far from the pack - perfect for spotting lab errors or critical conditions!

Real-World Connection 🌟: Modern hospital systems use these exact techniques to:

  • Generate real-time dashboards
  • Alert doctors to critical values
  • Track quality metrics
  • Optimize resource allocation
🤔 Self-Check: Why might we want to detect outliers in lab results?
What are the most important reasons for detecting outliers in medical lab results?
Safety and accuracy
Identify critical values needing immediate attention and potential lab errors.
Correct! Outlier detection serves dual purposes: identifying patients with critical values who need immediate care, and catching potential lab errors (like decimal point mistakes) that could lead to wrong treatment decisions.
Remove unusual patients
Exclude patients with abnormal values from studies.
Not the primary purpose. In medicine, outliers often represent the patients who need the most attention, not ones to exclude!
Simplify data analysis
Make statistical calculations easier by removing extreme values.
That's not the goal in clinical settings. Extreme values often indicate critical conditions that require immediate medical intervention.
Follow regulations
Meet government requirements for data reporting.
While regulations exist, the primary motivation is patient safety and data quality, not compliance.
