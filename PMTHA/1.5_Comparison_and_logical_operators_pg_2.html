Mission Briefing: Threshold Detection Fundamentals

In medicine, we're constantly evaluating whether patient values fall above or below critical thresholds. These aren't just numbers - they're the difference between "patient is stable" and "call the rapid response team!"

Your New Clinical Tools:

  • > (greater than): "Is this dangerously high?"
  • < (less than): "Is this dangerously low?"
  • >= (greater than or equal): "Has this reached the threshold?"
  • <= (less than or equal): "Is this within the safe limit?"

Let's start with basic threshold thinking:

# Basic threshold checking - like checking if it's hot outside temperature = 102 fever_threshold = 100.4 # Is temperature above fever threshold? has_fever = temperature > fever_threshold print("Patient has fever:", has_fever)
Copied!

Understanding Boundary Conditions

The difference between > and >= matters in medicine:

# Blood pressure at exactly the threshold systolic_bp = 140 hypertension_threshold = 140 # Different ways to evaluate the same reading using_greater_than = systolic_bp > hypertension_threshold # False using_greater_equal = systolic_bp >= hypertension_threshold # True print("Hypertensive (>):", using_greater_than) print("Hypertensive (>=):", using_greater_equal)
Copied!
🤔 Medical Decision
If 140 is the hypertension threshold, should we use > or >=?
>= (greater than or equal)
Correct! Most medical guidelines use >= because 140+ is considered hypertensive. A reading of exactly 140 meets the threshold for hypertension.
> (greater than)
Using only > would miss patients with BP exactly at 140, who should be classified as hypertensive according to medical guidelines.

🧪 Mini-Practice: Blood Pressure Categories

Complete this blood pressure assessment system:

📚 Medical Context: Blood pressure categories:

  • Normal: < 120 systolic AND < 80 diastolic
  • Elevated: 120-129 systolic
  • High (Stage 1): 130-139 systolic OR 80-89 diastolic
  • High (Stage 2): ≥ 140 systolic OR ≥ 90 diastolic
# Exercise: Blood pressure classification systolic_bp = 135 diastolic_bp = 88 # Fill in the comparison operators normal_systolic = systolic_bp ___ 120 elevated_range = systolic_bp ___ 120 # but we need to check it's also < 130 stage1_systolic = systolic_bp ___ 130 # and < 140 stage1_diastolic = diastolic_bp ___ 80 # and < 90 stage2_systolic = systolic_bp ___ 140 stage2_diastolic = diastolic_bp ___ 90 print(f"Blood Pressure: {systolic_bp}/{diastolic_bp}") print(f"Normal systolic range: {normal_systolic}") print(f"Stage 1 systolic: {stage1_systolic}") print(f"Stage 1 diastolic: {stage1_diastolic}") print(f"Stage 2 systolic: {stage2_systolic}") print(f"Stage 2 diastolic: {stage2_diastolic}")
Copied!

Complete Solution:

# Complete blood pressure classification systolic_bp = 135 diastolic_bp = 88 # Normal range checks normal_systolic = systolic_bp < 120 # False (135 is not < 120) # Elevated range (120-129 systolic) elevated_range = systolic_bp >= 120 # True (135 >= 120) # Stage 1 ranges (130-139 systolic OR 80-89 diastolic) stage1_systolic = systolic_bp >= 130 # True (135 >= 130) stage1_diastolic = diastolic_bp >= 80 # True (88 >= 80) # Stage 2 ranges (≥140 systolic OR ≥90 diastolic) stage2_systolic = systolic_bp >= 140 # False (135 < 140) stage2_diastolic = diastolic_bp >= 90 # False (88 < 90) print(f"Blood Pressure: {systolic_bp}/{diastolic_bp}") print(f"Normal systolic range: {normal_systolic}") # False print(f"Stage 1 systolic: {stage1_systolic}") # True print(f"Stage 1 diastolic: {stage1_diastolic}") # True print(f"Stage 2 systolic: {stage2_systolic}") # False print(f"Stage 2 diastolic: {stage2_diastolic}") # False # This patient has Stage 1 hypertension!

Medical Insight: This BP reading (135/88) falls into Stage 1 hypertension because both systolic (135) and diastolic (88) are in Stage 1 ranges.

🧪 Mini-Practice: Pediatric Fever Assessment

Children have different fever thresholds than adults. Let's build an age-appropriate fever detection system:

📚 Pediatric Context:

  • Infants (0-3 months): Fever ≥ 100.4°F (any fever is concerning)
  • Babies (3-24 months): Fever ≥ 101°F
  • Children (2+ years): Fever ≥ 102°F
# Exercise: Age-appropriate fever detection patient_age_months = 18 patient_temp_f = 101.2 # Age category thresholds infant_age_limit = 3 # months baby_age_limit = 24 # months infant_fever_threshold = 100.4 baby_fever_threshold = 101.0 child_fever_threshold = 102.0 # Fill in the age category checks is_infant = patient_age_months ___ infant_age_limit is_baby = patient_age_months ___ infant_age_limit # and also need < baby_age_limit is_child = patient_age_months ___ baby_age_limit # Fill in the fever checks for each age group infant_has_fever = patient_temp_f ___ infant_fever_threshold baby_has_fever = patient_temp_f ___ baby_fever_threshold child_has_fever = patient_temp_f ___ child_fever_threshold print(f"Patient: {patient_age_months} months old, Temperature: {patient_temp_f}°F") print(f"Is infant (0-3 months): {is_infant}") print(f"Is baby (3-24 months): {is_baby}") print(f"Is child (24+ months): {is_child}") print() print("Fever assessment by age category:") print(f"Would be fever if infant: {infant_has_fever}") print(f"Would be fever if baby: {baby_has_fever}") print(f"Would be fever if child: {child_has_fever}")
Copied!

Complete Solution:

# Complete pediatric fever assessment patient_age_months = 18 patient_temp_f = 101.2 infant_age_limit = 3 baby_age_limit = 24 infant_fever_threshold = 100.4 baby_fever_threshold = 101.0 child_fever_threshold = 102.0 # Age category determination is_infant = patient_age_months < infant_age_limit # False (18 < 3) is_baby = patient_age_months >= infant_age_limit # True (18 >= 3) is_child = patient_age_months >= baby_age_limit # False (18 < 24) # Fever thresholds by age group infant_has_fever = patient_temp_f >= infant_fever_threshold # True (101.2 >= 100.4) baby_has_fever = patient_temp_f >= baby_fever_threshold # True (101.2 >= 101.0) child_has_fever = patient_temp_f >= child_fever_threshold # False (101.2 < 102.0) print(f"Patient: {patient_age_months} months old, Temperature: {patient_temp_f}°F") print(f"Is infant (0-3 months): {is_infant}") # False print(f"Is baby (3-24 months): {is_baby}") # True print(f"Is child (24+ months): {is_child}") # False print() print("Fever assessment by age category:") print(f"Would be fever if infant: {infant_has_fever}") # True print(f"Would be fever if baby: {baby_has_fever}") # True print(f"Would be fever if child: {child_has_fever}") # False # Conclusion: This 18-month-old baby DOES have a fever (101.2°F ≥ 101°F threshold)
Copied!

Medical Insight: This 18-month-old falls in the "baby" category and DOES have a fever. Younger children have lower fever thresholds because their immune systems are still developing.

🧪 Lab Exercise 1: Laboratory Values Assessment System

Scenario: You're working in a clinical laboratory, and you need to create an automated system that flags abnormal lab results for physician review. Different tests have different reference ranges, and some are more critical than others.

📚 Medical Context:

  • Reference Range: The range of values expected in healthy individuals
  • Critical Values: Results that require immediate physician notification
  • Panic Values: Life-threatening results requiring immediate intervention

Step 1: Understanding Lab Reference Ranges

# Patient lab results patient_name = "John Davis" hemoglobin = 8.5 # g/dL (normal: 13.8-17.2 for men) white_blood_count = 2.8 # K/µL (normal: 4.0-11.0) platelet_count = 85 # K/µL (normal: 150-400) creatinine = 2.8 # mg/dL (normal: 0.7-1.3) glucose = 340 # mg/dL (normal: 70-100)

Step 2: Define Clinical Thresholds

{patient_name}") print("=" * 55) print("HEMATOLOGY:") print(f" Hemoglobin {hemoglobin} g/dL - Low: {hgb_low}, Critical: {hgb_critical}") print(f" WBC {white_blood_count} K/µL - Low: {wbc_low}, Critical Low: {wbc_critical_low_flag}") print(f" Platelets {platelet_count} K/µL - Low: {plt_low}, Critical: {plt_critical}") print() print("CHEMISTRY:") print(f" Creatinine {creatinine} mg/dL - High: {creat_high}, Critical: {creat_critical}") print(f" Glucose {glucose} mg/dL - High: {glucose_high}, Critical: {glucose_critical}") # Expected Output: # Hemoglobin 8.5 g/dL -
