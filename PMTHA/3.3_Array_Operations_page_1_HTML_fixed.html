Basic Mathematical Operations

🧮 The Fab Four: Addition, Subtraction, Multiplication, Division

These operations work element-wise, meaning each element in the array gets the operation applied to it individually. It's like having a personal calculator for each data point!

# Multiple patients' systolic blood pressure readings bp_readings = np.array([120, 135, 142, 118, 125, 139]) # Convert mmHg to other units for international standards bp_kpa = bp_readings * 0.133322 # Convert to kPa bp_torr = bp_readings * 1.0 # Already in Torr (same as mmHg) print("Blood Pressure Conversions:") print(f"mmHg: {bp_readings}") print(f"kPa: {bp_kpa.round(2)}") print(f"Torr: {bp_torr}") # Calculate pressure categories # Normal: <120, Elevated: 120-129, Stage 1: 130-139, Stage 2: ≥140 normal_count = np.sum(bp_readings < 120) elevated_count = np.sum((bp_readings >= 120) & (bp_readings < 130)) stage1_count = np.sum((bp_readings >= 130) & (bp_readings < 140)) stage2_count = np.sum(bp_readings >= 140) print(f"\nPressure Categories:") print(f"Normal (<120): {normal_count} patients") print(f"Elevated (120-129): {elevated_count} patients") print(f"Stage 1 (130-139): {stage1_count} patients") print(f"Stage 2 (≥140): {stage2_count} patients")
Copied!
Learning Checkpoint
If bp_readings = np.array([120, 135, 142]), what will bp_readings * 0.133322 return?
Option A
A single number
Not correct. NumPy operations are element-wise!
Option B
An array with each element multiplied by 0.133322
Correct! NumPy operations are element-wise, so multiplying an array by a scalar applies the operation to each element individually, returning a new array with each element multiplied by 0.133322.
Option C
An error message
No error occurs. Scalar-array multiplication is a valid NumPy operation.
Option D
The sum of all elements multiplied by 0.133322
That would require an additional operation like np.sum(). Multiplication alone returns an array.

📊 Statistical Functions for Medical Analysis

# Patient cholesterol levels (mg/dL) cholesterol = np.array([180, 220, 195, 240, 185, 210, 175, 230]) # Basic statistics mean_chol = np.mean(cholesterol) median_chol = np.median(cholesterol) std_chol = np.std(cholesterol) min_chol = np.min(cholesterol) max_chol = np.max(cholesterol) print("📊 Cholesterol Analysis Report") print("=" * 35) print(f"Average Level: {mean_chol:.1f} mg/dL") print(f"Median Level: {median_chol:.1f} mg/dL") print(f"Std Deviation: {std_chol:.1f} mg/dL") print(f"Range: {min_chol} - {max_chol} mg/dL") # Risk assessment # Total cholesterol: <200 Desirable, 200-239 Borderline, ≥240 High desirable = np.sum(cholesterol < 200) borderline = np.sum((cholesterol >= 200) & (cholesterol < 240)) high_risk = np.sum(cholesterol >= 240) print(f"\n🎯 Risk Assessment:") print(f"Desirable (<200): {desirable} patients") print(f"Borderline (200-239): {borderline} patients") print(f"High Risk (≥240): {high_risk} patients")

Complete Solution:

# Patient data: Heights (cm) and Weights (kg) heights_cm = np.array([165, 180, 175, 160, 170, 185, 168, 172]) weights_kg = np.array([65, 80, 75, 55, 70, 90, 62, 68]) # Step 1: Convert heights to meters heights_m = heights_cm / 100 # Step 2: Calculate BMI bmi_values = weights_kg / (heights_m ** 2) # Step 3: Categorize BMI values underweight = bmi_values < 18.5 normal = (bmi_values >= 18.5) & (bmi_values < 25) overweight = (bmi_values >= 25) & (bmi_values < 30) obese = bmi_values >= 30 # Detailed analysis print("🏥 Population BMI Analysis Report") print("=" * 40) print(f"Total patients analyzed: {len(bmi_values)}") print(f"Average BMI: {np.mean(bmi_values):.1f}") print(f"BMI Range: {np.min(bmi_values):.1f} - {np.max(bmi_values):.1f}") print(f"\n📊 BMI Distribution:") print(f"Underweight (<18.5): {np.sum(underweight)} patients ({np.mean(underweight)*100:.1f}%)") print(f"Normal (18.5-24.9): {np.sum(normal)} patients ({np.mean(normal)*100:.1f}%)") print(f"Overweight (25-29.9): {np.sum(overweight)} patients ({np.mean(overweight)*100:.1f}%)") print(f"Obese (≥30): {np.sum(obese)} patients ({np.mean(obese)*100:.1f}%)") # Detailed patient breakdown print(f"\n👥 Individual Patient Analysis:") for i in range(len(bmi_values)): height_m = heights_m[i] weight = weights_kg[i] bmi = bmi_values[i] if bmi < 18.5: category = "Underweight" emoji = "⬇️" elif bmi < 25: category = "Normal" emoji = "✅" elif bmi < 30: category = "Overweight" emoji = "⚠️" else: category = "Obese" emoji = "🚨" print(f"Patient {i+1}: {height_m:.2f}m, {weight}kg → BMI {bmi:.1f} {emoji} {category}")

🎯 Trigonometric Functions in Medical Modeling

# Model circadian body temperature variation hours = np.arange(0, 24, 0.5) # Every 30 minutes for 24 hours baseline_temp = 98.6 # Normal body temperature in °F amplitude = 1.8 # Temperature variation amplitude phase_shift = 6 # Peak occurs at 6 PM (18:00) # Circadian temperature model # Temperature peaks in evening, lowest in early morning temperature = baseline_temp + amplitude * np.sin(2 * np.pi * (hours - phase_shift) / 24) print("🌡️ Circadian Body Temperature Model") print("=" * 40) print(f"Time (hrs) Temperature (°F)") print("-" * 25) # Show temperature every 4 hours for i in range(0, len(hours), 8): # Every 4 hours hour = hours[i] temp = temperature[i] time_str = f"{int(hour):02d}:{int((hour % 1) * 60):02d}" print(f"{time_str} {temp:.1f}°F") # Find temperature extremes min_temp_idx = np.argmin(temperature) max_temp_idx = np.argmax(temperature) print(f"\nDaily Temperature Range:") print(f"Minimum: {temperature[min_temp_idx]:.1f}°F at {hours[min_temp_idx]:.1f} hours") print(f"Maximum: {temperature[max_temp_idx]:.1f}°F at {hours[max_temp_idx]:.1f} hours")
Copied!
Learning Checkpoint
In the circadian temperature model, what does the amplitude parameter control?
Option A
The average body temperature
That's the baseline_temp parameter. Amplitude controls something else.
Option B
How much the temperature varies above and below baseline
Correct! The amplitude parameter controls how much the temperature varies above and below the baseline temperature. A larger amplitude means greater temperature variation.
Option C

That's controlled by the phase_shift parameter.
Option D

The cycle is fixed at 24 hours (circadian). Amplitude affects the variation range.

Lab Exercise 3: Model Heart Rate Variability

Create a model showing how heart rate varies during exercise and recovery using exponential functions.

Answer:

# Heart rate during exercise and recovery time_minutes = np.arange(0, 30, 0.5) # 30 minutes, sampled every 30 seconds # Resting heart rate resting_hr = 70 # Exercise phase (0-10 minutes): exponential rise exercise_mask = time_minutes <= 10 max_hr = 160 # Maximum heart rate during exercise exercise_hr = resting_hr + (max_hr - resting_hr) * (1 - np.exp(-0.3 * time_minutes[exercise_mask])) # Recovery phase (10-30 minutes): exponential decay recovery_mask = time_minutes > 10 recovery_time = time_minutes[recovery_mask] - 10 recovery_hr = max_hr * np.exp(-0.15 * recovery_time) + resting_hr * (1 - np.exp(-0.15 * recovery_time)) # Combine both phases heart_rate = np.zeros_like(time_minutes) heart_rate[exercise_mask] = exercise_hr heart_rate[recovery_mask] = recovery_hr # Plot summary print("💓 Heart Rate During Exercise and Recovery") print("=" * 45) print("Time (min) Phase Heart Rate (bpm)") print("-" * 45) key_times = [0, 5, 10, 15, 20, 25, 30] for t in key_times: idx = int(t * 2) # Convert to index if idx < len(heart_rate): phase = "Exercise" if t <= 10 else "Recovery" print(f"{t:>5} {phase:<10} {heart_rate[idx]:.0f}") print(f"\nPeak heart rate: {np.max(heart_rate):.0f} bpm at {time_minutes[np.argmax(heart_rate)]:.1f} minutes") print(f"Recovery to <100 bpm at: {time_minutes[heart_rate < 100][-1]:.1f} minutes")
