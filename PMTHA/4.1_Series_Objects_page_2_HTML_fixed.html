Series Objects - Creating Series from Dictionaries

Welcome to this module! In this session, you'll master creating pandas Series from dictionaries - a crucial skill for handling medical data that often arrives as key-value pairs from various healthcare systems.

4.1.3. Mission Briefing: Creating Series from Dictionaries

🗂️ Why Dictionaries Make Perfect Medical Records

In medical informatics, data often arrives as key-value pairs - perfect for Python dictionaries! Think about it:

  • 🏥 Each vital sign has a name and a value
  • 🧪 Each lab test has a name and a result
  • 💊 Each medication has a name and a dosage

Converting dictionaries to Series gives us the best of both worlds: intuitive structure PLUS analytical superpowers!

🌡️ Patient Vital Signs Dashboard

# Patient vital signs as a dictionary # Emergency Department triage assessment vital_signs = { 'Heart Rate': 72, 'Temperature': 37.1, 'Respiratory Rate': 16, 'Oxygen Saturation': 98, 'Blood Pressure Systolic': 120, 'Blood Pressure Diastolic': 80 } # Convert to Series for analysis vitals_series = pd.Series(vital_signs) print("🚨 EMERGENCY DEPARTMENT TRIAGE") print("=" * 40) print("Patient Vital Signs:") print(vitals_series) # Quick triage assessment if vitals_series['Temperature'] > 38: print("\n⚠️ ALERT: Fever detected!") else: print("\n✅ Temperature: Normal")

🧪 Lab Results with Clinical Decision Support

# Basic Metabolic Panel (BMP) results lab_results = { 'Glucose': 95, 'Creatinine': 1.0, 'Potassium': 4.2, 'Sodium': 140, 'Calcium': 9.8 } # Normal ranges for reference (simplified) normal_ranges = { 'Glucose': (70, 100), 'Creatinine': (0.7, 1.3), 'Potassium': (3.5, 5.0), 'Sodium': (136, 145), 'Calcium': (8.5, 10.5) } labs_series = pd.Series(lab_results) print("\n🔬 Basic Metabolic Panel Results:") print("=" * 40) for test, value in labs_series.items(): low, high = normal_ranges[test] status = "✅" if low <= value <= high else "⚠️" print(f"{status} {test}: {value} (Normal: {low}-{high})")
Copied!

💡 Clinical Insight: Notice how easy it is to compare results against normal ranges when your data is well-organized in a Series!

Lab Results Analysis
Given the lab_results Series above, which code would correctly identify if the patient's Glucose level is within normal range?
labs_series['Glucose'] >= 70 and labs_series['Glucose'] <= 100
Using comparison operators with the Series index.
Correct! This code correctly accesses the Glucose value by its key and checks if it's within the normal range (70-100). Series allow accessing values by their index labels, making medical data analysis intuitive.
labs_series.Glucose in range(70, 101)
Using the 'in' operator with a range object.
Incorrect. The 'in' operator with range() only works for integers, not floats. Also, attribute access (labs_series.Glucose) won't work for index labels with spaces.
labs_series[0] >= 70 and labs_series[0] <= 100
Using numeric position to access the value.
While this might work, it's not reliable. The position of 'Glucose' might change if the dictionary order changes. Always use the label for clarity and safety.
labs_series.get('Glucose') == normal_ranges['Glucose']
Comparing the value directly to the range tuple.
This compares the glucose value (95) to a tuple (70, 100), which will never be equal. You need to check if the value is within the range, not equal to it.

🏥 Real-World Integration

Hospital Laboratory Information Systems (LIS) like LabCorp and Quest Diagnostics export test results as key-value pairs. Here's why Series are perfect for this:

  1. Instant Analysis: labs_series.mean() gives average of all tests
  2. Quick Lookups: labs_series['Glucose'] is clearer than remembering array positions
  3. Bulk Operations: Apply normal range checks to all tests at once
  4. Integration Ready: Easily combines with patient DataFrames

# Complete solution with enhanced clinical decision support pain_assessment = { 'Lower Back': 7, 'Neck': 4, 'Right Knee': 6, 'Left Shoulder': 2, 'Head': 3 } pain_series = pd.Series(pain_assessment) print("🏥 ORTHOPEDIC PAIN ASSESSMENT") print("Patient ID: 12345 | Date: Today") print("=" * 40) print("Pain Levels by Body Region (0-10 scale):") print(pain_series) # Enhanced clinical analysis print(f"\n📊 Clinical Summary:") print(f" Highest pain area: {pain_series.idxmax()} ({pain_series.max()}/10)") print(f" Average pain level: {pain_series.mean():.1f}") print(f" Total regions assessed: {len(pain_series)}") # Categorize pain levels print(f"\n📋 Pain Distribution:") mild = pain_series[(pain_series >= 0) & (pain_series <= 3)] moderate = pain_series[(pain_series >= 4) & (pain_series <= 6)] severe = pain_series[pain_series >= 7] print(f" Mild (0-3): {len(mild)} regions") print(f" Moderate (4-6): {len(moderate)} regions") print(f" Severe (7-10): {len(severe)} regions") # Treatment recommendations if len(severe) > 0: print(f"\n🚨 URGENT ATTENTION NEEDED:") for region, score in severe.items(): print(f" - {region}: Score {score} - Consider immediate intervention") # Visual pain map (text-based) print(f"\n🗺️ Pain Heat Map:") for region, score in pain_series.items(): bar = "█" * score + "░" * (10 - score) print(f" {region:15} [{bar}] {score}")

Creating the Pain Assessment
What is the correct way to create the pain_assessment dictionary and convert it to a Series?
Using square brackets for dictionary
pain_assessment = ['Lower Back': 7, 'Neck': 4, 'Right Knee': 6, 'Left Shoulder': 2, 'Head': 3]
pain_series = pd.Series(pain_assessment)
Incorrect. Square brackets [] create lists, not dictionaries. Dictionaries require curly braces {}.
Using curly braces with key:value pairs
pain_assessment = {'Lower Back': 7, 'Neck': 4, 'Right Knee': 6, 'Left Shoulder': 2, 'Head': 3}
pain_series = pd.Series(pain_assessment)
Correct! This uses the proper dictionary syntax with curly braces {} and key:value pairs separated by commas. This creates a proper dictionary that can be converted to a Series.
Using parentheses to create tuple
pain_assessment = ('Lower Back', 7, 'Neck', 4, 'Right Knee', 6, 'Left Shoulder', 2, 'Head', 3)
pain_series = pd.Series(pain_assessment)
This creates a tuple, not a dictionary. The Series would use numeric indices instead of body part names.
Using sets with nested lists
pain_assessment = {['Lower Back', 7], ['Neck', 4], ['Right Knee', 6], ['Left Shoulder', 2], ['Head', 3]}
pain_series = pd.Series(pain_assessment)
This syntax is invalid. You cannot create a set with lists as elements, and this wouldn't create the key-value structure needed.
Series Methods for Medical Analysis
Which pandas Series method would you use to find the body region with the highest pain level?
pain_series.max()
Returns the maximum value in the Series.
This returns only the value (7), not the location. In medical contexts, knowing WHERE the pain is highest is crucial.
pain_series.idxmax()
Returns the index of the maximum value.
Correct! idxmax() returns the index (body region name) of the maximum value in the Series. This is crucial for identifying which area needs immediate attention.
pain_series.argmax()
Returns the integer position of the maximum value.
argmax() is deprecated and returns the position (0, 1, 2...) not the label. Medical staff need the body part name, not a number.
pain_series.highest()
A method to find the highest value and its location.
There is no 'highest()' method in pandas. Use idxmax() to find the index of the maximum value.
Boolean Indexing for Medical Data
Which code correctly filters the pain_series to find all body regions with moderate pain (4-6)?
pain_series[4:7]
Using slice notation to select a range.
This uses positional slicing, not value-based filtering. It would select items by their position in the Series, not by their pain values.
pain_series[pain_series in [4, 5, 6]]
Using the 'in' operator with a list.
This syntax is invalid. The 'in' operator doesn't work this way with Series. Use comparison operators instead.
pain_series[(pain_series >= 4) & (pain_series <= 6)]
Using boolean indexing with comparison operators.
Correct! Boolean indexing with (pain_series >= 4) & (pain_series <= 6) creates a mask that selects all values between 4 and 6 inclusive. Note the parentheses and & operator for combining conditions in pandas.
pain_series.filter(lambda x: 4 <= x <= 6)
Using the filter method with a lambda function.
The filter() method works on index labels, not values. It's used to filter by index names that match certain criteria.

What does pain_series.std() calculate in the context of pain assessment?
The sum of all pain scores
Adding up all the pain values together.
That would be sum(), not std(). Standard deviation measures spread, not total.
The standard deviation showing how much pain levels vary across body regions
A measure of the spread or variability of pain scores.
Correct! The standard deviation (std()) measures the variability or spread of pain scores across different body regions. A high std indicates pain is concentrated in specific areas, while a low std suggests more uniform pain distribution.
The difference between highest and lowest pain scores
The range of pain values in the assessment.
That would be the range (max() - min()), not standard deviation. Std measures average distance from the mean.
The most common pain score

That would be the mode, not standard deviation. Std measures spread around the mean.

# Solution: COVID-19 oxygen monitoring times = ['00:00', '04:00', '08:00', '12:00', '16:00', '20:00'] o2_levels = [95, 93, 91, 89, 90, 92] o2_series = pd.Series(o2_levels, index=times) print("COVID-19 Patient Oxygen Monitoring") print("=" * 35) print(o2_series) # Find when O2 was lowest print(f"\nLowest O2: {o2_series.min()}% at {o2_series.idxmin()}") # Check if improving first_half = o2_series[:3].mean() second_half = o2_series[3:].mean() print(f"\nFirst 12 hours average: {first_half:.1f}%") print(f"Last 12 hours average: {second_half:.1f}%") if second_half > first_half: print("✅ Patient showing improvement!") else: print("⚠️ No improvement detected")
