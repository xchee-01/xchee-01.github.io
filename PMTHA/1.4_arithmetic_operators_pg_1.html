Mission Briefing: Basic Arithmetic Operations

Before we diagnose patients, let's learn how to use our basic tools. Python arithmetic operators are like the fundamental instruments in your medical bag - simple but powerful!

First, let's learn the operators themselves:

# Just the basic operators print(5 + 3) # Addition: 8 print(10 - 4) # Subtraction: 6 print(3 * 7) # Multiplication: 21 print(20 / 5) # Division: 4.0

Learning Checkpoint
What will the code above output for print(20 / 5)?

Not quite right. In Python, division (/) always returns a floating-point number, even when dividing integers.
4.0
Correct! In Python, the division operator (/) always returns a floating-point number, even when the result is a whole number.

Not quite. Python displays floating-point results with just one decimal place (4.0) when the fractional part is zero.

Incorrect. Python evaluates the expression and displays the result (4.0), not the expression itself.

Now let's apply these operators to something more interesting:

# Addition operator (+) a = 5 b = 10 sum_result = a + b print("The sum is:", sum_result) # The sum is: 15
Copied!

Great! Now let's step into the medical world gradually:

# Addition operator (+) in healthcare fasting_glucose = 95 # Blood sugar measured after fasting (mg/dL) post_meal_glucose = 142 # Blood sugar measured after eating (mg/dL) total_glucose = fasting_glucose + post_meal_glucose print("Sum of glucose readings:", total_glucose, "mg/dL")
Copied!

Mini Medical Note: Glucose levels are important indicators of diabetes. Normal fasting glucose is typically below 100 mg/dL.

Let's continue with the remaining operators, first with simple examples, then with healthcare applications:

# Subtraction operator (-) original_value = 50 decrease = 15 new_value = original_value - decrease print("After decrease:", new_value) # After decrease: 35

# Subtraction operator (-) in healthcare initial_white_blood_cells = 11500 # cells per microliter of blood normal_wbc_level = 7500 # normal level elevated_wbc_count = initial_white_blood_cells - normal_wbc_level print("Elevated white blood cells:", elevated_wbc_count, "cells/μL")
Copied!

Mini Medical Note: Elevated white blood cell count often indicates infection or inflammation.

# Multiplication operator (*) width = 4 height = 7 area = width * height print("The area is:", area) # The area is: 28
Copied!
# Multiplication operator (*) in healthcare medication_per_kg = 5 # mg per kg body weight patient_weight = 70 # kg medication_dose = medication_per_kg * patient_weight print("Recommended medication dose:", medication_dose, "mg")
Copied!
# Division operator (/) total = 100 parts = 4 part_size = total / parts print("Each part is:", part_size) # Each part is: 25.0
Copied!
# Division operator (/) in healthcare total_radiation = 5000 # mGy (milligray - a radiation unit) number_of_sessions = 20 radiation_per_session = total_radiation / number_of_sessions print("Radiation per therapy session:", radiation_per_session, "mGy")
Copied!

These operators work on various numeric data types. In Python, division (`/`) always returns a floating-point number (decimal), even when dividing integers - just like how a precise medical measurement might include decimal points!

There's also an integer division operator (`//`) that returns the quotient without the remainder - think of it as counting complete pills or full treatment days:

# Integer division examples print(10 // 3) # Results in 3 (the whole number of times 3 fits into 10) print(7 // 2) # Results in 3 (the whole number of times 2 fits into 7)
Copied!
# Integer division operator (//) in healthcare total_pills = 90 daily_intake = 3 treatment_days = total_pills // daily_intake print("Complete treatment days:", treatment_days, "days")
Copied!

Real-World Connection: Just as a nurse needs to determine how many full days a pill supply will last, integer division helps us calculate whole units when fractions don't make sense. Medical researchers use these basic arithmetic operations to analyze trial data, calculate drug concentrations, and process large genomic datasets.

Learning Checkpoint
When would you use regular division (/) versus integer division (//) in a healthcare setting?
Always use regular division (/) for all medical calculations
Not always. While regular division is common for precise measurements, there are clinical scenarios where integer division is more appropriate.
Use regular division (/) for precise dosage calculations and integer division (//) when counting whole units like pills or days
Correct! Regular division (/) is ideal for precise measurements like drug concentrations, while integer division (//) is perfect for scenarios where fractions don't make sense, like counting complete treatment days or whole pills.
Always use integer division (//) because medical treatments always use whole numbers
Incorrect. Many medical measurements and dosage calculations require precise decimal values, making regular division (/) essential in those cases.
The choice doesn't matter as both operators produce the same results
Not true. These operators produce different results when the division isn't even. For example, 5/2 = 2.5 while 5//2 = 2. In medical contexts, this difference could be critical.
