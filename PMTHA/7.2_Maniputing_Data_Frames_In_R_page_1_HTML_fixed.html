🔬 Mission Briefing: Adding and Modifying Clinical Variables

🎯 Why This Matters

In medical research, raw data is like an uncut diamond - valuable but not yet brilliant. We often need to derive new variables from existing data to reveal hidden patterns. Think about calculating Body Mass Index (BMI) from height and weight, or creating risk scores from multiple biomarkers.

📊 The Power of Derived Variables

Adding calculated fields to patient data is crucial for clinical decision support. These derived variables often provide more meaningful insights than raw measurements alone.

Let's start with a simple example:

# Enhanced patient dataset with height and weight patient_data <- data.frame( patient_id = c("P001", "P002", "P003", "P004", "P005"), age = c(45, 32, 58, 41, 67), weight_kg = c(78, 65, 92, 70, 85), height_m = c(1.75, 1.68, 1.80, 1.72, 1.70), systolic_bp = c(125, 118, 142, 130, 155), diastolic_bp = c(82, 75, 90, 85, 95) )

# Calculate BMI (weight in kg / height in meters squared) patient_data$bmi <- patient_data$weight_kg / (patient_data$height_m^2) # Let's see our results print(patient_data)

Now let's categorize blood pressure status:

# Create hypertension risk category based on blood pressure # Using WHO criteria: ≥140 systolic OR ≥90 diastolic = hypertensive patient_data$bp_category <- ifelse(patient_data$systolic_bp >= 140 | patient_data$diastolic_bp >= 90, "Hypertensive", "Normal") # Display patient ID with BP readings and category print(patient_data[, c("patient_id", "systolic_bp", "diastolic_bp", "bp_category")])
Copied!

🧪 Lab Exercise 3: Clinical Risk Score Calculation

Your Mission: Develop a simple metabolic risk score to identify patients who need lifestyle interventions!

Risk Scoring Criteria:

  • BMI ≥ 30: 2 points (obesity threshold)
  • Age ≥ 50: 1 point (age-related risk)
  • Hypertensive BP: 2 points (cardiovascular risk)
Learning Checkpoint
# Lab scenario: Calculate metabolic risk scores patient_data <- data.frame( patient_id = c("P001", "P002", "P003", "P004", "P005"), age = c(45, 32, 58, 41, 67), weight_kg = c(78, 65, 92, 70, 85), height_m = c(1.75, 1.68, 1.80, 1.72, 1.70), systolic_bp = c(125, 118, 142, 130, 155), diastolic_bp = c(82, 75, 90, 85, 95) ) # Calculate BMI first patient_data$bmi <- patient_data$weight_kg / (patient_data$height_m^2) # TODO: Create risk_score variable using the criteria above # Hint: You'll need to add three ifelse() statements together! patient_data$risk_score <- _______________ # Display results print(patient_data[, c("patient_id", "age", "bmi", "risk_score")])

Which R expression correctly calculates the risk score according to the given criteria?
Option A
ifelse(patient_data$bmi >= 30, 2, 0) + ifelse(patient_data$age >= 50, 1, 0) + ifelse(patient_data$systolic_bp >= 140 | patient_data$diastolic_bp >= 90, 2, 0)
Correct! Option A correctly uses ifelse() for each condition with the proper comparison operators (>=) and OR logic (|) for blood pressure criteria.
Option B
ifelse(patient_data$bmi > 30, 2, 0) + ifelse(patient_data$age > 50, 1, 0) + ifelse(patient_data$systolic_bp > 140 & patient_data$diastolic_bp > 90, 2, 0)
Incorrect. This uses > instead of >= and AND (&) instead of OR (|) for blood pressure. The criteria require >= and OR logic.
Option C
sum(patient_data$bmi >= 30) * 2 + sum(patient_data$age >= 50) + sum(patient_data$systolic_bp >= 140) * 2
Wrong approach. sum() would count all patients meeting each criterion, not calculate individual scores. Also missing diastolic BP check.
Option D
(patient_data$bmi >= 30) * 2 + (patient_data$age >= 50) * 1 + (patient_data$bp_category == "Hypertensive") * 2
This assumes bp_category exists, but it's not created in this scenario. The approach is clever but wouldn't work without defining bp_category first.

Expected output:

patient_id age bmi risk_score 1 P001 45 25.46939 0 2 P002 32 23.03004 0 3 P003 58 28.39506 3 4 P004 41 23.66144 0 5 P005 67 29.41176 3

Solution

Complete solution with step-by-step calculation:

# Complete solution with step-by-step calculation patient_data$risk_score <- ifelse(patient_data$bmi >= 30, 2, 0) + # BMI points ifelse(patient_data$age >= 50, 1, 0) + # Age points ifelse(patient_data$systolic_bp >= 140 | # BP points patient_data$diastolic_bp >= 90, 2, 0) print(patient_data[, c("patient_id", "age", "bmi", "risk_score")])

🔬 Mission Briefing: Sorting and Ordering Patient Data - Digital Triage

🚨 The Art of Medical Prioritization

Imagine you're working in a busy emergency department. Patients don't get seen in the order they arrive - they're prioritized by severity. R's sorting capabilities let us implement this same triage logic with data!

🏥 Did You Know? The word "triage" comes from the French word "trier," meaning "to sort."

Sorting Strategies for Clinical Data

Let's explore different ways to organize our patient data:

# Sort patients by age (youngest to oldest) age_sorted <- patient_data[order(patient_data$age), ] print(age_sorted[, c("patient_id", "age")])
Copied!
# Sort by BMI in descending order (highest risk first) bmi_sorted <- patient_data[order(patient_data$bmi, decreasing = TRUE), ] print(bmi_sorted[, c("patient_id", "bmi")])
Copied!

Multi-level sorting:

# Complex sorting: First by risk score (high to low), then by age priority_sorted <- patient_data[order(-patient_data$risk_score, patient_data$age), ] print(priority_sorted[, c("patient_id", "risk_score", "age")])
Copied!
Learning Checkpoint
💡 Pro Tip: The minus sign (`-`) is a clever trick for descending order in the `order()` function!

Which of the following correctly sorts a data frame by column 'score' in descending order?
df[order(df$score, decreasing = FALSE), ]
Using decreasing = FALSE parameter
No, this would sort in ascending order. decreasing = FALSE is the default behavior.
df[order(-df$score), ]
Using the minus sign before the column
Correct! The minus sign (-) before a numeric column in order() sorts it in descending order. This is a shorthand alternative to using decreasing = TRUE.
df[sort(df$score, decreasing = TRUE), ]
Using sort() instead of order()
Incorrect. sort() returns sorted values, not indices. You need order() to get row indices for subsetting the data frame.
df[order(df$score), desc = TRUE]
Using desc = TRUE parameter
Wrong syntax. The parameter is 'decreasing', not 'desc', and it goes inside order(), not after the bracket.
