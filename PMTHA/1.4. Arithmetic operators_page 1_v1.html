Arithmetic Operators in Python for Precision Health

Welcome to your journey as a Precision Health Programmer! In this module, you'll learn how to use arithmetic operators in Python - essential tools that will help you analyze patient data, calculate drug dosages, process genomic information, and build models for personalized healthcare. Just as precision medicine requires exact measurements and calculations to tailor treatments to individual patients, Python's arithmetic operators provide the mathematical foundation for your biomedical analysis toolkit.

Mission Briefing: Addition and Subtraction Operators

In healthcare analytics, you'll frequently need to add values (like combining test results) or subtract them (like calculating differences between measurements). Python makes these operations straightforward using the + and - operators, which work just as you'd expect from mathematics.

When working with patient data or biological measurements, addition and subtraction become powerful tools for tracking changes over time, comparing values to reference ranges, or aggregating results across patient cohorts.

# Addition in clinical contexts baseline_glucose = 85 # mg/dL glucose_increase = 15 # mg/dL post_meal_glucose = baseline_glucose + glucose_increase print(f"Baseline glucose: {baseline_glucose} mg/dL") print(f"Increase after meal: {glucose_increase} mg/dL") print(f"Post-meal glucose: {post_meal_glucose} mg/dL") # Subtraction for differential analysis current_wbc_count = 7500 # cells/μL previous_wbc_count = 9200 # cells/μL wbc_difference = current_wbc_count - previous_wbc_count print(f"Previous white blood cell count: {previous_wbc_count} cells/μL") print(f"Current white blood cell count: {current_wbc_count} cells/μL") print(f"Change in WBC count: {wbc_difference} cells/μL")

These basic arithmetic operations form the foundation of many clinical calculations, from tracking biomarker changes to calculating medication adjustments. In precision medicine, even simple addition and subtraction can provide valuable insights when applied to the right biomedical data.

Real-World Connection: Clinical researchers tracking treatment responses often calculate the change in tumor size by subtracting follow-up measurements from baseline measurements. This simple subtraction operation helps determine if a therapy is effective or if the patient should be switched to an alternative treatment.

Lab Exercise 1: Vital Signs Analysis

As a medical intern monitoring a patient recovering from surgery, you need to calculate changes in vital signs over time to determine if the patient is stabilizing.

# Lab scenario: Calculate and analyze changes in patient vital signs # Fix the code below by adding the correct arithmetic operators # Morning vital signs morning_temperature = 38.2 # Celsius morning_systolic_bp = 142 # mmHg morning_diastolic_bp = 95 # mmHg morning_heart_rate = 105 # bpm # Evening vital signs evening_temperature = 37.4 # Celsius evening_systolic_bp = 135 # mmHg evening_diastolic_bp = 88 # mmHg evening_heart_rate = 92 # bpm # Calculate changes (evening - morning) temperature_change = evening_temperature ... morning_temperature systolic_change = evening_systolic_bp ... morning_systolic_bp diastolic_change = evening_diastolic_bp ... morning_diastolic_bp heart_rate_change = evening_heart_rate ... morning_heart_rate # Display the patient's progress print("PATIENT VITAL SIGNS REPORT") print(f"Temperature change: {temperature_change}°C") print(f"Systolic blood pressure change: {systolic_change} mmHg") print(f"Diastolic blood pressure change: {diastolic_change} mmHg") print(f"Heart rate change: {heart_rate_change} bpm")

Mission Briefing: Multiplication and Division Operators

In medical research and clinical practice, multiplication (*) and division (/) operations are essential for scaling values, calculating ratios, and performing standardized measurements. For example, you might need to adjust dosages based on body weight, convert between measurement units, or normalize biomarker levels.

Python handles these operations with the * symbol for multiplication and / for division. There's also the integer division operator (//), which gives you only the whole number part of a division, and can be useful for certain biomedical calculations.

# Multiplication for drug dosing calculations patient_weight = 72 # kg dosage_per_kg = 5.5 # mg/kg total_dosage = patient_weight * dosage_per_kg print(f"Patient weight: {patient_weight} kg") print(f"Dosage per kg: {dosage_per_kg} mg/kg") print(f"Total calculated dosage: {total_dosage} mg") # Division for lab value normalization raw_platelet_count = 225000 # cells/μL normal_range_mid = 250000 # cells/μL normalized_ratio = raw_platelet_count / normal_range_mid print(f"Raw platelet count: {raw_platelet_count} cells/μL") print(f"Normalized to reference range: {normalized_ratio:.2f}") # Rounded to 2 decimal places # Integer division for medication scheduling total_pills = 29 daily_dose = 4 complete_days = total_pills // daily_dose print(f"Total pills available: {total_pills}") print(f"Daily dose: {daily_dose} pills") print(f"Complete days of medication: {complete_days} days")
Copied!

Understanding these operators allows you to perform critical calculations for patient care, from determining appropriate medication doses to analyzing laboratory results in clinical context. The precision that Python provides in these calculations directly supports the precision required in modern medicine.

Health Tech Tip: When performing drug dosage calculations, be aware that Python division (/) always returns a float, even when dividing integers. This is actually beneficial for medical applications where precision is critical, but you'll want to round appropriately for practical administration.

Real-World Connection: Pharmacologists use multiplication and division constantly when developing medication dosing guidelines. They multiply a patient's body surface area (BSA) by established dosing constants to calculate chemotherapy doses, ensuring each patient receives personalized treatment that balances efficacy and safety.

Lab Exercise 2: Body Surface Area Calculation

As a clinical researcher developing a chemotherapy protocol, you need to accurately calculate medication doses based on body surface area (BSA). The Mosteller formula for BSA is: √(height_cm × weight_kg / 3600).

# Lab scenario: Calculate chemotherapy dosing based on BSA # Fix the code by adding the appropriate multiplication and division operations # Patient data patient_height = 168 # cm patient_weight = 65 # kg # BSA calculation constants division_constant = 3600 # Calculate BSA using Mosteller formula: sqrt((height * weight) / 3600) height_weight_product = patient_height ... patient_weight division_result = height_weight_product ... division_constant body_surface_area = division_result ** 0.5 # Square root using exponentiation # Calculate medication doses based on BSA drug_a_dosage_per_m2 = 100 # mg/m² drug_b_dosage_per_m2 = 350 # mg/m² drug_a_total_dose = body_surface_area ... drug_a_dosage_per_m2 drug_b_total_dose = body_surface_area ... drug_b_dosage_per_m2 # Display the treatment plan print("ONCOLOGY TREATMENT PROTOCOL") print(f"Patient height: {patient_height} cm") print(f"Patient weight: {patient_weight} kg") print(f"Calculated BSA: {body_surface_area:.2f} m²") print(f"Drug A dose: {drug_a_total_dose:.1f} mg") print(f"Drug B dose: {drug_b_total_dose:.1f} mg")
Copied!

Expected output:

ONCOLOGY TREATMENT PROTOCOL Patient height: 168 cm Patient weight: 65 kg Calculated BSA: 1.74 m² Drug A dose: 174.0 mg Drug B dose: 609.0 mg

Answer:

# Complete solution # Patient data patient_height = 168 # cm patient_weight = 65 # kg # BSA calculation constants division_constant = 3600 # Calculate BSA using Mosteller formula: sqrt((height * weight) / 3600) height_weight_product = patient_height * patient_weight division_result = height_weight_product / division_constant body_surface_area = division_result ** 0.5 # Square root using exponentiation # Calculate medication doses based on BSA drug_a_dosage_per_m2 = 100 # mg/m² drug_b_dosage_per_m2 = 350 # mg/m² drug_a_total_dose = body_surface_area * drug_a_dosage_per_m2 drug_b_total_dose = body_surface_area * drug_b_dosage_per_m2 # Display the treatment plan print("ONCOLOGY TREATMENT PROTOCOL") print(f"Patient height: {patient_height} cm") print(f"Patient weight: {patient_weight} kg") print(f"Calculated BSA: {body_surface_area:.2f} m²") print(f"Drug A dose: {drug_a_total_dose:.1f} mg") print(f"Drug B dose: {drug_b_total_dose:.1f} mg")
Copied!

Excellent work! You've successfully calculated personalized chemotherapy doses based on a patient's body measurements. This type of calculation is critical in precision oncology, where even small errors in dosing can impact treatment efficacy or increase toxicity. By using multiplication and division operators correctly, you're ensuring that each patient receives the optimal dose for their specific body characteristics.
