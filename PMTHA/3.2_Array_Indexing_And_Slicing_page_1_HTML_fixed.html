Part 1: Basic Array Indexing - Your Data GPS

🌟 Understanding Zero-Based Indexing

Think of array indexing as GPS coordinates for your data. In Python's world, we count from zero—imagine a hospital where the ground floor is Floor 0, not Floor 1. This might feel weird at first (like using military time), but it's actually based on how computer memory works!

# Import NumPy - your medical data Swiss Army knife import numpy as np # Fun fact: NumPy was partly developed to analyze telescope data, # but now it's saving lives in medical research! 🔭➡️🏥
Copied!

📊 Your First Patient Data Access

Let's start with a real scenario—you're monitoring glucose levels from a continuous glucose monitor (CGM):

# Patient glucose readings (mg/dL) - taken every hour glucose_readings = np.array([95, 110, 125, 98, 105, 118, 102, 108]) # Access the first reading (remember: we start at 0!) first_reading = glucose_readings[0] print(f"🌅 Morning glucose: {first_reading} mg/dL") # Access the third reading (index 2) third_reading = glucose_readings[2] print(f"📍 Third hour glucose: {third_reading} mg/dL")
Copied!

💡 Pro Tip: Negative indexing is your friend! Use -1 to get the last element, -2 for second-to-last, etc. It's like counting backwards from the end!

# Get the most recent reading - super handy! latest_reading = glucose_readings[-1] print(f"📊 Latest glucose: {latest_reading} mg/dL") # Second-to-last reading penultimate = glucose_readings[-2] print(f"⏮️ Previous glucose: {penultimate} mg/dL")
Copied!

🏥 Real-World Clinical Context

Did you know? Modern CGMs take readings every 5 minutes—that's 288 readings per day! Doctors use indexing to quickly access readings at meal times, during sleep, or when symptoms occur.

Part 2: Array Slicing - Taking Data Biopsies

🍕 The Slice Syntax: start:stop:step

Array slicing is like taking a biopsy—you extract a sample that represents a larger whole. The syntax array[start:stop:step] might look like a secret code, but it's actually quite logical!

# White blood cell counts over 10 days (thousands/μL) wbc_counts = np.array([7.2, 8.1, 9.3, 11.2, 10.5, 9.8, 8.9, 7.8, 7.5, 7.3]) # Extract first 5 days (indices 0-4) first_five = wbc_counts[0:5] # Note: 5 is NOT included! print(f"🗓️ First 5 days: {first_five}") # Short version - if starting from 0, you can omit it! first_five_short = wbc_counts[:5] print(f"✨ Same result: {first_five_short}")
Copied!

💡 Memory Trick: The stop index is like a fence—you go up to it but don't include it!

📈 Advanced Slicing Patterns

# Get every other day (step = 2) alternate_days = wbc_counts[::2] print(f"🔄 Every other day: {alternate_days}") # Reverse the array - great for time series analysis! reversed_counts = wbc_counts[::-1] print(f"⏪ Reverse chronological: {reversed_counts}") # Middle section (days 3-7, indices 2-6) mid_week = wbc_counts[2:7] print(f"📊 Mid-week values: {mid_week}")
Copied!

🏥 Clinical Application: Treatment Windows

In chemotherapy, doctors monitor WBC counts to ensure patient safety. Let's analyze treatment phases:

# Simulated chemotherapy monitoring (14 days) chemo_wbc = np.array([8.5, 8.2, 7.8, 5.4, 3.2, 2.8, 3.1, 4.2, 5.5, 6.8, 7.2, 7.6, 7.9, 8.1]) # Pre-treatment baseline (first 3 days) baseline = chemo_wbc[:3] print(f"🏥 Baseline WBC: {baseline.mean():.1f}k/μL") # Nadir period (lowest counts, days 4-7) nadir = chemo_wbc[3:7] print(f"⚠️ Nadir WBC: {nadir.mean():.1f}k/μL") # Recovery phase (last 7 days) recovery = chemo_wbc[7:] print(f"📈 Recovery WBC: {recovery.mean():.1f}k/μL")
Copied!

Solution with Clinical Insights

# Baseline period baseline = pain_scores[:3] baseline_avg = baseline.mean() # Treatment window treatment_window = pain_scores[3:10] treatment_avg = treatment_window.mean() # Final week final_week = pain_scores[7:] final_avg = final_week.mean() # Calculate improvement improvement = (baseline_avg - final_avg) / baseline_avg * 100 print(f"📊 Clinical Trial Results:") print(f"Baseline pain: {baseline_avg:.1f}") print(f"Treatment phase: {treatment_avg:.1f}") print(f"Final week: {final_avg:.1f}") print(f"✨ Total improvement: {improvement:.0f}%") print(f"🎯 Clinical significance: {'Yes' if improvement > 30 else 'No'}")

Part 3: Advanced Selection - Becoming a Data Detective

🎭 Boolean Indexing: The Power of Conditions

Boolean indexing lets you ask questions like "Which patients need immediate attention?" Let's see it in action:

# Hemoglobin levels for 8 patients (g/dL) hemoglobin = np.array([12.5, 13.8, 11.2, 14.5, 10.8, 15.2, 11.9, 13.2]) # Create a boolean mask for anemia (Hb < 12 g/dL) anemia_mask = hemoglobin < 12 print(f"🩸 Anemia flags: {anemia_mask}") # Extract only anemic patients' values anemic_patients = hemoglobin[anemia_mask] print(f"⚠️ Anemic Hb levels: {anemic_patients}") # Count anemic patients anemia_count = np.sum(anemia_mask) # True = 1, False = 0 print(f"📊 Anemic patients: {anemia_count} out of {len(hemoglobin)}")
Copied!

🎯 Combining Conditions

Real medical decisions often involve multiple criteria:

# Find moderate anemia (10 < Hb < 12) moderate_mask = (hemoglobin > 10) & (hemoglobin < 12) moderate_anemia = hemoglobin[moderate_mask] print(f"🟡 Moderate anemia: {moderate_anemia}") # Find severe anemia OR polycythemia (Hb < 10 OR Hb > 16) critical_mask = (hemoglobin < 10) | (hemoglobin > 16) critical_patients = hemoglobin[critical_mask] print(f"🚨 Critical values: {critical_patients}")
Copied!

💡 Pro Tip: Use & for AND, | for OR, ~ for NOT with NumPy arrays (not and, or, not)!

🎲 Fancy Indexing: Cherry-Picking Your Data

Sometimes you need specific patients, not ranges:

# Select specific patients for follow-up follow_up_indices = np.array([1, 3, 5]) # Patients 2, 4, and 6 follow_up_values = hemoglobin[follow_up_indices] print(f"📋 Follow-up patients' Hb: {follow_up_values}") # Random sampling for quality control import numpy as np random_indices = np.random.choice(len(hemoglobin), size=3, replace=False) qa_sample = hemoglobin[random_indices] print(f"🎲 QA sample: {qa_sample}")
Copied!

Two issues: Use '&' not 'and' for NumPy arrays, and borderline includes 200 (use >=), high risk includes 240 (use >=).

Complete Risk Stratification Solution

# Create risk category masks optimal_mask = cholesterol < 200 borderline_mask = (cholesterol >= 200) & (cholesterol < 240) high_risk_mask = cholesterol >= 240 # Count patients optimal_count = np.sum(optimal_mask) borderline_count = np.sum(borderline_mask) high_count = np.sum(high_risk_mask) # Find top 25% highest values threshold_75 = np.percentile(cholesterol, 75) top_25_percent = cholesterol[cholesterol >= threshold_75] # Lifestyle intervention candidates lifestyle_patients = cholesterol[borderline_mask] print(f"💚 Optimal: {optimal_count} patients") print(f"🟡 Borderline: {borderline_count} patients") print(f"🔴 High risk: {high_count} patients") print(f"🎯 Top 25% values: {top_25_percent}") print(f"🏃 Lifestyle intervention needed: {lifestyle_patients}") # Bonus: Create a risk report risk_report = { 'Total Patients': len(cholesterol), 'Average Cholesterol': cholesterol.mean(), 'Highest Risk': cholesterol.max(), 'Needs Immediate Intervention': np.sum(cholesterol > 280) } print(f"\n📊 Risk Summary: {risk_report}")
