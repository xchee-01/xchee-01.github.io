Plotting Sine Waves in Python

A beginner's guide to scientific plotting with matplotlib

Introduction

The sine function is one of the most fundamental functions in mathematics, physics, and engineering. It's used to model periodic phenomena such as sound waves, light waves, and alternating current.

In this tutorial, you'll learn how to plot a sine wave using Python's matplotlib library, one of the most popular data visualization tools in the Python ecosystem.

What You'll Learn

  • How to import necessary libraries
  • How to generate data points for a sine wave
  • How to create a basic plot
  • How to customize your plot with labels, titles, and styling
  • How to modify parameters to change the appearance of your sine wave

Step-by-Step Guide

1 Import necessary libraries

We'll need two main libraries: numpy for numerical calculations and matplotlib for plotting.

import numpy as np
import matplotlib.pyplot as plt

numpy provides functions for working with arrays and mathematical operations, while matplotlib.pyplot gives us plotting capabilities.

2 Generate x-values (domain)

We need to create an array of x-values that will represent the domain of our sine function. We'll use np.linspace() to create evenly spaced values.

x = np.linspace(0, 2 * np.pi, 100)

This creates 100 evenly spaced points from 0 to 2π (one complete cycle of a sine wave).

3 Calculate y-values (sine function)

Now we'll calculate the sine value for each x-value in our array.

y = np.sin(x)

np.sin() applies the sine function to each value in the array, giving us our y-values.

4 Create a basic plot

Let's create a simple plot with our x and y values.

plt.figure(figsize=(10, 6))
plt.plot(x, y)
plt.show()

This creates a figure with specified dimensions, plots our data, and displays the result.

5 Add labels and title

Let's make our plot more informative by adding proper labels and a title.

plt.figure(figsize=(10, 6))
plt.plot(x, y)
plt.title('Sine Wave')
plt.xlabel('x (radians)')
plt.ylabel('sin(x)')
plt.grid(True)
plt.show()

This adds a title, x and y axis labels, and a grid to make the plot easier to read.

6 Customize your plot

Let's add some customization to make our plot more visually appealing.

plt.figure(figsize=(10, 6))
plt.plot(x, y, color='#003D7C', linewidth=2, linestyle='-', marker='', label='sin(x)')

# Add a horizontal line at y=0
plt.axhline(y=0, color='#EF7C00', linestyle='--', alpha=0.7)

plt.title('Sine Wave', fontsize=16)
plt.xlabel('x (radians)', fontsize=12)
plt.ylabel('sin(x)', fontsize=12)

# Add specific ticks at multiples of π/2
plt.xticks([0, np.pi/2, np.pi, 3*np.pi/2, 2*np.pi],
           ['0', 'π/2', 'π', '3π/2', '2π'])

plt.grid(True, alpha=0.3)
plt.legend()
plt.show()

Here we've customized the line color, added a horizontal line at y=0, adjusted font sizes, and created custom x-axis tick labels using multiples of π.

Understanding Sine Wave Parameters

A general sine function can be written as: y = A * sin(B * x + C) + D where:

  • A controls the amplitude (height of the wave)
  • B controls the period (length of one complete cycle)
  • C controls the phase shift (horizontal shift)
  • D controls the vertical shift

Note: The period of the sine wave is given by 2π/B. For example, if B=2, the period is π.

Let's modify our code to see how changing these parameters affects our sine wave:

plt.figure(figsize=(10, 6))

# Original sine wave
y1 = np.sin(x)
plt.plot(x, y1, label='sin(x)', color='#003D7C')

# Modified amplitude (A=0.5)
y2 = 0.5 * np.sin(x)
plt.plot(x, y2, label='0.5*sin(x)', color='#EF7C00')

# Modified period (B=2)
y3 = np.sin(2 * x)
plt.plot(x, y3, label='sin(2x)', color='#0083B6')

plt.title('Effect of Parameters on Sine Waves')
plt.xlabel('x (radians)')
plt.ylabel('y')
plt.grid(True, alpha=0.3)
plt.legend()
plt.show()

Complete Example

Here's a complete example that puts everything together:

import numpy as np
import matplotlib.pyplot as plt

# Generate x values from 0 to 4π
x = np.linspace(0, 4 * np.pi, 1000)

# Create multiple sine waves with different parameters
y1 = np.sin(x)                # Standard sine wave
y2 = 2 * np.sin(x)            # Amplitude = 2
y3 = np.sin(2 * x)            # Period = π
y4 = np.sin(x + np.pi/2)      # Phase shift = π/2
y5 = np.sin(x) + 1.5          # Vertical shift = 1.5

# Create a figure with subplots
plt.figure(figsize=(15, 10))

# Plot 1: Standard sine wave
plt.subplot(3, 2, 1)
plt.plot(x, y1, color='#003D7C')
plt.title('Standard: sin(x)')
plt.grid(True, alpha=0.3)

# Plot 2: Amplitude change
plt.subplot(3, 2, 2)
plt.plot(x, y2, color='#EF7C00')
plt.title('Amplitude: 2*sin(x)')
plt.grid(True, alpha=0.3)

# Plot 3: Period change
plt.subplot(3, 2, 3)
plt.plot(x, y3, color='#0083B6')
plt.title('Period: sin(2x)')
plt.grid(True, alpha=0.3)

# Plot 4: Phase shift
plt.subplot(3, 2, 4)
plt.plot(x, y4, color='#8B008B')
plt.title('Phase Shift: sin(x + π/2)')
plt.grid(True, alpha=0.3)

# Plot 5: Vertical shift
plt.subplot(3, 2, 5)
plt.plot(x, y5, color='#006400')
plt.title('Vertical Shift: sin(x) + 1.5')
plt.grid(True, alpha=0.3)

# Plot 6: Combined parameters
plt.subplot(3, 2, 6)
combined = 1.5 * np.sin(2 * x - np.pi/4) + 0.5
plt.plot(x, combined, color='#A52A2A')
plt.title('Combined: 1.5*sin(2x - π/4) + 0.5')
plt.grid(True, alpha=0.3)

# Adjust layout
plt.tight_layout()
plt.show()
