Challenge 1 Variable Scope Confusion

Consider the following JavaScript code:

function mystery() {
    if (true) {
        var x = 1;
        let y = 2;
        const z = 3;
    }
    console.log(x);
    console.log(y);
    console.log(z);
}

mystery();

Challenge 2 Variable Declaration Dilemma

What will be the output of the following Python code?

def calculate():
    result = 10
    
    def inner_function():
        nonlocal result
        result += 5
        
    inner_function()
    print(result)
    
    def another_inner():
        result = 2
        print(result)
        
    another_inner()
    print(result)

calculate()
Challenge 3 Variable Behavior Riddle

What will be displayed in the console after running this JavaScript code?

let a = { value: 10 };
let b = a;
let c = { value: 10 };

console.log(a === b);
console.log(a === c);
console.log(a.value === c.value);

a.value = 20;

console.log(b.value);
console.log(c.value);

Tip: Understanding variable scope, mutation, and reference vs. value is crucial for writing bug-free code. Pay close attention to how variables behave in different contexts.
