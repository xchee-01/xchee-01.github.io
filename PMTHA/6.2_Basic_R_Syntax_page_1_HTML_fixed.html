Chapter 1: Your First R Commands

Why R for Precision Medicine?

R is a specialized statistical programming language designed for data analysis. Unlike general-purpose languages, R excels at number-crunching, pattern-finding, and visualization - essential for medical research.

# Your first R command print("Welcome to Precision Medicine with R!") # Medical-focused examples print("Analyzing patient data...") print("DNA sequence loaded successfully!")

Chapter 2: Variables - Data Storage Units

The Assignment Operator

R uses <- to store values in variables (like labeled test tubes):

# Basic variable assignment glucose_level <- 126 # Blood glucose in mg/dL print(glucose_level) # Variable naming rules patient_age <- 65 # Good: snake_case systolic_bp <- 120 # Good: descriptive has_diabetes <- TRUE # Good: boolean flag # 2nd_patient <- "John" # BAD: Can't start with number # patient-name <- "Jane" # BAD: No hyphens allowed
Copied!
Learning Checkpoint
What is the preferred assignment operator in R?
=
Single equals sign
While = works, <- is the preferred R convention.

Right arrow
This assigns right-to-left, which is non-standard.

Left arrow
Correct! <- is the preferred assignment operator in R.
:=
Colon equals
This is used in data.table package, not base R.

Chapter 3: Comments - Documentation

Comments explain your code using #:

# Calculate BMI for obesity screening weight_kg <- 75 # Patient weight in kilograms height_m <- 1.75 # Patient height in meters bmi <- weight_kg / (height_m ^ 2) # Clinical thresholds (WHO guidelines) # 18.5-24.9: Normal weight # 25.0-29.9: Overweight # >=30: Obese
Copied!
Learning Checkpoint
Which symbol is used to create a comment in R?
//
Double forward slash
This is used in C++ and Java, not R.
#
Hash symbol
Correct! # creates single-line comments in R.
/*
Block comment start
R doesn't support block comments like C/C++.
--
Double dash
This is used in SQL, not R.

Best Practices:

  • Document WHY, not WHAT
  • Include units and clinical references
  • Explain complex formulas
Learning Checkpoint
Which comment demonstrates best practice?
# Multiply x by 2
Describes the obvious
This describes WHAT, not WHY.
# Double the dose for severe cases per protocol
Explains medical reasoning
Correct! This explains the medical reasoning behind the code.
# x <- x * 2
Duplicates the code
Never duplicate code in comments.
# Line 5
Generic line reference
This provides no useful information.

Chapter 5: The R Console

The R console is your interactive workspace:

Learning Checkpoint
What does [1] mean in R console output?
Error code 1
Indicates an error

First element of the output vector
Index of first element
Correct! [1] shows this is the first element of the output.

Code line reference

Console Tips:

  • Use ↑/↓ arrows for command history
  • Tab completion for variables
  • Ctrl+L (Windows/Linux) or Cmd+L (Mac) to clear
  • Ctrl+C to stop execution

Which formula correctly converts Fahrenheit to Celsius?
C = F - 32 * 5/9
Missing parentheses
Order of operations: need parentheses around F-32.
C = (F - 32) * 5/9
Correct formula
Correct! This is the proper F to C conversion formula.

Wrong order

Reversed formula
This is C to F, not F to C.
