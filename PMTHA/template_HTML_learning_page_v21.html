Mission Briefing: Python Statements - The Building Blocks

Every great medical discovery begins with an initial hypothesis, and similarly, your Python journey starts with learning how to write and execute simple statements. In Python, a statement is a unit of code that performs an action, like printing text or performing calculations.

Think of Python statements as instructions you might give to a laboratory assistant - clear, precise, and executed in a specific order. In precision medicine, you'll use these statements to process patient data, analyze biological samples, and interpret clinical results.

Mission Briefing: Data Types - Different Kinds of Information

In medicine, precision matters - a small difference in dosage or biomarker levels can have significant clinical implications. Python uses different data types to represent different kinds of information, just as you might use different laboratory tests to measure different biological parameters.

Let's explore the three fundamental data types you'll use constantly in biomedical programming:

Integers (Whole Numbers)

Integers are whole numbers without decimal points. In medical contexts, you might use integers to represent patient counts, days since treatment, or discrete measurements.

# Integer examples patients = 25 days = 7 print("Total patients:", patients) print("Days of treatment:", days) print("Patients per day:", patients / days) # Notice what happens here
Copied!

Think about it: Why might we use integers for patient counts instead of strings?

Floating-Point Numbers (Decimals)

Floats are numbers with decimal points, essential for precise measurements in medical research such as drug concentrations, lab values, or physiological readings.

# Float examples weight = 68.5 dosage = 2.5 print("Patient weight:", weight, "kg") print("Medication dosage:", dosage, "mg/kg") print("Total dose:", weight * dosage, "mg")
Copied!

Prediction task: What will the following code output?

bmi = 24.7 print("BMI category:", bmi > 25)
Copied!

Strings (Text)

Strings represent text data, enclosed in quotation marks. In healthcare, strings store patient names, diagnostic codes, DNA sequences, or any textual information.

# String examples name = "Alex Johnson" diagnosis = "Type 2 Diabetes" blood_type = "O+" print("Patient:", name) print("Diagnosis:", diagnosis)
Copied!

Mission Briefing: Boolean Values - True or False

In medicine, many diagnoses and test results come down to binary outcomes - positive or negative, present or absent, eligible or ineligible. Python uses Boolean values (True and False) to represent these binary states, making them perfect for representing diagnostic results and patient statuses.

Basic Boolean Values

# Boolean examples has_diabetes = True is_fasting = False print("Diabetes status:", has_diabetes) print("Fasting before test:", is_fasting)
Copied!

Simple Boolean Operations

Boolean operations combine conditions:

# AND operation (both must be True) high_glucose = True elevated_hba1c = True diabetes_indicated = high_glucose and elevated_hba1c print("Diabetes indicated by tests:", diabetes_indicated)
Copied!
# OR operation (at least one must be True) fever = False cough = True needs_assessment = fever or cough print("Needs clinical assessment:", needs_assessment)
Copied!
# NOT operation (inverts the value) is_normal_range = False requires_follow_up = not is_normal_range print("Requires follow-up:", requires_follow_up)
Copied!

Comparison Operations

Comparisons produce Boolean results:

# Greater than blood_pressure = 135 hypertension_range = blood_pressure > 130 print("BP in hypertension range:", hypertension_range)
Copied!
# Equal to (note the double equals) target_heart_rate = 72 current_heart_rate = 72 at_target = current_heart_rate == target_heart_rate print("Heart rate at target:", at_target)
Copied!

Common mistake alert:
Remember to use == (double equals) for comparison, not = (single equals).
x == y checks if x equals y
x = y assigns the value of y to x

Mission Briefing: Type Conversion - Changing Data Types

In healthcare informatics, you'll frequently need to convert between different data types to properly process and analyze patient information. For example, you might need to convert numeric input from a form (which comes in as a string) to a float before calculating a medication dosage.

Basic Type Conversion

# String to integer patient_age_string = "42" patient_age = int(patient_age_string) print("Age as integer:", patient_age) print("Age in five years:", patient_age + 5)
Copied!
# String to float temperature_string = "37.5" temperature = float(temperature_string) print("Temperature as float:", temperature) print("Fever threshold exceeded:", temperature > 37.2)
Copied!
# Number to string days = 7 message = "Treatment duration: " + str(days) + " days" print(message)
Copied!

Common Conversion Functions

  • int(): Converts to integer
  • float(): Converts to floating-point number
  • str(): Converts to string
  • bool(): Converts to Boolean

Healthcare Example

Medical data often arrives as strings but needs to be processed numerically:

# Lab results as strings glucose_string = "105.5" cholesterol_string = "185" # Convert to appropriate numeric types glucose = float(glucose_string) cholesterol = int(cholesterol_string) # Now we can perform calculations glucose_mmol = glucose * 0.0555 # Convert mg/dL to mmol/L cholesterol_status = cholesterol < 200 # Boolean result print("Glucose:", glucose, "mg/dL (", glucose_mmol, "mmol/L)") print("Cholesterol in normal range:", cholesterol_status)

Mission Briefing: Integrated Practice - Patient Risk Assessment

Now let's combine multiple concepts in a more comprehensive practice. You're developing a basic risk assessment tool that analyzes patient data for metabolic syndrome risk factors.

Step 1: Define input data (strings, as if from a form)

# Patient data (as received from medical record system) patient_name = "Jane Smith" patient_id = "HMS-2025-0473" age_string = "58" glucose_string = "135" systolic_bp_string = "148" diastolic_bp_string = "92" hdl_cholesterol_string = "38" medication_count_string = "3"
Copied!

Step 2: Convert data types

# Convert string values to appropriate numeric types age = int(age_string) glucose = int(glucose_string) systolic_bp = int(systolic_bp_string) diastolic_bp = int(diastolic_bp_string) hdl = int(hdl_cholesterol_string) medication_count = int(medication_count_string)
Copied!

Step 3: Evaluate risk factors using Boolean operations

# Evaluate individual risk factors glucose_elevated = glucose >= 126 hypertension = systolic_bp >= 140 or diastolic_bp >= 90 low_hdl = hdl < 40 age_risk = age > 55 poly_pharmacy = medication_count >= 5
Copied!

Step 4: Determine overall risk and produce report

# Calculate overall risk score (count of risk factors) risk_count = ( int(glucose_elevated) + int(hypertension) + int(low_hdl) + int(age_risk) + int(poly_pharmacy) ) # Determine risk level high_risk = risk_count >= 3 moderate_risk = risk_count == 2 low_risk = risk_count <= 1 # Generate risk assessment report print("PATIENT RISK ASSESSMENT") print("Patient:", patient_name, "(ID:", patient_id + ")") print("\nRISK FACTORS:") print("- Elevated glucose:", glucose_elevated) print("- Hypertension:", hypertension) print("- Low HDL cholesterol:", low_hdl) print("- Age > 55:", age_risk) print("- Polypharmacy:", poly_pharmacy) print("\nRISK ASSESSMENT:") print("Risk factors present:", risk_count, "of 5") if high_risk: print("Risk level: HIGH - Immediate intervention recommended") elif moderate_risk: print("Risk level: MODERATE - Lifestyle modification advised") else: print("Risk level: LOW - Routine monitoring")
Copied!

Medical Terms Glossary

  • A1C: A blood test that measures average blood glucose over 2-3 months
  • Biomarker: A measurable indicator of a biological state or condition
  • BRCA1/BRCA2: Genes related to breast cancer risk
  • eGFR: Estimated glomerular filtration rate, a test of kidney function
  • HbA1c: Glycated hemoglobin, used to diagnose diabetes
  • Metabolic syndrome: A cluster of conditions that increase risk of heart disease and diabetes
