import matplotlib.pyplot as plt import matplotlib.gridspec as gridspec import numpy as np # Create your figure canvas fig = plt.figure(figsize=(14, 10)) # Design your custom grid (like blueprints for a building) gs = gridspec.GridSpec(3, 3, figure=fig) # Create a large main display for continuous monitoring ax_main = fig.add_subplot(gs[0:2, 0:2]) # Spans 2×2 cells ax_main.set_title('24-Hour Vital Signs Trend') # Smaller displays for current readings ax_hr = fig.add_subplot(gs[0, 2]) # Top-right corner ax_hr.set_title('Current Heart Rate') ax_bp = fig.add_subplot(gs[1, 2]) # Middle-right ax_bp.set_title('Blood Pressure Now') # Full-width panel for medication timeline ax_meds = fig.add_subplot(gs[2, :]) # Bottom row, all columns ax_meds.set_title('Medication Schedule')
Copied!

💡 Pro Tip: Think of GridSpec coordinates like this:

  • gs[0:2, 0:2] means "from row 0 to 2, from column 0 to 2"
  • gs[2, :] means "row 2, all columns"

🎯 Solution with Medical Insights:

import matplotlib.pyplot as plt import numpy as np # Create ED triage dashboard fig, axes = plt.subplots(2, 2, figsize=(12, 10)) fig.suptitle('Emergency Department Triage Dashboard - Patient #1234', fontsize=14) # Simulate 60 minutes of patient monitoring time_points = np.arange(0, 60, 5) heart_rate = np.random.normal(110, 15, len(time_points)) # Tachycardia temperature = np.random.normal(38.5, 0.3, len(time_points)) # Fever blood_pressure_sys = np.random.normal(140, 10, len(time_points)) # Hypertension oxygen_sat = np.random.normal(94, 2, len(time_points)) # Hypoxia # Heart Rate Monitor (top-left) axes[0, 0].plot(time_points, heart_rate, 'r-', linewidth=2) axes[0, 0].set_title('Heart Rate - ⚠️ Tachycardia') axes[0, 0].set_ylabel('BPM') axes[0, 0].set_xlabel('Time (minutes)') axes[0, 0].axhline(y=100, color='orange', linestyle='--', alpha=0.5, label='Warning') axes[0, 0].fill_between(time_points, 60, 100, alpha=0.2, color='green') # Temperature Monitor (top-right) axes[0, 1].plot(time_points, temperature, 'orange', linewidth=2) axes[0, 1].set_title('Body Temperature - 🌡️ Fever Detected') axes[0, 1].set_ylabel('°C') axes[0, 1].set_xlabel('Time (minutes)') axes[0, 1].axhline(y=37.5, color='red', linestyle='--', alpha=0.5, label='Fever') axes[0, 1].fill_between(time_points, 36.5, 37.5, alpha=0.2, color='green') # Blood Pressure Monitor (bottom-left) axes[1, 0].plot(time_points, blood_pressure_sys, 'purple', linewidth=2) axes[1, 0].set_title('Systolic BP - 💓 Stage 1 Hypertension') axes[1, 0].set_ylabel('mmHg') axes[1, 0].set_xlabel('Time (minutes)') axes[1, 0].axhline(y=130, color='red', linestyle='--', alpha=0.5) axes[1, 0].fill_between(time_points, 90, 120, alpha=0.2, color='green') # Oxygen Saturation Monitor (bottom-right) axes[1, 1].plot(time_points, oxygen_sat, 'blue', linewidth=2) axes[1, 1].set_title('SpO₂ - 🫁 Low Oxygen Alert') axes[1, 1].set_ylabel('Saturation %') axes[1, 1].set_xlabel('Time (minutes)') axes[1, 1].axhline(y=95, color='red', linestyle='--', alpha=0.5, label='Critical') axes[1, 1].set_ylim(88, 100) axes[1, 1].fill_between(time_points, 95, 100, alpha=0.2, color='green') # Add legends and grid for ax in axes.flat: ax.grid(True, alpha=0.3) ax.legend(loc='best', fontsize=8) plt.tight_layout() plt.show()

What is Post-Operative Cardiac Syndrome?

Click to learn about this common post-surgery condition relevant to dashboard monitoring...

Post-Operative Cardiac Syndrome (POCS) is a complex inflammatory condition that can develop after cardiac surgery, affecting approximately 10-40% of patients who undergo procedures like coronary artery bypass grafting (CABG) or valve replacements.

Key clinical features include:

  • Fever developing 2-4 weeks post-surgery
  • Pericardial friction rub and chest pain
  • Elevated inflammatory markers (ESR, CRP)
  • Possible pericardial or pleural effusions
  • ECG changes including diffuse ST elevations

This is why continuous monitoring dashboards are crucial in post-cardiac surgery care. The dashboard systems you're learning to build help detect early signs of POCS through:

  • Temperature trend monitoring
  • Heart rate variability analysis
  • Integration of lab results showing inflammatory markers
  • Correlation of symptoms across multiple data streams

Modern precision medicine approaches use machine learning algorithms on dashboard data to predict POCS risk, enabling preventive interventions that significantly improve patient outcomes.
