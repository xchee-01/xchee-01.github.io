🔬 Mission Briefing: Hello, Python World!

Before we dive into medical applications, let's get familiar with the most basic way to communicate with Python - using the print() function. Think of print() as your first diagnostic tool - it shows you what's happening in your code.

# Your very first Python statement! print("Hello, Python World!")
Copied!

When you run this code, Python displays:

Hello, Python World!

Let's try another simple example:

# Printing a number print(42)
Copied!

Output:

42

See? Python displayed exactly what we asked for! The print() function is like a friendly nurse who shows whatever you give them to the patient (your screen).

Learning Checkpoint
What will happen if you run print(2 + 3)?
It will display "2 + 3"
Python will print the literal text expression.
Not quite right. Python evaluates expressions before printing them, so it calculates 2 + 3 first.
It will display "5"
Python will calculate the sum and display the result.
Correct! Python calculates 2 + 3 first, gets the result 5, and then displays that value.
It will display nothing
The expression is evaluated but not displayed.
That's not correct. The print() function's job is to display output, so it will show the result of the calculation.
It will cause an error
You can't use mathematical operations in print().
This is incorrect. Python can perform calculations inside a print() function without any errors.
# Printing a calculation print(2 + 3)
Copied!

Output:

5

Python did the math for us! It calculated 2 + 3 and then displayed the result.

Adding Comments to Your Code

Comments in Python start with a # symbol. Anything after the # on that line is ignored by Python:

# This is a comment - Python will ignore it print("This will be displayed") # This comment won't affect the output
Copied!

Think of comments like notes in a patient chart - they help you and others understand what's happening, but they don't affect the patient (your program).

🔬 Mission Briefing: Your First Medical Application

Now that we understand the basics, let's apply them to something more relevant to precision health:

# A simple patient information display print("Patient Information") print("-----------------") print("Name: Jane Doe") print("Age: 45") print("Blood Type: O+")
Copied!

This produces a nicely formatted output:

Patient Information ----------------- Name: Jane Doe Age: 45 Blood Type: O+

Just as a good medical report needs clear organization, your code should be easy to read and understand.
