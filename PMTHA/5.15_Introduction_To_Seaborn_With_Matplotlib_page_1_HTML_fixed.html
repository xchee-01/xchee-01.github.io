Mission Briefing: Understanding Seaborn's Integration with Matplotlib

🎯 Learning Objective: Master the synergy between Seaborn and matplotlib

Here's a secret that will save you hours of frustration: Seaborn doesn't replace matplotlib - it's matplotlib's best friend! 🤝 Think of it this way:

  • Matplotlib = The hospital building (foundation, rooms, basic equipment)
  • Seaborn = The specialized medical equipment (MRI, CT scanner, advanced diagnostics)

When you use Seaborn, you're actually using matplotlib with superpowers! This means you can combine the statistical magic of Seaborn with the fine-tuned control of matplotlib.

# Let's create a blood pressure distribution plot with clinical thresholds # ================================================== # This combines Seaborn's statistical power with matplotlib's customization # ================================================== # Step 1: Create the matplotlib foundation # ======================================== fig, ax = plt.subplots(figsize=(10, 6)) # Step 2: Use Seaborn for the statistical visualization # ================================================== sns.histplot(data=patient_data, x='systolic_bp', kde=True, ax=ax, color='steelblue', alpha=0.7) # Step 3: Add matplotlib customizations for clinical context # ================================================== # These are the blood pressure categories from the American Heart Association # ================================================== ax.axvline(x=120, color='green', linestyle='--', linewidth=2, label='Normal BP threshold') ax.axvline(x=130, color='gold', linestyle='--', linewidth=2, label='Elevated BP threshold') ax.axvline(x=140, color='red', linestyle='--', linewidth=2, label='Hypertension threshold') # Step 4: Professional labeling for publication # ============================================= ax.set_xlabel('Systolic Blood Pressure (mmHg)', fontsize=12, fontweight='bold') ax.set_ylabel('Number of Patients', fontsize=12, fontweight='bold') ax.set_title('Distribution of Systolic Blood Pressure in Patient Cohort\n' + 'Dr. Heartwell\'s Cardiology Clinic', fontsize=14, fontweight='bold') # Add a text box with clinical insight # ==================================== ax.text(0.02, 0.95, '📊 Clinical Insight:\n' + f'{sum(patient_data["systolic_bp"] > 140)} patients have hypertension', transform=ax.transAxes, fontsize=10, verticalalignment='top', bbox=dict(boxstyle='round', facecolor='wheat', alpha=0.5)) ax.legend(loc='upper right') plt.tight_layout() plt.show()

Let's simulate a clinical trial to explore these tools:

# Creating a Simulated Clinical Trial Dataset # =========================================== # =========================================== # =========================================== # Scenario: Testing two new diabetes medications vs placebo # ================================================== np.random.seed(42) # Generate baseline data for 200 patients # ======================================= n_patients = 200 clinical_trial = pd.DataFrame({ 'patient_id': range(n_patients), 'treatment_group': np.random.choice(['Placebo', 'Drug A', 'Drug B'], n_patients), 'baseline_glucose': np.random.normal(180, 30, n_patients), # mg/dL 'age_group': np.random.choice(['18-35', '36-50', '51-65', '65+'], n_patients), 'bmi': np.random.normal(28, 5, n_patients), # Body Mass Index 'exercise_hours': np.random.exponential(2, n_patients) # Weekly exercise }) # Simulate treatment effects (this is where the magic happens!) # ================================================== # Drug A: Moderate effect (-20 mg/dL average) # =========================================== # Drug B: Strong effect (-35 mg/dL average) # ========================================= # Placebo: Small placebo effect (-5 mg/dL) # ======================================== treatment_effects = { 'Placebo': np.random.normal(-5, 10, n_patients), 'Drug A': np.random.normal(-20, 15, n_patients), 'Drug B': np.random.normal(-35, 12, n_patients) } # Calculate final glucose levels after 12 weeks # ============================================= clinical_trial['final_glucose'] = clinical_trial['baseline_glucose'].copy() for group in ['Placebo', 'Drug A', 'Drug B']: mask = clinical_trial['treatment_group'] == group n_group = mask.sum() clinical_trial.loc[mask, 'final_glucose'] += treatment_effects[group][:n_group] # Calculate glucose reduction # =========================== clinical_trial['glucose_reduction'] = ( clinical_trial['baseline_glucose'] - clinical_trial['final_glucose'] ) print("🔬 Clinical Trial Data Preview:") print(clinical_trial.head())
Copied!

💊 Real-World Connection: This simulates how pharmaceutical companies test new diabetes medications. The FDA requires such randomized controlled trials before approving any new drug. Real trials often involve thousands of patients across multiple countries!

# Lab scenario: Presenting Clinical Trial Results to the FDA # ================================================== # ========================================================== # ================================================== # You need to show clear evidence of drug efficacy # ================================================ # Create a figure with multiple subplots for comprehensive analysis # ================================================== fig = plt.figure(figsize=(15, 10)) # Subplot 1: Box plots comparing glucose reduction by treatment # ================================================== plt.subplot(2, 2, 1) sns.boxplot(data=clinical_trial, x='treatment_group', y='glucose_reduction', palette=['lightgray', 'lightblue', 'lightgreen'], order=['Placebo', 'Drug A', 'Drug B']) # Add baseline reference # ====================== plt.axhline(y=0, color='black', linestyle=':', alpha=0.5, label='No change') # Add title and labels # ==================== plt.title('Glucose Reduction by Treatment Group', fontsize=14, fontweight='bold') plt.xlabel('Treatment Group') plt.ylabel('Glucose Reduction (mg/dL)') # Add significance markers # ======================== plt.text(1, 45, '***', fontsize=16, ha='center') # Drug A plt.text(2, 60, '****', fontsize=16, ha='center') # Drug B # Subplot 2: Violin plots showing distribution details # ================================================== plt.subplot(2, 2, 2) sns.violinplot(data=clinical_trial, x='treatment_group', y='glucose_reduction', palette=['lightgray', 'lightblue', 'lightgreen'], order=['Placebo', 'Drug A', 'Drug B']) plt.title('Distribution of Treatment Effects', fontsize=14, fontweight='bold') plt.xlabel('Treatment Group') plt.ylabel('Glucose Reduction (mg/dL)') # Subplot 3: Scatter plot of baseline vs final glucose # ================================================== plt.subplot(2, 2, 3) for group, color in zip(['Placebo', 'Drug A', 'Drug B'], ['gray', 'blue', 'green']): data = clinical_trial[clinical_trial['treatment_group'] == group] plt.scatter(data['baseline_glucose'], data['final_glucose'], alpha=0.6, label=group, color=color) #
