Advanced Bar Charts - Grouped and Stacked Visualizations

Welcome to the advanced techniques module! In this section, you'll master grouped and stacked bar charts - essential tools for comparing multiple variables and showing composition in medical data. These visualization techniques are crucial for analyzing complex clinical datasets and making informed healthcare decisions.

Mission Briefing: Grouped and Stacked Bar Charts for Complex Medical Data

Ready for the advanced techniques? 🎓 Sometimes one bar per category isn't enough. What if you need to compare male vs. female responses? Or show how cancer stages break down by hospital? Enter the dynamic duo: grouped and stacked bar charts!

Grouped Bar Charts = Side-by-side comparison (like twins standing together)
Stacked Bar Charts = Composition breakdown (like a layer cake of data)

Learning Checkpoint
When should you use a grouped bar chart instead of a basic bar chart?
When you want to show percentages
Basic bar charts can also show percentages effectively.
Not quite right. Basic bar charts can show percentages just as well. Grouped bar charts are for a different purpose.
When you need to compare multiple variables across categories
Grouped bar charts excel at showing multiple data series side by side.
Correct! Grouped bar charts are perfect for comparing multiple variables (like male vs female) across the same categories.
When you have only one data series
A single data series is better shown with a basic bar chart.
That's not correct. With only one data series, a basic bar chart would be more appropriate and simpler.
When you want to show time trends
Time trends are typically better shown with line charts.
Not the best choice. Time trends are usually better visualized with line charts, not grouped bar charts.

# Clinical data: Blood pressure by age group and gender # ================================================== age_groups = ['20-29', '30-39', '40-49', '50-59', '60+'] male_systolic = [122, 126, 131, 136, 142] female_systolic = [116, 120, 125, 132, 138]

# Set up positions for grouped bars # ================================= x = np.arange(len(age_groups)) width = 0.35 # Width of individual bars

Learning Checkpoint
In the code above, why do we subtract width/2 for male bars and add width/2 for female bars?
To make the bars overlap
This would actually prevent overlap, not cause it.
Not quite. This positioning actually prevents overlap by placing bars side by side.
To center the grouped bars around the x position
This creates a balanced visual appearance for each group.
Correct! By offsetting bars by half the width in opposite directions, we center the group around each x position, creating a balanced visual appearance.
To increase the bar size
Bar size is controlled by the width parameter, not position.
That's not right. The positioning doesn't affect bar size - that's controlled by the width parameter.
To create space between age groups
Space between age groups is controlled by the x positions.
Not correct. The space between age groups is determined by the x array positions, not the width offset.
# Create grouped bar chart # ======================== fig, ax = plt.subplots(figsize=(10, 6)) # Plot male data (blue for boys - how original!) # ============================================== bars1 = ax.bar(x - width/2, male_systolic, width, label='Male', color='#3498DB') # Plot female data (red for... breaking stereotypes!) # ================================================== bars2 = ax.bar(x + width/2, female_systolic, width, label='Female', color='#E74C3C') # Customize the chart # =================== ax.set_xlabel('Age Group', fontsize=12, fontweight='bold') ax.set_ylabel('Average Systolic Blood Pressure (mmHg)', fontsize=12, fontweight='bold') ax.set_title('Blood Pressure Trends by Age and Gender\nPopulation Health Study (n=5000)', fontsize=14, fontweight='bold') # Set x-axis labels # ================= ax.set_xticks(x) ax.set_xticklabels(age_groups) # Add legend and grid # =================== ax.legend() ax.grid(axis='y', alpha=0.3, linestyle='--') # Add clinical reference line for hypertension threshold # ================================================== ax.axhline(y=130, color='red', linestyle='--', alpha=0.7, label='Hypertension Threshold') # Display the chart # ================= plt.tight_layout() plt.show()
Copied!

📊 Medical Insight: Notice how both genders cross the hypertension threshold around age 50, but males hit it earlier? This visualization helps doctors know when to start monitoring blood pressure more closely!

Now for the stacked chart - let's visualize cancer staging across hospitals:

# Cancer staging data by hospital # =============================== hospitals = ['City General', 'University Medical', 'Regional Cancer Center'] stage_I = [45, 38, 52] # Early stage (green = hope!) stage_II = [78, 65, 89] # Moderate (yellow = caution) stage_III = [56, 71, 67] # Advanced (orange = concern) stage_IV = [31, 42, 38] # Late stage (red = urgent)
Copied!
# Create stacked bar chart # ======================== fig, ax = plt.subplots(figsize=(10, 7)) # Create the stacked bars (like building blocks!) # =============================================== p1 = ax.bar(hospitals, stage_I, label='Stage I', color='#2ECC71') p2 = ax.bar(hospitals, stage_II, bottom=stage_I, label='Stage II', color='#F39C12')
Copied!
Learning Checkpoint
When creating the third stack (Stage III), why must we calculate bottom_III as stage_I + stage_II?
To make the bars taller
Height is determined by the data values, not positioning.
Not correct. The height is determined by the data values themselves, not the positioning calculation.
To ensure Stage III starts where Stage II ends
Each segment must start at the cumulative height of all previous segments.
Correct! In stacked bars, each segment must start where the previous one ends. The 'bottom' parameter positions each new segment on top of all previous ones.
To create gaps between stages
This would actually prevent gaps, not create them.
That's not right. This calculation ensures no gaps between segments - they stack directly on top of each other.
To overlap the stages for visual effect
Stacked bars should not overlap - they stack sequentially.
Not correct. Stacked bars shouldn't overlap - they should stack sequentially without gaps or overlaps.
# Calculate cumulative heights for stacking # ========================================= bottom_III = np.array(stage_I) + np.array(stage_II) p3 = ax.bar(hospitals, stage_III, bottom=bottom_III, label='Stage III', color='#E67E22') # Add the top stack # ================= bottom_IV = bottom_III + np.array(stage_III) p4 = ax.bar(hospitals, stage_IV, bottom=bottom_IV, label='Stage IV', color='#E74C3C') # Customize the chart # =================== ax.set_ylabel('Number of Patients', fontsize=12, fontweight='bold') ax.set_title('Cancer Patient Distribution by Stage\nMulti-Center Oncology Study 2024', fontsize=14, fontweight='bold') ax.legend(loc='upper right') # Add total labels on top # ======================= totals = np.array(stage_I) + np.array(stage_II) + np.array(stage_III) + np.array(stage_IV) for i, total in enumerate(totals): ax.text(i, total + 3, f'Total: {total}', ha='center', fontweight='bold') plt.tight_layout() plt.show()
Copied!

🏥 Real-World Impact: This visualization reveals that the Regional Cancer Center sees more early-stage patients (better screening programs?), while University Medical has more late-stage cases (referral center for complex cases?). These insights drive healthcare policy!

Learning Checkpoint
Why is green used for Stage I cancer and red for Stage IV in medical visualizations?

Not correct. Colors in medical visualizations are never random - they're carefully chosen to convey meaning.

Correct! Color psychology in medical visualization uses green for positive/early conditions and red for urgent/severe conditions, helping immediate visual understanding.

That's not right. Medical visualizations prioritize clinical clarity and universal understanding over branding considerations.

Not accurate. The color choice is based on psychological associations and medical conventions, not color wheel relationships.

Learning Checkpoint
Based on the resistance data, which antibiotic-bacteria combination represents the most critical concern?
E. coli - Meropenem (2.1%)
Low resistance is good, not concerning.

Moderate resistance, but not the most critical.

P. aeruginosa - Ampicillin (95.1%)
Nearly complete resistance - antibiotic is almost useless.
Correct! P. aeruginosa showing 95.1% resistance to Ampicillin means this antibiotic is almost completely ineffective against this bacteria - a critical concern for treatment decisions.

Moderate resistance, still effective in most cases.
Not the most critical. 28.7% resistance means the antibiotic still works in over 70% of cases.

🎯 Your Goal: Create a chart so clear that an exhausted ICU doctor at 3 AM can immediately see which antibiotic to use!

Expected Output: A chart revealing that P. aeruginosa is a super-resistant nightmare, while meropenem remains our best weapon!

Solution:

# Complete solution for antibiotic resistance visualization # ================================================== bacteria = ['E. coli', 'K. pneumoniae', 'P. aeruginosa'] ampicillin_resistance = [45.2, 78.9, 95.1] ciprofloxacin_resistance = [28.7, 41.3, 52.8] gentamicin_resistance = [15.3, 35.7, 48.2] meropenem_resistance = [2.1, 12.4, 31.6] # Set up the plot # =============== fig, ax = plt.subplots(figsize=(12, 7)) # Set positions and width for bars # ================================ x = np.arange(len(bacteria)) width = 0.2 # Width for each bar group # Create bars for each antibiotic # =============================== bars1 = ax.bar(x - 1.5*width, ampicillin_resistance, width, label='Ampicillin', color='#E74C3C') bars2 = ax.bar(x - 0.5*width, ciprofloxacin_resistance, width, label='Ciprofloxacin', color='#3498DB') bars3 = ax.bar(x + 0.5*width, gentamicin_resistance, width, label='Gentamicin', color='#2ECC71') bars4 = ax.bar(x + 1.5*width, meropenem_resistance, width, label='Meropenem', color='#9B59B6') # Customize the chart # =================== ax.set_xlabel('Bacterial Species', fontsize=12, fontweight='bold') ax.set_ylabel('Resistance Rate (%)', fontsize=12, fontweight='bold') ax.set_title('Antibiotic Resistance Surveillance Report\nRegional Hospital Network 2024', fontsize=14, fontweight='bold') # Set x-axis ticks and labels # =========================== ax.set_xticks(x) ax.set_xticklabels(bacteria, style='italic') # Add legend # ========== ax.legend(loc='upper left', framealpha=0.9) # Add grid # ======== ax.grid(axis='y', alpha=0.3, linestyle='--') # Add reference line for high resistance # ====================================== ax.axhline(y=50, color='red', linestyle='--', alpha=0.7, linewidth=2) ax.text(2.5, 52, 'High Resistance Threshold (50%)', ha='right', va='bottom', color='red', fontweight='bold', fontsize=10) # Add value labels for bars over 50% # ================================== for bars in [bars1, bars2, bars3, bars4]: for bar in bars: height = bar.get_height() if height > 50: ax.text(bar.get_x() + bar.get_width()/2, height + 1, f'{height:.1f}%', ha='center', va='bottom', fontsize=9, fontweight='bold') plt.ylim(0, 105) plt.tight_layout() plt.show()
Copied!
Learning Checkpoint
With 4 antibiotics and a bar width of 0.2, why do we use positions like x - 1.5*width and x + 1.5*width?
To create random spacing
The spacing is carefully calculated, not random.
Not correct. The spacing is precisely calculated to distribute bars evenly, not random.
To evenly distribute 4 bars around the center x position
This creates equal spacing with the group centered at x.
Correct! With 4 bars of width 0.2, we need positions at -1.5, -0.5, +0.5, and +1.5 times the width to center them around x with equal spacing.
To make the chart wider
Chart width is controlled by figure size, not bar positions.
That's not right. Chart width is determined by the figure size parameter, not the bar positioning.
To overlap the bars
This positioning prevents overlap, not causes it.
Not correct. This positioning specifically prevents bar overlap by spacing them evenly.

💊 Brilliant work! Your visualization reveals critical patterns:

  • P. aeruginosa is nearly invincible to ampicillin (95.1% resistance!)
  • Meropenem is still our ace in the hole (max 31.6% resistance)
  • The red line instantly shows which drug-bug combos are in the danger zone

This chart could be the difference between choosing an effective antibiotic and losing precious time with a resistant infection!

Learning Checkpoint
You need to show both the total number of patients in each hospital AND how they break down by disease severity. Which chart type is best?
Basic bar chart
Can show totals OR breakdown, but not both effectively.
Not ideal. Basic bar charts can show either totals or individual categories, but not both composition and totals together.
Grouped bar chart
Shows comparisons but not composition of totals.
Not quite right. Grouped bar charts are great for comparisons but don't show how parts make up a whole.
Stacked bar chart
Shows both composition and totals in one visualization.
Correct! Stacked bar charts show both composition (disease severity breakdown) and totals (overall bar height) in one visualization.
Line chart
Best for trends over time, not categorical comparisons.
Not appropriate. Line charts are for continuous data and trends, not categorical comparisons with composition.
