1.7.4. Nested Conditionals - Complex Medical Logic

Sometimes medical decisions have layers - like checking if a patient qualifies for a clinical trial. They must meet age requirements AND have specific conditions AND not have exclusion criteria.

Nesting in Action

# Clinical trial eligibility checker # ================================== age = 45 has_diabetes = True has_heart_disease = False on_insulin = True if age >= 18 and age <= 65: print("✅ Age criteria met") if has_diabetes: print("✅ Has target condition") if not has_heart_disease: print("✅ No exclusion criteria") if on_insulin: print("🎯 ELIGIBLE for insulin optimization trial") else: print("❌ Not eligible - must be on insulin") else: print("❌ Not eligible - heart disease excludes participation") else: print("❌ Not eligible - diabetes required") else: print("❌ Not eligible - age outside 18-65 range")
Copied!

💡 Tip Box: Each nested level adds another "layer" of decision-making. Think of it like a medical checklist where you only proceed if each item passes!

Simplifying Nested Logic

Sometimes we can flatten nested conditions:

# Same logic, cleaner approach # ============================ if age < 18 or age > 65: print("❌ Not eligible - age requirement not met") elif not has_diabetes: print("❌ Not eligible - must have diabetes") elif has_heart_disease: print("❌ Not eligible - heart disease is exclusionary") elif not on_insulin: print("❌ Not eligible - must be on insulin") else: print("🎯 ELIGIBLE for clinical trial!")
Copied!

1.7.5. Boolean Logic - Combining Medical Conditions

Medical decisions often involve multiple factors. A stroke risk assessment might consider age AND blood pressure AND smoking status. Let's master combining conditions!

Logical Operators in Medicine

# Stroke risk assessment # ====================== age = 65 systolic_bp = 145 is_smoker = True has_diabetes = True # High risk if: age > 60 AND (high BP OR smoker) # ============================================== high_risk = age > 60 and (systolic_bp > 140 or is_smoker) if high_risk: print("⚠️ HIGH STROKE RISK") print("Immediate preventive measures recommended")
Copied!

Boolean Operator Reference

  • and: Both conditions must be True
  • or: At least one condition must be True
  • not: Reverses the truth value

Summary: Your Medical Decision-Making Toolkit

Congratulations! You've mastered the essential decision-making tools used in medical programming:

🔧 Your New Skills:

  1. If Statements - Single condition checks (like fever detection)
  2. If-Else - Binary decisions (like test results: positive/negative)
  3. Elif Chains - Multiple categories (like BMI or triage levels)
  4. Nested Conditionals - Complex layered logic (like clinical trial eligibility)
  5. Boolean Logic - Combining multiple conditions (like risk assessments)
  6. Truthiness - Data validation (like checking medical record completeness)

🌟 Real-World Impact:

These conditional statements power:

  • Electronic Health Record (EHR) systems
  • Clinical Decision Support Systems (CDSS)
  • Medical device software
  • Drug interaction checkers
  • Diagnostic AI algorithms
  • Patient monitoring systems

💡 Final Tip Box: Remember, every if statement in medical software could impact patient care. Always consider:

  • What happens if the condition is True?
  • What happens if it's False?
  • Are there edge cases to handle?
  • Is the logic clear for other developers (and future you)?
