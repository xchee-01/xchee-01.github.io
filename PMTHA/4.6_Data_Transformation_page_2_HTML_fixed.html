4.6 Data Transformation: Reshaping Data

Welcome to the advanced module on data reshaping for precision health! In this module, you'll master transforming data between different formats to enable powerful longitudinal analyses and time-series visualizations crucial for tracking patient outcomes.

🔬 Mission Briefing: Wide to Long Format Transformation

Here's where data transformation gets really interesting! Imagine you're tracking patient biomarkers over time - like watching a patient's health movie rather than just seeing snapshots. Wide format shows all timepoints as columns (great for data entry), but long format stacks them vertically (perfect for time-series analysis and visualization).

🎬 The Movie Analogy:

  • Wide format = All movie frames laid out side by side
  • Long format = Frames stacked in a film reel, ready to play

This transformation is crucial for:

  • Creating those beautiful line graphs showing patient improvement over time
  • Running sophisticated statistical models that account for repeated measurements
  • Feeding data into machine learning algorithms that predict treatment response

# Clean up timepoint labels for prettier graphs # ============================================= glucose_long['timepoint'] = glucose_long['timepoint'].str.replace('_glucose', '') # Extract numeric month values for proper time-series ordering # ======================================================== glucose_long['month'] = glucose_long['timepoint'].map({ 'baseline': 0, 'month3': 3, 'month6': 6 }) print("\nLong Format Glucose Data (Ready for Analysis!):") print(glucose_long.sort_values(['patient_id', 'month'])) # Bonus: Calculate change from baseline # ===================================== baseline_values = glucose_long[glucose_long['timepoint'] == 'baseline'][['patient_id', 'glucose_value']] baseline_values.columns = ['patient_id', 'baseline_value'] glucose_long = glucose_long.merge(baseline_values, on='patient_id') glucose_long['change_from_baseline'] = glucose_long['glucose_value'] - glucose_long['baseline_value']

Complete Solution:

# Complete solution # ================= # Step 1: Melt all biomarker columns # ================================== all_biomarkers_long = pd.melt( df_longitudinal, id_vars=['patient_id', 'treatment_group'], value_vars=['baseline_glucose', 'month3_glucose', 'month6_glucose', 'baseline_hba1c', 'month3_hba1c', 'month6_hba1c'], var_name='measurement', value_name='value' ) # Step 2: Extract timepoint and biomarker type (with regex magic! ✨) # ======================================================== # Using regex groups for more robust extraction # ============================================= all_biomarkers_long[['timepoint', 'biomarker']] = all_biomarkers_long['measurement'].str.extract( r'(baseline|month\d+)_(\w+)' ) # Step 3: Add numeric month for proper sorting # ============================================ month_mapping = {'baseline': 0, 'month3': 3, 'month6': 6} all_biomarkers_long['month'] = all_biomarkers_long['timepoint'].map(month_mapping) # Step 4: Drop the original measurement column and reorder # ======================================================== all_biomarkers_long = all_biomarkers_long.drop('measurement', axis=1) all_biomarkers_long = all_biomarkers_long[['patient_id', 'treatment_group', 'month', 'timepoint', 'biomarker', 'value']] # Sort for clarity # ================ all_biomarkers_long = all_biomarkers_long.sort_values(['patient_id', 'biomarker', 'month']) print("Comprehensive Long Format Biomarker Data:") print(all_biomarkers_long) # Bonus Analysis: Which treatment works better? # ============================================= print("\n📊 Treatment Effectiveness Analysis:") print("Average change in biomarkers by treatment group:") summary = all_biomarkers_long.groupby(['treatment_group', 'biomarker', 'timepoint'])['value'].mean().round(2) print(summary) # Clinical insight # ================ print("\n💡 Clinical Insight: Notice how P002 (Lifestyle intervention) shows dramatic improvement!") print("This demonstrates the power of lifestyle changes in diabetes management!")
