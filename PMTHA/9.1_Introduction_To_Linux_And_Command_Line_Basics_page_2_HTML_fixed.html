MODULE 2: Linux Filesystem and Practical Skills

The Linux Filesystem Structure

Linux uses a single tree structure starting from / (root).

Directory Hierarchy

/ # Root directory ├── home # User files ├── etc # System config ├── var # Variable data ├── usr # User programs ├── bin # Commands ├── tmp # Temporary └── dev # Devices
Copied!

City Analogy:

  • /home = Residential area
  • /etc = City hall
  • /var = Post office
  • /usr = Shopping district
Learning Checkpoint
Which directory would you look in to find system configuration files?
/home
Not quite. /home contains user personal files, not system configuration.
/etc
Correct! /etc contains system configuration files, like the "city hall" where rules and settings are stored.
/var
Not correct. /var contains variable data like logs and temporary files, not configuration.
/tmp
Incorrect. /tmp is for temporary files that can be deleted between reboots.

Key Directories

Directory Purpose Example Use
/home/user Personal files Documents, projects
/etc System settings Config files
/var/log System logs Troubleshooting
/tmp Temporary files Downloads
/usr/bin User commands Installed programs
Learning Checkpoint
You need to check system logs for errors. Which directory should you navigate to?
/home/user
Not correct. /home/user contains personal files, not system logs.
/usr/bin
Incorrect. /usr/bin contains executable programs, not log files.
/var/log
Correct! /var/log contains system logs used for troubleshooting and monitoring system activities.
/tmp
Not right. /tmp is for temporary files, not system logs.

Exploring Filesystem

# List root ls / # Disk usage du -sh /* 2>/dev/null # System logs ls -la /var/log
Copied!
Learning Checkpoint
What does the command du -sh /* show?
List of all users
Incorrect. User information would be found with commands like 'who' or in /etc/passwd.
Disk usage summary for root directories
Correct! du (disk usage) with -s (summary) and -h (human-readable) shows the size of each directory under root.
System date and time
Not correct. The 'date' command shows system date and time, not 'du'.
Current directory contents
Incorrect. 'ls' shows directory contents, while 'du' shows disk usage.

Practice Lab 2: Filesystem Navigation

  1. List root: ls /
  2. Check logs: ls /var/log
  3. View disk usage: du -sh /home

Combining Commands

Use pipe | to connect commands:

# Find large directories du -sh /* | sort -h # Search history history | grep "ls"
Copied!
Learning Checkpoint
What does the pipe symbol (|) do in Linux commands?
Separates multiple commands
Not quite. Semicolon (;) separates multiple commands, not the pipe.
Sends output of one command as input to another
Correct! The pipe (|) takes the output from the command on its left and uses it as input for the command on its right.
Comments out the rest of the line
Incorrect. The hash symbol (#) is used for comments, not the pipe.
Creates a new file
Not correct. The > symbol redirects output to a file, not the pipe.

Real-World System Check

# System info echo "=== System Check ===" echo "Date: $(date)" echo "User: $(whoami)" echo "Host: $(hostname)" # OS details cat /etc/os-release | grep PRETTY_NAME # Disk usage du -sh /var /tmp /home 2>/dev/null
Copied!
Learning Checkpoint
Which command shows your current username?
hostname
Not correct. hostname shows the system name, not your username.
whoami
Correct! The whoami command displays the username of the current user.
date
Incorrect. date shows the current date and time, not username.
pwd
Not right. pwd shows the current working directory, not username.

Command Reference

Essential Commands:

pwd # Current directory ls -la # List files cat file # Show file content echo text # Print text date # Current time whoami # Username hostname # System name

Efficiency Tips:

  • Tab = Auto-complete
  • ↑/↓ = Command history
  • Ctrl+R = Search history
  • !! = Repeat last command
Learning Checkpoint
Which keyboard shortcut searches through your command history?
Tab
Not quite. Tab is for auto-completion, not searching history.
Ctrl+C
Incorrect. Ctrl+C cancels the current command.
Ctrl+R
Correct! Ctrl+R opens reverse search, allowing you to find previously typed commands by typing part of them.
Ctrl+D
Not right. Ctrl+D exits the current shell or logs out.

Practice Challenges

  1. Info Gatherer: Show username and date in one command
  2. History Detective: Count your ls commands
  3. Help Seeker: What does ls -S do?
Learning Checkpoint
Which command would show both username and date in one line?
echo $(whoami) $(date)
Correct! echo $(whoami) $(date) uses command substitution to display both outputs in one line.
whoami | date
Not correct. This pipes whoami output to date, which doesn't work as expected.
ls -la whoami date
Incorrect. This would try to list files named 'whoami' and 'date'.
pwd && hostname
Not right. This shows directory and hostname, not username and date.
