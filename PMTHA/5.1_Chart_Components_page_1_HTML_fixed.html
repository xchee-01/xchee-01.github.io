5.1.1. Understanding Chart Anatomy - The DNA of Data Visualization

Before surgeons operate, they study anatomy. Before you visualize medical data, let's understand chart anatomy! Every chart has essential components that work together like organs in a body. Miss one, and your visualization might fail to communicate critical information.

💡 Fun Fact: Did you know? The first medical chart was created by Florence Nightingale in 1858! Her "coxcomb" diagram showed death causes in the Crimean War and literally changed how we think about hospital hygiene. Your charts could have similar impact!

The Component Hierarchy: From Container to Content

Imagine building a medical dashboard like assembling a puzzle:

  1. Figure → The frame (patient's complete chart)

5.1.2. The Figure - Your Medical Canvas

The figure is your master container - think of it as the clipboard that holds all patient information. In emergency rooms, doctors glance at these visual dashboards to make split-second decisions. Let's create your first one!

Creating Your First Medical Figure

# Create a figure with specific dimensions fig = plt.figure(figsize=(10, 6)) # Width=10 inches, Height=6 inches # Add a main title - like the patient's name tag fig.suptitle('Patient Vital Signs Monitoring Dashboard', fontsize=16)
Copied!

💡 Pro Tip: Size Matters in Medicine!

  • Too small (< 8×6): Critical details might be missed
  • Too large (> 14×10): Won't fit in medical reports
  • Sweet spot: 10×6 or 12×8 for most medical visualizations

Understanding Figure Properties

The figure is like a smart container with special powers:

  • Figsize: Controls display dimensions (crucial for readability)
  • DPI: Dots per inch (higher = sharper, important for publications)
  • Facecolor: Background color (white is standard for medical contexts)

5.1.3. Axes - Where Medical Data Lives

If the figure is your patient chart, axes are the individual test result sections. They define the coordinate system - the "where" and "how much" of your medical data. Let's explore!

Creating and Configuring Axes

# Method 1: Create figure and axes together fig, ax = plt.subplots(figsize=(10, 6)) # Method 2: Add axes to existing figure fig = plt.figure(figsize=(10, 6)) ax = fig.add_subplot(111) # 1 row, 1 column, first subplot
Copied!

The Subplot System Explained

The mysterious `111` actually makes sense:

  • First `1`: Number of rows
  • Second `1`: Number of columns
  • Third `1`: Which subplot to create

Think of it like hospital bed numbering: Floor-Room-Bed!

🧪 Quick Activity: Predict the Code
What would fig.add_subplot(223) create?
A) 2 rows, 2 columns, selecting the 3rd subplot (bottom-left position)
Creating a 2×2 grid and selecting the third position.
Correct! In a 2×2 grid, positions are numbered 1 (top-left), 2 (top-right), 3 (bottom-left), 4 (bottom-right). Like organizing four patient monitors in a 2×2 grid!
B) 2 rows, 2 columns, selecting the 3rd subplot (top-right position)
Creating a 2×2 grid and selecting the top-right position.
Not quite. The top-right position in a 2×2 grid would be position 2, not 3. Subplots are numbered left-to-right, top-to-bottom.
C) 2 rows, 3 columns, selecting the 2nd subplot
Creating a 2×3 grid with the second position selected.
Incorrect. Each digit represents a different parameter: rows (2), columns (2), subplot number (3).
D) 3 rows, 2 columns, selecting the 2nd subplot
Creating a 3×2 grid with the second position selected.
That's not right. The first digit (2) indicates rows, second digit (2) indicates columns, third digit (3) indicates which subplot.

Setting Up Medical Axes

# Configure axes for blood glucose monitoring ax.set_title('24-Hour Glucose Monitoring') ax.set_xlabel('Time (hours)') ax.set_ylabel('Glucose Level (mg/dL)') # Add safety zones ax.axhspan(70, 140, alpha=0.2, color='green', label='Normal Range') ax.axhspan(0, 70, alpha=0.2, color='red', label='Hypoglycemia Risk') ax.axhspan(140, 300, alpha=0.2, color='orange', label='Hyperglycemia Risk')
Copied!

💡 Clinical Context: Why Axes Matter in Medicine:

  • Wrong scale → Misdiagnosed conditions
  • Missing units → Medication errors
  • Unclear ranges → Delayed interventions

In 1999, NASA lost a $125 million Mars orbiter due to unit confusion. In medicine, such errors can cost lives!

5.1.4. Labels and Titles - Your Clinical Context

Labels are like medical ID bracelets - without them, even critical data becomes meaningless. Let's master the art of clinical labeling!

The Anatomy of Good Medical Labels

# Create sample patient data hours = np.arange(0, 24, 1) # Simulate body temperature with circadian rhythm temperature = 36.5 + 0.5 * np.sin(hours/3) + 0.2 * np.random.randn(24) # Create the visualization fig, ax = plt.subplots(figsize=(10, 6)) ax.plot(hours, temperature, 'b-', linewidth=2, marker='o', markersize=4) # Add comprehensive medical context ax.set_title('Patient Temperature Monitoring - ICU Bed 7\nPost-Surgery Day 1', fontsize=14, fontweight='bold') ax.set_xlabel('Hours Since Surgery', fontsize=12) ax.set_ylabel('Body Temperature (°C)', fontsize=12) # Add clinical reference lines ax.axhline(y=37.0, color='green', linestyle='--', alpha=0.7, label='Normal Temperature') ax.axhline(y=38.0, color='orange', linestyle='--', alpha=0.7, label='Mild Fever Threshold') ax.axhline(y=39.0, color='red', linestyle='--', alpha=0.7, label='High Fever Alert') # Style improvements ax.grid(True, alpha=0.3, linestyle=':') ax.legend(loc='upper right', frameon=True, fancybox=True, shadow=True) plt.tight_layout() plt.show()
Copied!

Which of the following is NOT a best practice for medical chart labeling?
