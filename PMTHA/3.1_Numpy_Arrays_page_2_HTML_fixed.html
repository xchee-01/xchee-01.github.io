3.3.3. Mission Briefing: Data Types - Precision Matters in Medicine!

Imagine giving a patient 1 gram of medication when they needed 1.5 grams—that's why data types matter! NumPy offers a precision tool for every medical measurement.

🎯 The Right Tool for the Right Job

Think of NumPy data types like medical instruments:

  • int32/int64: Like a counter - perfect for discrete values (cell counts, patient IDs)
  • float64: Like a precision scale - ideal for measurements (drug concentrations, biomarkers)
  • bool: Like a checkbox - great for yes/no conditions (has disease, responded to treatment)
# Integer for counting discrete items # =================================== white_blood_cells = np.array([5000, 7500, 11000, 4500], dtype=np.int32) print("WBC counts:", white_blood_cells) print("Memory used:", white_blood_cells.nbytes, "bytes")
Copied!

🔬 Medical Context: Normal WBC count is 4,500-11,000 cells/μL. Our array shows one patient (11,000) at the upper limit—worth monitoring!

Quick Check
Which NumPy data type would be BEST for storing patient ages in years?
float64
Use floating-point for maximum precision
Not quite. Ages in years are whole numbers that don't need decimal precision. float64 would waste memory.
int32
Use integer type for whole numbers
Correct! Ages in years are whole numbers (discrete values) that don't require decimal precision. int32 can handle ages from 0 to over 2 billion, which is more than sufficient for human ages.
bool
Use boolean for efficiency
Incorrect. bool can only store True/False values, not numeric ages.
complex128
Use complex numbers for advanced calculations
Not correct. Complex numbers are for mathematical operations with imaginary components, not for storing ages.
# Float for precise measurements # ============================== drug_concentrations = np.array([0.5, 1.25, 2.0, 0.75], dtype=np.float64) print("Drug levels (mg/mL):", drug_concentrations) print("Can store values like:", drug_concentrations[0] + 0.00001) # Ultra-precise!
Copied!

3.3.4. The Danger of Wrong Types

# WARNING: Type conversion can lose critical information! # ================================================== glucose_float = np.array([95.7, 110.3, 88.9, 125.5]) glucose_int = glucose_float.astype(np.int32) print("Original (precise):", glucose_float) print("Converted (lost decimals):", glucose_int) print("Lost information:", glucose_float - glucose_int)
Copied!

😱 Medical Alert: Those "lost" decimals could be the difference between normal and pre-diabetic readings!

Critical Thinking
A patient's temperature reading is 38.7°C. If you accidentally convert this to int32, what would be the result and potential clinical impact?
38°C - Might miss a mild fever
The decimal portion would be truncated
Correct! Converting 38.7 to int32 truncates to 38, losing the 0.7°C. This could cause you to miss a mild fever (normal is <37.5°C), potentially delaying treatment.
39°C - Would overestimate the fever
The value would be rounded up
Incorrect. Type conversion truncates (cuts off) decimal places, it doesn't round up.
38.7°C - No change
int32 can store decimal values
Not correct. Integer types cannot store decimal values - they only store whole numbers.
0°C - Complete data loss
The conversion would fail entirely
Incorrect. The conversion would succeed but truncate the decimal portion, not reset to zero.

3.3.5. Memory Efficiency Matters

# Boolean arrays: Maximum efficiency for binary data # ================================================== has_diabetes = np.array([True, False, False, True, False], dtype=bool) print("Diabetes status:", has_diabetes) print("Memory per patient:", has_diabetes.itemsize, "byte") print("If we had 1 million patients:", has_diabetes.itemsize * 1_000_000 / 1_024_000, "MB")
Copied!

🌍 Big Data Reality Check: The UK Biobank stores health data for 500,000 participants. Using bool instead of int32 for binary variables saves gigabytes of storage!

Memory Challenge
You're storing vaccination status (yes/no) for 10 million patients. How much memory would you save by using bool instead of int32?
10 MB
Minimal savings
Not quite. The savings would be much larger. Calculate: (4 bytes - 1 byte) × 10 million.
30 MB
Significant reduction
Correct! bool uses 1 byte per value, int32 uses 4 bytes. For 10 million patients: bool = 10 MB, int32 = 40 MB. Savings = 40 - 10 = 30 MB.
40 MB
Total memory for int32
That's the total memory used by int32, not the savings. The question asks for the difference.
100 MB
Massive savings
Too high. Check your calculation: int32 (4 bytes) - bool (1 byte) = 3 bytes saved per patient.
