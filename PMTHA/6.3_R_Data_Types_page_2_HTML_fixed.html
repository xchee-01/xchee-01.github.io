6.3.4. Complex Numbers in Medical Imaging

Ever wondered how MRI machines create brain images? They use complex numbers to measure both strength AND timing of magnetic signals!

# Creating complex numbers mri_signal <- 4 + 3i # Real: 4, Imaginary: 3 signal_strength <- Mod(mri_signal) # Magnitude: 5 signal_phase <- Arg(mri_signal) # Phase angle

💊 Medical Application: MRI signal processing

# Tissue signals white_matter <- 8 + 4i gray_matter <- 6 + 7i csf_signal <- 2 + 1i # Compare magnitudes samples <- c(white_matter, gray_matter, csf_signal) avg_magnitude <- mean(Mod(samples)) print(paste("Average signal:", round(avg_magnitude, 2)))

Learning Checkpoint
Which R function would you use to find the magnitude (strength) of a complex MRI signal?
abs()
Function
The absolute value function for regular numbers
Not quite. While abs() works for real numbers, Mod() is the specific function for complex number magnitudes in R.
Mod()
Function
The modulus function for complex numbers
Correct! Mod() calculates the magnitude (or modulus) of a complex number, which represents the signal strength in MRI imaging.
sqrt()
Function
The square root function
That's not right. sqrt() calculates square roots but doesn't handle complex numbers' magnitude calculation.
length()
Function
The length function for vectors
Incorrect. length() returns the number of elements in a vector, not the magnitude of a complex number.

6.3.5. Handling Missing Medical Data

Hospital datasets typically have 5-20% missing values. R provides special values to handle these realities:

# NA: Value should exist but is missing blood_pressure <- NA # Patient refused pain_level <- NA # Unable to communicate # NULL: Test wasn't attempted genetic_test <- NULL # Not ordered mri_results <- NULL # Not approved # Inf & NaN: Mathematical edge cases survival_rate <- 100 / 0 # Inf (perfect outcome!) impossible <- 0 / 0 # NaN
Copied!

💊 Medical Application: Clinical trials with dropouts

# Patient outcomes: 1=improved, 0=no change, NA=dropped treatment_group <- c(1, 1, 0, 1, NA, 1, 0, NA, 1, 1) # Calculate response rate (excluding dropouts) response_rate <- sum(treatment_group == 1, na.rm = TRUE) / sum(!is.na(treatment_group)) print(paste("Response rate:", round(response_rate * 100, 1), "%"))
Copied!
Learning Checkpoint
In medical data analysis, when should you use NA versus NULL in R?
NA for missing values, NULL for absent elements
NA when data should exist but is missing; NULL when the test/element doesn't exist
Correct! NA represents missing data in existing records (like a patient who didn't report pain level), while NULL means the element itself doesn't exist (like a test that wasn't ordered).
They are interchangeable
Both NA and NULL can be used for any missing data
Not quite. NA and NULL have distinct meanings in R. NA is for missing values within data, while NULL indicates the complete absence of an element.
NULL for missing values, NA for errors
NULL when data is missing; NA when there's an error
That's backwards. NA is used for missing values within data structures, while NULL represents the absence of the object itself.
Always use NA, never NULL
NULL is deprecated; only use NA for missing data
Incorrect. Both NA and NULL serve important but different purposes in R. NULL is still actively used to represent absent objects or uninitialized variables.
