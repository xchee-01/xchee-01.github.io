Output Functions and Interactive Input in Medical R Programming

Welcome to essential data communication in R! 🚀 In precision medicine, effectively reading patient data and presenting clinical results is fundamental. R's I/O functions are your medical data translator.

💡 Fun Fact: A typical hospital generates ~50 petabytes of data annually - 11,000 DVDs worth daily!

Output Functions: Your Communication Toolkit

R provides three main output functions:

  • print(): Formal presenter with technical details
  • cat(): Friendly narrator with clean output
  • paste(): Creative writer combining text and data
Learning Checkpoint
Which R function would you use to display clean, human-readable output without technical details like quotes or index numbers?
print()
The standard output function with formatting
Not quite. print() shows technical details like quotes and [1] index numbers, making it less ideal for clean output.
cat()
Concatenate and print function
Correct! cat() produces clean output without quotes or [1] index numbers, making it ideal for human-readable displays.
paste()
Function to combine strings
Not correct. paste() combines elements but doesn't output them - you'd still need print() or cat() to display the result.
display()
Display function for output
Incorrect. display() is not a standard R function for text output.

Basic Output Examples

# print() - Shows technical details patient_id <- "MRN-2024-1587" glucose_level <- 126 print(patient_id) # [1] "MRN-2024-1587" print(glucose_level) # [1] 126 # cat() - Clean human-readable output cat("Patient Blood Glucose:", glucose_level, "mg/dL\n") # Output: Patient Blood Glucose: 126 mg/dL # paste() - Combines elements diagnosis <- paste("Patient", patient_id, "has glucose", glucose_level) code <- paste0("ICD10-", "E11.9") # No spaces: "ICD10-E11.9"
Copied!
Learning Checkpoint
What is the difference between paste() and paste0()?
paste0() adds a newline at the end
It automatically adds line breaks
Incorrect. paste0() doesn't add newlines - neither function adds line breaks automatically.
paste0() combines elements without spaces
No separator between elements
Correct! paste0() concatenates elements without any separator, while paste() uses a space by default.
paste0() only works with numbers
Limited to numeric values
Not correct. paste0() works with all data types, just like paste().
There is no difference
They function identically
Incorrect. There is a significant difference in how they handle separators between elements.

Professional Clinical Reports

# Clinical Laboratory Report cat("╔════════════════════════════════╗\n") cat("║ CLINICAL LABORATORY REPORT ║\n") cat("╠════════════════════════════════╣\n") cat("║ Patient ID:", patient_id, "║\n") cat("║ Glucose:", glucose_level, "mg/dL", ifelse(glucose_level > 125, "⚠️ HIGH", "✓"), "║\n") cat("╚════════════════════════════════╝\n")
Copied!
Learning Checkpoint

Incorrect. The checkmark only appears when glucose_level is 125 or less.
⚠️ HIGH

Correct! Since 126 > 125, the ifelse() function returns "⚠️ HIGH".
Nothing

Incorrect. The ifelse() function always returns one of the two specified values.

Incorrect. This is valid R code that will execute without errors.

Learning Checkpoint
Based on the blood pressure values systolic=142 and diastolic=92, what hypertension stage does this indicate?
Normal
Blood pressure is within normal range
Incorrect. Normal blood pressure is <120/80 mmHg. These values are significantly elevated.
Stage 1
Mild hypertension
Not quite. Stage 1 is 130-139/80-89 mmHg. These values exceed Stage 1 thresholds.
Stage 2
Moderate to severe hypertension
Correct! Stage 2 hypertension is defined as systolic ≥140 OR diastolic ≥90. Both values exceed these thresholds.

Interactive Input with readline()

The readline() function enables user input in R. Think of it as R's consultation tool!

⚠️ Critical: readline() ALWAYS returns text - convert to numeric for calculations!

# Basic input patient_weight <- readline(prompt = "Enter weight (kg): ") patient_weight <- as.numeric(patient_weight) # Convert! cat("Weight recorded:", patient_weight, "kg\n")
Copied!
Learning Checkpoint
What happens if you don't convert readline() input to numeric before mathematical operations?
R automatically converts it
Automatic type conversion occurs
Incorrect. R does not automatically convert text to numbers for mathematical operations.
You'll get an error when performing calculations
Mathematical operations will fail
Correct! readline() always returns character/text data. Mathematical operations on text will produce errors.
The calculation works but gives wrong results
Produces incorrect numerical output
Incorrect. R will throw an error, not produce wrong results.
readline() already returns numeric values
No conversion needed
Incorrect. readline() always returns character data, never numeric.

Interactive BMI Calculator

cat("╔════════════════════╗\n") cat("║ BMI CALCULATOR ║\n") cat("╚════════════════════╝\n\n") weight <- as.numeric(readline("Enter weight (kg): ")) height <- as.numeric(readline("Enter height (m): ")) bmi <- weight / (height^2) cat("\n📊 BMI Result:", round(bmi, 1), "\n") if(bmi < 18.5) { cat("🔵 Classification: Underweight\n") } else if(bmi < 25) { cat("🟢 Classification: Normal weight\n") } else if(bmi < 30) { cat("🟡 Classification: Overweight\n") } else { cat("🔴 Classification: Obese\n") }
Copied!
Learning Checkpoint
For a patient with weight=70kg and height=1.75m, what BMI classification will be displayed?
🔵 Underweight
BMI < 18.5
Incorrect. BMI = 70/(1.75^2) = 22.9, which is not below 18.5.
🟢 Normal weight
BMI 18.5-24.9
Correct! BMI = 70/(1.75^2) = 22.9, which falls between 18.5 and 25 (Normal weight range).
🟡 Overweight
BMI 25-29.9
Incorrect. BMI = 22.9 is below 25, so it's not in the overweight range.
🔴 Obese
BMI ≥ 30
Incorrect. BMI = 22.9 is well below 30.

Data Quality Validation

cat("🔍 Reviewing patient glucose values...\n") cat("⚠️ Found outlier: Glucose = 450 mg/dL\n") response <- readline("Is this value correct? (yes/no): ") if(tolower(response) == "yes") { cat("✓ Value confirmed - flagging for review\n") cat("🏥 Alert: Possible diabetic emergency\n") } else { cat("🔄 Value marked for re-verification\n") }
Copied!

Why is tolower() used in the validation code above?
To convert the response to lowercase for case-insensitive comparison
Handles any case variation
Correct! tolower() ensures the comparison works whether the user types "yes", "YES", or "Yes".
To make the output look better
For aesthetic purposes
Incorrect. tolower() is used for functional comparison, not aesthetics.
To prevent errors in readline()
Error prevention in input
Incorrect. readline() works fine without tolower() - it's used after input is received.
To convert text to numbers
Type conversion function
Incorrect. tolower() converts text to lowercase, not to numbers.

🧪 Lab Exercise 2: Pediatric Dosage Calculator

Create an interactive calculator for amoxicillin (40 mg/kg/day, divided into 3 doses):

cat("=== Pediatric Amoxicillin Calculator ===\n") patient_name <- readline("Enter patient name: ") weight <- as.numeric(readline("Enter weight (kg): ")) daily_dose <- _____ * _____ dose_per_intake <- _____ / 3 cat("\n--- Prescription for", _____, "---\n") cat("Weight:", _____, "kg\n") cat("Total daily dose:", _____, "mg\n") cat("Give", round(_____, 0), "mg three times daily\n") if(daily_dose > 1500) { cat("WARNING: Dose exceeds typical maximum\n") }
Copied!
Learning Checkpoint
For a 25kg child, what would be the correct dose per intake (each of the 3 daily doses)?
40 mg
Base dosage amount
Incorrect. 40 mg/kg is the daily dose rate, not the per-intake dose.
333 mg
One-third of daily dose
Correct! Daily dose = 25kg × 40mg/kg = 1000mg. Dose per intake = 1000mg ÷ 3 = 333.33mg (rounded to 333mg).
1000 mg
Total daily dose
Incorrect. 1000mg is the total daily dose, which needs to be divided into 3 doses.
125 mg
Lower dosage option
Incorrect. This dose would be too low for the prescribed regimen.

Answer:

# Complete solution: cat("=== Pediatric Amoxicillin Calculator ===\n") patient_name <- readline("Enter patient name: ") weight <- as.numeric(readline("Enter weight (kg): ")) daily_dose <- weight * 40 dose_per_intake <- daily_dose / 3 cat("\n--- Prescription for", patient_name, "---\n") cat("Weight:", weight, "kg\n") cat("Total daily dose:", daily_dose, "mg\n") cat("Give", round(dose_per_intake, 0), "mg three times daily\n") if(daily_dose > 1500) { cat("WARNING: Dose exceeds typical maximum\n") }
Copied!
