NUS Jupyter Notebook Installation Guide

Installing Jupyter Notebook for Data Science

Welcome to this comprehensive guide on installing Jupyter Notebook! Jupyter Notebook is an essential tool for data science, machine learning, and scientific computing. It provides an interactive environment where you can write and execute code, visualize data, and document your analysis all in one place. By the end of this guide, you'll have Jupyter Notebook installed and ready to use on your laptop.

What is Jupyter Notebook?

Jupyter Notebook is an open-source web application that allows you to create and share documents containing live code, equations, visualizations, and narrative text. It's particularly popular in data science and machine learning because it enables interactive development and data exploration.

Key Features of Jupyter Notebook:

  • Interactive Computing: Execute code cells individually and see results immediately
  • Multi-language Support: Supports Python, R, Julia, and over 40 other programming languages
  • Rich Output: Display HTML, images, videos, LaTeX, and custom MIME types
  • Data Visualization: Create plots and charts inline with libraries like matplotlib and seaborn
  • Markdown Support: Mix code with formatted text, equations, and documentation
  • Easy Sharing: Export notebooks as HTML, PDF, or share .ipynb files

Did You Know? The name "Jupyter" is a combination of Julia, Python, and R - three core programming languages for data science. However, Jupyter now supports many more languages through its kernel system!

Prerequisites

Before installing Jupyter Notebook, ensure you have:

  • A laptop with Windows, macOS, or Linux operating system
  • At least 4GB of RAM (8GB or more recommended for data science work)
  • About 5GB of free disk space
  • An internet connection for downloading packages
  • Administrator privileges on your computer

Installing on Windows

There are multiple ways to install Jupyter Notebook on Windows. We'll cover the two most recommended methods: using Anaconda (easiest for beginners) and using pip (for those who already have Python).

Method 1: Installing with Anaconda (Recommended)

Anaconda is a Python distribution that includes Jupyter Notebook and many popular data science packages pre-installed.

Step 1: Download Anaconda

  1. Visit the official Anaconda website: https://www.anaconda.com/download
  2. Click on the Windows installer download button
  3. Choose the Python 3.x version (64-bit installer recommended)
  4. Save the installer file (approximately 600MB)

Step 2: Run the Installer

  1. Double-click the downloaded .exe file
  2. Click "Next" on the welcome screen
  3. Read and accept the license agreement
  4. Choose "Just Me" for installation type (recommended)
  5. Select the installation location (default is usually fine)
  6. Important: Check "Add Anaconda to my PATH environment variable"
  7. Click "Install" and wait for the process to complete (5-10 minutes)
# Open Command Prompt and verify installation conda --version python --version jupyter --version
Copied!

Method 2: Installing with pip

If you already have Python installed, you can use pip to install Jupyter Notebook.

Step 1: Check Python Installation

# Open Command Prompt (Win+R, type "cmd", press Enter) python --version # Should show Python 3.x.x pip --version # Should show pip version
Copied!

Step 2: Install Jupyter

# Upgrade pip first python -m pip install --upgrade pip # Install Jupyter Notebook pip install notebook # Optional: Install additional useful packages pip install numpy pandas matplotlib seaborn scikit-learn
Copied!

Installing on macOS

macOS users have several options for installing Jupyter Notebook. We'll cover installation via Homebrew and Anaconda.

Method 1: Installing with Homebrew and pip

Homebrew is a popular package manager for macOS that makes it easy to install Python and other tools.

Step 1: Install Homebrew (if not already installed)

# Open Terminal (Cmd+Space, type "Terminal") # Install Homebrew /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # Verify installation brew --version
Copied!

Step 2: Install Python 3

# Install Python 3 brew install python3 # Verify Python installation python3 --version pip3 --version
Copied!

Step 3: Install Jupyter Notebook

# Upgrade pip pip3 install --upgrade pip # Install Jupyter Notebook pip3 install notebook # Install commonly used packages pip3 install numpy pandas matplotlib seaborn scikit-learn
Copied!

Method 2: Installing with Anaconda

Similar to Windows, Anaconda provides an all-in-one solution for macOS users.

  1. Download Anaconda from: https://www.anaconda.com/download
  2. Choose the macOS installer (64-bit graphical installer)
  3. Double-click the downloaded .pkg file
  4. Follow the installation wizard
  5. Accept the license agreement
  6. Choose installation location (default recommended)
  7. Wait for installation to complete

Post-Installation Setup

# Initialize conda for your shell conda init zsh # For macOS Catalina and later # OR conda init bash # For older macOS versions # Close and reopen Terminal, then verify conda --version jupyter --version
Copied!

macOS Tip: If you're using macOS Catalina or later, your default shell is zsh. Make sure to initialize conda for zsh rather than bash for a smoother experience!

Installing on Linux

Linux distributions typically come with Python pre-installed, making Jupyter installation straightforward. We'll cover Ubuntu/Debian and Fedora/CentOS.

Ubuntu/Debian-based Systems

Step 1: Update Package Manager

# Update package list sudo apt update # Upgrade existing packages sudo apt upgrade -y
Copied!

Step 2: Install Python and pip

# Install Python 3 and pip sudo apt install python3 python3-pip python3-dev -y # Verify installation python3 --version pip3 --version
Copied!

Step 3: Install Jupyter Notebook

# Upgrade pip pip3 install --upgrade pip # Install Jupyter Notebook pip3 install notebook # Install data science packages pip3 install numpy pandas matplotlib seaborn scikit-learn
Copied!

Fedora/CentOS/RHEL Systems

# Install Python and development tools sudo dnf install python3 python3-pip python3-devel gcc -y # Install Jupyter pip3 install --user notebook # Add local bin to PATH (add to ~/.bashrc for permanent effect) export PATH=$PATH:~/.local/bin # Verify installation jupyter --version
Copied!

Creating a Virtual Environment (Recommended)

It's a best practice to use virtual environments to avoid package conflicts.

# Install venv module sudo apt install python3-venv # Ubuntu/Debian # OR sudo dnf install python3-virtualenv # Fedora # Create a virtual environment python3 -m venv jupyter_env # Activate the environment source jupyter_env/bin/activate # Install Jupyter in the virtual environment pip install notebook # To deactivate later deactivate
Copied!

Launching Your First Jupyter Notebook

Now that you have Jupyter Notebook installed, let's launch it and create your first notebook!

Starting Jupyter Notebook

Method 1: Command Line Launch

# Navigate to your desired working directory cd ~/Documents/DataScience # Example directory # Launch Jupyter Notebook jupyter notebook # Or launch in a specific directory jupyter notebook ~/Documents/MyProject
Copied!

This will:

  • Start the Jupyter server
  • Open your default web browser
  • Navigate to http://localhost:8888
  • Display the Jupyter dashboard

Method 2: Anaconda Navigator (Windows/macOS)

  1. Open Anaconda Navigator from your applications
  2. Find Jupyter Notebook in the home tab
  3. Click "Launch"
  4. Your browser will open with the Jupyter interface

Creating Your First Notebook

  1. In the Jupyter dashboard, click "New" → "Python 3"
  2. A new notebook will open in a new tab
  3. You'll see an empty cell where you can type code

Try This Example:

# Your first Jupyter notebook cell! import pandas as pd import numpy as np import matplotlib.pyplot as plt # Create some sample data data = { 'Subject': ['Math', 'Science', 'English', 'History', 'Art'], 'Score': [95, 88, 92, 78, 85] } df = pd.DataFrame(data) # Display the dataframe print("Student Scores:") print(df) # Create a bar plot plt.figure(figsize=(10, 6)) plt.bar(df['Subject'], df['Score'], color=['#003D7C', '#EF7C00', '#4D7CAE', '#666666', '#f5f5f5']) plt.title('Student Performance by Subject', fontsize=16) plt.xlabel('Subject', fontsize=12) plt.ylabel('Score', fontsize=12) plt.ylim(0, 100) # Add value labels on bars for i, v in enumerate(df['Score']): plt.text(i, v + 1, str(v), ha='center', va='bottom') plt.show()
Copied!

Essential Jupyter Shortcuts

Master these keyboard shortcuts to work efficiently:

  • Shift + Enter: Run cell and move to next
  • Ctrl/Cmd + Enter: Run cell and stay
  • Alt + Enter: Run cell and insert new cell below
  • Esc: Enter command mode (blue border)
  • Enter: Enter edit mode (green border)
  • A: Insert cell above (in command mode)
  • B: Insert cell below (in command mode)
  • DD: Delete cell (in command mode)
  • M: Convert to Markdown cell (in command mode)
  • Y: Convert to Code cell (in command mode)

Troubleshooting Common Issues

Here are solutions to common problems you might encounter during installation or while using Jupyter Notebook.

Issue 1: "jupyter: command not found"

Cause: Jupyter is not in your system PATH.

Solutions:

  • For pip installations: Ensure Python Scripts folder is in PATH
  • For Anaconda: Use Anaconda Prompt instead of regular terminal
  • Linux/macOS: Add ~/.local/bin to PATH
# Windows (add to System Environment Variables) %USERPROFILE%\AppData\Local\Programs\Python\Python3X\Scripts # macOS/Linux (add to ~/.bashrc or ~/.zshrc) export PATH=$PATH:~/.local/bin # Reload shell configuration source ~/.bashrc # or source ~/.zshrc
Copied!

Issue 2: Port 8888 Already in Use

Error: "The port 8888 is already in use, trying another port."

Solution: Specify a different port:

# Use a different port jupyter notebook --port=8889 # Or let Jupyter find an available port automatically jupyter notebook --port=0
Copied!

Issue 3: Kernel Died or Won't Start

Common causes and solutions:

  • Outdated packages: Update Jupyter and dependencies
  • Conflicting packages: Use virtual environments
  • Memory issues: Close other applications
# Update Jupyter and dependencies pip install --upgrade notebook ipykernel # Reinstall kernel python -m ipykernel install --user # Clear Jupyter cache jupyter notebook --clear
Copied!

Issue 4: ImportError for Common Libraries

Solution: Install missing packages in the correct environment:

# From within Jupyter notebook cell !pip install numpy pandas matplotlib seaborn # Or install for specific kernel import sys !{sys.executable} -m pip install numpy pandas matplotlib
Copied!

Issue 5: Browser Doesn't Open Automatically

Solution: Manually navigate to the URL shown in terminal:

  • Look for: http://localhost:8888/?token=...
  • Copy the entire URL including the token
  • Paste into your browser

Pro Tip: You can configure Jupyter to use a specific browser by setting the BROWSER environment variable or using the --browser flag when launching.
