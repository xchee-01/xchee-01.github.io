Mission Briefing: Data Types - The Building Blocks of Health Information

Let's build on our foundation by learning about data types. Before we jump straight into medical applications, let's understand the basics:

What Are Data Types?

Think of data types like different kinds of hospital equipment - each designed for a specific purpose:

# Just showing different types of data print(42) # A number without a decimal point print(98.6) # A number with a decimal point print("Patient") # Text data in quotes
Copied!

Python recognizes different kinds of data and treats them differently, just like you'd use different tools for taking temperature versus measuring blood pressure.

Integers (int) - Whole Numbers

Integers are whole numbers without decimal points:

# Examples of integers print(5) print(0) print(-10)
Copied!

Let's see how we might use integers:

# Using integers (whole numbers) patient_count = 25 days_since_admission = 3 heart_rate = 72 print("Patients in ward:", patient_count) print("Days since admission:", days_since_admission) print("Heart rate:", heart_rate, "bpm")
Copied!
Learning Checkpoint
Would you use an integer or something else to represent a patient's temperature? Why?
Integer
int
Patient temperatures are whole numbers when rounded to the nearest degree.
Not quite right. Patient temperatures are typically measured with decimal precision (e.g., 37.2°C), which cannot be accurately represented by integers. In medicine, this precision is crucial for diagnosis.
Float
float
Patient temperatures typically include decimal points requiring precise measurement.
Correct! Body temperatures are measured with decimal precision (e.g., 37.2°C or 98.6°F). Using a float allows you to capture this precision, which is essential for accurate medical assessment and monitoring trends in patient conditions.
Integer
int
Temperatures can be multiplied by 10 to store decimals as integers (e.g., 372 instead of 37.2).
While this approach could work technically, it introduces unnecessary complexity and the risk of conversion errors. It's more straightforward and safer to use floats for values that naturally have decimal points.
String
str
Patient temperatures should be stored as text to include the unit (°C or °F).
While strings can store temperature values with units, they don't allow for direct mathematical operations (like calculating averages or comparing values). It's better to use floats for the temperature value and handle units separately.

Floating-Point Numbers (float) - Decimal Numbers

Floats are numbers with decimal points, perfect for precise measurements:

# Examples of floating-point numbers print(3.14) print(0.5) print(-2.75)
Copied!

In healthcare, you'll use floats frequently:

# Using floats (decimal numbers) body_temperature = 37.2 medication_dose = 2.5 height_in_meters = 1.75 print("Temperature:", body_temperature, "°C") print("Medication dose:", medication_dose, "mg") print("Patient height:", height_in_meters, "m")
Copied!

Strings (str) - Text Data

Strings are text data, enclosed in quotes (either single ' or double "):

# Examples of strings print("Hello") print('Python') print("42") # This is a string, not a number!
Copied!

In medicine, strings store all kinds of text information:

# Using strings (text data) patient_name = "Maria Garcia" blood_type = "O+" diagnosis = "Type 2 Diabetes" print("Patient name:", patient_name) print("Blood type:", blood_type) print("Diagnosis:", diagnosis)
Copied!

# A simple patient record using different data types name = "John Smith" # String age = 45 # Integer temperature = 37.2 # Float is_urgent = False # Boolean (we'll learn more about this later) print("Patient:", name) print("Age:", age) print("Temperature:", temperature, "°C") print("Urgent case:", is_urgent)

Summary: Python Data Types

Congratulations on learning about Python data types! Here's a quick summary of what we covered:

  1. Integers (int): Whole numbers without decimal points, used for counts, indices, and discrete measurements (e.g., patient count, age).
  2. Floating-point numbers (float): Numbers with decimal points, perfect for precise measurements and calculations (e.g., temperature, dosage).
  3. Strings (str): Text data enclosed in quotes, used for names, descriptions, and any textual information (e.g., patient name, diagnosis).

Understanding these fundamental data types is crucial for your work in health informatics and precision medicine. By choosing the appropriate data type for different kinds of medical information, you can ensure accuracy in your analysis and make more informed clinical decisions.
