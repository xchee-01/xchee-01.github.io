Imagine you're in a high-tech medical command center, surrounded by screens displaying patient data from around the world. You need to transform thousands of lab results instantly - converting units, filtering critical values, and creating personalized treatment maps. Fun fact: The human genome contains about 3 billion base pairs, and modern sequencing can generate dictionaries with millions of gene-expression values. Dictionary comprehensions help scientists process this massive data in seconds rather than hours!

🔬 Understanding Dictionary Comprehensions: Your Data Transformation Superpower

The Basic Concept Made Simple

Think of dictionary comprehensions as a recipe for instant data transformation. Instead of writing:

# The old, slow way - like manually filing patient records patient_ages = {} for patient in patient_list: patient_ages[patient.id] = patient.age
Copied!

You can write:

# The comprehension way - like using a smart filing system! patient_ages = {patient.id: patient.age for patient in patient_list}
Copied!

It's like the difference between hand-copying medical records versus using an automated scanner - same result, but SO much faster! 🚄

💡 Breaking Down the Magic Formula

The syntax pattern is like a medical prescription:

{key_expression: value_expression for item in source if condition} ^ ^ ^ ^ ^ Patient ID Test Result Each patient Data Filter

Quick Check: Dictionary Comprehension Syntax
What is the correct syntax for a basic dictionary comprehension?
[key: value for item in iterable]
Not quite right. Square brackets [] are used for list comprehensions, not dictionary comprehensions.
{key: value for item in iterable}
Correct! Dictionary comprehensions use curly braces {} with a colon : separating keys and values.
(key: value for item in iterable)
Parentheses () create generator expressions, not dictionary comprehensions.
{key, value for item in iterable}
This syntax uses a comma instead of a colon. Dictionary comprehensions require a colon : to separate keys and values.

🏥 Real-World Medical Example #1: Temperature Monitoring

# Morning rounds temperature check patient_temps_celsius = { "Room_101": 36.5, "Room_102": 37.8, # Slight fever! "Room_103": 36.9, "Room_104": 38.2 # Definite fever! } # Convert to Fahrenheit for the American medical team patient_temps_fahrenheit = { room: (temp * 9/5) + 32 for room, temp in patient_temps_celsius.items() } print("Temperature Report (°F):") for room, temp in patient_temps_fahrenheit.items(): status = "⚠️ FEVER" if temp > 99.5 else "✅ Normal" print(f"{room}: {temp:.1f}°F {status}")
Copied!

🧬 Real-World Medical Example #2: Gene Expression Analysis

# Analyzing cancer biomarkers gene_expression_raw = { "BRCA1": 0.23, "BRCA2": 0.45, "TP53": 0.89, # Tumor suppressor gene "EGFR": 1.34 # Often overexpressed in cancer } # Normalize to percentage and flag abnormal expressions gene_analysis = { gene: { "percentage": expr * 100, "status": "HIGH" if expr > 0.8 else "NORMAL" } for gene, expr in gene_expression_raw.items() } print("🧬 Gene Expression Report:") for gene, data in gene_analysis.items(): emoji = "🔴" if data["status"] == "HIGH" else "🟢" print(f"{emoji} {gene}: {data['percentage']:.1f}% ({data['status']})")

What would be the correct dictionary comprehension to create priority_patients?
{pid: wait for pid, wait in er_patients if wait > 60}
Close, but you're missing .items() to iterate over key-value pairs.
{pid: wait for pid, wait in er_patients.items() if wait > 60}
Correct! You need .items() to iterate over key-value pairs, and use a colon : to separate keys from values.
{pid: wait for pid, wait in er_patients.values() if wait > 60}

🔬 Lab Exercise 1: International Clinical Lab Converter

Mission: You're coordinating an international diabetes study. Labs from different countries report glucose in different units. Let's standardize!

# 🌍 International Glucose Results # US labs report in mg/dL, European labs need mmol/L glucose_readings_mgdl = { "Boston_Patient_A": 95, # Normal fasting "Boston_Patient_B": 126, # Diabetic range "Miami_Patient_C": 180, # High! "Seattle_Patient_D": 110 # Prediabetic } # Conversion factor: 1 mmol/L = 18 mg/dL # So: mmol/L = mg/dL ÷ 18 # TODO: Convert all values to mmol/L for European colleagues glucose_readings_mmol = _______________ # Display with clinical interpretation print("🩸 Glucose Results (mmol/L) for European Team:") for patient, value in glucose_readings_mmol.items(): if value < 5.6: status = "✅ Normal" elif value < 7.0: status = "⚠️ Prediabetic" else: status = "🔴 Diabetic" print(f"{patient}: {value:.1f} mmol/L - {status}")
Copied!
Glucose Conversion Challenge
What would be the correct dictionary comprehension to convert glucose_readings_mgdl to mmol/L?
{patient: mgdl * 18.0 for patient, mgdl in glucose_readings_mgdl.items()}
That would multiply by 18, but we need to divide to convert mg/dL to mmol/L.
{patient: mgdl / 18.0 for patient, mgdl in glucose_readings_mgdl.items()}
Correct! To convert mg/dL to mmol/L, divide by 18. You need .items() to access key-value pairs.
{patient: mgdl / 18 for patient, mgdl in glucose_readings_mgdl}
The division is correct, but you need .items() to iterate over key-value pairs.
{mgdl / 18.0: patient for patient, mgdl in glucose_readings_mgdl.items()}
This reverses the key-value relationship. Patient ID should be the key, not the value.

Expected Output:

🩸 Glucose Results (mmol/L) for European Team: Boston_Patient_A: 5.3 mmol/L - ✅ Normal Boston_Patient_B: 7.0 mmol/L - 🔴 Diabetic Miami_Patient_C: 10.0 mmol/L - 🔴 Diabetic Seattle_Patient_D: 6.1 mmol/L - ⚠️ Prediabetic
💡 Complete Solution
glucose_readings_mmol = { patient: mgdl / 18.0 for patient, mgdl in glucose_readings_mgdl.items() }
Copied!

🔍 Filtering with Dictionary Comprehensions: Finding Needles in Medical Haystacks

The Power of Conditional Filtering

In medicine, we often need to identify specific patient groups - those at risk, those responding to treatment, or those needing immediate attention. Dictionary comprehensions with filters are like having a smart medical alert system!

🏥 Example: Cardiac Risk Assessment

# Blood pressure readings (systolic) cardiac_unit_patients = { "Bed_1A": {"name": "Smith", "bp": 118}, # Normal "Bed_2A": {"name": "Jones", "bp": 145}, # Stage 2 hypertension! "Bed_3B": {"name": "Davis", "bp": 132}, # Stage 1 hypertension "Bed_4B": {"name": "Wilson", "bp": 165}, # Hypertensive crisis! "Bed_5C": {"name": "Brown", "bp": 125} # Elevated } # Find patients needing immediate intervention (BP ≥ 140) critical_patients = { bed: f"{data['name']} - BP: {data['bp']}" for bed, data in cardiac_unit_patients.items() if data['bp'] >= 140 } print("🚨 ALERT: Patients Requiring Immediate BP Management:") for bed, info in critical_patients.items(): print(f" {bed}: {info}")
Copied!
Cardiac Risk Assessment
Based on the cardiac unit example, how many patients would be in the critical_patients dictionary?
1 patient
Check again - there's more than one patient with BP ≥ 140.
2 patients
Correct! Patients with BP ≥ 140 are Jones (145) and Wilson (165), so 2 patients.
3 patients
Remember, we're only counting patients with BP ≥ 140.
4 patients
Only patients with BP ≥ 140 are included in critical_patients.

🧪 Complex Filtering: Multi-Parameter Screening

# Comprehensive metabolic panel results patient_labs = { "P101": {"glucose": 95, "creatinine": 0.9, "potassium": 4.2}, "P102": {"glucose": 210, "creatinine": 2.1, "potassium": 5.8}, # Multiple issues! "P103": {"glucose": 110, "creatinine": 1.0, "potassium": 3.9}, "P104": {"glucose": 88, "creatinine": 3.5, "potassium": 6.2}, # Kidney failure? } # Find patients with ANY abnormal value # Normal ranges: glucose < 100, creatinine < 1.2, potassium 3.5-5.0 abnormal_labs = { pid: labs for pid, labs in patient_labs.items() if labs['glucose'] > 100 or labs['creatinine'] > 1.2 or labs['potassium'] < 3.5 or labs['potassium'] > 5.0 } print("📋 Patients with Abnormal Labs:") for pid, labs in abnormal_labs.items(): issues = [] if labs['glucose'] > 100: issues.append("High glucose") if labs['creatinine'] > 1.2: issues.append("High creatinine") if labs['potassium'] < 3.5 or labs['potassium'] > 5.0: issues.append("Abnormal potassium") print(f"{pid}: {', '.join(issues)}")
Copied!
Metabolic Panel Analysis
Which patient has the most abnormal lab values based on the given normal ranges?
P101 - no abnormal values
Correct! P101 has all values within normal ranges.
P102 - all three values abnormal
Correct! P102 has glucose > 100 (210), creatinine > 1.2 (2.1), and potassium > 5.0 (5.8).
P103 - only glucose abnormal
P103 does have slightly elevated glucose (110), but that's only one abnormal value.
P104 - creatinine and potassium abnormal

Mission: Identify patients with positive COVID antibody tests for a vaccine efficacy study.

# 🦠 COVID-19 Antibody Test Results (IgG levels) # Positive threshold: ≥ 1.4 (manufacturer's cutoff) antibody_results = { "VAX001": 0.3, # Negative "VAX002": 2.1, # Positive! "VAX006": 1.6, # Positive "VAX007": 0.2 # Negative } # TODO: Create positive_patients dictionary with only IgG ≥ 1.4 positive_patients = _______________ # Calculate statistics total_tested = len(antibody_results) total_positive = len(positive_patients) positivity_rate = (total_positive / total_tested) * 100 print(f"🦠 COVID-19 Antibody Screening Results") print(f"{'='*40}") print(f"Total Tested: {total_tested}") print(f"Positive Results: {total_positive} ({positivity_rate:.1f}%)") print(f"\n📊 Positive Patients:") for patient_id, igg_level in positive_patients.items(): strength = "Strong" if igg_level > 3.0 else "Moderate" print(f" {patient_id}: IgG = {igg_level} ({strength})")
