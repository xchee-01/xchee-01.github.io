🔬 Mission Briefing: Creating and Assigning Values to Variables

Variables in Python are like labeled containers that store information in your computer's memory. Creating a variable involves giving it a name and assigning a value to it using the assignment operator (=).

In precision medicine applications, variables allow you to work with patient data, genetic information, diagnostic values, and treatment parameters. By storing these values in variables, you can track patient health metrics over time, process large genomic datasets, or develop personalized treatment algorithms.

# Creating variables related to patient data patient_id = "PT-2025-0721" patient_age = 45 body_temperature = 37.2 is_diabetic = True hemoglobin_a1c = 5.7 dna_sequence = "ATGCTAGCTAGCTAGT" # Displaying patient information print("Patient ID:", patient_id) print("Age:", patient_age) print("Body Temperature (°C):", body_temperature) print("Diabetic Status:", is_diabetic) print("HbA1c (%):", hemoglobin_a1c) print("Target DNA Sequence:", dna_sequence)

In this example, we've created variables to store different types of medical data: strings for text information, integers and floats for numerical values, and a boolean for a binary status. These variables now hold their respective values in memory, allowing us to access and use this patient data throughout our program.

Real-World Connection: In genomic medicine platforms, researchers create thousands of variables to store DNA sequences, expression levels, and mutation information. For example, the Cancer Genome Atlas (TCGA) uses variables to track genetic mutations across different cancer types, enabling researchers to identify patterns that predict treatment response.

🔬 Mission Briefing: Understanding Variable Naming Conventions

Just as proper labeling is critical in a medical laboratory, following proper naming conventions for variables is essential in Python programming. Good variable names are descriptive and help make your code readable and maintainable—particularly important when developing applications for healthcare where accuracy is paramount.

In Python, variable names must follow these rules:

  • Must start with a letter or underscore (not a number)
  • Can only contain alphanumeric characters and underscores (A-Z, a-z, 0-9, and _)
  • Are case-sensitive (hemoglobin and Hemoglobin are different variables)
  • Cannot be Python reserved words (like print, if, for, etc.)

Beyond these rules, programmers follow conventions to make code more readable:

  • Use lowercase letters with underscores between words (snake_case): patient_age, blood_glucose
  • Choose descriptive names that reflect the data's purpose: tumor_diameter_mm instead of just size
  • Include units in variable names when relevant: weight_kg, temperature_celsius
  • Use meaningful prefixes for related variables: patient_name, patient_id, patient_dob
# Examples of good variable names in precision medicine patient_age = 65 serum_creatinine_mg_dl = 1.2 has_brca1_mutation = True tumor_volume_cm3 = 4.7 dna_methylation_percentage = 35.2 # Examples of poor variable names to avoid p = 65 # Not descriptive scr = 1.2 # Abbreviation is unclear x = True # No indication of what this represents sz = 4.7 # Ambiguous dmp = 35.2 # Cryptic abbreviation

Well-named variables are particularly important in healthcare applications where misinterpreting data could have serious consequences. For example, a variable named glucose_mmol_l clearly indicates the unit of measurement, preventing potentially dangerous misinterpretations.

Real-World Connection: In clinical decision support systems, standardized variable naming conventions allow international teams to collaborate effectively. For example, the SNOMED CT terminology system uses consistent naming patterns for medical concepts across different medical software systems, ensuring that patient data is interpreted correctly regardless of where it's used.

🔬 Mission Briefing: Applying Variable Reassignment

In medicine, patient conditions and measurements change over time—a key feature of Python variables is that their values can also change through reassignment. Once created, variables can be updated to reflect new data, making them perfect for tracking dynamic medical information.

Variable reassignment is performed using the same assignment operator (=), simply assigning a new value to an existing variable. This capability is essential when monitoring a patient's condition over time, simulating biological processes, or updating treatment parameters based on new test results.

# Initial patient vital signs patient_name = "Maria Garcia" body_temperature = 38.5 # Celsius white_blood_cell_count = 12500 # cells/μL is_infection_suspected = True antibiotic_dosage = 0 # mg print("Initial Assessment:") print("Patient:", patient_name) print("Temperature:", body_temperature, "°C") print("WBC count:", white_blood_cell_count, "cells/μL") print("Infection suspected:", is_infection_suspected) print("Current antibiotic dose:", antibiotic_dosage, "mg") # After starting treatment (variable reassignment) body_temperature = 37.3 # Temperature decreased white_blood_cell_count = 9800 # WBC count decreased is_infection_suspected = True # Still monitoring antibiotic_dosage = 500 # Started antibiotics print("\nFollow-up Assessment (Day 2):") print("Patient:", patient_name) print("Temperature:", body_temperature, "°C") print("WBC count:", white_blood_cell_count, "cells/μL") print("Infection suspected:", is_infection_suspected) print("Current antibiotic dose:", antibiotic_dosage, "mg") # Final assessment (further variable reassignment) body_temperature = 36.8 # Normal temperature white_blood_cell_count = 7500 # Normal WBC count is_infection_suspected = False # Resolved antibiotic_dosage = 250 # Reduced dose print("\nFinal Assessment (Day 5):") print("Patient:", patient_name) print("Temperature:", body_temperature, "°C") print("WBC count:", white_blood_cell_count, "cells/μL") print("Infection suspected:", is_infection_suspected) print("Current antibiotic dose:", antibiotic_dosage, "mg")

In this example, we're tracking a patient's recovery from an infection by reassigning values to the same variables over time. This allows us to update the patient's status without creating new variables, keeping our code organized and reflective of the patient's changing condition.

You can also use existing variables in calculations to determine new values:

# Adjusting drug dosage based on patient weight patient_weight_kg = 70 initial_drug_dose_mg = 150 # Recalculate dose after patient weight changes patient_weight_kg = 68.5 # Patient lost weight new_drug_dose_mg = initial_drug_dose_mg * (patient_weight_kg / 70) print("Adjusted dose:", new_drug_dose_mg, "mg") # Further adjustment based on kidney function decline kidney_function_percent = 80 new_drug_dose_mg = new_drug_dose_mg * (kidney_function_percent / 100) print("Kidney-adjusted dose:", new_drug_dose_mg, "mg")

Real-World Connection: Electronic Health Record (EHR) systems use variable reassignment to track patient vitals over time. For example, when monitoring COVID-19 patients, variables like oxygen_saturation and respiratory_rate are continuously updated to guide ventilation decisions and medication adjustments without losing the history of previous measurements.

🔬 Mission Briefing: Recognizing Variable Scope

In a hospital, different departments have different access to patient information based on their roles and responsibilities. Similarly, in Python, the concept of "scope" determines where in your code a variable can be accessed and modified.

Variable scope refers to the region of your program where a variable is visible and can be used. Understanding scope is crucial when working with complex medical applications that involve multiple functions and modules.

Python has two main types of variable scope:

  1. Global scope: Variables defined at the top level of a script or module, accessible throughout the entire program
  2. Local scope: Variables defined within a function, accessible only within that function
# Global variable (accessible throughout the program) hospital_name = "Precision Health Medical Center" def analyze_patient_sample(patient_id, biomarker_value): # Local variables (only accessible inside this function) reference_range_min = 0.5 reference_range_max = 1.8 is_within_range = reference_range_min <= biomarker_value <= reference_range_max # We can access global variables from inside functions print(f"Analysis performed at: {hospital_name}") print(f"Patient ID: {patient_id}") print(f"Biomarker value: {biomarker_value}") print(f"Within reference range: {is_within_range}") return is_within_range # Call the function patient_result = analyze_patient_sample("PT-2025-0892", 1.4) print(f"Result stored in global variable: {patient_result}") # This would cause an error if uncommented because reference_range_min is local to the function # print(f"Reference minimum: {reference_range_min}")

In this example:

  • hospital_name is a global variable accessible throughout the program
  • patient_id, biomarker_value, reference_range_min, reference_range_max, and is_within_range are local variables only accessible within the analyze_patient_sample function
  • Attempting to access local variables outside their function will result in an error

Understanding scope is critical in healthcare applications for several reasons:

  1. Data privacy: Limiting variable scope helps ensure patient data is only accessible where needed
  2. Code organization: Well-defined scope makes it clear which functions have access to which data
  3. Preventing errors: Limiting scope prevents unintended modifications to important variables

Real-World Connection: In clinical decision support systems, variable scope is used to implement hierarchical data access rules. Global variables might store hospital-wide parameters like reference ranges, while local variables in specific functions contain sensitive patient data that should only be accessible during specific analytical procedures.
