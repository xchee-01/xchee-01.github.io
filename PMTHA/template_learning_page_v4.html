Python Syntax Basics for Precision Health

1.1: Introduction to Python

Python is a powerful programming language widely used in medical research, precision health, and bioinformatics. Its clear syntax makes it ideal for beginners while being powerful enough for complex applications like gene sequence analysis and medical image processing.

What Makes Python Special?

  • Readability: Python's syntax is designed to be readable, almost like English.
  • Versatility: Used for data analysis, machine learning, and AI in healthcare.
  • Large Community: Extensive libraries for medical data analysis.

Fun Fact: Python is used by researchers to analyze genomic data in precision medicine, helping to identify genetic markers for personalized treatments. For example, the Cancer Genome Atlas uses Python to process massive datasets of tumor samples!

Let's start with the very basics:

print("Hello, Medical Science!")

This simple line of code displays the text "Hello, Medical Science!" - it's your first Python command!

1.2: Comments in Python

In medical research and clinical applications, clear documentation is crucial. Python comments allow you to include explanatory notes in your code that don't affect its execution.

Single-line Comments

Use the # symbol for comments on a single line:

# This is a comment explaining my medical data analysis print("Analyzing patient data...") # This comment is at the end of a line

Multi-line Comments

For longer explanations, you can use triple quotes:

""" This is a multi-line comment or docstring. This script analyzes blood pressure readings from multiple patient datasets. """ print("Starting blood pressure analysis")

Fun Fact: In medical research, well-documented code is critical for reproducibility. The NIH (National Institutes of Health) has guidelines recommending thorough code documentation for all funded research projects.

1.3: Basic Syntax Rules

Python has specific syntax rules that make it different from other languages. These rules help maintain code consistency and readability.

Key Syntax Rules:

  1. Case Sensitivity: Python is case-sensitive, meaning Gene and gene are different variables.
  2. Line Structure: Each statement typically occupies one line:
    patient_age = 45 patient_gender = "female"
  3. Continuation of Lines: Long lines can be broken using the backslash \ or implied continuations:
    long_dna_sequence = "ATCGATCGATCGATCGATCGATCGATCG" \ "ATCGATCGATCGATCGATCG" # Implied continuations within parentheses, brackets, or braces patient_data = ( "ID12345", "John Smith", "Diabetic" )
  4. Quotation Marks: You can use single ('), double ("), or triple quotes for strings:
    disease = 'Diabetes' patient_name = "Jane Smith" medical_notes = """ Patient shows symptoms of seasonal allergies. Prescribed antihistamine medication. """

Fun Fact: Python's syntax design philosophy is captured in "The Zen of Python" by Tim Peters, which includes principles like "Readability counts" and "Simple is better than complex." These principles align well with precision medicine, where clear, error-free code is essential when processing sensitive health data.

1.4: Code Structure and Indentation

In Python, indentation is not just for readability—it's a fundamental part of the syntax that defines the structure of your code.

Indentation Rules:

  1. Consistent Indentation: Use the same number of spaces for each level of indentation (usually 4 spaces).
  2. Block Definition: Indentation defines code blocks (like in if statements, loops, functions, etc.)
# Example of indentation in a medical diagnosis scenario if blood_pressure > 140: print("Patient has hypertension") recommended_treatment = "Consult cardiologist" if age > 65: print("Senior patient - additional monitoring required") else: print("Blood pressure in normal range") recommended_treatment = "No intervention needed"

Fun Fact: Proper code organization is particularly important in clinical decision support systems where the logic flow must accurately reflect medical decision-making protocols. For example, systems like Epic use well-structured code to implement clinical guidelines for conditions like sepsis detection.

1.5: Statements and Expressions

In Python, understanding the difference between statements and expressions is important for building logical programs.

Statements:

A statement is a complete line of code that performs an action. Examples include:

  • Print statements
  • Assignment statements
# Print statement print("Analyzing blood samples") # Assignment statement glucose_level = 95

Expressions:

An expression is a combination of values, variables, and operators that evaluates to a value.

# Examples of expressions in a medical context bmi = weight / (height ** 2) # Body Mass Index calculation is_hypertensive = blood_pressure > 140/90 # Boolean expression medication_dosage = patient_weight * 0.25 # Dosage calculation based on weight

Fun Fact: In precision medicine, complex expressions are used to calculate risk scores for diseases. For example, the Framingham Risk Score, which predicts cardiovascular disease risk, can be implemented as a Python expression that combines variables like age, blood pressure, and cholesterol levels.

1.6: Naming Conventions

In Python, using clear and consistent naming conventions helps make your code more readable and maintainable, which is especially important in medical and scientific applications.

Naming Rules and Best Practices:

  1. Variable Names:
    • Must start with a letter or underscore
    • Can contain letters, numbers, and underscores
    • Cannot be Python keywords (like if, for, while)
    • Case-sensitive (patient and Patient are different)
  2. Common Conventions:
    • Use snake_case for variables and functions (all lowercase with words separated by underscores)
    • Use CamelCase for class names
    • Use ALL_CAPS for constants
# Variables (snake_case) patient_name = "John Smith" blood_glucose_level = 105.5 # Constants (ALL_CAPS) NORMAL_BODY_TEMPERATURE = 37.0 MAX_HEART_RATE = 220 # Class name (CamelCase) class PatientRecord: pass

3. Descriptive Names: Choose names that clearly describe what the variable represents.

# Poor naming x = 42 # What does x represent? # Better naming age_at_diagnosis = 42

Fun Fact: The Human Genome Project, which sequenced the complete human genome, used consistent naming conventions for genes and genetic markers. For example, BRCA1 (BReast CAncer gene 1) follows naming conventions that help scientists identify its role and function.

1.7: Statement Termination and Line Continuation

Python syntax has distinctive rules for statement termination and continuing long lines of code, which differ from many other programming languages.

Statement Termination:

Unlike languages like C++ or Java, Python statements don't need semicolons:

# No semicolons needed in Python patient_name = "Alice Smith" blood_pressure = 120/80

Multiple statements on one line (not recommended for readability) can be separated by semicolons:

patient_name = "Bob Johnson"; age = 45; blood_type = "O+"

Line Continuation:

Long lines can be broken in several ways:

1. Implicit Line Continuation (within parentheses, brackets, or braces):

# Patient risk factors in a tuple risk_factors = ( "hypertension", "diabetes", "family history of heart disease", "high cholesterol" ) # Lab results in a list lab_results = [ "Blood glucose: 95 mg/dL", "HbA1c: 5.4%", "Total cholesterol: 190 mg/dL" ]

2. Explicit Line Continuation using the backslash (\):

long_medical_description = "The patient presents with symptoms of seasonal " \ "allergic rhinitis, characterized by nasal congestion, " \ "sneezing, and itchy eyes."

Fun Fact: In bioinformatics, researchers often work with extremely long DNA or protein sequences. Python's flexible line continuation rules make it possible to format these sequences in ways that help visualize important patterns or regions, enhancing research in genomic medicine.

1.8: Python Identifiers

In Python, identifiers are names used to identify variables, functions, classes, modules, or other objects. Understanding the rules for identifiers is crucial for writing correct Python code.

Rules for Python Identifiers:

  1. Characters allowed:
    • Letters (a-z, A-Z)
    • Digits (0-9)
    • Underscore (_)
  2. First character:
    • Must be a letter or underscore
    • Cannot start with a digit
  3. Case sensitivity:
    • patient_id and PATIENT_ID are different identifiers
  4. Reserved words:
    • Cannot use Python keywords as identifiers
    • Examples: if, else, for, while, class, return, import
# Valid identifiers in a medical context patient_id = "PT12345" _internal_record = "Confidential" BloodTest = "Complete blood count" vitaminD3_level = 45.2 # Invalid identifiers (would cause errors) # 3rd_visit = "Follow-up" # Cannot start with a digit # patient-name = "John" # Cannot use hyphens # class = "Outpatient" # Cannot use reserved words

Fun Fact: In precision medicine databases, standardized identifiers are crucial for tracking patients and biospecimens across multiple research studies. Large repositories like the UK Biobank assign unique identifiers to millions of samples, allowing researchers to correlate genetic information with health outcomes while maintaining patient privacy.
