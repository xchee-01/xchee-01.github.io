🔬 Part 5: Legends - Decoding Complex Medical Data

Legends are your Rosetta Stone for medical visualizations. When comparing treatments, tracking multiple biomarkers, or showing patient cohorts, legends prevent potentially fatal misinterpretations.

Quick Check
What is the primary purpose of legends in medical visualizations?
To make charts look more colorful
Aesthetic enhancement
Not correct. While legends can add visual elements, their primary purpose is much more critical in medical contexts.
To prevent misinterpretation of treatments and biomarkers
Clear identification of data elements
Correct! In medical settings, misidentifying a treatment line or biomarker could lead to incorrect clinical decisions. Legends are essential safety features.
To fill empty space on the chart
Space utilization
Incorrect. Legends should be positioned strategically for clarity, not just to fill space.
To show the chart creation date
Metadata display
Not right. While timestamps are important in medical records, that's not the legend's purpose.

Creating Multi-Patient Comparisons

Let's simulate a clinical trial comparing two cancer treatments:

# Simulate tumor marker decline over time # ======================================= weeks = np.linspace(0, 12, 50) np.random.seed(42) # For reproducibility # Three patient groups with different treatment responses # ================================================== drug_x = 100 * np.exp(-0.3 * weeks) + 5 * np.random.randn(50) drug_y = 100 * np.exp(-0.2 * weeks) + 5 * np.random.randn(50) placebo = 100 * np.exp(-0.05 * weeks) + 5 * np.random.randn(50) # Create the clinical trial visualization # ======================================= fig, ax = plt.subplots(figsize=(12, 7)) # Plot with meaningful styling # ============================ ax.plot(weeks, drug_x, 'b-', linewidth=2.5, marker='o', markevery=5, label='Drug X (n=50)', alpha=0.8) ax.plot(weeks, drug_y, 'r-', linewidth=2.5, marker='s', markevery=5, label='Drug Y (n=50)', alpha=0.8) ax.plot(weeks, placebo, 'gray', linewidth=2.5, marker='^', markevery=5, label='Placebo (n=50)', linestyle='--', alpha=0.8) # Professional medical chart formatting # ===================================== ax.set_title('Phase II Clinical Trial: Tumor Marker Response\nCA-125 Levels in Ovarian Cancer Patients', fontsize=14, fontweight='bold', pad=20) ax.set_xlabel('Weeks Since Treatment Start', fontsize=12) ax.set_ylabel('CA-125 Level (U/mL)', fontsize=12) # Add clinical significance threshold # =================================== ax.axhline(y=35, color='green', linestyle=':', alpha=0.7, linewidth=2, label='Normal Range (<35 U/mL)') # Configure legend with clinical trial conventions # ================================================ ax.legend(loc='upper right', frameon=True, fancybox=True, shadow=True, title='Treatment Groups', title_fontsize=12) # Add grid and styling # ==================== ax.grid(True, alpha=0.3, linestyle=':') ax.set_xlim(0, 12) ax.set_ylim(0, 110) # Add statistical annotation # ========================== ax.text(8, 60, 'p < 0.001', fontsize=10, bbox=dict(boxstyle="round,pad=0.3", facecolor="yellow", alpha=0.5)) plt.tight_layout() plt.show()

Just the drug names

Look more carefully at the labels. Clinical trials require more information than just drug names.
Drug names and sample sizes (n=50)
Treatment and patient count
Excellent! Including sample sizes (n=50) in legend labels is a clinical trial convention that helps readers assess statistical validity.
Only the colors used

Legend Configuration
Which parameters are used to enhance the legend's professional appearance?
frameon=False, shadow=False
Minimal styling
These settings would make the legend less visible. Professional medical charts need clear, prominent legends.
frameon=True, fancybox=True, shadow=True
Enhanced visual styling
Perfect! These parameters create a polished, professional appearance with a frame, rounded corners (fancybox), and subtle shadow effect.
Only the location parameter
Position only
Location is important, but the styling parameters (frameon, fancybox, shadow) enhance readability and professional appearance.
alpha=0.5, edgecolor='black'

Making the legend transparent would reduce readability. The code uses frameon, fancybox, and shadow instead.

🧪 Advanced Exercise 3: Multi-Biomarker COVID Recovery

Scenario: You're tracking inflammatory markers in recovering COVID-19 patients. Different biomarkers have vastly different scales, requiring special visualization techniques.

# Patient recovery data over 14 days # ================================== days = np.arange(0, 14) crp = [45, 42, 38, 35, 30, 25, 20, 18, 15, 12, 10, 8, 7, 6] # mg/L il6 = [80, 75, 68, 60, 50, 40, 32, 25, 20, 15, 12, 10, 8, 7] # pg/mL ferritin = [800, 750, 680, 600, 500, 420, 350, 300, 250, 200, 180, 160, 150, 140] # ng/mL # Create figure with dual y-axes (different scales) # ================================================= fig, ax1 = plt.subplots(figsize=(12, 7)) # TODO: Complete this visualization # ================================= # 1. Add appropriate labels and legends # ===================================== # 4. Include normal range indicators # ================================== # 5. Style for clinical presentation # ================================== # Hint: Use ax2 = ax1.twinx() for secondary axis # ==============================================

Answer:

# Create the figure # ================= fig, ax1 = plt.subplots(figsize=(12, 7)) # Plot CRP and IL-6 on primary axis # ================================= color1 = 'tab:red' ax1.plot(days, crp, color=color1, marker='o', linewidth=2.5, label='CRP (C-Reactive Protein)', markersize=8) ax1.plot(days, il6, 'tab:blue', marker='s', linewidth=2.5, label='IL-6 (Interleukin-6)', markersize=8) # Configure primary axis # ====================== ax1.set_xlabel('Days Since ICU Admission', fontsize=12, fontweight='bold') ax1.set_ylabel('CRP (mg/L) & IL-6 (pg/mL)', fontsize=12) ax1.tick_params(axis='y') # Add normal ranges for primary axis markers # ========================================== ax1.axhline(y=5, color='green', linestyle=':', alpha=0.5, linewidth=1.5) ax1.text(12, 6, 'CRP Normal', fontsize=9, color='green') # Create secondary axis for ferritin # ================================== ax2 = ax1.twinx() color2 = 'tab:green' ax2.plot(days, ferritin, color=color2, marker='^', linewidth=2.5, label='Ferritin', markersize=8, linestyle='-.') ax2.set_ylabel('Ferritin (ng/mL)', fontsize=12, color=color2) ax2.tick_params(axis='y', labelcolor=color2) # Add title # ========= fig.suptitle('COVID-19 Inflammatory Markers Recovery Profile\nPatient ID: CV-2847', fontsize=14, fontweight='bold') # Create combined legend # ====================== lines1, labels1 = ax1.get_legend_handles_labels() lines2, labels2 = ax2.get_legend_handles_labels() ax1.legend(lines1 + lines2, labels1 + labels2, loc='upper right', frameon=True, fancybox=True, shadow=True, title='Biomarkers', title_fontsize=11) # Add grid # ======== ax1.grid(True, alpha=0.3, linestyle=':') # Add recovery phases # =================== ax1.axvspan(0, 5, alpha=0.1, color='red', label='Acute Phase') ax1.axvspan(5, 10, alpha=0.1, color='yellow', label='Recovery Phase') ax1.axvspan(10, 14, alpha=0.1, color='green', label='Resolution Phase') # Styling # ======= fig.tight_layout() plt.show()
Copied!

Fantastic! This complex visualization shows how inflammatory markers decrease during COVID recovery. The dual axes handle the different scales elegantly, and the phase shading helps clinicians assess recovery stage.

Combined Legend Creation
How do you create a single legend for plots on different axes?
You can't - each axis needs its own legend
Separate legends required
Actually, you can combine legends! There's a specific technique for this.
Use get_legend_handles_labels() from both axes and combine them
Extract and merge legend data
Perfect! By extracting handles and labels from both axes and combining them, you create a unified legend that shows all data series together.
Only show the legend for the primary axis
Ignore secondary axis data
This would leave the secondary axis data unlabeled, creating confusion about what the lines represent.
Create a text box instead of a legend
Manual text annotation
Text boxes don't show the line styles and colors. A proper legend is more effective.

Legend Positioning
Which legend position is recommended for charts showing declining trends?
'lower left'
Bottom left corner
This position might overlap with the declining data lines as they approach the lower part of the chart.
'upper right'
Top right corner
Correct! For declining trends, the upper right keeps the legend away from the data lines, which typically trend downward and to the right.
'center'
Center of the plot
Center positioning almost always overlaps with data, making both the legend and data hard to read.
'bottom'
Below the plot area
'bottom' isn't a valid legend location parameter. You might be thinking of placing it outside the plot area.

🧪 Capstone Project: Multi-Patient ICU Monitor

Create a comprehensive vital signs dashboard showing:

  1. Heart rate trends
  2. Blood pressure
  3. Oxygen saturation
  4. Temperature
# Generate realistic patient data # =============================== hours = np.arange(0, 24, 0.5) # 30-minute intervals np.random.seed(42) # Patient vitals with realistic variations # ======================================== heart_rate = 75 + 10*np.sin(hours/4) + 5*np.random.randn(len(hours)) bp_systolic = 120 + 8*np.sin(hours/6) + 4*np.random.randn(len(hours)) bp_diastolic = 80 + 5*np.sin(hours/6) + 3*np.random.randn(len(hours)) spo2 = 97 + 2*np.sin(hours/8) + np.random.randn(len(hours)) temperature = 36.8 + 0.3*np.sin(hours/4) + 0.1*np.random.randn(len(hours)) # Create the dashboard # ==================== fig = plt.figure(figsize=(15, 10)) fig.suptitle('ICU Patient Monitor - Bed 12 - John Doe (ID: 4782)\nPost-Cardiac Surgery - Day 2', fontsize=16, fontweight='bold') # Heart Rate # ========== ax1 = plt.subplot(2, 2, 1) ax1.plot(hours, heart_rate, 'r-', linewidth=2, label='HR') ax1.axhspan(60, 100, alpha=0.2, color='green', label='Normal Range') ax1.set_title('Heart Rate', fontsize=12, fontweight='bold') ax1.set_ylabel('BPM') ax1.set_ylim(50, 110) ax1.grid(True, alpha=0.3) ax1.legend(loc='upper right') # Blood Pressure # ============== ax2 = plt.subplot(2, 2, 2) ax2.plot(hours, bp_systolic, 'r-', linewidth=2, label='Systolic') ax2.plot(hours, bp_diastolic, 'b-', linewidth=2, label='Diastolic') ax2.axhspan(90, 140, alpha=0.1, color='green') ax2.axhspan(60, 90, alpha=0.1, color='green') ax2.set_title('Blood Pressure', fontsize=12, fontweight='bold') ax2.set_ylabel('mmHg') ax2.set_ylim(50, 150) ax2.grid(True, alpha=0.3) ax2.legend(loc='upper right') # Oxygen Saturation # ================= ax3 = plt.subplot(2, 2, 3) ax3.plot(hours, spo2, 'b-', linewidth=2, label='SpO2') ax3.axhspan(95, 100, alpha=0.2, color='green', label='Normal') ax3.axhline(y=90, color='red', linestyle='--', alpha=0.7, label='Critical') ax3.set_title('Oxygen Saturation', fontsize=12, fontweight='bold') ax3.set_xlabel('Hours') ax3.set_ylabel('SpO2 %') ax3.set_ylim(85, 102) ax3.grid(True, alpha=0.3) ax3.legend(loc='lower right') # Temperature # =========== ax4 = plt.subplot(2, 2, 4) ax4.plot(hours, temperature, 'orange', linewidth=2, label='Temp') ax4.axhspan(36.5, 37.5, alpha=0.2, color='green', label='Normal') ax4.axhline(y=38, color='red', linestyle='--', alpha=0.7, label='Fever') ax4.set_title('Body Temperature', fontsize=12, fontweight='bold') ax4.set_xlabel('Hours') ax4.set_ylabel('°C') ax4.set_ylim(35.5, 39) ax4.grid(True, alpha=0.3) ax4.legend(loc='upper right') # Adjust layout # ============= plt.tight_layout() # Add alert box # ============= fig.text(0.5, 0.02, '⚠️ ALERT: Mild tachycardia noted at 14:00 - Continue monitoring', ha='center', fontsize=12, bbox=dict(boxstyle="round,pad=0.5", facecolor="yellow", alpha=0.7)) plt.show()
Copied!
Dashboard Layout
What function is used to create multiple plots in a grid layout?
plt.plot(2, 2, 1)
Plot function with grid parameters
plt.plot() is for creating line plots, not for arranging multiple plots in a grid.
plt.subplot(2, 2, 1)
Subplot function with rows, columns, index
Correct! plt.subplot(rows, cols, index) creates a grid of subplots. The (2, 2, 1) means 2 rows, 2 columns, and select the 1st subplot.
plt.grid(2, 2, 1)
Grid function for layout
plt.grid() adds gridlines to a plot, not for creating subplot layouts.
plt.axes(2, 2, 1)
Axes function with positioning
plt.axes() creates a single axes object, not a grid of subplots.
Vital Signs Knowledge
Which vital sign has a critical threshold set at 90 in the dashboard?
Heart Rate (BPM)
Beats per minute
Heart rate normal range is shown as 60-100 BPM. Look for the red dashed line at y=90.
Systolic Blood Pressure (mmHg)
Upper blood pressure reading
Blood pressure shows normal ranges (90-140 systolic, 60-90 diastolic) but no critical threshold line.
Oxygen Saturation (SpO2 %)
Blood oxygen level
Correct! SpO2 below 90% is critically low and requires immediate medical attention. The red dashed line marks this dangerous threshold.
Body Temperature (°C)
Core body temperature
Temperature shows a fever threshold at 38°C, not 90. The critical line for SpO2 is at 90%.
Visual Medical Indicators
What method is used to show normal ranges in the vital signs charts?
ax.plot() with different colors
Line plots with color coding
ax.plot() draws lines for the data values, not shaded regions for normal ranges.
ax.axhspan() with transparent coloring
Horizontal span with alpha transparency
Perfect! ax.axhspan() creates horizontal shaded regions. The alpha parameter makes them semi-transparent so the data lines remain visible.
ax.scatter() with markers
Scatter plot markers
Scatter plots show individual points, not continuous ranges. We need shaded regions for normal ranges.
ax.bar() with heights
Bar charts for ranges
Bar charts are for discrete categories, not continuous ranges over time.

🎯 Summary & Key Takeaways

🏆 Chart Component Mastery Checklist

You've learned to create medical visualizations using:

✅ Figures - The master container holding all visual elements

  • Set appropriate sizes for medical contexts (10×6 to 12×8)
  • Add clear, descriptive titles with patient/study identifiers

✅ Axes - The coordinate systems where data lives

  • Configure for specific medical measurements
  • Use multiple axes for different scales
  • Add reference ranges and safety zones

✅ Labels & Titles - The critical context

  • Always include units of measurement
  • Specify time references clearly
  • Follow medical naming conventions

✅ Legends - The interpretation guide

  • Position for optimal readability
  • Include sample sizes (n=X) for research
  • Group related items logically
Medical Figure Sizing
What are the recommended figure sizes for medical contexts?
5×5 to 6×6
Small square figures
Too small for medical data. Complex medical visualizations need more space for clarity and detail.
10×6 to 12×8
Large rectangular figures
Correct! These sizes provide enough space for clear labels, multiple data series, legends, and annotations without crowding.
20×20 to 30×30
Extra large figures
Too large! These would be difficult to display on screens or print in journals.
3×3 to 4×4
Tiny compact figures
Way too small for medical data. Text would be illegible and important details lost.
