Linux Pipes and Command Chaining

Welcome to the magical world of Linux command orchestration! 🎭 Think of yourself as a conductor leading an orchestra of commands, where each instrument (command) plays its part perfectly, passing its melody (output) to the next player.

Fun Fact: The pipe operator was invented by Douglas McIlroy at Bell Labs in 1973. He described it as making Unix commands "talk to each other"!

🖥️ The Pipe (|) Operator - Your Command Connector

What Is a Pipe?

Imagine you're at a sushi conveyor belt restaurant 🍣. Each chef (command) prepares their specialty and places it on the belt (pipe) for the next chef to work with.

Definition Box 📦
The pipe operator (|) takes the output from one command and feeds it as input to the next command.

🔍 Your First Pipe Adventure

Let's count files in your directory:

# List all files $ ls file1.txt file2.txt file3.txt document.pdf script.sh # Count them with a pipe! $ ls | wc -l 5
Copied!

What just happened? 🤔

  • ls listed all files
  • The pipe | grabbed that output
  • wc -l counted the lines
  • Result: 5 files!

Quick Practice

Try This Command

3

That would be wc -c (characters). The -w flag counts words.

🔧 Lab Exercise 1: Your First Pipeline Mission

Mission Brief
Check how many users are logged into the system.
# See who's logged in $ who alice tty1 2024-01-15 09:00 bob pts/0 2024-01-15 09:30 alice pts/1 2024-01-15 10:00 # Count unique users $ who | cut -d' ' -f1 | sort | uniq | wc -l
What's the result?
2
Two unique users: alice and bob
🎉 Achievement Unlocked: Pipeline Apprentice! You correctly identified the unique users.
3
Three login sessions
That's the total sessions. The pipeline finds unique users by removing duplicates.
1
Only one user
Look again - alice and bob are two different users.

Copied!

Finding Memory Hogs

# Find top 5 memory-consuming processes $ ps aux | sort -k4 -rn | head -5
Copied!

Breaking it down:

  1. ps aux - Shows all processes
  2. sort -k4 -rn - Sort by %MEM column
  3. head -5 - Show only top 5

🔧 Lab Exercise 2: System Resource Detective

Mission 🕵️
Find top 5 CPU-consuming processes. Which command pipeline would you use?
# Complete this pipeline ps aux | sort -k? -rn | head -5
sort -k3 -rn
Column 3 contains %CPU
Excellent detective work! Column 3 in ps aux output shows CPU percentage.
sort -k4 -rn
Column 4 for CPU
That's for memory (%MEM). CPU percentage is in column 3.
sort -k1 -rn
Column 1 for processes
Column 1 shows the username. CPU percentage is in column 3.

🖥️ grep - Your Text Search Superhero

🦸‍♂️ Meet grep

grep finds patterns in text like having super-vision!

# Find errors $ cat system.log | grep ERROR # Case-insensitive search $ journalctl | grep -i error # Show Python processes $ ps aux | grep python | grep -v grep
Copied!

🔍 grep Options

Option What it Does
-i Ignore case
-v Exclude matches
-n Show line numbers
-c Count matches

Note: The Linux commands shown in this lesson should be run in a Linux terminal, not in a Python interpreter. You can try them on your own Linux system or using a tool like WSL (Windows Subsystem for Linux) on Windows.
