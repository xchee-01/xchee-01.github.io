🎭 The Conditional Expression (Ternary Operator)

Time to level up! You can use conditional expressions INSIDE comprehensions for sophisticated data transformations:

# Basic syntax # ============ [value_if_true if condition else value_if_false for item in sequence]
Copied!

This is like having a smart assistant that not only filters but also makes decisions!

Quick Check
What is the correct syntax for a ternary operator in a list comprehension?
[for item in sequence if condition else value]
This syntax pattern with the for loop first.
Not quite right. This syntax is incorrect - the expression must come before the for clause.
[value_if_true if condition else value_if_false for item in sequence]
This syntax with ternary operator before the for clause.
Correct! The ternary operator syntax is `value_if_true if condition else value_if_false`, placed before the `for` clause.
[if condition then value_if_true else value_if_false for item in sequence]
This syntax using 'then' keyword.
That's not correct. Python doesn't use the 'then' keyword - it uses the pattern 'value_if_true if condition else value_if_false'.
[item for item in sequence if condition else value]
This syntax with if-else after the for clause.
That's not right. You cannot use 'else' with a filter condition that comes after the for clause.

🏥 Clinical Risk Categorization

# Simple risk categories for cholesterol # ====================================== cholesterol_levels = [180, 220, 195, 260, 170, 240, 200] risk_categories = ["✅ Low" if chol < 200 else "⚠️ High" for chol in cholesterol_levels] print(f"Risk profile: {risk_categories}") # Output: Risk profile: ['✅ Low', '⚠️ High', '✅ Low', '⚠️ High', '✅ Low', '⚠️ High', '⚠️ High'] # ================================================== # More sophisticated multi-level categorization # ============================================= patient_cholesterol = [ ("Alice", 180), ("Bob", 245), ("Carol", 195), ("David", 270), ("Eve", 165) ] # Create detailed risk reports with emojis for quick visual scanning # ================================================== risk_reports = [ f"{name}: {chol} mg/dL - " + ("💚 Optimal" if chol < 170 else "💛 Borderline" if chol < 200 else "🧡 High" if chol < 240 else "❤️ VERY HIGH - Immediate consultation needed!") for name, chol in patient_cholesterol ] for report in risk_reports: print(report)
Copied!
Clinical Application
Given the cholesterol categorization code above, what will be the output for a patient with cholesterol level 195 mg/dL?
💚 Optimal
The patient has optimal cholesterol levels.
Not quite. Optimal is for cholesterol < 170, and 195 is higher than that.
💛 Borderline
The patient has borderline cholesterol levels.
Correct! With cholesterol 195, the condition `chol < 170` is False, but `chol < 200` is True, so it returns "💛 Borderline".
🧡 High
The patient has high cholesterol levels.
That's not correct. High is for cholesterol between 200 and 240, but 195 is less than 200.
❤️ VERY HIGH - Immediate consultation needed!
The patient needs immediate medical attention.
That's not right. VERY HIGH is for cholesterol ≥ 240, and 195 is well below that threshold.

🧬 Nested Comprehensions (Use Sparingly!)

Sometimes you need to process 2D data like genetic sequences:

# Genetic codon table (simplified) # ================================ dna_sequences = [ ['ATG', 'CCA', 'TAG'], ['GGC', 'TAA', 'CCG'], ['AAA', 'TGA', 'GCT'] ] # Find all stop codons (TAG, TAA, TGA) with their positions # ================================================== stop_codons = [(row_idx, col_idx, codon) for row_idx, row in enumerate(dna_sequences) for col_idx, codon in enumerate(row) if codon in ['TAG', 'TAA', 'TGA']] print("Stop codons found at positions:", stop_codons) # Output: Stop codons found at positions: [(0, 2, 'TAG'), (1, 1, 'TAA'), (2, 1, 'TGA')] # ==================================================
Copied!
Code Analysis
In the nested comprehension above, what is the order of the for loops?
Inner loop (columns) executes first, then outer loop (rows)
The column iteration happens before row iteration.
Not quite. This would be the reverse of how nested comprehensions work in Python.
Outer loop (rows) executes first, then inner loop (columns) for each row
The row iteration happens first, then columns within each row.
Correct! In nested comprehensions, the order matches nested for loops - the first for clause is the outer loop, the second is the inner loop.
Both loops execute simultaneously
The loops run in parallel at the same time.
That's not correct. Python executes loops sequentially, not simultaneously.
The order doesn't matter for the result
Loop order has no impact on the final output.
That's not right. The order of loops determines how the data is traversed and would affect the order of results.

⚠️ Warning: Nested comprehensions can hurt readability. If it takes more than 5 seconds to understand, use regular loops!

[weight * 0.5 for weight in weights_kg if weight * 0.5 <= 40]

[min(weight * 0.5, 40) for weight in weights_kg]

Pattern Recognition
Which comprehension pattern would you use to extract only high-risk patients (cholesterol > 240) and format their names with a warning?
[name for name, chol in patients if chol > 240]
Extract names only.
Close, but this only extracts names without the warning formatting.
[f"⚠️ {name}: HIGH RISK" for name, chol in patients if chol > 240]
Filter and format with warning.
Correct! This combines filtering (if chol > 240) with transformation (formatting with warning), which is exactly what's needed.
[name if chol > 240 else None for name, chol in patients]
Conditional extraction.
This would include None values for low-risk patients, which isn't what we want.
[(name, chol) for name, chol in patients where chol > 240]
SQL-like syntax.
That's not valid Python syntax - Python uses 'if' not 'where' for filtering.
