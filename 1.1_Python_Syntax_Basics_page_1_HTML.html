Mission Briefing: Writing and Executing Simple Python Statements

Think of Python statements as giving clear instructions to your digital medical assistant. Just like how a doctor writes precise prescriptions, you'll write precise Python commands. The beauty? Python reads almost like English, making it perfect for healthcare professionals transitioning into programming!

🧪 What Are Python Statements?

A statement is a single instruction that Python executes - imagine it as one step in a clinical protocol. Each statement performs one specific action, whether it's displaying patient information, calculating drug dosages, or analyzing genomic sequences.

# Your first medical Python statement - displaying patient information print("Patient admitted to Precision Medicine Unit")
Copied!

🏥 Medical Connection: In real hospitals, similar print statements display critical alerts on nursing station monitors!

📋 Multiple Statements: Building Your First Clinical Protocol

# Multiple statements work together like steps in a clinical protocol print("Starting patient analysis...") print("Loading genomic data...") print("Analysis complete!")
Copied!

When you run these statements, Python executes them sequentially, from top to bottom - exactly like following a step-by-step medical procedure!

💡 Pro Tip: The print() function is your window into what your program is doing - like a heart monitor showing real-time patient status!

Mission Briefing: Identifying and Using Integers, Floats, and Strings

In the medical world, precision matters! Just as you wouldn't confuse milligrams with milliliters, Python distinguishes between different types of data. Let's explore the three fundamental data types you'll use every day in medical programming.

📊 The Medical Data Trinity

Data Type Medical Use Case Example
Integer Patient count, age, pill quantity patients = 150
Float Temperature, dosage, lab values temp = 98.6
String Names, diagnoses, DNA sequences diagnosis = "Diabetes"

🔢 Integers: Counting What Matters

# Integer: Counting patients in a clinical trial patients_enrolled = 150 days_in_study = 90 medications_prescribed = 3 print("Study details:", patients_enrolled, "patients,", days_in_study, "days")
Copied!

🧬 Did You Know? The human genome has approximately 3,000,000,000 base pairs - that's an integer so large Python handles it effortlessly!

🌡️ Floats: Precision in Measurement

# Float: Recording precise medical measurements body_temperature = 98.6 blood_glucose = 126.5 # mg/dL drug_dose = 2.5 # mg print("Patient vitals - Temp:", body_temperature, "°F, Glucose:", blood_glucose, "mg/dL")
Copied!

📝 Strings: Capturing Medical Information

# String: Storing patient and medical information patient_name = "Sarah Johnson" diagnosis = "Type 2 Diabetes Mellitus" dna_sequence = "ATCGATCG" # A tiny snippet! print("Patient:", patient_name, "- Diagnosis:", diagnosis)
Copied!

🎯 Practice Time: Patient Data Entry System

Your Mission: Fix the code to properly represent each data type.

Lab Exercise: Patient Medical Record
To properly create a patient medical record, which of the following correctly represents all data types?
# Lab scenario: Creating a patient medical record patient_age = ? # Should be an integer cholesterol_level = ? # Should be a float with decimal patient_name = ? # Should be a string
Option A
patient_age = "65"
cholesterol_level = 200
patient_name = Sarah Johnson
Not quite. Age is in quotes (making it a string), cholesterol lacks decimal precision, and the name needs quotes.
Option B
patient_age = 65
cholesterol_level = 200.0
patient_name = "Sarah Johnson"
🌟 Outstanding! You're now handling medical data like a professional health informaticist! Integer for age, float for precise measurement, and string with quotes for text.
Option C
patient_age = 65.0
cholesterol_level = "200.0"
patient_name = "Sarah Johnson"
Close, but age should be an integer (whole number), and cholesterol should be a float, not a string.
Option D
patient_age = 65
cholesterol_level = 200.0
patient_name = 'Sarah Johnson'
Almost perfect! While single quotes work for strings in Python, we're using double quotes as our standard in medical programming for consistency.

Complete Solution

Solution with Output:

# Complete solution for patient medical record patient_age = 65 # Integer for whole years cholesterol_level = 200.0 # Float for precise measurement patient_name = "Sarah Johnson" # String with quotes for text print("Patient:", patient_name, ", Age:", patient_age, ", Cholesterol:", cholesterol_level, "mg/dL")
Copied!

Expected output:

Patient: Sarah Johnson, Age: 65, Cholesterol: 200.0 mg/dL
