Module 1.1: Python Syntax Basics

🧬 Python Syntax Basics for Precision Health Programming 🧬

🎯 Welcome to your journey as a Precision Health Programmer! In this module, you'll learn the fundamental building blocks of Python programming - the essential syntax that forms the foundation of all biomedical computing. Just as DNA has its own syntax of nucleotides (A, T, G, C), Python has its own syntax that we'll use to analyze patient data, process genomic sequences, and build medical diagnostic tools.

Fun Fact: Did you know that Python is named after Monty Python's Flying Circus, not the snake? The creator wanted programming to be fun - just like we're about to make medical programming enjoyable!

Think of Python statements as giving clear instructions to your digital medical assistant. Just like how a doctor writes precise prescriptions, you'll write precise Python commands. The beauty? Python reads almost like English, making it perfect for healthcare professionals transitioning into programming!

🧪 What Are Python Statements?

A statement is a single instruction that Python executes - imagine it as one step in a clinical protocol. Each statement performs one specific action, whether it's displaying patient information, calculating drug dosages, or analyzing genomic sequences.

Your first medical Python statement - displaying patient information 
print("Patient admitted to Precision Medicine Unit")

Medical Connection: In real hospitals, similar print statements display critical alerts on nursing station monitors!

📋 Multiple Statements: Building Your First Clinical Protocol

Multiple statements work together like steps in a clinical protocol 
print("Starting patient analysis...")
print("Loading genomic data...")
print("Analysis complete!")

When you run these statements, Python executes them sequentially, from top to bottom - exactly like following a step-by-step medical procedure!

Pro Tip: The print() function is your window into what your program is doing - like a heart monitor showing real-time patient status!

In the medical world, precision matters! Just as you wouldn't confuse milligrams with milliliters, Python distinguishes between different types of data. Let's explore the three fundamental data types you'll use every day in medical programming.

📊 The Medical Data Trinity

Data Type Medical Use Case Example
Integer Patient count, age, pill quantity patients = 150
Float Temperature, dosage, lab values temp = 98.6
String Names, diagnoses, DNA sequences diagnosis = "Diabetes"

🔢 Integers: Counting What Matters

Integer: Counting patients in a clinical trial 
patients_enrolled = 150
days_in_study = 90
medications_prescribed = 3
print("Study details:", patients_enrolled, "patients,", days_in_study, "days")

Did You Know? The human genome has approximately 3,000,000,000 base pairs - that's an integer so large Python handles it effortlessly!

🌡️ Floats: Precision in Measurement

Float: Recording precise medical measurements 
body_temperature = 98.6
blood_glucose = 126.5  # mg/dL
drug_dose = 2.5       # mg
print("Patient vitals - Temp:", body_temperature, "°F, Glucose:", blood_glucose, "mg/dL")

📝 Strings: Capturing Medical Information

String: Storing patient and medical information 
patient_name = "Sarah Johnson"
diagnosis = "Type 2 Diabetes Mellitus"
dna_sequence = "ATCGATCG"  # A tiny snippet!
print("Patient:", patient_name, "- Diagnosis:", diagnosis)

🔄 Combining Data Types in Real Medical Scenarios

Real-world medical reporting 
patient_id = 12345                    # Integer
glucose_level = 126.5                 # Float  
condition = "Hyperglycemia"           # String
alert_status = "⚠️ ELEVATED"         # String with emoji!

print("Patient", patient_id, "has glucose:", glucose_level, "mg/dL", alert_status, condition)

Real-World Application: Electronic Health Records (EHRs) like Epic and Cerner use these exact data types millions of times per second across hospitals worldwide!
