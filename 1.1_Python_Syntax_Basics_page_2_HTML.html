🔬 Mission Briefing: Understanding Boolean Values and Basic Operations

Welcome to the world of medical decision-making! In healthcare, many decisions are binary: Is the test positive? Is the patient eligible? Should we proceed with treatment? Python's Boolean values (True and False) are perfect for representing these yes/no medical decisions.

🎭 The Two Faces of Medical Logic

# Boolean values in medical testing
# =================================
covid_test_positive = True
antibodies_detected = False
symptoms_present = True

print("COVID-19 test result:", covid_test_positive)
print("Antibodies detected:", antibodies_detected)
Remember: Boolean values MUST be capitalized as True or False - Python is as precise as a surgical procedure!

🔗 Boolean Operations: Making Medical Decisions

The AND Operation: All Conditions Must Be Met
# Patient must meet ALL criteria for treatment
# ============================================
has_diabetes = True
has_insurance = True
eligible_for_program = has_diabetes and has_insurance
print("Eligible for diabetes management program:", eligible_for_program)
The OR Operation: Any Condition Triggers Action
# High risk if ANY risk factor is present
# =======================================
age_over_65 = True
has_chronic_condition = False
immunocompromised = False
high_risk_patient = age_over_65 or has_chronic_condition or immunocompromised
print("High risk patient:", high_risk_patient)
The NOT Operation: Reversing Results
# Checking contraindications
# ==========================
allergic_to_penicillin = True
can_take_penicillin = not allergic_to_penicillin
print("Can prescribe penicillin:", can_take_penicillin)

🏥 Complex Medical Decision Trees

# Emergency room triage decision
# ==============================
severe_pain = True
difficulty_breathing = False
high_fever = True

# Immediate attention if severe pain AND (breathing issues OR high fever)
# ==================================================
needs_immediate_care = severe_pain and (difficulty_breathing or high_fever)
print("Requires immediate attention:", needs_immediate_care)
Real-World Impact: Triage algorithms in emergency departments use exactly this type of Boolean logic to prioritize patient care and save lives!

🔬 Mission Briefing: Converting Between Different Data Types

In the medical field, data comes from everywhere - patient forms, lab machines, wearable devices - and it's not always in the format we need. That's where type conversion becomes your superpower! Let's learn to transform data safely and accurately.

🔄 Why Type Conversion Matters in Medicine

Imagine a glucose meter sends the reading "145.7" as text, but you need to calculate if it's above the danger threshold of 140. Without type conversion, you're stuck! Python provides elegant tools to transform between data types.

🎯 Essential Conversion Functions

Function Purpose Medical Example
int() Convert to integer Age from form input
float() Convert to decimal Lab values from devices
str() Convert to text Display formatting
bool() Convert to True/False Test result interpretation

📥 String to Number Conversions

# Converting patient input for calculations
# =========================================
age_input = "72"                      # From patient form
patient_age = int(age_input)          # Convert to integer
years_until_80 = 80 - patient_age
print("Years until age 80:", years_until_80)

# Converting lab results for analysis
# ===================================
glucose_text = "145.7"                # From glucose meter
glucose_value = float(glucose_text)   # Convert to float
is_diabetic = glucose_value > 126
print("Glucose:", glucose_value, "mg/dL - Diabetic range:", is_diabetic)

📤 Number to String Conversions

# Creating formatted medical reports
# ==================================
temperature = 101.3
pulse = 88
report = "Vital Signs: Temp " + str(temperature) + "°F, Pulse " + str(pulse) + " bpm"
print(report)

# Better approach using f-strings (sneak peek!)
# =============================================
report_modern = f"Vital Signs: Temp {temperature}°F, Pulse {pulse} bpm"
print(report_modern)

🧮 Advanced Medical Calculations

# BMI Calculator with type conversions
# ====================================
height_cm_input = "175"               # From patient form
weight_kg_input = "82.5"              # From scale

# Convert to numbers
# ==================
height_m = float(height_cm_input) / 100  # Convert cm to meters
weight_kg = float(weight_kg_input)

# Calculate BMI
# =============
bmi = weight_kg / (height_m ** 2)
bmi_category = "Normal" if 18.5 <= bmi < 25 else "Check with physician"

print(f"BMI: {round(bmi, 1)} - Category: {bmi_category}")

⚠️ Safe Conversion Practices

# What happens with invalid conversions?
# ======================================
try:
    # This will cause an error
    invalid_age = int("sixty-five")
except ValueError:
    print("Error: Please enter age as a number!")
    
# Safe conversion with validation
# ===============================
user_input = "125.5"
if user_input.replace(".", "").isdigit():
    safe_value = float(user_input)
    print("Valid input:", safe_value)
else:
    print("Invalid input - please enter numbers only")
Safety First: In medical applications, always validate data before conversion. A conversion error could mean the difference between mg and g in a dosage!
