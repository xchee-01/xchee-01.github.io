Quiz 1: Python Numeric Types

Beginner
1. What is the result of the expression 5 / 2 in Python 3?
  • A) 2
  • B) 2.0
  • C) 2.5
  • D) 3
Correct Answer: C) 2.5
In Python 3, the division operator / performs "true division" and always returns a float, even when dividing two integers. If you want integer division (truncating toward zero), you can use the floor division operator //.
2. Which of the following is NOT a valid numeric type in Python?
  • A) int
  • B) float
  • C) complex
  • D) char
Correct Answer: D) char
Python doesn't have a separate character type like C or Java. In Python, characters are represented as strings of length 1. The built-in numeric types in Python are int, float, and complex.
3. What is the output of the following code?
x = 1.0 y = 1 print(x == y)
  • A) True
  • B) False
  • C) 1.0
  • D) Error
Correct Answer: A) True
Python compares the values, not the types, when using the equality operator ==. Since 1.0 and 1 represent the same value, the equality test returns True. If you want to check for both value and type equality, you would use the is operator or isinstance() function.

Quiz 2: Numeric Operations

Beginner
1. What is the result of 17 % 5 in Python?
  • A) 3
  • B) 2
  • C) 3.4
  • D) 0
Correct Answer: B) 2
The modulo operator % returns the remainder of the division. When 17 is divided by 5, the quotient is 3 with a remainder of 2. So, 17 % 5 equals 2.
2. What does the ** operator do in Python?
  • A) Multiplication
  • B) Exponentiation
  • C) Double negation
  • D) Bitwise XOR
Correct Answer: B) Exponentiation
The ** operator raises a number to a power. For example, 2 ** 3 equals 8 (2 raised to the power of 3).
3. What is the output of the following code?
print(15 // 4)
  • A) 3
  • B) 3.0
  • C) 3.75
  • D) 4
Correct Answer: A) 3
The floor division operator // performs integer division, discarding any fractional result. 15 divided by 4 is 3.75, but floor division gives 3.

Quiz 3: NumPy Fundamentals

Intermediate
1. Which NumPy function would you use to create an array of evenly spaced values between a start and end point?
  • A) np.array()
  • B) np.arange()
  • C) np.linspace()
  • D) np.zeros()
Correct Answer: C) np.linspace()
np.linspace(start, stop, num) creates an array of num evenly spaced values from start to stop, inclusive. This is different from np.arange(), which generates values with a fixed step size rather than a fixed number of points.
2. What is the shape of the array resulting from the following code?
import numpy as np a = np.array([[1, 2, 3], [4, 5, 6]])
  • A) (2, 3)
  • B) (3, 2)
  • C) (1, 6)
  • D) (6, 1)
Correct Answer: A) (2, 3)
The array has 2 rows and 3 columns, so its shape is (2, 3). The first dimension represents the number of rows, and the second dimension represents the number of columns.
3. What does the following code do?
import numpy as np a = np.arange(10) b = a[::2] print(b)
  • A) Creates a copy of 'a'
  • B) Extracts all even-indexed elements from 'a'
  • C) Returns the first two elements of 'a'
  • D) Reshapes 'a' into a 2D array
Correct Answer: B) Extracts all even-indexed elements from 'a'
The slice notation [::2] means "start at the beginning, go to the end, with a step of 2". This selects every other element starting from index 0, so the output would be [0, 2, 4, 6, 8]. These are the elements at even indices (0, 2, 4, 6, 8) in the original array.

Quiz 4: Floating-Point Precision

Intermediate
1. What is the output of the following code?
print(0.1 + 0.2 == 0.3)
  • A) True
  • B) False
  • C) 0.3
  • D) Error
Correct Answer: B) False
Due to the way floating-point numbers are represented in binary, many decimal fractions cannot be represented exactly. The sum of 0.1 and 0.2 is actually stored as a value very close to, but not exactly equal to, 0.3 (something like 0.30000000000000004). Therefore, the direct equality comparison returns False.
2. Which module in Python provides exact decimal arithmetic?
  • A) math
  • B) decimal
  • C) fractions
  • D) numpy
Correct Answer: B) decimal
The decimal module provides support for decimal floating-point arithmetic. It offers exact representations of decimal numbers, which is especially useful for financial calculations where precision is critical. The fractions module provides support for rational number arithmetic, but it doesn't specifically address decimal arithmetic.
3. What is a better way to check if two floating-point numbers are approximately equal?
  • A) Using the == operator directly
  • B) Rounding both numbers before comparison
  • C) Using math.isclose() or numpy.isclose()
  • D) Converting them to integers
Correct Answer: C) Using math.isclose() or numpy.isclose()
The math.isclose() and numpy.isclose() functions compare two values for approximate equality, allowing for a small tolerance. This is generally the most reliable way to compare floating-point numbers. For example: math.isclose(0.1 + 0.2, 0.3) would return True.

Quiz 5: Bit Manipulation

Intermediate
1. What is the result of 5 & 3 in Python?
  • A) 1
  • B) 7
  • C) 2
  • D) 8
Correct Answer: A) 1
The & operator performs a bitwise AND. In binary:
5 = 101
3 = 011
5 & 3 = 001 = 1 in decimal
Only the rightmost bit is 1 in both numbers, so only that bit is 1 in the result.
2. What does the << operator do in Python?
  • A) Bitwise OR
  • B) Left shift
  • C) Right shift
  • D) Bitwise XOR
Correct Answer: B) Left shift
The << operator performs a left shift. It shifts the bits of the left operand to the left by the number of positions specified by the right operand. For example, 3 << 1 shifts the bits of 3 (011) one position to the left, resulting in 6 (110).
3. What is a common use of the bitwise XOR (^) operation?
  • A) Finding the maximum value
  • B) Swapping two variables without a temporary variable
  • C) Division by two
  • D) Counting set bits
Correct Answer: B) Swapping two variables without a temporary variable
XOR can be used to swap two variables without using a temporary variable, as follows: 
a = a ^ b
b = a ^ b  # Now b has the original value of a
a = a ^ b  # Now a has the original value of b
This works because XOR has the property that (A ^ B) ^ B = A, and it's often used as a bitwise trick in low-level programming.

Quiz 6: Linear Algebra with NumPy

Advanced
1. Which NumPy function would you use to compute the dot product of two matrices?
  • A) np.dot()
  • B) np.multiply()
  • C) np.matmul()
  • D) Both A and C are correct
Correct Answer: D) Both A and C are correct
Both np.dot() and np.matmul() can be used to compute the matrix product. For 2D arrays, they behave the same way, computing the matrix product. However, they differ in behavior for higher-dimensional arrays. np.multiply() performs element-wise multiplication, not the matrix dot product.
2. What does the following code compute?
import numpy as np A = np.array([[1, 2], [3, 4]]) e, v = np.linalg.eig(A)
  • A) The determinant of A
  • B) The eigenvalues and eigenvectors of A
  • C) The singular value decomposition of A
  • D) The inverse of A
Correct Answer: B) The eigenvalues and eigenvectors of A
The np.linalg.eig() function computes the eigenvalues and right eigenvectors of a square array. The eigenvalues are returned in the array e, and the corresponding eigenvectors are in the columns of the array v.
3. What is the output of the following code?
import numpy as np A = np.array([[1, 2], [3, 4]]) b = np.array([5, 6]) x = np.linalg.solve(A, b) print(x)
  • A) [-4, 4.5]
  • B) [5, 6]
  • C) [1, 2]
  • D) Error: Singular matrix
Correct Answer: A) [-4, 4.5]
The np.linalg.solve() function solves the linear equations Ax = b for x. In this case, we're solving the system:
1x + 2y = 5
3x + 4y = 6
The solution is x = -4 and y = 4.5, so the function returns the array [-4, 4.5].

Quiz 7: Numerical Integration

Advanced
1. Which SciPy function is used for numerical integration of a function over a single variable?
  • A) scipy.integrate.quad
  • B) scipy.integrate.simps
  • C) scipy.integrate.odeint
  • D) scipy.integrate.trapz
Correct Answer: A) scipy.integrate.quad
scipy.integrate.quad performs numerical integration using adaptive quadrature methods. It's the general-purpose integration function for definite integrals of a single variable. simps and trapz are for integrating tabulated data using Simpson's rule and the trapezoidal rule, respectively. odeint is for solving ordinary differential equations.
2. What does the following code calculate?
from scipy import integrate import numpy as np def f(x): return np.sin(x) result, error = integrate.quad(f, 0, np.pi) print(result)
  • A) 0
  • B) 1
  • C) 2
  • D) π
Correct Answer: C) 2
The code calculates the definite integral of sin(x) from 0 to π. The antiderivative of sin(x) is -cos(x), so the integral is:
[-cos(x)]0π = -cos(π) - (-cos(0)) = -(-1) - (-1) = 1 + 1 = 2
3. Which numerical integration method is most suitable for highly oscillatory functions?
  • A) Trapezoidal rule
  • B) Simpson's rule
  • C) Gaussian quadrature
  • D) Tanh-sinh quadrature
Correct Answer: D) Tanh-sinh quadrature
Tanh-sinh quadrature (also known as double exponential quadrature) is particularly effective for highly oscillatory integrands. It uses a change of variables to cluster sample points near the endpoints, which is beneficial for oscillatory functions. Gaussian quadrature is efficient for smooth functions but not necessarily for highly oscillatory ones.

Quiz 8: Statistical Computing

Intermediate
1. Which function would you use to perform a one-sample t-test in SciPy?
  • A) scipy.stats.ttest_1samp
  • B) scipy.stats.ttest_ind
  • C) scipy.stats.ttest_rel
  • D) scipy.stats.t.test
Correct Answer: A) scipy.stats.ttest_1samp
scipy.stats.ttest_1samp performs a one-sample t-test, which tests whether the mean of a sample differs significantly from a specified value. ttest_ind is for independent two-sample t-tests, and ttest_rel is for paired sample t-tests.
2. What statistic does the following code calculate?
import numpy as np from scipy import stats data = [14, 15, 16, 17, 17, 18, 18, 19, 19, 20, 21, 22] result = stats.skew(data) print(result)
  • A) Mean
  • B) Variance
  • C) Skewness
  • D) Kurtosis
Correct Answer: C) Skewness
stats.skew() calculates the skewness of a distribution, which is a measure of the asymmetry of the probability distribution. Positive skewness indicates a distribution with a long right tail, while negative skewness indicates a distribution with a long left tail. A perfectly symmetric distribution has a skewness of zero.
3. What does a p-value of 0.02 in a hypothesis test indicate?
  • A) The null hypothesis is definitely true
  • B) The null hypothesis is definitely false
  • C) There is a 2% chance the null hypothesis is true
  • D) There is strong evidence against the null hypothesis
Correct Answer: D) There is strong evidence against the null hypothesis
A p-value of 0.02 means that, assuming the null hypothesis is true, there is only a 2% chance of observing results as extreme as or more extreme than those observed. This is typically considered strong evidence against the null hypothesis (assuming a conventional significance level of 0.05). It does NOT directly indicate the probability that the null hypothesis is true, which is a common misconception.

Quiz 9: High-Performance Computing

Advanced
1. What is vectorization in the context of NumPy?
  • A) Converting data into vector format
  • B) Replacing explicit loops with array operations
  • C) Calculating the direction and magnitude of a vector
  • D) Multithreading on vector processors
Correct Answer: B) Replacing explicit loops with array operations
Vectorization in NumPy refers to the process of replacing explicit loops with operations on arrays. This leverages optimized, pre-compiled C code instead of interpreted Python loops, leading to significant performance improvements, especially for large datasets.
2. What is the primary purpose of the Numba library in Python?
  • A) Data visualization
  • B) Just-in-time compilation of Python functions
  • C) Database connectivity
  • D) Machine learning algorithms
Correct Answer: B) Just-in-time compilation of Python functions
Numba is a just-in-time (JIT) compiler for Python that specializes in accelerating numerical Python functions. It works by translating Python functions to optimized machine code at runtime using the LLVM compiler library. This can lead to dramatic speedups, especially for code that would otherwise be limited by Python's interpretation overhead.
3. Which of the following code snippets would likely be faster for large arrays?
  • A) 
    result = 0
for i in range(len(array)):
    result += array[i]
  • B) 
    result = np.sum(array)
  • C) 
    result = sum(array)
  • D) Performance would be approximately the same for all options
Correct Answer: B) result = np.sum(array)
np.sum(array) uses vectorized operations implemented in optimized C code, making it significantly faster than the Python loop in option A or even the built-in sum() function in option C for large NumPy arrays. The performance difference can be several orders of magnitude for large arrays.

Quiz 10: Practical Applications

Intermediate
1. Which Python library would be most appropriate for time series analysis?
  • A) NumPy
  • B) SciPy
  • C) pandas
  • D) Matplotlib
Correct Answer: C) pandas
While NumPy and SciPy provide fundamental numerical capabilities, pandas is specifically designed for data manipulation and analysis, with special support for time series data. It provides data structures like DataFrame and Series, and has built-in functionality for resampling, shifting, and windowing operations that are essential for time series analysis.
2. Which numerical method would be most appropriate for finding the root of a non-linear equation?
  • A) Linear regression
  • B) Newton-Raphson method
  • C) Simpson's rule
  • D) Singular value decomposition
Correct Answer: B) Newton-Raphson method
The Newton-Raphson method is an iterative numerical method for finding the roots of a real-valued function. It uses the function's derivative to converge quickly to a solution. Linear regression is used for fitting data to a line, Simpson's rule is for numerical integration, and SVD is used for matrix factorization.
3. What would be the best approach to handle a computationally intensive loop that cannot be easily vectorized?
  • A) Rewrite the algorithm to use recursion
  • B) Use multiprocessing to distribute the work
  • C) Use Numba's @jit decorator
  • D) Both B and C are valid approaches
Correct Answer: D) Both B and C are valid approaches
For computationally intensive loops that cannot be vectorized, both using Numba's JIT compilation and multiprocessing are valid approaches:
• Numba's @jit decorator compiles the loop to machine code, significantly improving single-thread performance.
• Multiprocessing distributes the work across multiple CPU cores, which can be especially beneficial for embarrassingly parallel problems.
The best approach depends on the specific problem, and sometimes a combination of both techniques can yield the best results.
