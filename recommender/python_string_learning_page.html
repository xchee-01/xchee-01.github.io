Introduction to Python Strings

Strings in Python are sequences of characters enclosed in quotes. They are one of the most commonly used data types and are used to represent text.

Important Note:

Strings in Python are immutable, which means once a string is created, it cannot be changed.

Creating Strings in Python

Strings can be created using single quotes, double quotes, or triple quotes:

# Single quotes
single_quoted = 'Hello, World!'

# Double quotes
double_quoted = "Python Programming"

# Triple quotes for multi-line strings
multi_line = '''This is a
multi-line
string'''

# Or with double quotes
multi_line2 = """Another
multi-line
string"""

print(single_quoted)
print(double_quoted)
print(multi_line)
Hello, World!
Python Programming
This is a
multi-line
string

Escape Characters

Use backslash (\) to escape special characters in strings:

# Escaping quotes
text1 = "She said, \"Hello!\""

# Newline character
text2 = "First line.\nSecond line."

# Tab character
text3 = "Name:\tPython"

print(text1)
print(text2)
print(text3)
She said, "Hello!"
First line.
Second line.
Name: Python
Escape Character Description
\n Newline
\t Tab
\' Single quote
\" Double quote
\\ Backslash

Basic String Operations

Concatenation

Joining two or more strings together:

first_name = "John"
last_name = "Doe"

# Using the + operator
full_name = first_name + " " + last_name

print(full_name)
John Doe

Repetition

Repeating a string multiple times:

# Using the * operator
repeated = "Python " * 3

print(repeated)
Python Python Python

String Length

Getting the length of a string:

text = "Hello, Python!"
length = len(text)

print(f"The string has {length} characters")
The string has 14 characters

String Indexing and Slicing

Each character in a string has a position, starting from 0 for the first character:

Indexing

text = "Python"

# Get first character (index 0)
first = text[0]

# Get third character (index 2)
third = text[2]

# Get last character
last = text[-1]

print(f"First character: {first}")
print(f"Third character: {third}")
print(f"Last character: {last}")
First character: P
Third character: t
Last character: n

Slicing

Getting a substring using the slice notation [start:end:step]:

text = "Python Programming"

# Characters from position 0 to 5 (excluded)
slice1 = text[0:6]

# Shorthand for starting from 0
slice2 = text[:6]

# Characters from position 7 to the end
slice3 = text[7:]

# Every second character
slice4 = text[::2]

# Reverse the string
reversed_text = text[::-1]

print(f"Slice 1: {slice1}")
print(f"Slice 2: {slice2}")
print(f"Slice 3: {slice3}")
print(f"Slice 4: {slice4}")
print(f"Reversed: {reversed_text}")
Slice 1: Python
Slice 2: Python
Slice 3: Programming
Slice 4: Pto rgamn
Reversed: gnimmargorP nohtyP

Common String Methods

Python provides many built-in methods to work with strings:

Method Description Example
upper() Converts to uppercase "hello".upper() → "HELLO"
lower() Converts to lowercase "HELLO".lower() → "hello"
strip() Removes whitespace from start and end " hello ".strip() → "hello"
replace() Replaces occurrences of a substring "hello".replace("l", "p") → "heppo"
split() Splits string by separator "a,b,c".split(",") → ["a", "b", "c"]
join() Joins iterable with string as separator ",".join(["a", "b", "c"]) → "a,b,c"
find() Finds first occurrence of substring "hello".find("l") → 2
count() Counts occurrences of substring "hello".count("l") → 2
startswith() Checks if string starts with substring "hello".startswith("he") → True
endswith() Checks if string ends with substring "hello".endswith("lo") → True

Examples:

text = " Python Programming "

# Remove whitespace
stripped = text.strip()

# Change case
upper = text.upper()
lower = text.lower()

# Replace characters
replaced = text.replace("P", "J")

# Split into list
words = stripped.split()

print(f"Stripped: '{stripped}'")
print(f"Uppercase: {upper}")
print(f"Lowercase: {lower}")
print(f"Replaced: {replaced}")
print(f"Split words: {words}")
Stripped: 'Python Programming'
Uppercase: PYTHON PROGRAMMING
Lowercase: python programming
Replaced: Jython Jrogramming
Split words: ['Python', 'Programming']

String Formatting

Python offers several ways to format strings:

1. f-strings (Python 3.6+)

name = "Alice"
age = 25

# Using f-strings
message = f"Hello, my name is {name} and I am {age} years old."

# With expressions
message2 = f"In five years, I'll be {age + 5} years old."

print(message)
print(message2)
Hello, my name is Alice and I am 25 years old.
In five years, I'll be 30 years old.

2. format() Method

name = "Bob"
age = 30

# Basic formatting
message = "Hello, my name is {} and I am {} years old.".format(name, age)

# Using indexes
message2 = "Hello, my name is {0} and I am {1} years old. Hi {0}!".format(name, age)

# Using named placeholders
message3 = "Hello, my name is {n} and I am {a} years old.".format(n=name, a=age)

print(message)
print(message2)
print(message3)
Hello, my name is Bob and I am 30 years old.
Hello, my name is Bob and I am 30 years old. Hi Bob!
Hello, my name is Bob and I am 30 years old.

3. % Operator (Older Style)

name = "Charlie"
age = 35

# Using % operator
message = "Hello, my name is %s and I am %d years old." % (name, age)

print(message)
Hello, my name is Charlie and I am 35 years old.

def reverse_string(s):
    result = ""
    for char in s:
        result = char + result
    return result

Exercise 2: Palindrome Check

Write a function to check if a string is a palindrome (reads the same forwards and backwards).

def is_palindrome(s):
    # Remove spaces and convert to lowercase
    s = s.lower().replace(" ", "")
    return s == s[::-1]

# Test
test1 = "racecar"
test2 = "hello"
test3 = "A man a plan a canal Panama"

print(f"{test1}: {is_palindrome(test1)}")
print(f"{test2}: {is_palindrome(test2)}")
print(f"{test3}: {is_palindrome(test3)}")
racecar: True
hello: False
A man a plan a canal Panama: True

Exercise 3: Count Vowels

Write a function to count the number of vowels in a string.

def count_vowels(s):
    vowels = "aeiou"
    count = 0
    for char in s.lower():
        if char in vowels:
            count += 1
    return count

# Test
text = "Python Programming"
vowel_count = count_vowels(text)
print(f"The string '{text}' has {vowel_count} vowels.")
The string 'Python Programming' has 4 vowels.
