Understanding Domain and Range

Welcome! In mathematics, especially when working with functions, two fundamental concepts are Domain and Range. Understanding these helps you know what values can go into a function and what values can come out. Let's break it down simply.

What is a Function? (Quick Recap)

Think of a function like a machine. You put something in (an input), the machine does something according to its rule, and it gives you something back (an output).

We often write functions like f(x) = x + 2. Here:

  • f is the name of the function (the machine).
  • x is the input variable.
  • x + 2 is the rule the machine follows.
  • f(x) represents the output (which we often call y).

So, if you input x = 3 into f(x) = x + 2, the output is f(3) = 3 + 2 = 5.

What is the Domain?

The Domain of a function is the set of all possible input values (usually x-values) that are allowed for that function.

Think: What numbers can I safely put into my function machine?

For many simple functions, the domain is "all real numbers". But sometimes, there are restrictions!

Common Restrictions for Domain:

  1. Division by Zero: You cannot divide by zero! If your function has a fraction, the denominator (bottom part) cannot be equal to zero.
  2. Square Roots (and other even roots): You cannot take the square root of a negative number (in the realm of real numbers). The value inside the square root sign must be zero or positive (non-negative).

Example 1: f(x) = 2x + 1

Can you put any real number in for x? Yes! There's no division by x and no square roots involving x.

Domain: All real numbers.

Notation: We can write this as (-∞, ∞) using interval notation, or {x | x ∈ ℝ} using set-builder notation (read as "the set of all x such that x is an element of the real numbers").

Example 2: g(x) = 1 / x

Here we have a fraction. The denominator is x. We know we cannot divide by zero, so x cannot be 0.

Domain: All real numbers except 0.

Notation: (-∞, 0) U (0, ∞) or {x | x ∈ ℝ, x ≠ 0} (The 'U' means 'union', combining the two intervals).

Example 3: h(x) = √x (the square root of x)

We cannot take the square root of a negative number. So, the value inside the square root, x, must be greater than or equal to zero.

Domain: All real numbers greater than or equal to 0.

Notation: [0, ∞) (The square bracket '[' means 0 is included) or {x | x ≥ 0}.

What is the Range?

The Range of a function is the set of all possible output values (usually y-values or f(x)-values) that the function can produce.

Think: What numbers can possibly come out of my function machine, given the allowed inputs (the domain)?

Finding the range can sometimes be trickier than finding the domain. It often helps to think about the behaviour of the function or look at its graph.

Example 1 (revisited): f(x) = 2x + 1

Domain was all real numbers. If you can put any x in, can you get any output y? Yes, this is a straight line that goes up and down forever.

Range: All real numbers.

Notation: (-∞, ∞) or {y | y ∈ ℝ}.

Example 2 (revisited): g(x) = 1 / x

Domain was all real numbers except 0. What values can y take? Can y ever be 0? For 1/x to be 0, the numerator (1) would have to be 0, which is impossible. So, y can be any real number except 0.

Range: All real numbers except 0.

Notation: (-∞, 0) U (0, ∞) or {y | y ≠ 0}.

Example 3 (revisited): h(x) = √x

Domain was x ≥ 0. The square root symbol √ traditionally means the *principal* (non-negative) square root. So, the output will always be 0 or positive.

Range: All real numbers greater than or equal to 0.

Notation: [0, ∞) or {y | y ≥ 0}.

Example 4: k(x) = x²

Domain: You can square any real number, so the domain is all real numbers: (-∞, ∞).

Range: What happens when you square a number? If you square a positive number, you get a positive number (e.g., 3² = 9). If you square a negative number, you get a positive number (e.g., (-3)² = 9). If you square zero, you get zero (0² = 0). So, the output (y or k(x)) can never be negative. It can be zero or any positive number.

Range: All real numbers greater than or equal to 0.

Notation: [0, ∞) or {y | y ≥ 0}.

Visualizing Domain and Range (Graphs)

Graphs are very helpful!

  • The Domain corresponds to all the x-values covered by the graph (how far it spreads horizontally).
  • The Range corresponds to all the y-values covered by the graph (how far it spreads vertically).

Imagine "squashing" the graph onto the x-axis to see the Domain, and "squashing" it onto the y-axis to see the Range.

Key Takeaways

  • Domain: Set of all possible inputs (x-values). Watch out for division by zero and square roots of negative numbers.
  • Range: Set of all possible outputs (y-values). Consider the function's behavior and any limitations on the output.
  • Think of the function machine analogy: Domain = Allowed Ingredients, Range = Possible Products.
  • Graphs provide a visual way to see domain (horizontal spread) and range (vertical spread).

Practice Time!

Try to find the Domain and Range for these functions (using interval notation):

  1. f(x) = x - 5
    Domain: (-∞, ∞), Range: (-∞, ∞)
  2. g(x) = 1 / (x - 2)
    Domain: (-∞, 2) U (2, ∞) [because x-2 ≠ 0], Range: (-∞, 0) U (0, ∞) [because 1/(x-2) can never be 0]
  3. h(x) = √(x + 1)
    Domain: [-1, ∞) [because x+1 ≥ 0], Range: [0, ∞) [because √ output is non-negative]
  4. k(x) = x² + 3
    Domain: (-∞, ∞), Range: [3, ∞) [because x² ≥ 0, so x²+3 ≥ 3]

Hint: For range, think about the minimum or maximum values the function can produce.

Keep practicing! Domain and Range become clearer the more examples you work through.
