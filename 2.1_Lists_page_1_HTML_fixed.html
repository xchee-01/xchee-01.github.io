Mission Briefing: Understanding Lists as Medical Data Containers

💡 Quick Concept: Lists = Your Digital Medical Filing Cabinet

Imagine you're the head nurse in a busy ICU. You've got 10 patients, each with hourly vital signs to track. Writing each measurement on a separate sticky note would be chaos! Instead, you'd use a chart with organized rows - that's exactly what Python lists do for your data.

🧩 Breaking It Down: What Makes Lists Special?

Think of lists like a pill organizer:

  • Each compartment (index) holds one item
  • You can see all compartments at once
  • Items stay in order (Monday's pills don't jump to Friday!)
  • You can add or remove pills as needed
# Creating your first medical list - it's that simple! patient_temps = [98.6, 99.1, 99.5, 100.2, 99.8] print("Patient temperature readings:", patient_temps)
Copied!

💡 Pro Tip: Lists can hold ANY data type - like a patient file that contains:

  • Numbers (age, weight, lab values)
  • Text (name, symptoms, medications)
  • True/False values (has_allergies, is_diabetic)
  • Even other lists (test results over time)!

🏥 Real-World Example: Mixed Data Types

# A complete patient record in one list patient_data = ["Sarah Chen", 45, "A+", 120.5, True] # name age blood weight diabetic print("Patient info:", patient_data)

Mission Briefing: Creating and Accessing List Elements

💡 Quick Concept: Every Item Has an Address (Index)

Picture a hospital corridor with numbered rooms. Room 0 (yes, we start at zero - programmers are quirky that way! 🤓) is the first room, Room 1 is the second, and so on. That's exactly how list indexing works!

📍 Understanding Index Positions

# Blood pressure readings for 5 days blood_pressure = [120, 118, 125, 130, 122] # Index: 0 1 2 3 4 # Accessing readings - it's like knocking on a specific room door first_reading = blood_pressure[0] # Room 0 = First reading print(f"Monday's BP: {first_reading}") third_reading = blood_pressure[2] # Room 2 = Third reading print(f"Wednesday's BP: {third_reading}")
Copied!

🎯 The Magic of Negative Indexing

Here's where Python gets clever! Negative numbers count from the end:

# Think of it like entering the hospital from the back entrance last_reading = blood_pressure[-1] # -1 = Last room second_last = blood_pressure[-2] # -2 = Second to last print(f"Today's BP: {last_reading}") print(f"Yesterday's BP: {second_last}")
Copied!

💡 Memory Trick:

Positive Index: Count from the START (like regular counting)
    [0] [1] [2] [3] [4]
    
Negative Index: Count from the END (like a countdown)
    [-5][-4][-3][-2][-1]

Mission Briefing: Modifying Lists for Dynamic Patient Data

💡 Quick Concept: Lists Are Living Documents

Unlike a printed medical chart, digital lists can grow, shrink, and change - just like patient conditions! Let's explore how to keep your data as dynamic as real healthcare.

📝 Adding New Data Points

# Morning glucose readings glucose_levels = [95, 110, 98] print("Morning readings:", glucose_levels) # Lunchtime - patient eats, we test again glucose_levels.append(145) # append = add to the end print("After lunch:", glucose_levels) # Oops! Forgot the 10 AM reading glucose_levels.insert(2, 101) # insert(position, value) print("Complete timeline:", glucose_levels)
Copied!

💡 Tip: append() vs insert()

  • append(value) → Always adds to the END (like writing on the next line)
  • insert(position, value) → Adds ANYWHERE (like squeezing a note between lines)

✏️ Updating Existing Values

# Lab made an error - let's fix it! glucose_levels[1] = 108 # Direct assignment print("Corrected:", glucose_levels) # You can even do math directly glucose_levels[0] = glucose_levels[0] + 2 # Calibration adjustment print("Calibrated:", glucose_levels)
Copied!

🗑️ Removing Data

# Quality control: removing contaminated sample bad_reading = 145 glucose_levels.remove(bad_reading) # Removes first occurrence print("Clean data:", glucose_levels) # Alternative: Remove by position last_value = glucose_levels.pop() # Removes and returns last item print(f"Removed: {last_value}") print("Remaining:", glucose_levels)
Copied!

Mission Briefing: List Slicing for Data Analysis

💡 Quick Concept: Slicing = Taking a Snapshot of Your Data

Imagine you're reviewing a patient's medical history. Sometimes you need all of it, but often you just want "last week's labs" or "morning vitals." That's where slicing shines!

🔪 The Slicing Syntax: [start:stop:step]

Think of it like cutting a delicious medical data sandwich:

  • start: Where to begin cutting (inclusive)
  • stop: Where to stop cutting (exclusive - the knife stops BEFORE this)
  • step: How thick each slice is
# Week of blood pressure readings bp_readings = [118, 120, 125, 119, 122, 128, 124] # Day: 0 1 2 3 4 5 6 # Mon Tue Wed Thu Fri Sat Sun # Get first three days first_half = bp_readings[0:3] # Days 0, 1, 2 (Mon-Wed) print("Early week:", first_half) # Get mid-week readings mid_week = bp_readings[2:5] # Days 2, 3, 4 (Wed-Fri) print("Mid-week:", mid_week)
Copied!

🎯 Advanced Slicing Tricks

# Every other day (for trending) alternate_days = bp_readings[::2] # Start at 0, go to end, step by 2 print("Every other day:", alternate_days) # Last 3 readings recent = bp_readings[-3:] # From -3 to end print("Last 3 days:", recent) # Reverse the list (newest first) reversed_bp = bp_readings[::-1] # Step of -1 reverses print("Newest first:", reversed_bp)
Copied!

💡 Pro Tip: Slice Shortcuts

[:3]   → First 3 items (start=0 is default)
[2:]   → From index 2 to end (stop=end is default)
[:]    → Copy entire list
[::2]  → Every 2nd item
[::-1] → Reverse the list

🧬 Medical Application: Gene Analysis

# BRCA1 gene fragment (simplified) gene_sequence = ["ATG", "GAA", "TTC", "CAG", "AGC", "TTA", "GGC", "AAT"] # Extract specific codon region for analysis target_region = gene_sequence[2:6] print("Region of interest:", target_region) # Check every 3rd codon for patterns pattern_check = gene_sequence[::3] print("Pattern analysis:", pattern_check)
Copied!

Lab Exercise 2: Analyzing Patient Recovery Patterns

🎯 Your Mission: Track post-surgery recovery using pain scores!

You're helping the orthopedic ward analyze recovery patterns. Studies show that identifying pain trends helps optimize medication timing. Let's slice some data!

Lab scenario: Post-surgery pain tracking
# Pain scores for 10 days post-surgery (0-10 scale) pain_scores = [8, 7, 7, 6, 5, 5, 4, 3, 3, 2]
To extract early recovery (first 3 days), which slice would you use?
pain_scores[0:3] or pain_scores[:3]
Gets indices 0, 1, and 2 (first three days).
Correct! Both notations work - when starting from 0, you can omit it. This gives you [8, 7, 7].
pain_scores[1:3]
Gets the first three values.
Not quite. This starts at index 1 (second day) and only gives you 2 values: [7, 7].
pain_scores[0:2]
Gets from day 0 to day 2.
Close, but remember: the stop index is exclusive. This only gives you 2 values: [8, 7].
For mid-recovery (days 4-7), which slice would you use? Remember: day 4 is index 3!
pain_scores[3:7]
Gets indices 3, 4, 5, 6 (days 4-7).
Perfect! This gives you [6, 5, 5, 4] - exactly days 4 through 7.
pain_scores[4:7]
Gets days 4-7.
Remember: day 4 is at index 3 (we start counting at 0). This would give you days 5-7.
pain_scores[3:6]
Gets indices 3-6.
Close! But this only gives you days 4-6, missing day 7. Remember the stop index is exclusive.
To get scores for every other day (for a summary report), which slice would you use?
pain_scores[::2]
Start at beginning, go to end, step by 2.
Excellent! This gives you [8, 7, 5, 4, 3] - every alternate day's pain score.
pain_scores[2::]
Skip the first 2 and get the rest.
This would skip the first 2 days entirely. We want every other day, not skip days.
pain_scores[0:10:2]
Explicitly specify start, stop, and step.
While this works, it's unnecessary to specify 0:10 when you want the whole list. Just [::2] is cleaner.

💡 Hint: Remember that day 4 is index 3 (we start counting at 0)!

Complete Solution

# Complete solution for pain tracking analysis pain_scores = [8, 7, 7, 6, 5, 5, 4, 3, 3, 2] # Extract early recovery (first 3 days) early_recovery = pain_scores[0:3] # or just [:3] print("Early recovery scores:", early_recovery) # Extract mid-recovery (days 4-7) = indices 3-6 mid_recovery = pain_scores[3:7] print("Mid-recovery scores:", mid_recovery) # Get scores for every other day alternate_scores = pain_scores[::2] print("Alternate day scores:", alternate_scores)
