In this lesson, you'll learn how to store and manage patient data using Python variables. This fundamental concept is essential for all healthcare data processing tasks.

What Are Variables?

Think of variables as labeled containers that store information. In healthcare programming, we use variables to store patient data, test results, medication dosages, and much more. Just like patient charts hold different types of information, variables can hold different types of data.

Healthcare Analogy

A variable is like a labeled specimen container in a lab. The label (variable name) tells you what's inside, and the contents (variable value) can be examined or changed as needed.

Creating Variables in Python

In Python, creating a variable is simple - you just give it a name and assign a value using the equals sign (=):

# Storing patient information
patient_name = "John Smith"
patient_age = 42
patient_weight = 75.5  # in kilograms
has_diabetes = True

# Displaying the information
print("Patient:", patient_name)
print("Age:", patient_age)
print("Weight:", patient_weight, "kg")
Quick Tip: Variable names should be descriptive. Instead of x or data1, use meaningful names like patient_temperature or blood_pressure_systolic.

Data Types in Healthcare

Python automatically determines the type of data you're storing. Here are the most common types you'll use in healthcare applications:

Strings (text)

Patient names, diagnoses, medication names

diagnosis = "Type 2 Diabetes"

Integers (whole numbers)

Age, pulse rate, days of treatment

heart_rate = 72

Floats (decimals)

Temperature, dosage, lab values

temperature = 98.6

Booleans (True/False)

Test results, patient status flags

is_admitted = True

Variable Naming Rules

When naming variables in Python, especially for healthcare applications, follow these important rules:

Python Variable Naming Rules

  • Must start with a letter or underscore: patient_id ✓, 2nd_dose ✗
  • Can contain letters, numbers, underscores: test_result_1 ✓
  • Case-sensitive: bloodPressure and bloodpressure are different
  • No spaces allowed: Use underscores instead: blood_pressure
  • Avoid Python keywords: Don't use words like if, for, class
Healthcare Best Practice: Use clear, descriptive names that any healthcare professional could understand. For example, systolic_bp is better than sbp or value1.

Updating Variable Values

Variables can be updated as patient conditions change or new data becomes available:

# Initial patient vitals
temperature = 98.6
print("Initial temperature:", temperature)

# Patient develops fever
temperature = 101.2
print("Updated temperature:", temperature)

# Calculate temperature change
temp_change = 101.2 - 98.6
print("Temperature increased by:", temp_change, "°F")

Type Checking

Python provides the type() function to check what kind of data a variable holds. This is useful when debugging healthcare applications:

# Check variable types
lab_result = 126.5
patient_id = "MRN-2024-1234"
is_critical = True

Summary

Key Takeaways

  • Variables store data that can be used and modified throughout your program
  • Python has four main data types: strings (text), integers (whole numbers), floats (decimals), and booleans (True/False)
  • Variable names should be descriptive and follow Python's naming rules
  • You can update variable values as needed, making them perfect for tracking changing patient data
  • The type() function helps identify what kind of data a variable contains
