Algorithm Builder: Bubble Sort

Challenge: Create a Bubble Sort Algorithm

Arrange the code blocks to implement a bubble sort algorithm. Bubble sort works by repeatedly stepping through the list, comparing adjacent elements and swapping them if they are in the wrong order.

Your task: Create the algorithm by dragging code blocks into the workspace in the correct order.

  • The algorithm should iterate through the array
  • Compare adjacent elements
  • Swap elements if needed
  • Continue until the array is sorted

When ready, click "Run Algorithm" to test your solution!
