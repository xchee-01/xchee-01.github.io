📊 Understanding map() - Transform All Data

# Step 1: Simple example - Square all numbers numbers = [1, 2, 3, 4, 5] squared = list(map(lambda x: x**2, numbers)) print(f"Squared: {squared}") # Step 2: Medical application - Temperature conversion temperatures_c = [36.5, 37.2, 38.1, 37.8, 36.9] temperatures_f = list(map(lambda c: (c * 9/5) + 32, temperatures_c)) # Pretty print with labels for c, f in zip(temperatures_c, temperatures_f): print(f"{c}°C = {f:.1f}°F")

🔍 Understanding filter() - Select Specific Data

# Filter patients with fever (temperature >= 38°C) fever_patients = list(filter(lambda temp: temp >= 38, temperatures_c)) print(f"Patients with fever: {fever_patients}") # Count fever cases fever_count = len(fever_patients) total_patients = len(temperatures_c) print(f"Fever rate: {fever_count}/{total_patients} ({fever_count/total_patients*100:.0f}%)")

📐 Understanding sorted() - Organize Your Data

# Sort temperatures from highest to lowest sorted_temps = sorted(temperatures_c, key=lambda x: x, reverse=True) print(f"Temperatures (highest to lowest): {sorted_temps}") # Sort patient records by temperature patients = [ {"id": "P001", "temp": 36.5, "name": "Alice"}, {"id": "P002", "temp": 37.2, "name": "Bob"}, {"id": "P003", "temp": 38.1, "name": "Charlie"}, {"id": "P004", "temp": 37.8, "name": "Diana"}, {"id": "P005", "temp": 36.9, "name": "Eve"} ] # Sort by temperature descending fever_priority = sorted(patients, key=lambda p: p["temp"], reverse=True) print("\nPatients by fever priority:") for patient in fever_priority: status = "🔥 FEVER" if patient["temp"] >= 38 else "✓ Normal" print(f"{patient['id']}: {patient['name']} - {patient['temp']}°C {status}")

Advanced Lambda Applications in Healthcare

🏥 Real-World Medical Data Processing

Let's apply lambda functions to real healthcare scenarios. These examples demonstrate how lambda functions can streamline medical data analysis.

Example 1: BMI Calculation for Patient Groups

# Patient data with height (m) and weight (kg) patients = [ {"name": "Patient A", "height": 1.75, "weight": 70}, {"name": "Patient B", "height": 1.60, "weight": 85}, {"name": "Patient C", "height": 1.82, "weight": 95}, {"name": "Patient D", "height": 1.68, "weight": 65} ] # Calculate BMI using map and lambda patients_with_bmi = list(map( lambda p: {**p, "bmi": round(p["weight"] / (p["height"] ** 2), 1)}, patients )) # Categorize BMI status def get_bmi_status(bmi): if bmi < 18.5: return "Underweight" elif bmi < 25: return "Normal" elif bmi < 30: return "Overweight" else: return "Obese" # Add BMI status patients_with_status = list(map( lambda p: {**p, "status": get_bmi_status(p["bmi"])}, patients_with_bmi )) # Display results for patient in patients_with_status: print(f"{patient['name']}: BMI = {patient['bmi']} ({patient['status']})")
Copied!

Example 2: Drug Dosage Calculations

# Calculate drug dosage based on patient weight # Standard dose: 5mg per kg of body weight weights = [45, 68, 82, 55, 73] # Patient weights in kg dosage_per_kg = 5 # mg/kg # Calculate dosages using map and lambda dosages = list(map(lambda w: w * dosage_per_kg, weights)) # Create detailed report report = list(map( lambda pair: f"Patient {pair[0]+1}: {pair[1][0]}kg → {pair[1][1]}mg dose", enumerate(zip(weights, dosages)) )) print("Drug Dosage Calculations:") for line in report: print(line) # Filter patients needing dose adjustment (>350mg requires split dosing) high_dose_patients = list(filter( lambda pair: pair[1] > 350, zip(range(1, len(dosages)+1), dosages) )) if high_dose_patients: print("\n⚠️ Patients requiring split dosing:") for patient_num, dose in high_dose_patients: print(f"Patient {patient_num}: {dose}mg (split into 2 doses of {dose/2}mg)")
Copied!

🧬 Lambda Functions with Multiple Arguments

Lambda functions can handle multiple parameters, making them perfect for complex medical calculations.

# Calculate eGFR (estimated Glomerular Filtration Rate) # Formula: 186 × (Creatinine)^-1.154 × (Age)^-0.203 × (0.742 if female) patients = [ {"name": "John", "age": 45, "creatinine": 1.2, "gender": "M"}, {"name": "Sarah", "age": 62, "creatinine": 0.9, "gender": "F"}, {"name": "Mike", "age": 38, "creatinine": 1.5, "gender": "M"}, {"name": "Emma", "age": 55, "creatinine": 1.1, "gender": "F"} ] # Lambda function with multiple parameters calculate_egfr = lambda age, creat, is_female: round( 186 * (creat ** -1.154) * (age ** -0.203) * (0.742 if is_female else 1), 1 ) # Apply to all patients for patient in patients: egfr = calculate_egfr( patient["age"], patient["creatinine"], patient["gender"] == "F" ) # Determine kidney function stage if egfr >= 90: stage = "Normal" elif egfr >= 60: stage = "Mild decrease" elif egfr >= 30: stage = "Moderate decrease" elif egfr >= 15: stage = "Severe decrease" else: stage = "Kidney failure" print(f"{patient['name']}: eGFR = {egfr} mL/min/1.73m² ({stage})")
Copied!
Best Practice
Use lambda functions for simple, one-line operations. For complex logic that spans multiple lines or requires extensive documentation, use regular functions instead.

Practice Challenge: Lab Results Analysis

🔬 Analyze Blood Test Results

You're tasked with analyzing blood glucose test results from multiple patients. Use lambda functions to process the data efficiently!

Your Mission
  1. Convert glucose levels from mg/dL to mmol/L
  2. Filter patients with high glucose (>126 mg/dL indicates diabetes)
  3. Sort patients by risk level
# Blood glucose test results (mg/dL) test_results = [ {"patient_id": "P101", "glucose_mg_dl": 95, "fasting": True}, {"patient_id": "P102", "glucose_mg_dl": 142, "fasting": True}, {"patient_id": "P103", "glucose_mg_dl": 118, "fasting": True}, {"patient_id": "P104", "glucose_mg_dl": 88, "fasting": True}, {"patient_id": "P105", "glucose_mg_dl": 156, "fasting": True}, {"patient_id": "P106", "glucose_mg_dl": 201, "fasting": True} ] # Step 1: Convert mg/dL to mmol/L (divide by 18) results_with_mmol = list(map( lambda r: {**r, "glucose_mmol_l": round(r["glucose_mg_dl"] / 18, 1)}, test_results )) # Step 2: Add risk classification def classify_glucose(mg_dl): if mg_dl < 100: return "Normal" elif mg_dl < 126: return "Prediabetes" else: return "Diabetes" results_classified = list(map( lambda r: {**r, "risk": classify_glucose(r["glucose_mg_dl"])}, results_with_mmol )) # Step 3: Filter high-risk patients high_risk = list(filter( lambda r: r["glucose_mg_dl"] >= 126, results_classified )) # Step 4: Sort by glucose level (highest first) sorted_results = sorted( results_classified, key=lambda r: r["glucose_mg_dl"], reverse=True ) # Display comprehensive report print("=== GLUCOSE TEST RESULTS ANALYSIS ===\n") print("All Patients (sorted by glucose level):") for result in sorted_results: status_icon = "🟢" if result["risk"] == "Normal" else "🟡" if result["risk"] == "Prediabetes" else "🔴" print(f"{status_icon} {result['patient_id']}: {result['glucose_mg_dl']} mg/dL " f"({result['glucose_mmol_l']} mmol/L) - {result['risk']}") print(f"\n⚠️ High-risk patients requiring immediate attention: {len(high_risk)}") for patient in high_risk: print(f" - {patient['patient_id']}: {patient['glucose_mg_dl']} mg/dL")
