  • Can be manipulated and explored after creation
  • Include built-in tools for examining your data

Learning Checkpoint
What happens when you add trendline='ols' to your scatter plot?
It just draws a straight line through the data
Not quite right. While it does draw a line, it's not just any line - it's specifically a linear regression line fitted using Ordinary Least Squares method.
It adds a regression line and shows the equation when you hover
Correct! The 'ols' parameter adds an Ordinary Least Squares regression line and displays statistical information including the line equation and R² value when you hover over it.
It adds multiple trend lines for different statistical models
That's not right. The 'ols' parameter adds just one trend line using the Ordinary Least Squares linear regression method, not multiple trend lines or models.
It allows users to draw their own trend line interactively
That's not what 'ols' does. It automatically calculates and displays a statistical regression line, rather than allowing users to draw their own line.

🔬 Mission Briefing: Creating Interactive Dashboard Elements

One of Plotly's most powerful features is its ability to create interactive dashboards. Let's explore how to add dropdown menus and sliders to your visualizations.

Step 1: First, Let's Create a More Complex Dataset

# Generate data for multiple experiment conditions np.random.seed(42) # For reproducible results # Create a more complex experiment dataset with multiple conditions experiment_conditions = ['Control', 'Low Dose', 'Medium Dose', 'High Dose'] time_points = np.linspace(0, 48, 25) # 0 to 48 hours cell_lines = ['A549', 'HeLa', 'MCF7'] # Create the DataFrame experiment_data = pd.DataFrame() for cell in cell_lines: for condition in experiment_conditions: # Base growth rate varies by condition if condition == 'Control': growth_rate = 0.05 elif condition == 'Low Dose': growth_rate = 0.04 elif condition == 'Medium Dose': growth_rate = 0.03 else: # High Dose growth_rate = 0.01 # Base growth rate also varies slightly by cell line if cell == 'A549': growth_rate *= 1.2 elif cell == 'HeLa': growth_rate *= 1.0 else: # MCF7 growth_rate *= 0.9 # Generate growth curve with some noise base_count = 1000 for time in time_points: cell_count = base_count * np.exp(growth_rate * time) # Add some experimental noise noise_factor = 0.1 # 10% noise measured_count = cell_count * (1 + np.random.normal(0, noise_factor)) # Add row to DataFrame new_row = pd.DataFrame({ 'Time (hours)': [time], 'Cell Count': [measured_count], 'Condition': [condition], 'Cell Line': [cell] }) experiment_data = pd.concat([experiment_data, new_row], ignore_index=True) # Let's confirm our data looks right print(f"Dataset has {len(experiment_data)} rows and {experiment_data['Cell Line'].nunique()} cell lines") experiment_data.head()

# Let's create a dataset for physics - projectile motion with different angles import numpy as np # Physics parameters g = 9.81 # Gravity (m/s²) v0 = 20 # Initial velocity (m/s) angles = np.arange(15, 76, 5) # Launch angles from 15° to 75° in 5° increments # Function to calculate trajectory def calc_trajectory(angle_deg, v0, steps=20): angle_rad = np.radians(angle_deg) t_flight = 2 * v0 * np.sin(angle_rad) / g # Time of flight t = np.linspace(0, t_flight, steps) x = v0 * np.cos(angle_rad) * t y = v0 * np.sin(angle_rad) * t - 0.5 * g * t**2 return x, y, t # Generate dataset for multiple angles trajectory_data = pd.DataFrame() for angle in angles: x, y, t = calc_trajectory(angle, v0) temp_df = pd.DataFrame({ 'Distance (m)': x, 'Height (m)': y, 'Time (s)': t, 'Launch Angle (°)': [angle] * len(t) }) trajectory_data = pd.concat([trajectory_data, temp_df], ignore_index=True)

# Simulate a genetic algorithm converging on a solution generations = 20 population_size = 50 fitness_data = pd.DataFrame() # Generate data for each generation np.random.seed(42) for gen in range(generations): # As generations progress, mean fitness improves and variance decreases mean_fitness = 50 + 45 * (1 - np.exp(-0.2 * gen)) std_fitness = 25 * np.exp(-0.1 * gen) # Generate fitness scores for this generation fitness_scores = np.random.normal(mean_fitness, std_fitness, population_size) # Ensure fitness is between 0 and 100 fitness_scores = np.clip(fitness_scores, 0, 100) # Add to dataframe gen_data = pd.DataFrame({ 'Generation': [gen] * population_size, 'Individual': range(1, population_size + 1), 'Fitness Score': fitness_scores }) fitness_data = pd.concat([fitness_data, gen_data], ignore_index=True) # Create an animated histogram fig = px.histogram(fitness_data, x='Fitness Score', nbins=20, animation_frame='Generation', # This creates the animation range_x=[0, 100], color_discrete_sequence=['#2E86C1'], title='Genetic Algorithm Fitness Distribution Over Generations') # Improve the appearance fig.update_layout( xaxis_title='Fitness Score (higher is better)', yaxis_title='Number of Individuals', height=500, width=800 ) fig.show()

Step 2: Creating a More Complex Animation

Let's create an animation showing the diffusion of molecules, a common process in cell biology and chemistry:

# Simulate 2D diffusion process grid_size = 50 time_steps = 20 # Create initial concentration spike in the center diffusion = np.zeros((time_steps, grid_size, grid_size)) diffusion[0, grid_size//2, grid_size//2] = 100 # Simple diffusion model diffusion_coef = 0.1 for t in range(1, time_steps): for i in range(1, grid_size-1): for j in range(1, grid_size-1): # 2D diffusion equation (discrete approximation) diffusion[t, i, j] = diffusion[t-1, i, j] + diffusion_coef * ( diffusion[t-1, i+1, j] + diffusion[t-1, i-1, j] + diffusion[t-1, i, j+1] + diffusion[t-1, i, j-1] - 4 * diffusion[t-1, i, j] ) # Prepare data for Plotly diffusion_data = [] for t in range(time_steps): for i in range(grid_size): for j in range(grid_size): diffusion_data.append({ 'X Position': i, 'Y Position': j, 'Concentration': diffusion[t, i, j], 'Time Step': t }) # Create animated heatmap diffusion_df = pd.DataFrame(diffusion_data) fig = px.density_heatmap(diffusion_df, x='X Position', y='Y Position', z='Concentration', animation_frame='Time Step', range_color=[0, 100], color_continuous_scale='Viridis', title='Molecular Diffusion Simulation') fig.update_layout(height=600, width=700) fig.show()
