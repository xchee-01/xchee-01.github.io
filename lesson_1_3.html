🔬 Module 4: Case Sensitivity - Precision in Medical Coding ================================================== ==============================================================

🎯 Learning Objectives ===================== • Master Python's case sensitivity rules • Avoid common capitalization errors • Understand how case sensitivity prevents medical mistakes

🧠 Cognitive Load Management =========================== We'll use memorable medical examples where case matters critically, making the concept unforgettable.

---

In medicine, precision matters. The difference between "mg" and "Mg" could be life-threatening (milligrams vs magnesium). Python is similarly case-sensitive - every capital letter matters!

⚠️ Critical Concept: In Python, glucose, Glucose, and GLUCOSE are three completely different variables - like three different patients with similar names!

🔤 The Case Sensitivity Rules ============================

Everything in Python is case-sensitive:

- Variable names - Function names - Keywords - Everything except comments!

💊 Medical Case Examples =======================

Copied!
python

These are THREE different variables! ==================================== medication = "Aspirin" # lowercase - regular variable Medication = "Tylenol" # Capitalized - different variable! MEDICATION = "Ibuprofen" # ALL CAPS - yet another variable!

print(medication) # Prints: Aspirin print(Medication) # Prints: Tylenol print(MEDICATION) # Prints: Ibuprofen

Copied!
Question: In Python, which of these statements is TRUE?

A) glucose and Glucose refer to the same variable B) GLUCOSE and glucose are different variables C) Python converts all variables to lowercase automatically D) Case only matters for function names, not variables

Correct Answer: B Explanation: Python is case-sensitive for everything. glucose, Glucose, and GLUCOSE are three completely different variables that can hold different values.

🧬 Gene Naming Conventions =========================

In bioinformatics, case often has meaning:

Common convention in genetics

============================= brca1 = "gene" # Gene name (lowercase italic in papers) BRCA1 = "protein" # Protein name (uppercase) Brca1 = "mouse gene" # Mouse gene (first letter capitalized)

print(f"Human gene: {brca1}") print(f"Human protein: {BRCA1}") print(f"Mouse homolog: {Brca1}")

🔬 Module 5: Python Keywords - The Reserved Medical Terms ================================================== ===========================================================

🎯 Learning Objectives ===================== • Identify Python's reserved keywords • Understand why keywords cannot be redefined • Use keywords properly in medical contexts

🧠 Cognitive Load Management =========================== We'll focus on the 10 most common keywords first, then gradually introduce others as needed.

---

Just as medicine has protected terms (like "Dr." or "RN" that have specific legal meanings), Python has reserved keywords that have special meanings and cannot be used for other purposes.

🚫 The Golden Rule: You cannot use keywords as variable names - it's like trying to legally change your name to "Doctor" without going to medical school!

🗝️ The Most Important Python Keywords =====================================

The "Magnificent Seven" - Used in 90% of programs:

1. if - Makes decisions

if patient_temperature > 100.4:

print("Fever detected!")

2. else - The alternative

``python if glucose < 70: print("Hypoglycemia") else: print("Glucose normal")

`

3. for - Repeats actions

`python

for symptom in ["Fever", "Cough", "Fatigue"]: print(f"Checking: {symptom}")

`

4. in - Checks membership

`python

if "Diabetes" in patient_conditions: print("Monitor glucose closely")

`

5. True/False - Boolean values

`python

has_allergy = True is_pregnant = False

`

6. def - Defines functions

`python

def calculate_bmi(weight, height): return weight / (height 2)

`

7. return - Sends back results

`python

def is_hypertensive(bp_systolic): return bp_systolic >= 140

` Question: Which of the following is NOT a Python keyword?

A) if B) print C) for D) return

Correct Answer: B Explanation: While print is a built-in function in Python, it's not a keyword. Keywords like if, for, and return have special syntactic meaning and cannot be used as variable names.

🔬 Module 6: Line Continuation - Handling Complex Medical Data ================================================== ================================================================

🧠 Cognitive Load Management =========================== Start with simple two-line continuations, then build to complex medical data structures.

---

In medical research, we often work with data that's too long for one line: genomic sequences with thousands of base pairs, patient histories spanning years, or complex diagnostic criteria. Python provides elegant ways to break long lines for readability!

🧬 The DNA Problem: Imagine writing a DNA sequence on a single line:

ATCGATCGATCGATCGATCGATCGATCGATCGATCGATCGATCGATCGATCGATCGATCG...

Nobody wants to scroll horizontally forever!

📏 Two Ways to Continue Lines ============================

Method 1: Backslash \ (Explicit)
Genetic sequence split across lines

=================================== dna_sequence = "ATCGATCGATCG" + \ "TAGCTAGCTAGC" + \ "GCATGCATGCAT"

print(f"Total length: {len(dna_sequence)} base pairs")

Copied!
Method 2: Parentheses () (Preferred)
Patient medication list (cleaner approach)

========================================== medications = ( "Metformin 500mg twice daily, " "Lisinopril 10mg once daily, " "Atorvastatin 20mg at bedtime, " "Aspirin 81mg once daily" )

Copied!
Question: Which method is preferred for line continuation in Python?

A) Using backslash (\) B) Using parentheses () C) Using semicolons (;) D) Using forward slash (/)

Correct Answer: B Explanation: Parentheses are the preferred method for line continuation because they're cleaner, less error-prone, and more readable. Backslashes work but are considered less Pythonic.
