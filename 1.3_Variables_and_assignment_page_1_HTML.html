🔬 Part 1: Variables – Your Medical Data Containers

Understanding the Basics First

Let's start with a simple truth: variables are just named boxes where we store information. Nothing more, nothing less! 📦

Your first variable - it's that simple!

patient_name = "Alex Rivera"
Copied!

That's it! You've just created a variable called patient_name that holds the text "Alex Rivera". The = sign doesn't mean "equals" in math terms – it means "put this value into this box."

The Medical Connection

Now let's see why this matters in healthcare:

Storing a blood glucose reading

glucose_level = 126
Copied!

Recording a patient's temperature

body_temp = 98.6
Copied!

Tracking medication status

medication_taken = True
Copied!
🎯 Quick Practice
Before moving on, which of these correctly creates a variable for a patient's heart rate?
heart_rate = 72
Assigns the value 72 to a variable named heart_rate
Perfect! You've created a variable called heart_rate and stored the value 72 in it. This is exactly how we store patient vital signs in Python.
heart rate = 72
Assigns 72 to a variable with a space in the name
Variable names cannot contain spaces. Use underscores instead: heart_rate
72 = heart_rate
Puts heart_rate into 72
The assignment is backwards! The variable name goes on the left, value on the right.
heart-rate = 72
Uses a hyphen in the variable name
Python interprets the hyphen as subtraction. Use underscores for multi-word variables: heart_rate

🧬 Part 2: Naming Your Variables Like a Pro

Python's Simple Rules

Think of variable names like patient ID bands – they need to be clear and follow certain rules:

  1. Start with a letter or underscore (not a number)
  2. Use only letters, numbers, and underscores
  3. Case matters (Patient ≠ patient)

✅ Good variable names

patient_age = 45 blood_type = "O+" is_allergic_to_penicillin = True
Copied!

❌ Won't work - starts with number

2nd_dose = 500 # Error!
Copied!

❌ Won't work - has spaces

patient name = "John" # Error!
Copied!

💡 Pro Tip: In healthcare, clarity saves lives! Always choose descriptive names:

  • temp ❌ (Temperature? Temporary?)
  • body_temperature_celsius ✅ (Crystal clear!)
🧪 Mini Lab: Fix the Variable Names
Can you spot and fix the naming errors?
patient-id = "12345" # Problem: dash not allowed 1st_visit = "2024-01-15" # Problem: starts with number bp reading = 120 # Problem: space not allowed
Which set of fixes is correct?
Option A
patient_id = "12345"
first_visit = "2024-01-15"
bp_reading = 120
Excellent! You've correctly fixed all three issues: replaced the dash with underscore, changed the number prefix to a word, and removed the space.
Option B
patientId = "12345"
visit1 = "2024-01-15"
bpReading = 120
While these would work, Python convention prefers snake_case (with underscores) over camelCase for variable names.
Option C
patient.id = "12345"
_1st_visit = "2024-01-15"
bp-reading = 120
Dots are for object attributes, not variable names. Also, bp-reading still has a dash which Python interprets as subtraction.

🔬 Part 3: Data Types in Clinical Context

The Fantastic Four of Medical Data

Python automatically figures out what type of data you're storing (smart, right?). Here are the four types you'll use constantly:

1. Strings (text) - For names, IDs, and descriptions

patient_mrn = "MRN2024-001" diagnosis = "Type 2 Diabetes" medication_name = "Metformin"
Copied!

2. Integers (whole numbers) - For counts and discrete values

patient_age = 67 pills_per_day = 3 hospital_room = 204
Copied!

3. Floats (decimals) - For precise measurements

weight_kg = 72.5 hemoglobin_a1c = 6.8 drug_dose_mg = 12.5
Copied!

4. Booleans (True/False) - For yes/no conditions

is_pregnant = False has_insurance = True needs_interpreter = False
Copied!
🤔 Think About It
Why might storing weight as an integer (72 instead of 72.5) be dangerous in pediatric medicine?
Precision is Critical
Small weight differences matter significantly for medication dosing in children
Exactly right! In pediatrics, even 0.5 kg can significantly affect medication dosing calculations. For a 10 kg child, that's a 5% difference which could lead to under or overdosing.
Storage Space
Integers take up less computer memory than floats
While true, memory savings are trivial compared to patient safety. We should never sacrifice medical precision for minimal storage gains.
Display Formatting
Whole numbers look cleaner in medical reports
Medical accuracy always trumps aesthetic preferences. Precise measurements are essential for safe patient care.
No Real Difference
The 0.5 kg difference doesn't matter clinically
This is dangerously incorrect. In pediatrics, precise weight measurements are crucial for calculating safe medication doses, fluid requirements, and nutritional needs.
🧪 Quick Challenge: Categorize the Data Types
Match each medical data point to its ideal type:
Correct Matching
1. White blood cell count: 7,500 → Integer
2. Patient email: "alex@email.com" → String
3. BMI: 24.7 → Float
4. COVID test positive → Boolean
Perfect! You correctly identified all four data types. WBC counts are whole numbers (integers), emails are text (strings), BMI has decimals (float), and test results are True/False (boolean).
Mixed Types
1. White blood cell count: 7,500 → Float
2. Patient email: "alex@email.com" → String
3. BMI: 24.7 → Integer
4. COVID test positive → String
Not quite. WBC counts are typically whole numbers (integers), and BMI needs decimals (float). COVID test results are best represented as boolean (True/False).
All Strings
1. White blood cell count: 7,500 → String
2. Patient email: "alex@email.com" → String
3. BMI: 24.7 → String
4. COVID test positive → String
While you could store everything as strings, this prevents mathematical operations. Use appropriate data types for each value type.

🚀 Part 4: Variable Reassignment – Tracking Patient Changes

The Power of Updates

In healthcare, nothing stays constant. Variables can be updated to reflect changes:

Morning vital signs

oxygen_saturation = 95 print(f"Morning O2: {oxygen_saturation}%")
Copied!

After oxygen therapy

oxygen_saturation = 98 print(f"After treatment: {oxygen_saturation}%")
Copied!

💭 Medical Metaphor: Think of reassignment like updating a patient's chart. The chart (variable name) stays the same, but the information (value) gets updated.

Progressive Monitoring Example

ICU patient monitoring over time

patient_status = "critical" print(f"Admission: {patient_status}") # After 2 hours of treatment patient_status = "serious" print(f"2 hours later: {patient_status}") # After successful intervention patient_status = "stable" print(f"Current status: {patient_status}")
Copied!
🎯 Self-Check
What will this code output?
pain_level = 8 pain_level = pain_level - 3 print(pain_level) # What number appears?
5
The pain level is reduced from 8 to 5
Correct! The code starts with pain_level = 8, then updates it to pain_level - 3 (which is 8 - 3 = 5). The variable now holds the new value 5.
8
The original value remains unchanged
The assignment operator updates the variable. After pain_level = pain_level - 3, the variable stores the new value (5), not the original (8).
3
The amount that was subtracted
The code prints the final value of pain_level, not the amount subtracted. 8 - 3 = 5.
Error
Cannot use a variable in its own assignment
Python allows self-referential assignment. It evaluates the right side first (pain_level - 3), then stores the result back in pain_level.

Summary: Variables and Assignment

Congratulations! You've mastered the fundamentals of variables and assignment in Python for precision health applications. Let's recap what you've learned:

  1. Variables are containers - They store medical data like patient names, vital signs, and test results
  2. Naming rules matter - Clear, descriptive names following Python conventions ensure your code is maintainable and safe
  3. Four essential data types:
    • Strings for text (patient names, diagnoses)
    • Integers for whole numbers (age, room numbers)
    • Floats for decimals (weight, dosages)
    • Booleans for True/False (test results, conditions)
  4. Variables can be updated - Essential for tracking patient progress and changing medical conditions

These concepts form the foundation of every medical software system, from electronic health records to genomic analysis tools. In the next module, you'll learn about arithmetic operators to perform calculations with your medical data!
